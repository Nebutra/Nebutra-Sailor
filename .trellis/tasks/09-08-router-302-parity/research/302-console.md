# 302.AI logged-in console — read-only walk (2026-09-08/09)

> Method: `opencli browser r302c` driving the owner's signed-in Chrome, English locale, USD.
> Read-only: no create/delete/pay/submit. Dialogs opened were cancelled/closed.
> Builds on `docs/plans/2026-07-23-router-302-full-route-interaction-study.md` (public market routes) — this file only covers the admin shell (`/dashboard/**` and its Nuxt siblings) plus the Use shell (`all.302.ai`).
> Screenshots: `research/shots/302-console/` (paths in §5). Owner secrets are never recorded — API keys are described by format only.

## 1. Summary

The 302 admin shell is one Nuxt 3 + Arco Design app that keeps the market's top utility bar (currency · language · user | Home · Dashboard · Quick-Start · Technical Support ▾ · Change Log · Notify) and the market's search bar, then swaps in a left sidebar with six groups (Data Summary / Online Application / API / Agent / External Resource / User Center — 17 items, all rendered as `arco-menu-item external-link` divs, no `<a href>`). Every management page follows the same template: a row of 2–3 stat cards on top (Balance in PTC with "Go Top Up"/"View Price", last-7-days consumption with "View Details", counts), a one-line "Tutorial + Token Calculator" hint plus a yellow collapsible "Features: …Read All" band, an inline "Add …" create form (not a dialog), then an "Existing …" list block with a Keyword/Key search row (`Reset` / `Search`), an Arco table with a fixed column recipe (`… Status · Daily Cost · Monthly Cost · Total Cost · Create Time · Operation`), and Chinese-locale pagination (`共 N 条 · 10 条/页`) and empty state (`暂无数据`). Money is a single unit, **PTC, 1 PTC = 1 USD**, shown to 3–6 decimals; usage rows carry Prompt/Completion/Cache Creation/Cache Read token counts. Quotas everywhere are the same triple: Total/Monthly/Daily, each an "Unlimited ON/OFF" switch plus a PTC input. The Use shell (`all.302.ai`) is a separate app ("302AI Omni Toolbox") reached through an OAuth-style "Login with 302" consent page or via a Quick-Start deep link that auto-provisions an API key.

## 4. UX patterns worth copying / anti-patterns

**Copy**
1. One page template for every resource: stat cards → hint + collapsible "Features" band → inline create form → list with search bar → table. Zero learning cost across 7 resource types.
2. The uniform cost column trio `Daily Cost · Monthly Cost · Total Cost` + `Status` switch + `Create Time` + `Operation` on every table; cost is the primary lens, not counts.
3. Quota control idiom: label + `?` tooltip + "Unlimited" ON/OFF switch that enables a PTC input — reused for key, bot, agent, MCP, sub-account (Total/Monthly/Daily).
4. Expiry presets (`Eternal · 1 Month · 1 Day · 1 Hour`) next to a datetime picker.
5. Masked key `sk-xxx******xxxxxx` with `Copy` in the row; `Guide` modal that shows base URL + key together with the "replace api.openai.com" instruction; `Logs` per key (disabled unless logging was opted-in).
6. Single money unit (PTC = USD) shown on every page with `Go Top Up` in the same card; explicit fee math per payment channel in the method chooser.
7. Filter bars: `Reset` (plain) + `Search` (solid) pair, consistent order; page-size selector; keyword select (API Name / Key) fused to the input.
8. Sidebar external-link items carry an "open external" arrow icon so leaving the shell is signalled.
9. Sub-account creation with `Quantity` for bulk provisioning and per-module permission switches in the same modal.
10. Empty and pending states are terse (`暂无数据`, "Feature under development, stay tuned"); no giant illustrations.

**Anti-patterns**
1. Locale leaks: Chinese pagination/empty/date/dialog labels under English UI.
2. Sidebar items are `div.external-link` with JS `window.open`, no `href` — no middle-click, no crawlable routes; placeholder routes (`/api-keys/api-store` → "api store page").
3. `Quick-Start` silently creates an API key and passes it in a URL query string (see §6) — a security and surprise issue.
4. Stat numbers disagree across pages within seconds (Request Count 2499 vs 2500, keys 2→3) because each page recomputes; no timestamp.
5. `/logger` and `/usage-log` are shell-less standalone pages with empty `<title>`; "View Details" drops the user out of the admin shell.
6. Dense yellow "Features:" band on every page repeats marketing copy; two competing titles (`Enterprise AI Resource Hub… h1` hidden in logo).
7. Withdraw tab shows a full bank form even when there is no revenue; affiliate page is a paywall banner only.
