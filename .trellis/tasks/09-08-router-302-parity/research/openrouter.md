# OpenRouter — global benchmark study (product surfaces + /api/v1 contract)

> Studied: 2026-09-08/09. Method: opencli browser session `ror` (Chrome, **signed out of OpenRouter** — the owner's Chrome is signed into 302.ai only) for product pages, `WebFetch` for docs. Read-only; no clicks on anything that mutates state.
> Builds on the 302 route map in `docs/plans/2026-07-23-router-302-full-route-interaction-study.md` (not repeated here).
> Screenshots: `.trellis/tasks/09-08-router-302-parity/research/shots-openrouter/`.

## 1. Summary

OpenRouter is a **catalog-first** product: the `/models` page is a faceted search over ~600 model records (18 filter groups, 22 sort keys, List/Table toggle, output-modality tabs with counts) and every model has a permalink `/{author}/{slug}` that is simultaneously the marketing page, the pricing table, the provider comparison (input/output/cache-read $/M, latency, throughput, uptime per provider), the observability dashboard (uptime 3d/24h, latency/throughput per provider per region, tool-call and structured-output error rates, cache hit rate, weighted *effective* price vs listed price with a price-history chart), the benchmark card (Artificial Analysis indices, GPQA/HLE/…), the "who uses it" card (apps by token volume), and the API snippet (six SDK tabs). Around that hub sit rankings/apps/benchmarks/discover/compare/collections/providers pages that are all just different slices of the same model×endpoint×usage data. The API contract is OpenAI-compatible with one `provider` routing object (`order/only/ignore/sort/max_price/quantizations/zdr/data_collection/require_parameters/allow_fallbacks`), a `models[]` fallback array, model-slug variants (`:free :nitro :floor :exacto :online :thinking :extended :batch`, `~author/family-latest` aliases, `@preset/slug`), a standardized error envelope with `error.code` = HTTP status + `metadata.error_type`, and money everywhere denominated in **USD credits, priced per 1M tokens**, with a 5.5 % card / 5 % crypto top-up fee and zero markup on inference. The signed-in console (`/settings/keys`, `/settings/credits`, `/activity`, `/settings/preferences`) redirected to `/sign-in`, so those surfaces are reconstructed from docs only (see §6).

## 3. Entities and fields as observed

**Model** (`GET /api/v1/models`, `/api/v1/models/{author}/{slug}`): `id` = `author/slug[:variant]` (e.g. `anthropic/claude-fable-5.1:batch`), `canonical_slug`, `name` (`"Anthropic: Claude Fable 5.1"`), `created` (unix s), `description`, `context_length` (int tokens; UI `1.05M`/`262K`/`4K`), `knowledge_cutoff`, `expiration_date`, `hugging_face_id`, `architecture{modality "text->text", input_modalities[text,image,file,audio,video], output_modalities[text,image,embeddings,audio,video,rerank,speech,transcription], tokenizer, instruct_type}`, `pricing{prompt, completion, request, image, audio, audio_output, web_search, internal_reasoning, input_cache_read, input_cache_write, input_cache_write_1h, input_audio_cache, image_token, image_output, discount (0–1), overrides[]}` — **strings of USD per single token** in the API, rendered per 1M in UI; `top_provider{context_length, max_completion_tokens, is_moderated}`, `per_request_limits{prompt_tokens, completion_tokens}`, `supported_parameters[]`, `default_parameters{}`, `supported_voices`, `benchmarks{}`, `reasoning{supported_efforts, default_effort, mandatory}`, `alias_target{slug,name}`, `links{details}`.

**Variants / slug grammar**: `:free` · `:nitro` (sort throughput + admit priority tier) · `:floor` (sort price + admit flex tier) · `:exacto` (tool-calling quality sort) · `:online` (= `plugins:[{id:"web"}]`) · `:thinking` · `:extended` · `:batch` (50 % off, 24 h window) · `~author/family-latest` alias (`~openai/gpt-latest`) · `@preset/slug` or `model@preset/slug` · routers `openrouter/auto`, `openrouter/pareto-code`, free router, fusion.

**Endpoint** (provider×model, `GET /api/v1/models/{author}/{slug}/endpoints`): `name, model_id, model_name, tag, provider_name, context_length, max_completion_tokens, max_prompt_tokens, quantization` (int4 int8 fp4 mxfp4 nvfp4 fp6 fp8 mxfp8 fp16 bf16 fp32 unknown), `pricing{…overrides}`, `latency_last_30m{p50,p75,p90,p99}`, `throughput_last_30m{…}`, `uptime_last_5m / _30m / _1d` (%), `perf_last_30m_by_workload`, `supported_parameters`, `supports_tool_choice`, `supports_implicit_caching`, `supports_voice_cloning`, `status`. Provider slugs: base `google-vertex` matches all regions; specific `google-vertex/us-east5`, `deepinfra/turbo`.

**Provider**: name, slug, `Trains` (Yes/No), `Retention` (Zero / N-day / Retains prompts / Unknown), BYOK support, Headquarters (country), ToS/Privacy links, daily/monthly tokens, model count. Data-policy request knobs: `provider.data_collection: "allow"|"deny"`, `provider.zdr: true`, `enforce_distillable_text`.

**API key**: `hash` (id), `name`, `label`, `limit` (USD|null), `limit_remaining`, `limit_reset` (`daily|weekly|monthly|null`), `disabled`, `usage`, `usage_daily/weekly/monthly`, `byok_usage`, `include_byok_in_limit`, `expires_at`, `created_at`, `updated_at`, `workspace_id` (UUID), `creator_user_id`, `is_free_tier` (via `GET /api/v1/key`). Secret format `sk-or-v1-<alnum>`, shown once. Management keys are a separate class (admin only, no inference).

**Credits / money**: USD; `GET /credits → {total_credits, total_usage}`; per-request `usage.cost` (credits), `usage.cost_details.upstream_inference_cost`, `usage.is_byok`, `prompt_tokens_details{cached_tokens, cache_write_tokens, audio_tokens, video_tokens}`, `completion_tokens_details{reasoning_tokens, audio_tokens, image_tokens}`, `server_tool_use{web_search_requests}`. Zero-completion insurance: not billed when `completion_tokens == 0` with blank finish reason, or `finish_reason == "error"`.

**Generation** (`GET /api/v1/generation?id=`): `id, upstream_id, request_id, session_id, preset_id, workspace_id, app_id, model, provider_name, router, api_type, created_at, generation_time, latency, moderation_latency, tokens_prompt, tokens_completion, native_tokens_prompt/completion/reasoning/cached/completion_images, num_media_prompt/completion, num_input_audio_prompt, num_search_results, num_fetches, web_search_engine, total_cost, usage, upstream_inference_cost, cache_discount, finish_reason, native_finish_reason, streamed, cancelled, origin, http_referer, user_agent, is_byok, service_tier, data_region, external_user, provider_responses, response_cache_source_id`.

**Activity row** (`GET /api/v1/activity`): `date (YYYY-MM-DD), model, model_permaslug (e.g. openai/gpt-4.1-2025-04-14), endpoint_id (UUID), provider_name, usage (USD), byok_usage_inference, requests, prompt_tokens, completion_tokens, reasoning_tokens, workspace_id`; filters `date, api_key_hash, user_id, workspace_id, group_by=workspace`; last 30 days.

**Request contract** (`POST /api/v1/chat/completions`; also `/responses`, `/messages` (Anthropic skin), `/embeddings`, `/rerank`, `/images`, `/audio/speech`, `/audio/transcriptions`, video async): headers `Authorization: Bearer`, `HTTP-Referer`, `X-OpenRouter-Title`, `X-OpenRouter-Cache: true` + `X-OpenRouter-Cache-TTL`, `X-OpenRouter-Metadata: enabled`, `x-anthropic-beta`. Body: `model | models[] | route`, `messages|prompt`, sampling (`temperature 0–2, top_p, top_k, frequency_penalty, presence_penalty, repetition_penalty 0–2, min_p, top_a, seed, stop, max_tokens, logit_bias, logprobs, top_logprobs 0–20`), `response_format{type:"json_schema", json_schema{name,strict,schema}}`, `tools, tool_choice, parallel_tool_calls`, `reasoning{effort none|minimal|low|medium|high|xhigh|max, max_tokens, exclude, enabled}`, `verbosity`, `transforms:["middle-out"]` (auto for ≤8k ctx), `provider{order, allow_fallbacks, require_parameters, data_collection, zdr, only, ignore, quantizations, sort "price"|"throughput"|"latency" | {by, partition "model"|"none"}, preferred_min_throughput, preferred_max_latency, max_price{prompt, completion, request, image}}`, `plugins:[{id:"web", max_results, search_prompt, engine native|exa|firecrawl|parallel|perplexity}, {id:"response-healing"}, {id:"auto-router", cost_tier, allowed_models, excluded_models}]`, `service_tier default|priority("fast")|flex`, `session_id`, `user`, `prediction`, `debug`. Default load balancing = inverse-square price weighting after excluding providers with outages in the last 30 s; `max_price` is the only hard constraint.

**Response extras**: `provider` (which host served), `model` (concrete model after alias/fallback), `openrouter_metadata{requested, strategy direct|auto|free|latest|alias|fallback|pareto|bodybuilder|fusion, region, attempt, is_byok, endpoints, pipeline}` when opted in; cache headers `X-OpenRouter-Cache-Status HIT|MISS`, `-Cache-Age`, `-Cache-Source-Id`; `Retry-After` on 429/503; `X-RateLimit-*`.

**Error envelope**: `{error:{code:<HTTP status>, message, metadata{error_type, provider_code?, reasons[], flagged_input, provider_name, model_slug}}}`; codes 400/401/402/403/404/408/412/413/422/429/500/502/503/504; `error_type` enum: `context_length_exceeded, max_tokens_exceeded, token_limit_exceeded, string_too_long, authentication, permission_denied, payment_required, rate_limit_exceeded, provider_overloaded, provider_unavailable, invalid_request, invalid_prompt, not_found, precondition_failed, payload_too_large, unprocessable, content_policy_violation, refusal, invalid_image, image_too_large, image_too_small, unsupported_image_format, image_not_found, image_download_failed, server, timeout, unmapped`. Mid-stream errors arrive as SSE chunk with `choices[0].finish_reason:"error"` + `error{}`.

**Limits**: free variants 20 req/min; 50 req/day (<$10 lifetime purchases) or 1,000 req/day (≥$10); negative balance → 402 even for free models; per-key `limit` → 402; guardrail/budget breach → 403 with reason.

**Org / workspace**: Organization (≤10 members on self-serve; roles Admin, Member; shared credit pool; only admins buy credits) → Workspaces (Default + named; each with own keys, guardrails, BYOK, presets, budgets `limit_usd` per interval daily/weekly/monthly/lifetime, reset midnight UTC / Monday / 1st) → Guardrails (spend cap + reset, model/provider allowlist, ZDR per model group, region, prompt-injection regex, sensitive-info redact/block, custom regex; assigned to members and/or keys; strictest wins). Enterprise-only: SSO (SAML: Okta, Entra, Google Workspace), SCIM group→workspace mappings, in-region base URLs `eu.openrouter.ai` / `us.openrouter.ai` (fail-closed), private models, invoicing, Slack/webhook alerts, observability Broadcast destinations (Datadog, Langfuse, S3, …).

## 4. UX patterns worth copying — and anti-patterns

**Copy**
1. **One permalink per model that is everything at once** (`/{author}/{slug}`): pricing, providers, live perf, uptime, benchmarks, apps, activity, snippets, FAQ. 302 splits this across market card → price table → docs; OpenRouter never makes you leave the page. Sticky anchor sub-nav (`Providers · Pricing · Performance · …`) instead of tabs that reload.
2. **Faceted rail + URL-mirrored filters + API parity**: every UI filter is a query param that the public `/api/v1/models` also accepts. Facet counts on modality tabs (`Text 429 · Image 50 …`) and on `/providers` facets (`Zero retention 46`).
3. **List/Table toggle with the same data**: cards for browsing, dense table (`Model Name · Weekly Tokens · Input · Output · Context · Latency · Throughput · Released`) for comparison; `—` for unmeasured cells, never blank.
4. **Money and units are typographically consistent**: `$5/M input tokens`, `$25/M output tokens`, `$0.25` cache read, `1.05M context`, `13 t/s`, `3.81s`, `99.38%`, `305B tokens`; non-token models switch unit words (`/hour`, `/second`, `characters`) rather than pretending everything is tokens.
5. **Effective vs listed price** with weighted averages and cache-hit rate — honest pricing that explains why bills are lower than list. Discount badges (`50% off`) on cards and a `Discounted` facet.
6. **Availability vs "Without Routing"** dual-line chart: sells the router's value with data. Uptime definitions written in one sentence directly under the heading.
7. **Provider comparison table with a variant dropdown** (`Batch · Standard · Nitro · Exacto`) and percentile selector (`P50`) — routing modes are explained in one line of copy above the table.
8. **Region selector using airport POP codes grouped by continent** for latency views.
9. **Trust signals as columns**: `/providers` puts Trains / Retention / BYOK / Headquarters / ToS / Privacy into a sortable table, and the same policy powers request-time routing (`data_collection`, `zdr`).
10. **Alias & deprecation handling in-catalog**: `~family-latest` cards, deprecated fast-mode cards carry the migration snippet (`service_tier: "fast"`), `expiration_date` field, "Show deprecated" facet, deprecation alerts.
11. **Request Builder** page generates cURL/Python/TS from the same model picker; model detail has six SDK snippet tabs with `Copy`.
12. **Error contract**: HTTP status duplicated in `error.code`, machine `error_type`, `Retry-After`, mid-stream error chunk shape, zero-completion insurance — all documented in one page.
13. **Key create dialog fields** (`name, limit, limit_reset, expires_at, include_byok_in_limit`) and per-key usage windows (daily/weekly/monthly) are the whole "spend control" story for solo devs; org budgets are a separate, strictly-decreasing ladder.
14. **Dismissible contextual notices** on the model page (data-retention consent, BYOK-only endpoint) instead of global banners.
15. **Rankings disclaimer** ("measure adoption, not quality") and CC BY licence on data — cheap credibility.

**Anti-patterns / caveats**
- Facet rail collapses 17 of 18 groups by default; `More…` hides most values (Series, Categories, Providers, Authors) — discoverability suffers on first visit.
- Card list mixes weekly-volume units (tokens / characters / hours) in the same visual slot; scanning is harder.
- Model page is very long (10+ sections); without the sticky sub-nav it would be unusable — do not copy the length without the nav.
- Docs paths have churned (`/docs/features/*` → 404, now `/docs/guides/features/*`; `/docs/api-reference/*` → `/docs/api_reference/*`); keep a `llms.txt` index like they do.
- Everything monetary is USD-only; there is no currency toggle (302 has CNY/USD) — parity work should keep 302's currency switch.
- Console routes moved under `/workspaces/default/...` while docs still say `/settings/keys`; avoid dual paths.
