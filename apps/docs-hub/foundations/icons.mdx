## Overview

The Nebutra iconic language consists of high-contrast, scalable SVGs optimized for structural clarity in enterprise dashboard (Harness-Engineering scale) and aesthetic playfulness for Marketing profiles. 

## Design Rationale

Geist and Lucide icons are our primary families, wrapped via `@nebutra/icons`.

## Usage

Always import icons from the centralized facade payload:
```tsx
import { SearchIcon, SettingsIcon } from "@nebutra/icons";
```
