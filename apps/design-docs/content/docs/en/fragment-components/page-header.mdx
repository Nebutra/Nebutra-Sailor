> This page previously documented a `breadcrumbs` prop rendered with `@primer/react` `Breadcrumbs`,
> imported from `@nebutra/ui`. `@primer/react` has been removed from the repo entirely, `PageHeader`
> has never taken a `breadcrumbs` or `children` prop, and the correct import is `@nebutra/ui/layout`.
> This page now documents the real component (`packages/design/ui/src/layout/PageHeader.tsx`).

## Demo

```tsx
import { PageHeader } from "@nebutra/ui/layout";
import { Button } from "@nebutra/ui/components";

<PageHeader
  title="Pipeline settings"
  description="Configure ingestion rules, filters, and destinations."
  actions={<Button variant="primary">Save changes</Button>}
/>;
```

## Usage

```tsx
import { PageHeader } from "@nebutra/ui/layout";
import { Button } from "@nebutra/ui/components";

export function PipelineSettingsPage({ pipeline }: { pipeline: Pipeline }) {
  return (
    <div className="p-6">
      <PageHeader
        title={pipeline.name}
        description={`Last updated ${formatRelative(pipeline.updatedAt)}`}
        actions={
          <div className="flex gap-2">
            <Button variant="secondary" onClick={handleDisable}>Pause</Button>
            <Button onClick={handleSave}>Save</Button>
          </div>
        }
      />

      <PipelineForm pipeline={pipeline} />
    </div>
  );
}
```

## Props

### `PageHeaderProps`

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | **Required.** Page heading rendered as `<h1>` |
| `description` | `string` | — | Muted subtitle rendered below the title |
| `actions` | `React.ReactNode` | — | Action controls (buttons, menus), stacked below the title on narrow screens and anchored to the right on `sm:` and up |
| `className` | `string` | — | Additional classes on the root element |

There is no `breadcrumbs` prop and no `children` slot. Compose breadcrumbs, tabs, or any other
content as a sibling of `PageHeader` in the page, not inside it.

## Examples

### Title only

```tsx
<PageHeader title="Members" />
```

### No actions

```tsx
<PageHeader
  title="Analytics"
  description="Usage metrics for the last 30 days."
/>
```

### Actions only

```tsx
<PageHeader
  title="API keys"
  actions={
    <Button onClick={() => setOpen(true)}>
      Generate key
    </Button>
  }
/>
```

### Tabs below the header

Since `PageHeader` has no `children` slot, render tabs (or any other content) as a sibling:

```tsx
<PageHeader title="Analytics" description="Usage metrics for the last 30 days." />
<Tabs className="mt-4">
  <Tab>Overview</Tab>
  <Tab>Events</Tab>
  <Tab>Errors</Tab>
</Tabs>
```

## Accessibility

- The `title` renders as `<h1>` — each page must have exactly one `<h1>`.
- The root element is a plain `<div>` — it carries no implicit landmark role. Wrap the page in
  `<main>` (or an equivalent landmark) at a higher level if one isn't already present.
- The `actions` slot has no implicit landmark role; wrap with `<nav aria-label="Page actions">` if it
  contains navigation.
- `description` is plain `<p>` text — do not use it as the sole source of critical instructions.
