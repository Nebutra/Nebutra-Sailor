title: "EmptyState"
description: "Empty state layout wrapper with a single icon/mascot slot, title, description, and action(s)."
---

> This page previously documented an `icons` array (three icons, animated trio), `theme`, and
> `isIconAnimated` props. Neither `@nebutra/ui/layout` `EmptyState` nor the underlying
> `@nebutra/ui/primitives` `EmptyState.Root` has ever had those props — both take a **singular**
> icon. This page now documents the real component
> (`packages/design/ui/src/layout/EmptyState.tsx`).

## Demo

```tsx
import { EmptyState } from "@nebutra/ui/layout";
import { FolderOpen } from "@nebutra/icons";
import { Button } from "@nebutra/ui/components";

<EmptyState
  title="No projects yet"
  description="Create your first project to get started with Nebutra."
  icon={<FolderOpen />}
  action={<Button onClick={() => router.push("/projects/new")}>Create project</Button>}
/>;
```

## Usage

```tsx
import { EmptyState } from "@nebutra/ui/layout";
import { Database } from "@nebutra/icons";

export function PipelinesPage() {
  const { pipelines } = usePipelines();

  if (pipelines.length === 0) {
    return (
      <EmptyState
        title="No pipelines"
        description="Build your first pipeline to start processing events."
        icon={<Database />}
        action={<Button onClick={openCreateDialog}>New pipeline</Button>}
      />
    );
  }

  return <PipelineList pipelines={pipelines} />;
}
```

## Props

### `EmptyStateProps`

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | **Required.** Primary message |
| `description` | `string` | — | Supporting description beneath the title |
| `mascot` | `React.ReactNode` | — | Visual anchor. When omitted and `tone="branded"`, a default `<BrandMark>` renders |
| `icon` | `React.ReactNode` | — | Inline icon shown above the title. Ignored when `mascot` is provided |
| `action` | `React.ReactNode` | — | Primary call-to-action node — a real `Button`/`Link`, not a config object |
| `secondaryAction` | `React.ReactNode` | — | Secondary call-to-action node |
| `tone` | `"default" \| "branded" \| "subtle"` | `"default"` | `default`: neutral bordered state. `branded`: `BrandMark` anchor for first-touch panels. `subtle`: quieter inline state |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Controls padding and text scale |
| `className` | `string` | — | Additional classes on the root element |

There is no `icons` array, no `theme` prop, and no `isIconAnimated` prop. `icon` (and `mascot`) each
take exactly one node.

`action` and `secondaryAction` take rendered nodes, not `{ label, onClick, icon }` config objects —
pass a real `<Button>` (or `<Link>`) element.

## Examples

### Branded tone

```tsx
<EmptyState
  title="Welcome to Nebutra"
  description="Connect your first data source to get started."
  tone="branded"
/>
```

### Subtle — quieter inline state

```tsx
<EmptyState
  title="Nothing here yet"
  description="Items will appear once data is available."
  tone="subtle"
  size="sm"
/>
```

### With a secondary action

```tsx
<EmptyState
  title="Failed to load data"
  description="An error occurred while fetching your resources."
  icon={<AlertCircle />}
  action={<Button onClick={refetch}>Retry</Button>}
  secondaryAction={<Link href="/support">Contact support</Link>}
/>
```

## Advanced composition — `@nebutra/ui/primitives`

`layout/EmptyState` is a simplified wrapper around the canonical compound primitive,
`EmptyState.Root` from `@nebutra/ui/primitives`. New composition work that needs variants beyond
`default`/`branded`/`subtle` (e.g. `no-results`, `permission`, `error`) or an `align` control should
use the primitive directly rather than extending this wrapper's prop surface.

## Accessibility

- The root element renders as `<section>` with `role="region"` and `aria-labelledby` pointing to the
  title.
- When `description` is present, `aria-describedby` references the description paragraph.
- The icon container is `aria-hidden="true"` — decorative only.
- `action`/`secondaryAction` should be real interactive elements (`<button type="button">`, `<a>`) —
  the component does not add semantics for you.
