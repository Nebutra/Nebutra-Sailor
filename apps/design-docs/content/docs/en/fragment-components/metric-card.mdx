## Use Case

`MetricCard` is the dense metric row used inside dashboards, side panels, and operational summaries. It is lighter than `KpiCard`: no card shell by default, optional bordered wrapper, and smaller typography for high-density surfaces.

Use `MetricGrid` when adjacent metrics should align in two to four columns. Use `MetricCardBordered` only when the metric needs its own frame.

## Usage

```tsx
import { MetricCard, MetricCardBordered, MetricGrid } from "@nebutra/ui/primitives";

<MetricGrid columns={3}>
  <MetricCardBordered
    label="Events ingested"
    value="2.4M"
    trend="up"
    trendValue="+12%"
    description="vs last week"
  />
  <MetricCardBordered
    label="Error rate"
    value="0.18%"
    trend="down"
    trendValue="-0.3%"
    description="lower is better"
  />
</MetricGrid>
```

## Anatomy

- `MetricCard` renders the metric label, value, optional trend, optional icon, and optional description.
- `MetricGrid` owns simple two-, three-, or four-column alignment.
- `MetricCardBordered` wraps `MetricCard` with a tokenized border and card background.
- `StatItem` renders compact inline stats with a status dot, label, and value.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Short descriptor above the value. |
| `value` | `number \| string` | — | Primary metric value. Numbers are locale-formatted. |
| `trend` | `"up" \| "down" \| "neutral"` | — | Optional trend direction. |
| `trendValue` | `string` | — | Compact trend text such as `+12%`. |
| `description` | `string` | — | Muted secondary text below the value row. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Typography density. |
| `icon` | `ReactNode` | — | Decorative icon before the label. |
| `className` | `string` | — | Outer wrapper class. |

### MetricGrid

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Metric cards or stat items. |
| `columns` | `2 \| 3 \| 4` | `3` | Grid column count. |
| `className` | `string` | — | Grid class override. |

## States

| State | Contract |
|-------|----------|
| Up | Uses upward icon and success tone. |
| Down | Uses downward icon and error tone. |
| Neutral | Uses neutral icon and muted tone. |
| Bordered | Adds a frame without changing the underlying metric API. |

## Accessibility

- Trend direction is represented by icon, text, and color together.
- Icons are decorative; the label and value remain text.
- Group related metrics under a visible heading in the parent dashboard section.
- Do not use `MetricCard` as an unnamed button. Wrap it in a named control if it navigates.

## Design Contract

- Use `MetricCard` for dense operational comparisons; use `KpiCard` for top-level executive summaries.
- Keep labels short and values tabular. Long explanatory text belongs in surrounding copy or a detail view.
- Trend polarity is literal direction. Do not invert colors per metric; explain “lower is better” in `description`.
- `MetricCardBordered` is a composition helper, not a new semantic variant.
