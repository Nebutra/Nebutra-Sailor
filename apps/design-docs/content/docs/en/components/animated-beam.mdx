## Usage

```tsx
import { AnimatedBeam } from "@nebutra/ui/primitives";
```

Animated Beam connects real DOM nodes with a quiet animated rail. Use it when the connection is
part of the information architecture: webhook routing, deployment pipelines, agent handoffs, or
integration status. For decorative hero light trails, use a marketing decoration instead.

## Example

```tsx
function FlowDemo() {
  const containerRef = useRef<HTMLDivElement>(null);
  const sourceRef = useRef<HTMLDivElement>(null);
  const targetRef = useRef<HTMLDivElement>(null);

  return (
    <div ref={containerRef} className="relative grid grid-cols-2">
      <ServiceNode ref={sourceRef} name="GitHub" />
      <ServiceNode ref={targetRef} name="Nebutra" />
      <AnimatedBeam
        containerRef={containerRef}
        fromRef={sourceRef}
        toRef={targetRef}
        tone="brand"
        intensity="normal"
      />
    </div>
  );
}
```

## Props

| Prop                 | Type                                             | Default   | Description |
| -------------------- | ------------------------------------------------ | --------- | ----------- |
| `containerRef`       | `RefObject<HTMLElement>`                         | —         | Ref to the bounding container |
| `fromRef`            | `RefObject<HTMLElement>`                         | —         | Start element ref |
| `toRef`              | `RefObject<HTMLElement>`                         | —         | End element ref |
| `tone`               | `"neutral" \| "brand" \| "success" \| "warning"` | `"brand"` | Semantic beam color |
| `intensity`          | `"subtle" \| "normal" \| "strong"`               | `"normal"` | Beam and rail emphasis |
| `curvature`          | `number`                                         | `0`       | Bezier curve height in px |
| `reverse`            | `boolean`                                        | `false`   | Reverse the beam travel direction |
| `duration`           | `number`                                         | `4`       | Animation duration in seconds |
| `delay`              | `number`                                         | `0`       | Start delay in seconds |
| `startXOffset`       | `number`                                         | `0`       | X offset from the start element center |
| `startYOffset`       | `number`                                         | `0`       | Y offset from the start element center |
| `endXOffset`         | `number`                                         | `0`       | X offset from the end element center |
| `endYOffset`         | `number`                                         | `0`       | Y offset from the end element center |
| `className`          | `string`                                         | —         | Additional CSS classes on the SVG |

## Advanced Paint Props

The raw SVG paint props remain for migration and one-off visualization work:
`pathColor`, `pathWidth`, `pathOpacity`, `gradientStartColor`, and `gradientStopColor`.
Prefer `tone` and `intensity` in product surfaces so colors remain aligned with tokens.

## Design Principles

- Use real service or workflow labels; avoid abstract `A → B` demos.
- Keep beam count low. More than three simultaneous beams usually needs a proper graph view.
- Animated content is decorative and rendered `aria-hidden`; node labels carry the semantics.
- Reduced motion users see the static rail without the travelling beam.
