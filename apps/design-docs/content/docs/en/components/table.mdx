## Usage

```tsx
import { Table } from "@nebutra/ui/primitives";

export function UsageTable() {
  return (
    <Table>
      <Table.Header>
        <Table.Row>
          <Table.Head>Product</Table.Head>
          <Table.Head>Usage</Table.Head>
          <Table.Head numeric>Charge</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body interactive striped>
        <Table.Row>
          <Table.Cell>Brake Pads Set</Table.Cell>
          <Table.Cell>100 sets</Table.Cell>
          <Table.Cell numeric>$5,000.00</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  );
}
```

The compound API is canonical. Named exports remain available for existing consumers:

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@nebutra/ui/primitives";
```

## Props

All parts extend their native HTML attributes.

| Component | Element | Key props |
| --- | --- | --- |
| `Table` | `<table>` | `className`, `style`, `wrapperClassName`, `wrapperStyle` |
| `Table.Colgroup` | `<colgroup>` | native colgroup props |
| `Table.Col` | `<col>` | native col props |
| `Table.Header` | `<thead>` | native section props |
| `Table.Body` | `<tbody>` | `striped`, `bordered`, `interactive`, `virtualize` |
| `Table.Row` | `<tr>` | native row props |
| `Table.Head` | `<th>` | `numeric`, `scope` |
| `Table.Cell` | `<td>` | `numeric`, `colSpan`, `rowSpan` |
| `Table.Footer` | `<tfoot>` | native footer props |
| `Table.Caption` | `<caption>` | native caption props |

## Examples

### Bordered and striped

```tsx
<Table>
  <Table.Header>
    <Table.Row>
      <Table.Head>Product</Table.Head>
      <Table.Head>Status</Table.Head>
      <Table.Head numeric>Requests</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body bordered striped>
    {rows.map((row) => (
      <Table.Row key={row.id}>
        <Table.Cell>{row.product}</Table.Cell>
        <Table.Cell>{row.status ?? "—"}</Table.Cell>
        <Table.Cell numeric>{row.requests}</Table.Cell>
      </Table.Row>
    ))}
  </Table.Body>
</Table>
```

### Full featured

```tsx
<Table>
  <Table.Colgroup>
    <Table.Col className="w-[44%]" />
    <Table.Col className="w-[22%]" />
    <Table.Col className="w-[22%]" />
    <Table.Col className="w-[12%]" />
  </Table.Colgroup>
  <Table.Header>
    <Table.Row>
      <Table.Head>Product</Table.Head>
      <Table.Head>Usage</Table.Head>
      <Table.Head>Price</Table.Head>
      <Table.Head numeric>Charge</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body interactive striped>
    {items.map((item) => (
      <Table.Row key={item.product}>
        <Table.Cell>{item.product}</Table.Cell>
        <Table.Cell>{item.usage}</Table.Cell>
        <Table.Cell>{item.price}</Table.Cell>
        <Table.Cell numeric>{formatCurrency(item.charge)}</Table.Cell>
      </Table.Row>
    ))}
  </Table.Body>
  <Table.Footer>
    <Table.Row>
      <Table.Cell className="font-medium text-foreground" colSpan={3}>
        Subtotal
      </Table.Cell>
      <Table.Cell className="font-medium text-foreground" numeric>
        {formatCurrency(total)}
      </Table.Cell>
    </Table.Row>
  </Table.Footer>
</Table>
```

### Progressive disclosure

```tsx
<div className="relative">
  <Table id={tableId}>
    <Table.Header>{/* columns */}</Table.Header>
    <Table.Body interactive striped virtualize>
      {visibleRows.map((row) => (
        <Table.Row key={row.id}>{/* cells */}</Table.Row>
      ))}
    </Table.Body>
  </Table>
  <ShowMore
    controls={tableId}
    expanded={expanded}
    hiddenCount={hiddenCount}
    onExpandedChange={setExpanded}
  />
</div>
```

## Best practices

- Use `Table` for data where rows share the same shape and at least one column is comparable across rows.
- Use `Entity` for a descriptive row with one primary action. Use `Description` for key/value metadata.
- Render `EmptyState` outside the table when the underlying list is empty.
- Render `—` for unknown or not applicable cell values. Do not use `N/A`, `null`, or an empty string.
- Sortable column headers are buttons inside `Table.Head`; the arrow is decorative and the button announces the next sort state.
- Apply `numeric` to numeric headers and cells so digits align with tabular numbers.
- Column headers are Title Case nouns or noun phrases: Last Used, Requests (7d), Created, Status.

## Accessibility

- The component keeps native table elements intact: `table`, `thead`, `tbody`, `th`, `td`, `tfoot`, and `caption`.
- `Table.Head` defaults to `scope="col"`. Set `scope="row"` for row headers in complex tables.
- For sortable columns, add `aria-sort="ascending"` or `aria-sort="descending"` to the active `Table.Head`.
- Pair progressive disclosure with `ShowMore` so the trigger has `aria-controls` and `aria-expanded`.
