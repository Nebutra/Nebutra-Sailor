## Installation

```tsx
import { Pagination } from "@nebutra/ui/primitives";
```

## Overview

`Pagination` moves between sibling pages: docs articles, blog posts, changelog entries, and
onboarding steps. It is not a numbered pager for data sets. For table rows or server-paged data,
use `PaginationControl` or the table pattern.

The component hides the missing side at the start or end of a sequence instead of rendering a
disabled rail.

## Usage

```tsx
const previous = {
  title: "Home",
  href: "/docs",
};

const next = {
  title: "Introduction",
  href: "/docs/introduction",
};

<Pagination previous={previous} next={next} />;
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `previous` | `{ title: string; href: string }` | — | Previous sibling page. Omit at the start of a sequence. |
| `next` | `{ title: string; href: string }` | — | Next sibling page. Omit at the end of a sequence. |
| `previousLabel` | `string` | `"Previous"` | Direction label rendered above the previous title. |
| `nextLabel` | `string` | `"Next"` | Direction label rendered above the next title. |
| `aria-label` | `string` | `"Page navigation"` | Accessible label for the root navigation landmark. |
| `className` | `string` | — | Additional classes on the root `<nav>`. |

## Best Practices

- Use `Pagination` for sequential navigation between sibling pages.
- Use `PaginationControl` for data sets where users move through rows of the same collection.
- Pass destination page names as `previous.title` and `next.title`; the component already renders
  direction labels, chevrons, and `Go to {direction} page: {title}` aria labels.
- Omit the missing side at sequence boundaries instead of passing a disabled link.
- Keep titles Title Case and put the distinctive word first. Long titles truncate by design.
- Do not put ordinal copy such as `Page 3 of 10` in a title. That belongs to numbered paging.

## Accessibility

- Root `<nav>` defaults to `aria-label="Page navigation"`.
- Previous and next links use `rel="prev"` and `rel="next"`.
- Each link gets a generated aria label that includes the destination title.
- Missing previous or next slots render as an empty rail on desktop and are hidden on mobile.
