## Installation

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@nebutra/ui/primitives";
```

## Overview

`Select` is for short, fixed lists where typing adds nothing: frameworks, regions, plans, and small
status filters. Use the compound listbox API for product surfaces where the opened menu must stay
inside Nebutra's visual system.

The native shorthand remains available for real form submission, mobile pickers, and `optgroup`
support. Its opened `<option>` popup is browser/OS controlled, so it is not used as the primary
visual demo. Use `Combobox` once filtering is useful and `MultiSelect` when users can choose more
than one value.

## Usage

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Select a framework" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="nextjs">Next.js</SelectItem>
    <SelectItem value="react">React</SelectItem>
  </SelectContent>
</Select>;
```

Native `<option>` and `<optgroup>` children are also supported:

```tsx
<Select label="Region" placeholder="Select a region">
  <optgroup label="North America">
    <option value="iad1">Washington, D.C.</option>
    <option value="sfo1">San Francisco</option>
  </optgroup>
</Select>
```

## Props

### Native Select

Use the native shorthand when the browser control itself is the product requirement: classic form
submit, mobile OS picker, or `optgroup` semantics. Do not rely on the opened native option popup for
brand styling.

| Prop | Type | Default | Description |
|---|---|---|---|
| `options` | `{ value: string; label: string; disabled?: boolean }[]` | — | Short fixed option list. |
| `label` | `string` | — | Short Title Case field label. |
| `placeholder` | `string` | — | Disabled first option shown before selection. |
| `size` | `"xsmall" \| "small" \| "medium" \| "large"` | `"medium"` | Control density. |
| `variant` | `"default" \| "ghost"` | `"default"` | Visual treatment. |
| `prefix` | `ReactNode` | — | Decorative leading icon. |
| `suffix` | `ReactNode` | `ChevronDown` | Decorative trailing icon. |
| `error` | `string` | — | Validation message; sets `aria-invalid` and `aria-describedby`. |
| `disabled` | `boolean` | `false` | Disables the native select. |
| `value` | `string` | — | Controlled value. |
| `defaultValue` | `string` | — | Uncontrolled default value. |
| `onChange` | `ChangeEventHandler<HTMLSelectElement>` | — | Native change callback. |

### Compound Listbox

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectLabel,
  SelectSeparator,
} from "@nebutra/ui/primitives";
```

The compound API keeps the Base UI listbox behavior for grouped menu-like selection and owns the
opened menu surface, radius, shadow, and focus treatment.

| Component | Purpose |
|---|---|
| `Select` | Root state provider when no native props are passed. |
| `SelectTrigger` | Button trigger. Accepts the same `size` scale as native Select. |
| `SelectValue` | Selected value / placeholder renderer. |
| `SelectContent` | Positioned listbox surface. |
| `SelectItem` | Selectable listbox option. |
| `SelectGroup` / `SelectLabel` / `SelectSeparator` | Grouping primitives for longer lists. |

## Best Practices

- Pick compound `Select` for visible product menus that must match Nebutra surface styling.
- Pick native shorthand only when browser form semantics, mobile picker behavior, or `optgroup`
  support is more important than styling the opened popup.
- Switch to `Combobox` when filtering helps; use `MultiSelect` when more than one value can be
  chosen.
- Group native lists past about ten items with `<optgroup>`. The compound API also supports
  `SelectGroup` for menu-like grouped lists.
- Use short Title Case labels such as `Framework` or `Region`.
- Make placeholders action-oriented: `Select a framework`, not `Choose one...` or a repeated label.
- Validate on blur and pass a sentence-case `error` string ending in a period.
- Do not wrap a labelled `Select` in a tooltip. Put hints on a sibling icon button so the label
  stays announced.

## Accessibility

- Native Select keeps browser form semantics, mobile pickers, and keyboard behavior.
- `error` sets `aria-invalid` and connects the field to the inline error message.
- The compound API follows the ARIA listbox pattern through Base UI primitives.

## Design Contract

- Use Select for short, finite lists where filtering is unnecessary.
- Use the same trigger density as Input and Textarea in the surrounding form.
- Keep option labels parallel and stable.

## Real Product Examples

- Region selection in a deployment form.
- Framework selection in a starter template picker.
- Billing country or invoice language when the list remains short.

## Anti-patterns

- Do not use Select for long searchable lists. Use Combobox.
- Do not use Select for multi-value choices. Use MultiSelect or CheckboxGroup.
- Do not use a menu item group as a fake form select.
