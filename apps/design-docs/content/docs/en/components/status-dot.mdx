## Usage

`StatusDot` is for deployment lifecycle state only. Do not reuse it for arbitrary workflow, queue, or billing status.

```tsx
<StatusDot state="BUILDING" titlePrefix="Production deployment" label />
```

## States

| State | Motion |
| --- | --- |
| `QUEUED` | Pulses |
| `BUILDING` | Pulses |
| `READY` | Static |
| `ERROR` | Static |
| `CANCELED` | Static |
| `DELETED` | Static |

## Accessibility

- Default `aria-label` is composed from `titlePrefix` and state copy.
- Pass `decorative` when adjacent visible text already names the state.
- Color is not the only signal; `label` renders sentence-cased state text.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `"QUEUED" \| "BUILDING" \| "READY" \| "ERROR" \| "CANCELED" \| "DELETED"` | required | Deployment lifecycle state. |
| `label` | `boolean` | `false` | Renders visible state text next to the dot. |
| `titlePrefix` | `string` | `"Deployment"` | Prefix used to compose the accessible label. |
| `decorative` | `boolean` | `false` | Hides the dot from assistive tech when nearby copy already names the state. |
| `className` | `string` | - | Additional layout class. |

## Design Contract

- Use `StatusDot` for deployment lifecycle only. Generic entity state needs a separate status primitive with its own enum.
- Treat pulsing as activity state, not severity. Only `QUEUED` and `BUILDING` animate.
- When the surrounding row already names the state, pass `decorative`; otherwise render `label` or keep the accessible label.
