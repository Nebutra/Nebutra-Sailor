## Usage

```tsx
import { Switch } from "@nebutra/ui/primitives";

<Switch name="source-output" defaultValue="source">
  <Switch.Control label="Source" value="source" />
  <Switch.Control label="Output" value="output" />
</Switch>
```

## Design Contract

`Switch` chooses between two or three mutually exclusive options that change the
view of the same surface. It renders native radio inputs, so arrow-key
navigation, form submission, and screen reader semantics stay aligned.

Use `Toggle` for a boolean on/off setting. Use `Tabs` or `Select` when there are
more than three options or labels need more than a couple of words.

## Controlled State

```tsx
const [view, setView] = useState("source");

<Switch name="view" value={view} onValueChange={setView}>
  <Switch.Control label="Source" value="source" />
  <Switch.Control label="Output" value="output" />
</Switch>
```

## Icon Controls

Always pass `label`, even when an icon is visible. The label becomes the radio's
accessible name.

```tsx
<Switch name="layout">
  <Switch.Control label="Grid View" value="grid" icon={<GridSquare />} />
  <Switch.Control label="List View" value="list" icon={<ListUnordered />} />
</Switch>
```

## Props

### Switch

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string` | generated id | Native radio group name. Pass a stable value for forms. |
| `size` | `"small" \| "medium" \| "large"` | `"medium"` | Default size for child controls |
| `value` | `string` | — | Controlled selected value |
| `defaultValue` | `string` | — | Uncontrolled selected value |
| `onValueChange` | `(value: string) => void` | — | Called when a control is selected |
| `disabled` | `boolean` | `false` | Disables all controls |

### Switch.Control

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Native radio value |
| `label` | `string` | `value` fallback | Visible text or accessible name for icon-only controls |
| `icon` | `ReactNode` | — | Optional icon rendered instead of visible text |
| `size` | `"small" \| "medium" \| "large"` | root size | Per-control size override |
| `checked` | `boolean` | — | Controlled radio checked state |
| `defaultChecked` | `boolean` | `false` | Uncontrolled initial checked state |
| `disabled` | `boolean` | `false` | Disables this control |

## Best Practices

Use Switch as a segmented selector for two or three mutually exclusive options
that show different views of the same surface, like `Source` and `Output`.

Pass a stable `name` so the underlying radios are grouped. Without a stable name,
form serialization and cross-render identity are harder to reason about.

Set `defaultValue`, controlled `value`, or exactly one `defaultChecked` control so
the group has a defined initial state.

Keep labels Title Case, short, and parallel: `Source / Output`, not `Source /
Show output`.

Pad each control so the widest label fits without the active pill resizing. Test
with the longest copy in the set.

Pair icon-only controls with Tooltip so sighted users get the same label
assistive technology receives.
