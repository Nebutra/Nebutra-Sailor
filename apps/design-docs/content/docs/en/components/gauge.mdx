## Usage

```tsx
import { Gauge } from "@nebutra/ui/primitives";
```

```tsx
<div>
  <p id="cache-hit-rate">Build Cache Hit Rate · 92%</p>
  <Gauge aria-labelledby="cache-hit-rate" showValue size="medium" value={92} />
</div>
```

## Design Principles

- Use Gauge for a 0–100 ratio against a fixed maximum: quota usage, cache hit rate, uptime, or billing-period consumption.
- Use Progress for determinate task progress such as upload completion or setup steps.
- Use Status Dot or Badge for binary, enum, or deployment state.
- Pair every Gauge with adjacent label text or a Tooltip that names what the value represents.
- Do not rely on color alone. Pair warning or error thresholds with copy nearby.
- Default thresholds follow product usage semantics: `>=80%` warning, `>=95%` error. For health scores where high is good, pass an explicit `colors` scale.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | `0` | Current value, clamped to 0–100 |
| `size` | `"tiny" \| "small" \| "medium" \| "large" \| number` | `"medium"` | Preset size or legacy pixel diameter |
| `colors` | `GaugeColorMap \| GaugeColorStop[]` | usage scale | Threshold colors or explicit `primary` / `secondary` colors |
| `secondaryColor` | `string` | — | Legacy track color override; prefer `colors.secondary` |
| `showValue` | `boolean` | `false` | Renders the numeric value only, without `%` |
| `label` | `boolean \| ReactNode` | — | Legacy alias for `showValue`; ReactNode becomes center overlay |
| `children` | `ReactNode` | — | Center icon overlay |
| `arcPriority` | `"default" \| "equal"` | `"default"` | `equal` renders both arcs with the same length for true ratios |
| `indeterminate` | `boolean` | `false` | Shows loading state when the value is unknown |

### `GaugeColorMap`

```ts
type GaugeColorMap = Record<string, string> & {
  primary?: string;
  secondary?: string;
};
```

Threshold keys are numeric strings. The highest threshold less than or equal to `value` wins.

```tsx
<Gauge
  value={50}
  colors={{
    primary: "hsl(var(--info))",
    secondary: "hsl(var(--info) / 0.18)",
  }}
/>
```

## Accessibility

- Gauge sets `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`.
- Use `aria-labelledby` to connect adjacent label text: “Build Cache Hit Rate, 92 percent.”
- Indeterminate gauges omit `aria-valuenow` and set `aria-busy`.
- `showValue` is visual only; the accessible value comes from ARIA.
