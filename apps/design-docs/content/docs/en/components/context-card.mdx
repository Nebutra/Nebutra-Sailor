## Overview

`ContextCard` reveals compact entity metadata on hover or keyboard focus: a project, deployment, user, team, API key, webhook delivery, or billing plan. It is not a replacement for `Tooltip`. Use `Tooltip` for a one-line explanation, `ContextCard` for 2-4 metadata rows, and `Drawer` or a detail page for long-form or multi-action content.

The primitive is built on Base UI Popover instead of Tooltip so a single action can remain keyboard reachable. The trigger keeps its own accessible name; the card is supplementary context.

## Installation

```tsx
import { ContextCard } from "@nebutra/ui/primitives";
```

## Usage

### Entity metadata

```tsx
import { Button, ContextCard } from "@nebutra/ui/primitives";

<ContextCard.Trigger
  side="top"
  content={
    <ContextCard.Entity
      title="Nebula Console"
      description="nebutra/production"
      metadata={[
        { label: "Plan", value: "Pro" },
        { label: "Owner", value: "Platform" },
        { label: "Last Active", value: "2m ago" },
      ]}
      action={
        <Button size="tiny" variant="outline" className="w-full">
          Open Project
        </Button>
      }
    />
  }
>
  <button type="button">Nebula Console</button>
</ContextCard.Trigger>
```

### Placement

```tsx
<ContextCard.Trigger
  side="right"
  align="start"
  width="sm"
  content={<ContextCard.Entity title="API Gateway" description="api.nebutra.com" />}
>
  <button type="button">API Gateway</button>
</ContextCard.Trigger>
```

### Custom content

Use custom content only when `ContextCard.Entity` cannot express the shape. Keep content compact and cap interactive content at one primary action.

```tsx
<ContextCard.Trigger
  side="top"
  content={
    <div className="grid gap-[var(--context-card-section-gap)]">
      <p className="font-medium">API Gateway</p>
      <p className="text-muted-foreground">Routes authenticated tenant traffic.</p>
    </div>
  }
>
  <button type="button">Gateway</button>
</ContextCard.Trigger>
```

## Props

### ContextCard.Trigger

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `ReactNode` | - | **Required.** Content shown inside the card |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | Which side the card appears on |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment relative to the trigger |
| `sideOffset` | `number` | `8` | Distance from the trigger in pixels |
| `alignOffset` | `number` | `0` | Cross-axis offset from the trigger |
| `width` | `"sm" \| "md"` | `"md"` | Component-token width of the card |
| `openDelay` | `number` | `150` | Entry delay in milliseconds |
| `closeDelay` | `number` | `120` | Exit delay in milliseconds |
| `children` | `ReactNode` | - | **Required.** The element that triggers the card |
| `className` | `string` | - | Additional CSS classes for the card |

### ContextCard.Entity

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode` | - | **Required.** Entity name in Title Case |
| `description` | `ReactNode` | - | One identifying line, such as owner, slug, or URL |
| `metadata` | `{ id?: string; label: ReactNode; value?: ReactNode }[]` | - | 2-4 compact `Label: value` rows. Missing values render `—` |
| `action` | `ReactNode` | - | Optional single primary action |

## Best Practices

- Use Context Card to reveal entity metadata on hover or focus: a user, deployment, project, webhook, API key, or plan.
- Do not use it for destructive actions. The card can dismiss during pointer movement.
- Keep interactive content to one primary action. More actions belong in `Menu`, `Drawer`, or a detail page.
- Do not nest Context Card inside Tooltip or another Context Card.
- Do not restate trigger text as the first metadata row.

## Accessibility

- Opens on hover and keyboard focus with a tokenized 150ms entry delay.
- Press `Enter` or `ArrowDown` from the trigger to move focus into the card when it contains a focusable action.
- Press `Escape` to close the card and return focus to the trigger.
- The trigger must keep a useful accessible name; card content is supplementary.
