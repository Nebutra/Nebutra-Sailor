## Installation

```tsx
import { SearchTool, type SearchResult } from "@nebutra/ui/primitives";
```

Or install standalone via the shadcn registry:

```bash
npx shadcn@latest add https://ui.nebutra.com/r/search-tool.json
```

## Usage

`SearchTool` renders a collapsed "Found N results" pill inside a chat reply. Expanding reveals a query strip and a scrollable list of results.

```tsx
import { SearchTool, type SearchResult } from "@nebutra/ui/primitives";

const results: SearchResult[] = [
  {
    title: "United UA837 SFO→NRT · $1,105 economy",
    source: "google.com/flights",
    url: "https://www.google.com/flights",
  },
  // …
];

<SearchTool query="best flights to Tokyo" results={results} />
```

## State machine

| State        | Render                                                                  |
| ------------ | ----------------------------------------------------------------------- |
| `pending`    | Shimmer "Searching…" header. Body not expandable.                       |
| `completed`  | "Found N result(s)" header. Body expandable when `results.length > 0`.  |

## Honest clickability

Rows with a `url` render as real `<a target="_blank" rel="noopener noreferrer">` anchors with an `ArrowUpRight` affordance and a hover background. Rows without a `url` render as inert `<li>` — **no fake hover**, no `cursor-pointer` lie.

```tsx
// Anchor row
{ title: "United UA837 SFO→NRT", source: "google.com", url: "https://…" }

// Inert row — no hover, no anchor
{ title: "Audit components", source: "Notion" }
```

This is a deliberate UX governance choice: surfaces that look clickable must actually be clickable.

## Metadata

Each row shows the source and optional date together (`source · date`), or just `source` when date is absent. The pasted-source pattern of "show one or the other" was a fake-simplification — both fields carry orthogonal information and both should render when present.

## Controlled expand

```tsx
const [open, setOpen] = useState(false);

<SearchTool
  query="…"
  results={results}
  expanded={open}
  onExpandedChange={setOpen}
/>
```

## Props

| Prop                  | Type                            | Default       | Description                                                      |
| --------------------- | ------------------------------- | ------------- | ---------------------------------------------------------------- |
| `state`               | `"pending" \| "completed"`      | `"completed"` | Visual progression                                               |
| `query`               | `string`                        | required      | Query text rendered in the expanded panel's strip                |
| `results`             | `readonly SearchResult[]`       | `[]`          | Result rows. Empty → panel is not expandable                     |
| `defaultOpen`         | `boolean`                       | `false`       | Initial expand (uncontrolled)                                    |
| `expanded`            | `boolean`                       | —             | Controlled expand state                                          |
| `onExpandedChange`    | `(next: boolean) => void`       | —             | Controlled callback                                              |
| `maxResultsHeightPx`  | `number`                        | `200`         | Scroll cap on the result panel                                   |
| `className`           | `string`                        | —             | Outer wrapper class                                              |

### `SearchResult`

| Field    | Type     | Required | Description                                                   |
| -------- | -------- | -------- | ------------------------------------------------------------- |
| `id`     | `string` | —        | Stable key — falls back to `url` then to title-based key      |
| `title`  | `string` | yes      | Headline of the result                                        |
| `source` | `string` | yes      | Originating domain or system (e.g. `google.com`, `Notion`)    |
| `date`   | `string` | —        | Display string for when the result was produced               |
| `url`    | `string` | —        | If provided, row renders as a real external anchor            |

## Accessibility

- Wrapper is `<section aria-busy aria-label="Search: …">`.
- Toggle button: `aria-expanded` + `aria-controls` linked to the panel id.
- Panel header is a real `<header>`; the result list is `<ul aria-label="Search results">`.
- External anchors carry `target="_blank"` + `rel="noopener noreferrer"`.

## Reuses

- [`TextShimmer`](/en/docs/components/text-shimmer) for the pending-state header.

## Design Contract

- Use `SearchTool` only for retrieval/search result traces in conversational UI.
- Rows that look clickable must be real anchors. Never add pointer styling to URL-less results.
- Keep query text visible in the expanded panel so copied screenshots preserve the search context without surrounding chat history.
