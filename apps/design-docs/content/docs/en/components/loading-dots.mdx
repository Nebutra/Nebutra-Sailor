## Installation

```tsx
import { LoadingDots } from "@nebutra/ui/primitives";
```

Standalone registry install:

```bash
npx shadcn@latest add https://ui.nebutra.com/r/loading-dots.json
```

## Usage

Use `LoadingDots` for inline "work is continuing" copy such as saving, building, or waiting for an AI tool. Use `Spinner` for standalone loading affordances.

```tsx
<LoadingDots>Saving</LoadingDots>
```

## Accessibility

- Wrapper uses `aria-live="polite"` so the label can be announced without interrupting the user.
- The dots are `aria-hidden`.
- `prefers-reduced-motion: reduce` disables the animation and leaves static dots.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Controls text size and dot rhythm. |
| `children` | `ReactNode` | `"Loading"` | Visible label rendered before the dots. |
| `className` | `string` | - | Additional class for layout context only. |

## Governance

- Keep this primitive inline. Do not use it as a page-level loading state.
- Do not add custom animation timing at the call site; motion belongs in the primitive.
- Prefer concrete labels such as `Saving`, `Building`, or `Thinking`.
