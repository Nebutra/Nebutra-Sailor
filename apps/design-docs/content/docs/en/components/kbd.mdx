
## Examples

### Modifiers

```tsx
<Kbd meta />
<Kbd shift />
<Kbd alt />
<Kbd ctrl />
```

### Combination

```tsx
<Kbd meta shift />
```

### Small

```tsx
<Kbd small>/</Kbd>
```

## Design Principles

- Use `Kbd` for shortcut hints inside prose, menu items, command rows, and button suffixes.
- Pass modifiers via boolean props. `meta` renders Command on Apple platforms and Ctrl on Windows/Linux.
- `children` is one key, digit, punctuation mark, or named key: `K`, `7`, `/`, `Enter`, `Esc`.
- Do not pack complete shortcut strings into children. Use `<Kbd meta>K</Kbd>`, not `<Kbd>Cmd+K</Kbd>`.
- Use `small` in dense surfaces like menu rows, command-bar items, and table cells.
- Keep punctuation outside the element so copied prose and screen-reader output stay clean.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `meta` | `boolean` | `false` | Command on Apple platforms; Ctrl on Windows/Linux |
| `shift` | `boolean` | `false` | Shift modifier |
| `alt` | `boolean` | `false` | Option on Apple platforms; Alt on Windows/Linux |
| `ctrl` | `boolean` | `false` | Control modifier |
| `small` | `boolean` | `false` | Compact size for dense UI |
| `children` | `ReactNode` | — | Single key, digit, punctuation mark, or named key |

## Accessibility

- `Kbd` renders a native `<kbd>` element.
- Modifier glyphs receive an accessible label, so `⌘K` is announced as “Command or Control K”.
- Adjacent prose should still name the action: “Press ⌘ K to open the command menu.”
