## Overview

`SplitButton` composes `Button` and `DropdownMenu` for flows where one action is the clear default and a short menu of nearby variants belongs next to it.

The primary action remains a real button. The chevron trigger is a separate menu button with its own accessible label, so screen readers hear the action set instead of an unlabeled icon.

## Installation

```tsx
import { SplitButton, SplitButtonMenuItem } from "@nebutra/ui/primitives"
```

## Usage

```tsx
<SplitButton
  buttonProps={{
    onClick: save,
    type: "default",
  }}
  menuButtonLabel="More save options"
  menuItems={
    <>
      <SplitButtonMenuItem
        description="Save changes."
        menuItemProps={{ onClick: save }}
        title="Save"
      />
      <SplitButtonMenuItem
        description="Save changes and create a production deployment."
        menuItemProps={{ onClick: saveAndDeploy }}
        title="Save and Deploy"
      />
    </>
  }
>
  Save
</SplitButton>
```

## Props

### `SplitButton`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Visible primary button label |
| `buttonProps` | `SplitButtonPrimaryProps` | — | Props forwarded to the primary `Button` |
| `menuButtonLabel` | `string` | — | Accessible label for the chevron trigger |
| `menuItems` | `ReactNode` | — | Menu content, normally `SplitButtonMenuItem` children |
| `menuAlignment` | `"bottom-start" \| "bottom-end"` | `"bottom-start"` | Menu placement relative to the split control |
| `menuProps` | `SplitButtonMenuContentProps` | — | Props forwarded to `DropdownMenuContent`, plus `width` |
| `disabled` | `boolean` | `false` | Disables both the primary and menu trigger |

### `buttonProps`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"default" \| "secondary"` | `"default"` | Visual button type. Destructive variants are intentionally unavailable |
| `size` | `"tiny" \| "small" \| "medium" \| "large" \| "sm" \| "default" \| "lg"` | `"medium"` | Geist aliases and native Nebutra button sizes |
| `htmlType` | `"button" \| "submit" \| "reset"` | `"button"` | Native button type for forms |
| `loading` | `boolean` | `false` | Shows the primary loading spinner and disables the whole split control |
| `prefix` | `ReactNode` | — | Optional icon before the primary label |

### `SplitButtonMenuItem`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | Menu item label |
| `description` | `ReactNode` | — | Short supporting copy below the title |
| `icon` | `ReactNode` | — | Decorative leading icon |
| `menuItemProps` | `DropdownMenuItem` props | — | Props forwarded to the underlying menu item |

## Design Principles

- Mirror the primary action as the first menu item. The visible label and first menu item title should match exactly.
- Use only `default` and `secondary` visual types. Destructive action variants belong in a visible confirmation surface, not behind a chevron.
- Keep the menu to 1-4 closely related variants. Use `Menu` for unrelated actions.
- Prefer Verb + Noun labels: `Deploy Preview`, `Deploy Production`, `Rollback Deployment`.
- Switch to `menuAlignment="bottom-end"` only when the control sits flush against the right edge of its container.

## Accessibility

- The primary action and menu trigger are two native buttons.
- `menuButtonLabel` is required because the chevron-only trigger has no visible text.
- Loading and disabled states disable both halves of the split control so keyboard focus does not land on a dead menu.
- The menu inherits keyboard behavior from `DropdownMenu`: Arrow keys move focus, Enter/Space activates, Escape closes.
