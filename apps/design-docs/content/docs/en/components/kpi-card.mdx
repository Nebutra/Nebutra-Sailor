## Usage

`KpiCard` is a compact dashboard statistic card. Use it for high-level operational metrics that need a single value, an icon, and an optional week-over-week trend.

```tsx
import { ChartTrendingUp } from "@nebutra/icons";
import { KpiCard } from "@nebutra/ui/primitives";

<KpiCard
  title="Active tenants"
  value={1284}
  icon={<ChartTrendingUp className="size-5" />}
  trend={{ value: 12, isPositive: true }}
  description="Enterprise workspaces only"
/>
```

## When To Use

- Use for dashboard summary rows with three to six comparable metrics.
- Use `Description` for key/value metadata inside detail pages.
- Use a chart component when the user needs trend shape, not just trend direction.

## States

| State | Contract |
|-------|----------|
| Positive trend | Uses up icon and positive tone for an improving metric. |
| Negative trend | Uses down icon and destructive tone for a declining metric. |
| Flat trend | Uses neutral copy when `trend.value` is `0`. |
| No trend | Shows the value and optional description without fabricating change. |

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | — | Short metric label. |
| `value` | `string \| number` | — | Primary metric value. Numbers are locale-formatted. |
| `icon` | `ReactNode` | — | Decorative metric icon. |
| `trend` | `{ value: number; isPositive: boolean }` | — | Percent trend shown as up/down/flat treatment. |
| `description` | `string` | — | Supporting copy below the trend. |
| `className` | `string` | — | Outer card class. |

## Accessibility

- The metric value must be understandable without the trend color.
- Icons are decorative; keep the metric title and value as text.
- Use a surrounding heading or dashboard section label when multiple KPI cards appear together.
- Avoid putting primary navigation only on the card without an accessible label.

## Design Contract

- `KpiCard` is for top-level summary metrics, not detailed analytics.
- Use three to six cards in a row so users can compare operational health quickly.
- Trend is a secondary indicator. If trend shape matters, use `Chart`.
- Keep the icon quiet and semantic; it should identify the metric family, not decorate the card.

## Real Product Examples

- SaaS overview dashboards showing active tenants, billable usage, open incidents, and monthly recurring revenue.
- Admin health pages summarizing gateway requests, failed webhooks, and queue latency before deeper charts.
- Team or workspace reports where a metric needs one number, one trend direction, and a short qualifier.

## Anti-patterns

- Do not use `KpiCard` for exact financial ledgers, audit history, or data that must be reconciled row by row.
- Do not place one KPI card alone as a decorative hero tile. It works best as a comparable metric set.
- Do not encode the entire meaning in trend color or icon choice; the title, value, and description must carry the metric.
