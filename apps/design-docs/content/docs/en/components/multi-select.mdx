## Installation

```tsx
import {
  MultiSelectRoot,
  MultiSelectTrigger,
  MultiSelectContent,
  MultiSelectRow,
} from "@nebutra/ui/primitives";
```

## Overview

`MultiSelect` is the compact menu primitive for choosing multiple values from a known list. It is
not a tag input. Use `MultipleSelector` when users need search, creation, and removable badge chips.
Use `Combobox` when filtering is more important than seeing the full option set.

The primitive owns menu state, focus movement, Escape handling, and the row action model. Selection
state stays controlled by the consumer.

## Usage

```tsx
const [selected, setSelected] = useState<Set<string>>(() => new Set(["design"]));

function toggle(id: string) {
  setSelected((current) => {
    const next = new Set(current);
    if (next.has(id)) next.delete(id);
    else next.add(id);
    return next;
  });
}

<MultiSelectRoot>
  <MultiSelectTrigger aria-label="Selected workstreams">
    {selected.size === 0 ? "No workstreams selected" : `${selected.size} workstreams selected`}
  </MultiSelectTrigger>
  <MultiSelectContent>
    {items.map((item) => (
      <MultiSelectRow
        key={item.id}
        name={item.name}
        checked={selected.has(item.id)}
        onChange={() => toggle(item.id)}
        onSelectOnly={() => setSelected(new Set([item.id]))}
        onSelectAll={() => setSelected(new Set(items.map((next) => next.id)))}
        selectedCount={selected.size}
        totalCount={items.length}
      />
    ))}
  </MultiSelectContent>
</MultiSelectRoot>
```

## Interaction Contract

| Focus target | Enter / Space | Arrow keys |
|---|---|---|
| Row checkbox | Toggle the row | Up / Down moves rows |
| Row action | Select Only, Select All, Select, or Deselect | Left / Right switches row controls |
| Menu content | Escape closes and returns focus to the trigger | Tab is trapped inside the menu |

The row action label is visible on hover and focus. It intentionally mirrors what a screen reader
announces, so bulk actions are not hidden behind generic labels.

## Props

### `MultiSelectRoot`

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Trigger and content composition |
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial uncontrolled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the popover opens or closes |

### `MultiSelectTrigger`

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Visible trigger label |
| `width` | `"sm" \| "md" \| "lg"` | `"md"` | Tokenized trigger and menu width |
| `aria-label` | `string` | `"Multi select"` | Stable accessible name for non-text labels |

### `MultiSelectContent`

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Rows or an empty/loading/error state |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Popover alignment |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side |
| `sideOffset` | `number` | `6` | Offset from the trigger |
| `width` | `"sm" \| "md" \| "lg"` | `"md"` | Tokenized menu width |

### `MultiSelectRow`

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` | `string` | — | Item label and row accessible name |
| `checked` | `boolean` | — | Controlled selected state |
| `onChange` | `() => void` | — | Toggle callback |
| `selectedCount` | `number` | — | Current selected item count |
| `totalCount` | `number` | — | Total item count |
| `description` | `ReactNode` | — | Secondary row copy |
| `count` | `number` | — | Optional trailing count |
| `disabled` | `boolean` | `false` | Disables both row controls |
| `onSelectOnly` | `() => void` | — | Smart action when a checked row is part of a larger selection |
| `onSelectAll` | `() => void` | — | Smart action when selecting this row completes the set |

## Design Principles

- Show the selected count in the trigger; show the single name only when it improves scan speed.
- Keep checkbox focus and action focus separate. Users should never guess whether Enter toggles a
  row or performs a bulk action.
- Keep action labels visible on hover and keyboard focus. Hidden actions must still become spoken
  labels when focused.
- Use `MultipleSelector` for searchable tag input; use `MultiSelect` for fixed, dense filter menus.
