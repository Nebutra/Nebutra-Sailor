## Overview

`Combobox` is the searchable single-select primitive for known values such as regions, frameworks, API scopes, and environment variable names. Use `Select` for short fixed lists, `MultipleSelector` for multiple values, and `Input` when the query itself is the submitted value.

The component supports two modes:

1. **Options mode** — pass `options`; the primitive renders the input, list, groups, empty state, and selected indicator.
2. **Composition mode** — render `Combobox.Input`, `Combobox.List`, `Combobox.Group`, and `Combobox.Option` when the list needs custom structure.

## Props

### Combobox

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `ComboboxOption[]` | — | Known values rendered by options mode. |
| `value` | `string \| null` | — | Controlled selected value. |
| `onChange` | `(value: string \| null) => void` | — | Called when selection changes. Selecting the current option clears to `null`. |
| `defaultValue` | `string \| null` | `null` | Initial uncontrolled value. |
| `disabled` | `boolean` | `false` | Disables the trigger and prevents opening. |
| `errored` | `boolean` | `false` | Applies invalid styling and `aria-invalid`. |
| `size` | `"small" \| "medium" \| "large"` | `"medium"` | Form-control size. Legacy `sm`, `default`, and `lg` still map through for existing consumers. |
| `width` | `number \| string` | `100%` | Root and trigger width. Numbers are pixels; strings are CSS lengths. |
| `listMaxWidth` | `number \| string` | — | Maximum popover/list width for long option text. |
| `label` | `string` | — | Optional visible label rendered above the trigger. |
| `hideLabel` | `boolean` | `false` | Visually hides the built-in label while keeping it accessible. |
| `placeholder` | `string` | `"Select..."` | Trigger copy before a value is selected. Prefer domain-specific copy such as `Search regions...`. |
| `emptyMessage` | `string` | `"No results found."` | Options-mode empty result text. |
| `searchPlaceholder` | `string` | `"Search..."` | Search input placeholder in options mode. |
| `loading` | `boolean` | `false` | Shows the loading message while async results are in flight. |
| `loadingMessage` | `string` | `"Loading options..."` | Loading message for options mode. |

### ComboboxOption

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Stable machine value used for selection matching. |
| `label` | `string` | Human-readable label displayed in options mode. |
| `disabled` | `boolean` | Disables a specific option. |
| `group` | `string` | Groups the option under a `CommandGroup` heading. |

### Subcomponents

| Component | Based on | Description |
|-----------|----------|-------------|
| `Combobox.Input` | `CommandInput` | Search field used to filter options. |
| `Combobox.List` | `CommandList` | List wrapper with `emptyMessage` and `maxWidth`. |
| `Combobox.Option` | `CommandItem` | Selectable option with selected check icon. |
| `Combobox.Empty` | `CommandEmpty` | Manual empty state for legacy composition. Prefer `Combobox.List emptyMessage`. |
| `Combobox.Group` | `CommandGroup` | Related option group. |
| `Combobox.Separator` | `CommandSeparator` | Visual divider between groups. |

## Design Principles

- Visible labels are short nouns such as `Region` or `Environment Variable`.
- Placeholders describe the search target, not the control: use `Search regions...`, not bare `Search...`.
- Keep async lists open while loading; do not collapse the popover during refetch.
- Empty states should name the searched item and query when possible, for example `No regions match "fra"`.
- Option text should match canonical branding and casing, such as `Next.js`, not `NextJS`.

## Accessibility

- The trigger uses `role="combobox"`, `aria-expanded`, `aria-controls`, and `aria-invalid` when errored.
- Use the built-in `label` prop for simple fields, or pair a sibling `Label htmlFor` with the root `id`.
- If there is no visible label, pass `aria-label`.
- Arrow keys move through `Combobox.Option` items; `Enter` selects; `Escape` closes.
