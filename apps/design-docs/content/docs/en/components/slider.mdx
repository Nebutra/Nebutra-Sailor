## Usage

```tsx
import { Slider } from "@nebutra/ui/primitives"
```

```tsx
const [value, setValue] = useState([50])

<Slider
  label="Sample Rate"
  max={96}
  min={8}
  onValueChange={setValue}
  step={4}
  unit=" kHz"
  value={value}
/>
```

## Props

Slider renders a native `<input type="range">` so it keeps browser keyboard behavior. The public API accepts both the historical `number` shape and the Geist-compatible single-item `number[]` shape.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number \| number[]` | — | Controlled value. Arrays use the first item because this is a single-thumb slider |
| `defaultValue` | `number \| number[]` | `min` | Initial uncontrolled value |
| `valueMode` | `"number" \| "array"` | inferred | Forces the callback shape when value/defaultValue is absent |
| `onValueChange` | `(value) => void` | — | Called while the value changes |
| `onValueCommit` | `(value) => void` | — | Called on pointer release or slider keyboard commit |
| `min` | `number` | `0` | Minimum product limit |
| `max` | `number` | `100` | Maximum product limit |
| `step` | `number` | `1` | Snapping increment |
| `label` | `string` | — | Visible label and accessible name |
| `unit` | `string` | — | Suffix rendered next to the live value |
| `showValue` | `boolean` | `true` | Renders the live value in tabular numerals |
| `formatValue` | `(value: number) => ReactNode` | — | Custom live value formatter |

## Best Practices

Use Slider for ranged numeric input where shape and proximity matter more than precision: bandwidth caps, opacity, audio volume, color channels.

For exact values like a port number or memory limit, pair the slider with a numeric Input. Keyboard users often prefer typing exact values.

Snap to a sensible `step` such as `1`, `5`, or `10` so dragging never produces noisy values. Clamp `min` and `max` to real product limits.

Always render the live value next to the track in tabular numerals and label what the number represents, such as Sample Rate · 44 kHz.

Threshold colors must reuse breakpoints surfaced elsewhere in the UI. Do not invent slider-only warning or error thresholds.

## Accessibility

Give the slider a visible `label` or an `aria-label`. Do not intercept native arrow-key, Page Up/Down, Home, or End behavior.

The live value is visual context. Screen readers still receive the native `aria-valuemin`, `aria-valuemax`, and `aria-valuenow` from the range input.
