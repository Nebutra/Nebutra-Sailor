## Overview

`Description` is a compact heading + subheading block. An optional `tooltip` prop renders an info icon next to the title — hovering or focusing it shows a `ContextCard` with additional context.

## Installation

```tsx
import { Description } from "@nebutra/ui/primitives";
```

## Usage

### Default

```tsx
import { Description } from "@nebutra/ui/primitives"

<Description
  title="Section Title"
  content="Data about this section."
/>
```

### With tooltip

```tsx
<Description
  title="Section Title"
  content="Data about this section."
  tooltip="Additional context about what this section refers to."
/>
```

### Rich tooltip content

The `tooltip` prop accepts any `ReactNode`:

```tsx
<Description
  title="Deployment Region"
  content="Where your workloads run."
  tooltip={
    <div className="flex flex-col gap-1">
      <p className="font-medium">Region selection</p>
      <p className="text-muted-foreground text-xs">
        Choose the region closest to your users to reduce latency.
      </p>
    </div>
  }
/>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | **Required.** Primary label / heading |
| `content` | `ReactNode` | — | **Required.** Supporting value below the title |
| `tooltip` | `ReactNode` | — | If provided, shows an info icon that reveals this content on hover |
| `className` | `string` | — | Additional CSS classes for the wrapper |

## States

| State | Contract |
|-------|----------|
| Default | Renders a semantic `<dl>` with muted `dt` and emphasized `dd`. |
| With tooltip | Adds a focusable info glyph backed by `ContextCard`; the value remains visible without opening the tooltip. |
| Rich tooltip | Accepts structured tooltip content, but the trigger stays a small explanatory affordance. |

## Accessibility

- Tooltip is built on `ContextCard`, which uses Base UI Popover with a 200ms hover delay.
- Keyboard accessible: focus the info icon to show the tooltip.
- Screen readers announce tooltip content via `role="tooltip"`.
- `Escape` dismisses the tooltip.

## Design Contract

- Use `Description` for definition-list metadata: region, plan, last deployed, build duration.
- Do not use it as form helper text; `Field` owns helper and error copy for inputs.
- Keep `title` text-only. Interactive controls belong in `content` or the surrounding layout.
- Preserve `<dl><dt><dd>` semantics. Styling changes must not flatten it into generic paragraphs.
