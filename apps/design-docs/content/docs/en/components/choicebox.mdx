## Overview

`ChoiceboxGroup` is a compound component providing card-style selection items. Each item has a title, description, and optional custom content that appears when selected. Supports both radio (single-select) and checkbox (multi-select) modes.

## Usage

```tsx
import { ChoiceboxGroup } from "@nebutra/ui/primitives";
```

## Examples

### Radio Mode (Single Select)

```tsx
const [value, setValue] = useState("trial");

<ChoiceboxGroup
  direction="row"
  label="Select a plan"
  type="radio"
  value={value}
  onChange={(v) => setValue(v as string)}
>
  <ChoiceboxGroup.Item
    title="Pro Trial"
    description="Free for two weeks"
    value="trial"
  />
  <ChoiceboxGroup.Item
    title="Pro"
    description="Get started now"
    value="pro"
  />
</ChoiceboxGroup>
```

### Checkbox Mode (Multi Select)

```tsx
const [value, setValue] = useState<string[]>([]);

<ChoiceboxGroup
  direction="row"
  label="Select plans"
  type="checkbox"
  value={value}
  onChange={(v) => setValue(v as string[])}
>
  <ChoiceboxGroup.Item title="Pro Trial" description="Free for two weeks" value="trial" />
  <ChoiceboxGroup.Item title="Pro" description="Get started now" value="pro" />
</ChoiceboxGroup>
```

### Disabled

```tsx
{/* Group-level disabled */}
<ChoiceboxGroup disabled type="radio" label="..." ...>
  <ChoiceboxGroup.Item title="..." value="..." />
</ChoiceboxGroup>

{/* Item-level disabled */}
<ChoiceboxGroup type="checkbox" label="..." ...>
  <ChoiceboxGroup.Item disabled title="Pro Trial" value="trial" />
  <ChoiceboxGroup.Item title="Pro" value="pro" />
</ChoiceboxGroup>
```

### Custom Content

Custom content renders below title/description when the item is selected.

```tsx
<ChoiceboxGroup.Item title="Pro Trial" description="Free for two weeks" value="trial">
  <div className="flex justify-center p-2">
    <Badge variant="blue">14 days remaining</Badge>
  </div>
</ChoiceboxGroup.Item>
```

### Column Layout

```tsx
<ChoiceboxGroup direction="column" type="radio" label="Choose a tier" ...>
  <ChoiceboxGroup.Item title="Starter" description="For personal projects" value="starter" />
  <ChoiceboxGroup.Item title="Team" description="For small teams" value="team" />
</ChoiceboxGroup>
```

## Props

### ChoiceboxGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"radio" \| "checkbox"` | — | **Required.** Selection mode |
| `direction` | `"row" \| "column"` | `"row"` | Layout direction |
| `label` | `string` | — | **Required.** Accessible group label |
| `showLabel` | `boolean` | `false` | Visually display the label |
| `value` | `string \| string[]` | — | Controlled value |
| `defaultValue` | `string \| string[]` | — | Uncontrolled default |
| `onChange` | `(value: string \| string[]) => void` | — | Selection callback |
| `disabled` | `boolean` | `false` | Disable all items |
| `className` | `string` | — | Additional CSS classes |

### ChoiceboxGroup.Item

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | **Required.** Primary label |
| `description` | `string` | — | Secondary text |
| `value` | `string` | — | **Required.** Item value |
| `disabled` | `boolean` | `false` | Disable this item |
| `className` | `string` | — | Additional CSS classes |
| `children` | `ReactNode` | — | Custom content shown when selected |

## When to use

- A choice that benefits from a larger tap target plus a description or icon — framework picker, plan comparison, deployment region with latency.
- **Single-select** for mutually exclusive choices, **multi-select** for additive ones. Don't mix the two within one group.
- Cap at **4–6 tiles**. Past that, switch to `Select` or `Combobox` so the page doesn't scroll for a single field. For plain text labels with no description, use `Radio`.

## Content rules

- Titles are **parallel**: one Title Case title plus one sentence-case description per tile, ending in a period.
- Don't restate the title in the description. The description adds the differentiator (`$20/mo · 100 GB bandwidth`), not a synonym.
- Don't place nested buttons or links inside a tile that would steal the click — the whole tile is the click target.

## Disabling — always explain why

A faded tile with no reason reads as broken. Wrap a disabled `ChoiceboxGroup.Item` in a `Tooltip` that names the constraint:

```tsx
import { Tooltip, TooltipContent, TooltipTrigger } from "@nebutra/ui/primitives";

<Tooltip>
  <TooltipTrigger asChild>
    <ChoiceboxGroup.Item
      disabled
      title="Enterprise"
      description="Custom SLA + dedicated support."
      value="enterprise"
    />
  </TooltipTrigger>
  <TooltipContent>Available on the Pro plan and above</TooltipContent>
</Tooltip>
```

## Accessibility

- Radio mode: `role="radiogroup"` on group, `role="radio"` on items (WAI-ARIA equivalent of `<fieldset><legend>` — composes cleaner with custom label styling and `aria-labelledby`)
- Checkbox mode: `role="group"` on group, `role="checkbox"` on items
- `aria-checked` reflects selection state; `aria-disabled` on disabled items
- Keyboard: Arrow keys navigate radio items (roving tabindex); Space/Enter toggle both modes
- Color is not the selection signal — the corner check / filled dot pairs with the border highlight so colorblind users see the active state
- Group-level `disabled` propagates to all items via context (replaces `<fieldset disabled>` inheritance)
- Focus ring: 2px primary color with 2px offset
