title: AnimateIn
description: Entrance animation primitive with branded presets, staggered groups, and reduced-motion handling.
---

## Installation

```tsx
import { AnimateIn, AnimateInGroup } from "@nebutra/ui/primitives";
```

Standalone registry install:

```bash
npx shadcn@latest add https://ui.nebutra.com/r/animate-in.json
```

## Usage

Use `AnimateIn` for short entrance transitions where motion clarifies page hierarchy. Do not wrap every element on a dense dashboard; motion should help the user track state, not add visual noise.

```tsx
<AnimateIn preset="emerge" inView>
  <section>Usage report</section>
</AnimateIn>
```

Use `AnimateInGroup` when sibling items should enter in a single rhythm:

```tsx
<AnimateInGroup stagger="normal" inView>
  {items.map((item) => (
    <AnimateIn key={item.id} preset="fadeUp">
      <Card>{item.title}</Card>
    </AnimateIn>
  ))}
</AnimateInGroup>
```

## Presets

| Preset | Use for |
| --- | --- |
| `emerge` | Default Nebutra materialize-in entrance. |
| `flow` | Horizontal streaming motion. |
| `fade` | Minimal opacity-only entrance. |
| `fadeUp` | List/card entrance with vertical lift. |
| `scale` | Small surface pop-in. |

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `preset` | `"emerge" \| "flow" \| "fade" \| "fadeUp" \| "scale"` | `"emerge"` | Branded entrance recipe. |
| `delay` | `"none" \| "short" \| "normal" \| "long"` | `"none"` | Tokenized delay before the element enters. |
| `duration` | `"short" \| "normal" \| "slow"` | `"normal"` | Tokenized transition duration. |
| `inView` | `boolean` | `false` | Starts motion when the element enters the viewport. |
| `once` | `boolean` | `true` | When `inView` is set, animate only the first time by default. |
| `className` | `string` | - | Class applied to the motion wrapper. |

`AnimateInGroup` accepts `stagger`, `inView`, `once`, `className`, and `children`. Group-level `stagger` is tokenized as `"none"`, `"tight"`, `"normal"`, or `"slow"`.

## Accessibility

- Respects `prefers-reduced-motion`.
- Reduced-motion users receive opacity-only transitions.
- Uses `LazyMotion` so framer-motion features are lazy-loaded.

## Design Contract

- Use `AnimateIn` for entrance hierarchy only; do not use it for hover, active, loading, or attention-seeking effects.
- Consume motion presets through this primitive instead of raw `motion.div` values, so duration, easing, reduced-motion, and lazy-loading stay consistent.
- Prefer `opacity` and `transform` recipes. If a design requires layout-affecting animation, promote a new motion preset first.
