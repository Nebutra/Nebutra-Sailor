## Usage

```tsx
import { MiddleTruncate } from "@nebutra/ui/primitives";
```

```tsx
<div className="max-w-64">
  <MiddleTruncate value="apps/vercel-site/app/(dashboard)/[teamSlug]/[project]/settings/page.tsx" />
</div>
```

## Design Contract

- Use MiddleTruncate for strings where both ends identify the resource: file paths, URLs, deployment IDs, commit hashes, branch names, and model names.
- Use end truncation for prose, descriptions, and headings. Cutting a sentence in the middle destroys meaning.
- Pair values users may need verbatim with a Tooltip or copy affordance that exposes the full string.
- Lock container width during hover or row expansion. The component listens to its container width, so animated layout width can move the split point.
- Do not wrap MiddleTruncate in another `text-overflow: ellipsis` container. Two truncation strategies will compete.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | required | Full original string |
| `minStartChars` | `number` | `6` | Minimum start characters to preserve when space allows |
| `minEndChars` | `number` | `8` | Minimum end characters to preserve when space allows |
| `ellipsis` | `string` | `"…"` | Separator between preserved start and end |
| `className` | `string` | — | Applies typography or layout classes to the wrapper |

## Accessibility

- The full value remains in the DOM when truncated, so assistive technology receives the original string rather than the visible ellipsis form.
- Copying from the component writes the full `value` to the clipboard.
- Inside focusable controls, pass an explicit `aria-label` on the control or on MiddleTruncate so the resource is named without relying on the visual split.
