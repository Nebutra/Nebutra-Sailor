## Overview

`Grid` renders two-dimensional cell-and-guide layouts for marketing pages, docs landing pages, and feature breakdowns where the guide lines are part of the design. Use plain Tailwind grid utilities for ordinary card lists where guides are not visible.

The component has three layers:

- `Grid.System` sets guide width, debug mode, and the optional container-query boundary.
- `Grid` owns the column/row math and decorative guide background.
- `Grid.Cell` positions content and can use `solid` to clip guides behind dense content.

Guides are CSS backgrounds, not DOM nodes, so they do not appear in the accessibility tree.

## Installation

```tsx
import { Grid } from "@nebutra/ui/primitives";
```

## Usage

### Empty guide grid

```tsx
<Grid.System debug guideWidth={1} unstable_useContainer>
  <Grid columns={5} height="preserve-aspect-ratio" rows={2} />
</Grid.System>
```

### Basic grid

```tsx
<Grid.System guideWidth={1} unstable_useContainer>
  <Grid columns={3} rows={2}>
    <Grid.Cell>1</Grid.Cell>
    <Grid.Cell>2</Grid.Cell>
    <Grid.Cell>3</Grid.Cell>
    <Grid.Cell>4</Grid.Cell>
    <Grid.Cell>5</Grid.Cell>
    <Grid.Cell>6</Grid.Cell>
  </Grid>
</Grid.System>
```

### Responsive grid with clipping

```tsx
<Grid.System unstable_useContainer>
  <Grid columns={{ sm: 1, md: 2, lg: 3 }} rows={{ sm: 6, md: 3, lg: 2 }}>
    <Grid.Cell column={{ sm: "1", md: "1/3" }} row={{ sm: "1/3", md: 1 }} solid>
      1 + 2
    </Grid.Cell>
    <Grid.Cell>3</Grid.Cell>
    <Grid.Cell>4</Grid.Cell>
    <Grid.Cell column={{ sm: 1, md: "1/3", lg: "2/4" }} row={{ sm: "5/7", md: 3, lg: 2 }} solid>
      5 + 6
    </Grid.Cell>
  </Grid>
</Grid.System>
```

### Hidden guide axis

```tsx
<Grid.System unstable_useContainer>
  <Grid columns={12} height="preserve-aspect-ratio" hideGuides="row" rows={3} />
</Grid.System>
```

## Props

### `Grid.System`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `debug` | `boolean` | `false` | Applies debug cell wash to transparent cells |
| `guideWidth` | `number \| string` | `1` | Decorative guide stroke width |
| `unstable_useContainer` | `boolean` | `false` | Uses container queries for responsive `Grid` props |
| `children` | `ReactNode` | — | Usually one `Grid` element |

### `Grid`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `columns` | `number \| { sm?: number; md?: number; lg?: number }` | — | Equal-width column count |
| `rows` | `number \| { sm?: number; md?: number; lg?: number }` | `1` | Row count for guide math and placement |
| `height` | `"preserve-aspect-ratio" \| string \| number` | — | Preserves the column/row ratio or sets a fixed CSS height |
| `hideGuides` | `"row" \| "column" \| "both"` | — | Hides one or both decorative guide axes |

### `Grid.Cell`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `column` | `number \| string \| responsive value` | — | CSS `grid-column` placement |
| `row` | `number \| string \| responsive value` | — | CSS `grid-row` placement |
| `solid` | `boolean` | `false` | Uses an opaque tokenized background to clip guides |
| `children` | `ReactNode` | — | Cell content |

## Design Principles

Use Grid only when the guide lines communicate structure. Set rows and columns at all intended breakpoints so reading order remains predictable. Do not nest Grid more than one level; overlapping guide systems become visual noise.

When a cell becomes interactive, put the semantic element inside the cell. The cell exposes `focus-within` styling, while the actual button or link keeps its own name and keyboard contract.
