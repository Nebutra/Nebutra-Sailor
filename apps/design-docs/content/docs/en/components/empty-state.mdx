## Overview

`EmptyState` prevents confusion when a view has no content. It can describe a first-run blank slate, a filtered no-results state, completed work, permission or tier denial, or a failed load.

The component is intentionally quiet: one title, one description, one primary CTA, and at most one secondary CTA.

## Installation

```tsx
import { EmptyState } from "@nebutra/ui/primitives"
```

## Usage

### Blank Slate

```tsx
import { ChartBarPeak } from "@nebutra/icons"
import { EmptyState } from "@nebutra/ui/primitives"

<EmptyState.Root
  description="A message conveying the state of the product."
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="Title"
/>
```

### Informational

```tsx
<EmptyState.Root
  description="This should detail the actions you can take on this screen, as well as why it's valuable."
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="Title"
  variant="informational"
>
  <Button type="button" variant="secondary">Primary Action</Button>
  <Button asChild type="button" variant="ghost">
    <a href="/docs">Learn More</a>
  </Button>
</EmptyState.Root>
```

### No Results

Use `live` after async filtering changes so assistive technology announces the new state.

```tsx
<EmptyState.Root
  description="No logs match “status:error”. Clear the filter to see all logs."
  icon={<EmptyState.Icon icon={<MagnifyingGlass size={32} />} />}
  live
  title="No Logs Match Your Filter"
  variant="no-results"
>
  <Button type="button" variant="secondary">Clear Filter</Button>
</EmptyState.Root>
```

### Error

```tsx
<EmptyState.Root
  description="Couldn't load deployments. Request ID: req_7K3QZ."
  icon={<EmptyState.Icon icon={<Warning size={32} />} />}
  title="Deployments Failed To Load"
  variant="error"
>
  <Button type="button" variant="destructive">Try Again</Button>
</EmptyState.Root>
```

## Props

### EmptyState.Root

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | Title Case message conveying the state |
| `description` | `ReactNode` | — | Sentence case supporting copy |
| `icon` | `ReactNode` | — | Use `<EmptyState.Icon icon={...} />` for consistent sizing |
| `children` | `ReactNode` | — | CTA slot. Use real `Button` or `Link` elements |
| `action` | `ReactNode` | — | Compatibility alias for primary CTA |
| `link` | `ReactNode` | — | Compatibility alias for secondary CTA |
| `variant` | `EmptyStateVariant` | `"blank-slate"` | Semantic empty-state variant |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Layout density |
| `align` | `"center" \| "start"` | `"center"` | Content alignment |
| `live` | `boolean` | `false` | Adds `aria-live="polite"` for async state changes |

### EmptyState.Icon

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `icon` | `ReactNode` | — | Icon element, usually 32px |
| `className` | `string` | — | Additional classes for the icon wrapper |

## Variants

| Variant | Use when |
|---------|----------|
| `blank-slate` | The user has not created the first resource |
| `informational` | The user needs a benefit explanation plus CTA |
| `educational` | The user can start contextual onboarding |
| `guide` | Starter content helps the user tinker or set up |
| `no-results` | A filter or search returned zero rows |
| `cleared` | Completed work leaves the surface empty |
| `permission` | Role or tier denies access |
| `error` | Loading failed and retry is possible |

## Content

- `title` is Title Case: `No Logs Match Your Filter`.
- `description` is sentence case and adds information not already in the title.
- Quote a single typed query with curly quotes: `No logs match “status:error”.`
- CTA labels are Title Case Verb + Noun. Avoid `Get Started`, `Continue`, and `OK`.
- Cap at one primary CTA, plus one secondary CTA when two paths are genuinely valid.

## Accessibility

- CTAs must be real `Button` or `Link` elements so they join the tab order.
- Use `live` for no-results states after async filter changes.
- Icons are decorative; the title and description carry the meaning.

## Design Contract

- Empty states explain the current absence of content; they do not market the whole product.
- The surface owns one semantic state at a time. Do not combine permission denial, no-results, and onboarding copy in the same instance.
- The icon is decorative and token-sized through `EmptyState.Icon`; meaning must live in copy and CTA labels.
- Variants map to product states, not colors. Do not override a variant just to get a different accent.

## Real Product Examples

- A new workspace project list before the first project exists, with a direct create action.
- A filtered audit-log table returning no results, with a clear-filter action and the active query named in the copy.
- A recoverable loading failure for deployments, including a retry action and request ID for support.

## Anti-patterns

- Do not use empty states as marketing panels or feature explainers when the page already has usable content.
- Do not show an empty state while data is still loading; use `LoadingState` or skeleton treatment until the request resolves.
- Do not hide permission, billing, or error causes behind generic "No items" copy. The state must name why the content is unavailable.
