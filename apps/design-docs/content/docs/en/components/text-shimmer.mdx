## Usage

```tsx
import { TextShimmer } from "@nebutra/ui/primitives"
```

## Examples

### Loading State

```tsx
<TextShimmer duration={1}>Generating code...</TextShimmer>
```

### AI Typing Indicator

```tsx
<TextShimmer duration={1.5} className="text-sm text-muted-foreground">
  Claude is thinking...
</TextShimmer>
```

### Custom Colors via CSS Variables

```tsx
<TextShimmer
  duration={1.2}
  className="text-xl [--base-color:theme(colors.blue.600)] [--base-gradient-color:theme(colors.blue.200)]"
>
  Premium Feature
</TextShimmer>
```

### As Heading

```tsx
<TextShimmer as="h1" className="text-4xl font-bold" duration={3}>
  Welcome
</TextShimmer>
```

### Paused (static display)

```tsx
<TextShimmer paused>Static Text</TextShimmer>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `string` | — | Text content (must be a string) |
| `as` | `React.ElementType` | `"p"` | HTML element to render as |
| `duration` | `number` | `2` | Shimmer sweep duration in seconds |
| `spread` | `number` | `2` | Shimmer beam spread (multiplied by text length) |
| `paused` | `boolean` | `false` | Pause the animation |
| `className` | `string` | — | Additional CSS classes |

## CSS Variables

Customize shimmer colors by overriding CSS variables:

| Variable | Default (light) | Default (dark) | Purpose |
|----------|-----------------|----------------|---------|
| `--base-color` | `#a1a1aa` | `#71717a` | Text base color |
| `--base-gradient-color` | `#000` | `#ffffff` | Shimmer highlight color |

## Accessibility

- Use shimmer for short-lived generation or emphasis only. Long-running loading states need a status message outside the animated text.
- The text content remains the accessible name; do not put important state changes only in shimmer styling.
- Respect `paused` when a parent enters reduced-motion mode or when the shimmer is rendered inside dense reading surfaces.
- Avoid pairing shimmer with low-contrast muted text. The base color must remain readable when the highlight is not passing through.

## Token Contract

- Prefer semantic CSS variables for `--base-color` and `--base-gradient-color`; do not hardcode brand hex values in product surfaces.
- Duration is a motion parameter and should stay consistent with the surrounding loading pattern.
- `TextShimmer` is the tool-family text substrate. Use `LoadingDots` for compact non-text progress and `AnimateIn` for entrance motion.
- Keep animated properties to background position and color interpolation; do not introduce layout-shifting shimmer effects.
