## Usage

```tsx
import { Skeleton } from "@nebutra/ui/primitives"
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `width` | `number \| string` | — | Width in px or any CSS length |
| `height` | `number \| string` | — | Height in px or any CSS length |
| `boxHeight` | `number \| string` | — | Outer minimum height to keep layout stable |
| `pill` | `boolean` | `false` | Fully rounded shape |
| `rounded` | `boolean` | `false` | Canonical radius-md shape |
| `squared` | `boolean` | `false` | Tighter radius-sm shape |
| `animated` | `boolean` | `true` | Enables pulse animation while respecting reduced motion |
| `show` | `boolean` | `true` | When false and children are provided, renders children unwrapped |
| `children` | `ReactNode` | — | Optional loaded content used to preserve geometry |
| `className` | `string` | — | Additional layout class |

<Info>
  Prefer `width` / `height` / `boxHeight` for stable geometry. Use `className`
  for layout placement, not one-off color or motion overrides.
</Info>

### Conditional Loading

```tsx
function UserCard({ userId }: { userId: string }) {
  const { data: user, isLoading } = useUser(userId)

  if (isLoading) {
    return (
      <div className="flex items-center space-x-4">
        <Skeleton className="h-12 w-12 rounded-full" />
        <div className="space-y-2">
          <Skeleton className="h-4 w-48" />
          <Skeleton className="h-4 w-36" />
        </div>
      </div>
    )
  }

  return <UserInfo user={user} />
}
```

## Accessibility

- Skeleton elements have `aria-hidden="true"` by default — they are decorative loading indicators.
- Wrap a loading section in `aria-busy="true"` on the container to announce loading state.
- Provide a visible or screen-reader-only "Loading..." label alongside complex skeleton layouts.

```tsx
<div aria-busy="true" aria-label="Loading user profile">
  <Skeleton className="h-12 w-12 rounded-full" />
</div>
```

## Design Contract

- Use `Skeleton` only when the eventual layout is known. Unknown wait states should use `LoadingDots` or a progress surface.
- Match the shape and footprint of the loaded content; skeletons are layout stabilizers, not decorative placeholders.
- Once data is loaded, `show={false}` should get out of the way and render children without an extra wrapper.
