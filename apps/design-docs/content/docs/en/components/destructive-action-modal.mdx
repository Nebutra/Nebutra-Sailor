title: "Destructive Action Modal"
description: "Typed confirmation modal for serious destructive actions."
---

## Overview

`DestructiveActionModal` confirms serious destructive actions with a required type-to-confirm gate. Use it for delete, rotate, revoke, disconnect, downgrade, or disabling a security setting. Do not use it for routine confirmations.

The component gates intent only. The caller owns `open` and decides when to close after the destructive request succeeds or fails.

## Installation

```tsx
import { DestructiveActionModal } from "@nebutra/ui/primitives"
```

## Usage

### Default

```tsx
import { Button, DestructiveActionModal } from "@nebutra/ui/primitives"
import { useState } from "react"

export function DeleteProjectDemo() {
  const [open, setOpen] = useState(false)
  const [loading, setLoading] = useState(false)

  function handleConfirm(): void {
    setLoading(true)
    deleteProject().then(() => {
      setLoading(false)
      setOpen(false)
    })
  }

  return (
    <>
      <Button onClick={() => setOpen(true)} size="sm" variant="destructive">
        Delete Project
      </Button>
      <DestructiveActionModal
        confirmLabel="Delete Project"
        description={
          <>
            <span className="font-medium">next-year-boilerplate</span> and all
            its deployments, domains, and environment variables will be
            permanently deleted.
          </>
        }
        irreversibleDescription="Deleting next-year-boilerplate cannot be undone."
        loading={loading}
        onCancel={() => setOpen(false)}
        onConfirm={handleConfirm}
        open={open}
        title="Delete Project"
        verificationLabel="project name"
        verificationPhrase="next-year-boilerplate"
      />
    </>
  )
}
```

### Reversible

Omit `irreversibleDescription` for actions that can be re-enabled, undone, or rolled back. Keep the typed gate when the consequence is serious.

```tsx
<DestructiveActionModal
  confirmLabel="Disable Vercel Authentication"
  description="Anyone will be able to view your deployments without being a member of your team."
  onCancel={() => setOpen(false)}
  onConfirm={() => setOpen(false)}
  open={open}
  title="Disable Vercel Authentication"
  verificationPhrase="disable vercel authentication"
/>
```

### With error

Pass a string or `Error` to `error`. The modal stays open so the user can retry.

```tsx
<DestructiveActionModal
  confirmLabel="Delete Project"
  description="my-project and all its deployments will be permanently deleted."
  error="Couldn't delete project. Try again."
  irreversibleDescription="Deleting my-project cannot be undone."
  onCancel={() => setOpen(false)}
  onConfirm={handleConfirm}
  open={open}
  title="Delete Project"
  verificationLabel="project name"
  verificationPhrase="my-project"
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controlled open state |
| `title` | `string` | Title Case Verb + Noun statement |
| `description` | `ReactNode` | Consequence copy that names the resource when relevant |
| `confirmLabel` | `string` | Primary button label. Match `title` 1:1 |
| `verificationPhrase` | `string` | Exact phrase required before submit enables |
| `verificationLabel` | `string` | Optional resource label, e.g. `project name` |
| `irreversibleDescription` | `ReactNode` | Optional red band copy for irreversible actions |
| `error` | `string \| Error \| null` | Inline retryable failure |
| `loading` | `boolean` | Disables both buttons and shows primary loading state |
| `onCancel` | `() => void` | Called for cancel, outside click, and Escape |
| `onConfirm` | `() => void` | Called when the typed gate is open and the form submits |
| `cancelLabel` | `string` | Cancel button label |
| `className` | `string` | Additional classes for the panel |

## Design principles

- Use the resource name itself for entity deletes, paired with `verificationLabel`.
- Use a lowercase verb phrase only when there is no entity to name.
- `confirmLabel` matches `title`; never use `Confirm`, `OK`, or a bare verb.
- `irreversibleDescription` names the action and resource and ends with `cannot be undone.`
- The component never closes itself from `onConfirm`; close after the API settles.

## Real Product Examples

- Deleting a project and all linked deployments after the user types the project name.
- Rotating a production API key when webhook consumers and integration owners have been named.
- Disabling an organization security policy after the admin types the required confirmation phrase.

## Anti-patterns

- Do not use this modal for low-risk confirmations such as closing a draft or clearing a filter.
- Do not set `verificationPhrase` to a generic word like `delete`; use the resource name or exact high-risk action.
- Do not close the modal optimistically before the destructive request has settled and retry errors can be shown.

## Accessibility

- The verification input focuses on open.
- The input is associated with its full prompt via `htmlFor` and `aria-labelledby`.
- Submit is disabled until the value matches `verificationPhrase` exactly.
- Enter submits only after the gate is open.
- The warning icon in the irreversible band is `aria-hidden`; the sentence carries the meaning.
