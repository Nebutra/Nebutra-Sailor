## Usage

```tsx
import { Toggle } from "@nebutra/ui/primitives";
import { useState } from "react";

export function FirewallToggle() {
  const [checked, setChecked] = useState(false);

  return (
    <Toggle checked={checked} onChange={setChecked}>
      Firewall
    </Toggle>
  );
}
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `checked` | `boolean` | — | Controlled checked state. Use this for settings that persist immediately. |
| `defaultChecked` | `boolean` | `false` | Initial checked state for uncontrolled examples and form demos. |
| `onChange` | `(checked: boolean, event: ChangeEvent<HTMLInputElement>) => void` | — | Called when the native checkbox changes. |
| `onCheckedChange` | `(checked: boolean, event: ChangeEvent<HTMLInputElement>) => void` | — | Alias callback for consumers that want explicit switch naming. |
| `size` | `"small" \| "normal" \| "large"` | `"small"` | Visual size of the switch and label. |
| `color` | `"default" \| "blue" \| "cyan" \| "success" \| "warning" \| "error" \| "neutral"` | `"default"` | Semantic color for the ON state. Legacy aliases `green`, `amber`, `red`, `teal`, and `gray` resolve to the matching semantic token. |
| `icon` | `{ checked?: ReactNode; unchecked?: ReactNode }` | — | Optional icon rendered inside the thumb. |
| `direction` | `"label-first" \| "switch-first" \| "switch-last"` | `"label-first"` | Layout order. `switch-last` is kept as a compatibility alias. |
| `labelCasing` | `"title" \| "normal"` | `"title"` | Documents expected label casing. It does not transform text, so product names keep their real casing. |
| `disabled` | `boolean` | `false` | Disables the native input and dims the whole control. |

## Best Practices

Use Toggle for a single boolean setting where ON takes effect immediately, such as Password Protection or Auto-Cancel Builds. Use Checkbox for multi-select lists, and use Switch for 2-3 mutually exclusive views.

Keep the component controlled in production flows: own `checked`, update it from `onChange`, persist the new value, and surface the result with a success or error toast. Disable Toggle only when the action is impossible, and pair that disabled state with helper text or a Tooltip that names the resolver.

The visible label is `children`, not a `label` prop. Use a short Title Case noun phrase naming what is true when ON: `Password Protection`, not `Enable Password Protection`. Render an optional one-sentence description as a sibling under the label when the setting needs context.

## Accessibility

Toggle uses a native checkbox input, so keyboard and form behavior stay platform-correct. Provide an accessible name through `children`, `aria-label`, or `aria-labelledby`; development builds warn when all three are missing.

Set `aria-label` only when the visible label sits elsewhere in the row. Otherwise, let `children` carry the same text that sighted and screen-reader users receive.
