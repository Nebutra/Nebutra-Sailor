## Installation

```tsx
import { Note } from "@nebutra/ui/primitives";
```

## Usage

Use `Note` next to the control, card, or section it explains. It is persistent until the underlying state changes.

```tsx
<Note label="Region Change" tone="warning">
  Changing this region restarts all functions.
</Note>
```

Use `action` for one inline recovery or upgrade path.

```tsx
<Note action={<Button size="sm">Review Usage</Button>} tone="secondary">
  This workspace is close to its included usage limit.
</Note>
```

## Tone Model

The source Geist examples expose many visual `type` values, including `alert`, `lite`, `ghost`, `violet`, and `rotate-ccw`. Nebutra intentionally does not ship those as Note tones. `rotate-ccw` is an icon name, `alert` duplicates warning/error semantics, and `violet` has no approved semantic or brand token in this system.

| Tone        | Meaning                                      | Default role |
| ----------- | -------------------------------------------- | ------------ |
| `default`   | Neutral contextual note                      | `note`       |
| `secondary` | Lower-emphasis neutral information           | `note`       |
| `success`   | Passed check or completed validation         | `note`       |
| `warning`   | Consequence the user should acknowledge      | `note`       |
| `error`     | Problem the user must fix                    | `alert`      |
| `cyan`      | Nebutra accent signal, reserved for branded intelligence/data context | `note` |

`type` exists as a Geist-compatible alias, but new Nebutra code should use `tone`.

## Behavior

- A Note does not dismiss itself. If the message can be dismissed without changing state, the message probably belongs elsewhere.
- Use one Note per concept. Stacking multiple notes on one card is a page architecture problem.
- `action` is a single inline CTA. Do not place two buttons in the action slot.
- Disabled notes set `aria-disabled` and make the action subtree inert.

## Content

- `label` is a 1-2 word Title Case prefix: `Region Change`, `Rate Limit`, `Plan Limit`.
- Pass `label={false}` when the tone icon is enough and the body names the subject.
- `children` should be one active-voice sentence that names the impact.
- Do not use hedges like "Heads up", "FYI", or "Please note".

## Props

| Prop       | Type                                                                 | Default | Description |
| ---------- | -------------------------------------------------------------------- | ------- | ----------- |
| `tone`     | `"default" \| "secondary" \| "success" \| "warning" \| "error" \| "cyan"` | `"default"` | Semantic tone |
| `type`     | Same as `tone`                                                       | —       | Geist-compatible alias; do not pass with `tone` |
| `size`     | `"small" \| "medium" \| "large"`                                     | `"medium"` | Density scale |
| `fill`     | `boolean`                                                            | `false` | Stronger background treatment |
| `label`    | `string \| false`                                                    | tone default | Prefix label |
| `action`   | `ReactNode`                                                          | —       | Single inline CTA |
| `icon`     | `ReactNode \| false`                                                 | tone icon | Leading glyph override |
| `disabled` | `boolean`                                                            | `false` | Disables the action subtree and dims the surface |
| `role`     | `"note" \| "alert" \| "status"`                                      | auto    | Override the default role |

## Accessibility

- `error` defaults to `role="alert"`; all other tones default to `role="note"`.
- The icon is decorative. The message body and label carry the accessible information.
- When used inside a focusable card or row action, pass an explicit accessible name to the surrounding control so the ellipsis or icon is not the only announced content.
- Do not use color as the only threshold signal. Pair warning/error tones with copy that names the consequence.
