---
title: "Message Content"
description: "Streaming-aware markdown renderer for AI responses, tool output, and compact assistant surfaces."
---

## Usage

Use `MessageContent` anywhere markdown comes from a model, tool, or streaming assistant response. It normalizes common LLM markdown defects before rendering, then applies the Nebutra prose contract.

```tsx
import { MessageContent } from "@nebutra/ui/primitives";

<MessageContent>
  {`## Deployment Summary

1.

Promote edge config

\`\`\`nonsense
const unsafe = true
\`\`\``}
</MessageContent>;
```

## Behavior

- Broken ordered list markers such as `1.` followed by blank lines are joined back into valid list items.
- Unknown code fence language hints are downgraded to `text`.
- Supported code fence languages are intentionally narrow: shell, JS/TS, JSX/TSX, JSON, HTML, YAML, Markdown, diff, and plain text.
- The renderer remains streaming-friendly; pass partial chunks as `children`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `string` | - | Markdown source. Can be partial while streaming. |
| `density` | `"compact" \| "comfortable"` | `"comfortable"` | Adjusts paragraph, heading, and code block rhythm through component tokens. |
| `inverted` | `boolean` | `false` | Applies inverted prose for light text on dark/brand message bubbles. |
| `className` | `string` | - | Applies to the message root. |
| `style` | `CSSProperties` | - | Merged after component CSS variables. |

## Design Principles

- Use `MessageContent` for AI/chat text. Use MDX/Fumadocs renderers for authored documentation pages.
- Do not use raw `ReactMarkdown` in product surfaces; it creates divergent typography, link, table, and code behavior.
- Keep controls outside markdown. Markdown content is prose, not a command surface.
- Prefer `density="compact"` inside chat bubbles and tool call rows; use `comfortable` for standalone summaries.

## Accessibility

- Markdown should supplement the message's accessible container label, not replace it.
- Links keep their rendered text as the accessible name.
- Code blocks should include a language hint when possible, but unknown hints degrade to `text` instead of leaking arbitrary class names.

## Tokens

`MessageContent` consumes `messageContentTokens` for code radius, code padding, inline code padding, table radius, and density rhythm. Runtime colors stay on semantic prose utilities.
