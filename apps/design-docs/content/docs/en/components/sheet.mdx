## Usage

```tsx
import {
  Sheet,
  SheetBody,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@nebutra/ui/primitives"
```

```tsx
<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline">Open Sheet</Button>
  </SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Deployment Details</SheetTitle>
      <SheetDescription>Inspect the deployment without leaving the table.</SheetDescription>
    </SheetHeader>
    <SheetBody>{/* metadata rows */}</SheetBody>
    <SheetFooter>
      <SheetClose asChild>
        <Button variant="outline">Close</Button>
      </SheetClose>
      <Button>Open Deployment</Button>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

## Props

### Sheet

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial uncontrolled open state |
| `onOpenChange` | `(open, details) => void` | — | Called when open state changes |
| `modal` | `boolean \| "trap-focus"` | `"trap-focus"` | Keeps keyboard focus in the sheet while allowing outside pointer surfaces such as toasts |
| `disablePointerDismissal` | `boolean` | `true` | Prevents outside clicks from closing the sheet |

### SheetContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | Edge the sheet enters from |
| `noOverlay` | `boolean` | `false` | Hides the backdrop for low-interruption inspector panels |
| `overlay` | `boolean` | `true` | Renders the backdrop; `noOverlay` wins when both are provided |
| `showClose` | `boolean` | `true` | Renders the built-in close icon button |
| `close` | `boolean` | `true` | Alias for `showClose` |

## Best Practices

Use Sheet for persistent associated context like deployment details, log row inspection, or a member profile where the underlying page remains useful.

For a blocking decision, use Dialog. For a mobile-only bottom sheet, use Drawer. Do not use Sheet to confirm destructive actions.

Pick `side` from the trigger location: a row inspector slides from the right, and a global filter can slide from the left or bottom. Do not change sides mid-session.

Sheet does not close on outside click by default. Always render an explicit close affordance and honor Escape.

Title is Title Case and names the entity, such as Deployment Details or Member Profile. Body content should be read-mostly, with optional action buttons in the footer.

## Real Product Examples

- Inspecting deployment details from a deployments table while keeping the row list visible.
- Reviewing a member profile, role, recent activity, and quick actions from a team page.
- Opening global filters for logs or audit events without navigating away from the current query.

## Anti-patterns

- Do not use Sheet for final destructive confirmations; use `AlertDialog` or `DestructiveActionModal`.
- Do not use Sheet as a replacement for a full settings page when the flow has multiple sections or validation steps.
- Do not switch the `side` during the same workflow; spatial behavior must stay predictable.

## Accessibility

Sheet is built on Base UI Dialog. The root defaults to `modal="trap-focus"` and `disablePointerDismissal`, so keyboard users stay inside the panel while pointer-only surfaces like toasts can remain reachable.

`SheetTitle` provides the accessible name. Add `SheetDescription` only when the description is short and load-bearing.

The built-in close button has `aria-label="Close"`. If you hide it, provide a visible close control in `SheetFooter`.
