## Overview

`Menu` is a semantic dropdown component built on top of Nebutra `DropdownMenu`, which currently uses Base UI Menu under the hood. It exposes a high-level API with `prefix`, `suffix`, `locked`, `disabled`, and `href` slots on each item — covering all standard UI Menu variants without exposing substrate internals at the usage site.

Use `DropdownMenu` directly when you need raw building blocks like checkbox items, radio groups, or sub-menus. Use `Menu` for standard navigation and action lists.

## Link Items

Automatically renders the item as an `<a>` tag when the `href` prop is provided. Keyboard and mouse navigation is preserved through the `DropdownMenu` render-slot bridge.

## Props

The API mirrors Nebutra `DropdownMenu` content props, but the `.Item` accepts custom rendering props.

### `Menu.Trigger`

Extends `<button>` HTML attributes.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `chevron` | `boolean` | `false` | Adds a rotating ChevronDown icon |
| `className` | `string` | — | Override trigger styles |

### `Menu.Content`

Extends Nebutra `DropdownMenuContent` props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `align` | `"start" \| "center" \| "end"` | `"start"` | Horizontal alignment relative to trigger |
| `sideOffset` | `number` | `4` | Gap between trigger and content in px |

### `Menu.Item`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `prefix` | `ReactNode` | — | Icon/element on the left |
| `suffix` | `ReactNode` | — | Icon/element on the right (overridden by lock icon when `locked`) |
| `disabled` | `boolean` | `false` | Grays out item, removes pointer events |
| `locked` | `boolean` | `false` | Permission-gated state — shows lock icon, prevents interaction |
| `href` | `string` | — | Renders item as `<a>` navigating to this URL |
| `onSelect` | `(e: Event) => void` | — | Called on item selection |
| `className` | `string` | — | Additional CSS classes |

## Accessibility

- `Menu` inherits menu roles, roving focus, Escape handling, and typeahead behavior from `DropdownMenu`.
- Use `locked` for permission-gated actions that should remain discoverable. Use `disabled` for temporarily unavailable actions.
- `prefix` and `suffix` icons must be decorative unless they add information not already present in the label.
- Link items must still read as actions. Avoid mixing unrelated navigation and destructive commands in the same menu.

## Design Contract

- Use `Menu` for short action or navigation lists where every row has the same density and interaction model.
- Use raw `DropdownMenu` when the menu needs checkbox items, radio groups, separators, nested submenus, or custom item composition.
- Keep menus stable. If users need to scan, compare, or edit multiple fields, use a Popover, Dialog, or page-level settings surface.
