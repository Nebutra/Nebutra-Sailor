## Installation

```tsx
import { Collapse, CollapseGroup } from "@nebutra/ui/primitives";
```

Standalone registry install:

```bash
npx shadcn@latest add https://ui.nebutra.com/r/collapse.json
```

## Usage

Use `Collapse` when a consumer expects the Geist-style `title` and `defaultExpanded` API. Use `Accordion` directly when you need the full compound primitive.

```tsx
<Collapse title="Advanced settings" defaultExpanded>
  <p>Only show details most users can skip.</p>
</Collapse>
```

Coordinate siblings with `CollapseGroup`:

```tsx
<CollapseGroup multiple>
  <Collapse title="Request">...</Collapse>
  <Collapse title="Response">...</Collapse>
</CollapseGroup>
```

## Props

### Collapse

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | required | Panel heading. Names the topic, not the action. |
| `defaultExpanded` | `boolean` | `false` | Initial uncontrolled open state. |
| `size` | `"default" \| "small"` | `"default"` | Density variant inherited from Accordion. |
| `keepMounted` | `boolean` | `true` | Keeps closed content in the DOM for find-in-page and crawlers. |
| `disabled` | `boolean` | `false` | Disables the trigger. |
| `children` | `ReactNode` | required | Panel content. |

### CollapseGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `multiple` | `boolean` | `false` | Allows more than one child panel to stay open. |
| `size` | `"default" \| "small"` | - | Applies density to children that do not specify their own size. |
| `children` | `ReactNode` | required | `Collapse` children. |

## Relationship To Accordion

`Collapse` is a facade over Nebutra `Accordion`. It should not fork focus management, ARIA wiring, or animation behavior. If behavior needs to change, fix Accordion first unless the difference is specific to the flat Geist API.

## Accessibility

- Inherits Accordion button, region, `aria-expanded`, and `aria-controls` wiring.
- `keepMounted` defaults to true so browser find-in-page can still locate collapsed content.
- Disabled panels must have nearby explanatory copy when the reason is not obvious.

## Design Contract

- Use `Collapse` for optional or advanced details most users can skip, not for primary page structure.
- Use `CollapseGroup` when siblings coordinate open state; use standalone `Collapse` for one-off disclosure.
- Fix shared behavior in `Accordion` first. `Collapse` should remain a flat API facade, not a behavioral fork.
