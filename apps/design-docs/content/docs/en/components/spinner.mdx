## Usage

```tsx
import { Spinner } from "@nebutra/ui";

<Spinner />
<Spinner size="sm" />
<Spinner label="Verifying deployment" />
```

## Design Contract

`Spinner` is intentionally a single canonical loader. It indicates an action is
running without implying progress. The component renders a 12-segment
`currentColor` indicator, uses component motion tokens, and stops motion through
`prefers-reduced-motion`.

Legacy `variant` values are still accepted so older call sites do not break, but
they render the same spinner. Use copy and context to differentiate work, not a
different animation.

## Size

Use size tokens for system surfaces and numeric sizes only when matching a
specific adjacent icon.

```tsx
<Spinner size="xs" />
<Spinner size="sm" />
<Spinner size="md" />
<Spinner size="lg" />
<Spinner size={32} />
```

## Tone

Tone maps to semantic text color.

```tsx
<Spinner tone="default" />
<Spinner tone="foreground" />
<Spinner tone="inverse" />
```

## In a Button

For submit buttons, use `Button`'s loading state so sizing, disabled state, and
busy affordance stay aligned.

```tsx
<Button loading>Saving changes</Button>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| number` | `"md"` | Spinner size token or explicit pixel size |
| `tone` | `"default" \| "foreground" \| "inverse"` | `"default"` | Semantic color tone |
| `label` | `string` | — | Accessible status label for standalone use |
| `decorative` | `boolean` | inferred | Forces decorative mode when the parent already exposes busy state |
| `variant` | legacy union | `"default"` | Deprecated compatibility prop; all variants render the same spinner |

## Best Practices

Use a Spinner for indeterminate, single-action waits of roughly one to three
seconds: submit buttons, inline refresh, row-level retry, pagination changes.

Pick Skeleton when async data fills a known layout, LoadingDots for inline copy,
and Progress when total work is known.

Mount the Spinner only after the action starts. Pre-rendering and toggling
visibility can leave a partial rotation visible at idle.

Pair any wait longer than about one second with copy that names the work:
`Verifying...`, `Deploying...`, `Retrying...`.

Set `aria-busy="true"` on the element wrapping the in-flight action. When the
spinner is standalone, pass `label`; otherwise leave it decorative so screen
readers do not announce duplicate loading text.
