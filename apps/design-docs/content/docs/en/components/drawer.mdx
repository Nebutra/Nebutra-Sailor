## Design Principles

- Use Drawer as a bottom sheet on small viewports for short focused work: filters, one-step forms, or a primary action paired with Cancel.
- Use Modal for destructive confirmations and blocking decisions. Drawer intentionally does not carry the same severity signal.
- Use Sheet for lateral desktop context. Side drawers remain type-compatible for legacy consumers, but new product flows should not use them.
- Keep the body scroll inside `DrawerBody`; the page behind the overlay must not scroll while the drawer is open.

## Props

### Drawer

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state |
| `show` | `boolean` | — | Geist-compatible controlled open alias |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |
| `onDismiss` | `() => void` | — | Called when the drawer closes by Escape, outside press, swipe, or close control |
| `height` | `number \| string` | `80vh` | Caps bottom sheet height; numbers resolve to px |
| `customHeight` | `number \| string` | — | Alias for `height` when a capped custom frame is needed |
| `dismissible` | `boolean` | `true` | Allows outside press and swipe dismiss |
| `direction` | `"bottom" \| "top" \| "left" \| "right"` | `"bottom"` | Prefer `bottom`; use Sheet for lateral panels |

### DrawerContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `height` | `number \| string` | inherited | Overrides root height for this content |
| `verticalScroll` | `boolean` | `true` | Keeps scrolling inside the drawer frame |
| `showHandle` | `boolean` | `true` | Shows the bottom sheet drag handle |

## Accessibility

- Built on Vaul, with dialog semantics and focus trapping.
- `DrawerTitle` and `DrawerDescription` provide the accessible name and description.
- Escape closes the drawer and focus returns to the trigger.
- Body scroll is locked while open; scrollable content stays inside `DrawerBody`.
- Preserve swipe-down and outside-dismiss unless dirty input would cause data loss.
