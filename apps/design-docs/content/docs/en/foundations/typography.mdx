## Font System — "Precision Stack"

The Nebutra design system uses three fonts. Geist handles all text roles through weight and size variation alone — no separate display typeface is needed.

| Font | Role | Variable | License |
|------|------|----------|---------|
| **Geist Sans** | UI, body, headings, display | `--font-geist-sans` | SIL OFL (Vercel) |
| **Geist Mono** | Code, data, tokens, IDs | `--font-geist-mono` | SIL OFL (Vercel) |
| **Noto Sans SC** | Chinese (CJK) UI text | `--font-cn` | SIL OFL (Google) |

---

## Geist Sans — Primary Typeface

Geist Sans is the single typeface for all Nebutra UI text — from hero headlines to body copy. It is a variable font supporting weights 100 through 900, enabling precise control across every scale without switching fonts.

**Design rationale:** Geist was designed by Vercel for high-density developer products. Its geometric precision and optical sizing match the Vercel / Linear / Cursor aesthetic that Nebutra targets.

### Roles by Weight

| Weight | Value | Use Case |
|--------|-------|----------|
| Thin | 100 | Oversized decorative display at 96px+ |
| ExtraLight | 200 | Large ambient headlines |
| Light | 300 | Subtitle / tagline at hero scale |
| Regular | 400 | Body copy, descriptions, paragraph text |
| Medium | 500 | Labels, navigation items, captions |
| SemiBold | 600 | Subheadings, button labels (H3–H4) |
| Bold | 700 | Hero headlines (H1–H2), strong emphasis |
| ExtraBold | 800 | Extra emphasis on hero text |
| Black | 900 | Maximum impact display text |

### Letter Spacing

Tighten tracking at large sizes — Geist's proportions require it:

| Scale | Tracking |
|-------|----------|
| Display (72px+) | `-0.04em` |
| Heading (40–64px) | `-0.03em` |
| Subheading (24–36px) | `-0.02em` |
| Body (14–20px) | `0em` |

### Code

```css
/* Display heading */
font-family: var(--font-sans);
font-weight: 700;
letter-spacing: -0.03em;

/* Body text */
font-family: var(--font-sans);
font-weight: 400;
letter-spacing: 0;
```

```tsx
{/* Hero headline */}
<h1 className="font-sans font-bold text-heading-72 tracking-tight">
  Enterprise SaaS Platform
</h1>

{/* Body copy */}
<p className="font-sans font-normal text-copy-16">
  Nebutra transforms raw data into intelligent cloud-native outcomes.
</p>

{/* Navigation label */}
<span className="font-sans font-medium text-ui-14">
  Dashboard
</span>
```

## Geist Mono — Code Typeface

Geist Mono is the monospace typeface for all code, terminal output, and technical data. It is the monospace counterpart to Geist Sans, sharing the same geometric DNA.

### When to Use

- Code blocks and inline code
- Terminal / CLI output
- API endpoint displays
- Technical data values (IDs, hashes, tokens, API keys)
- Configuration examples and environment variables

### Code

```css
font-family: var(--font-mono);
font-weight: 400;
font-feature-settings: "calt" 1, "liga" 1;
```

```tsx
<code className="font-mono text-copy-14">
  const apiKey = process.env.NEBUTRA_API_KEY
</code>

<pre className="font-mono text-copy-14 bg-neutral-950 text-cyan-400 p-4 rounded-lg">
  <code>npm install @nebutra/ui</code>
</pre>
```

## Noto Sans SC — Chinese Typeface

Noto Sans SC is the CJK typeface for all Chinese UI text. Applied via the `font-cn` Tailwind class or the `--font-cn` CSS variable.

### When to Use

- All Chinese body text and UI labels
- Mixed Latin + Chinese content
- Chinese marketing copy
- CJK data labels and descriptions

### Weights

| Weight | Value | Use Case |
|--------|-------|----------|
| Regular | 400 | Chinese body copy |
| Medium | 500 | Chinese labels, navigation |
| Bold | 700 | Chinese headings |

### Code

```css
font-family: var(--font-cn);
font-weight: 400;
```

```tsx
<p className="font-cn font-normal text-copy-16">
  云端聚合 · 引领未来
</p>
```

## Font Stacks

### CSS Custom Properties

```css
:root {
  /* Primary UI — Geist Sans (all Latin text) */
  --font-sans: var(--font-geist-sans), "Geist", -apple-system,
               BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif;

  /* Code — Geist Mono */
  --font-mono: var(--font-geist-mono), "Geist Mono",
               ui-monospace, SFMono-Regular, "SF Mono", Menlo, monospace;

  /* Chinese — token-provided local/system stack */
  --font-cjk: var(--font-cn), "Noto Sans SC", "PingFang SC",
              "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
}
```

### Tailwind Utility Classes

```tsx
{/* All UI text (Latin) */}
<h1 className="font-sans">Enterprise SaaS Platform</h1>

{/* Chinese text */}
<p className="font-cn">中文正文内容</p>

{/* Code / monospace */}
<code className="font-mono">const x = 1</code>
```

### Next.js Font Loading

```tsx
// app/layout.tsx
import { GeistSans } from "geist/font/sans";
import { GeistMono } from "geist/font/mono";
import "@nebutra/tokens/styles.css";

// Apply to <html>:
// className={`${GeistSans.variable} ${GeistMono.variable}`}
//
// CJK fallback comes from @nebutra/tokens --font-cn.
// Do not use next/font/google for Noto Sans SC in CI-built apps.
```

## CJK Rhythm

Mixed Latin + Chinese content requires special handling to maintain visual rhythm.

### The `font-cn` Class

Apply `font-cn` to any container that displays Chinese text. This switches the font stack to Noto Sans SC and adjusts:

- **Line height** increases from 1.5 to 1.75 (CJK characters need more vertical space)
- **Letter spacing** resets to 0 (CJK does not use letter-spacing)
- **Word spacing** is managed automatically by the browser for CJK

```tsx
{/* Pure Chinese content */}
<p className="font-cn text-copy-16">
  无锡云毓智能科技有限公司致力于企业级SaaS平台建设
</p>

{/* Mixed Latin + Chinese */}
<div className="font-cn">
  <p>Nebutra (云毓智能) 是一个企业级 SaaS 平台</p>
</div>
```

### Size Adjustments

CJK glyphs are optically larger than Latin characters at the same font size. Apply a slight reduction when mixing:

```css
/* Mixed content adjustment */
.font-cn {
  font-family: var(--font-cjk);
  line-height: 1.75;
  font-size-adjust: 0.52;
}
```

### Punctuation

- Use Chinese punctuation (。，！？；：""''） in Chinese sentences
- Use English punctuation in English sentences
- In mixed content, follow the language of the surrounding clause

## Do / Don't

**Do** use Geist Sans for all Latin text — both display headlines and body copy.

**Do** control hierarchy through weight (400 body → 700 headline) and size — not font switching.

**Do** use Noto Sans SC (via `font-cn`) for all Chinese text.

**Do** apply `font-cn` to containers with CJK content to activate proper line-height.

**Do** use Geist Mono for all code and technical data.

**Do** tighten letter-spacing at display sizes (`-0.03em` to `-0.04em`).

**Don't** use non-brand fonts (Inter, Poppins, Roboto, Arial, SF Pro) in Nebutra products.

**Don't** use a separate "display" font family — Geist Sans handles all scales through weight variation.

**Don't** set letter-spacing on body text — tracking adjustments belong only to headings and display text.

**Don't** mix `font-sans` and `font-cn` on the same element — choose one based on the content language.
