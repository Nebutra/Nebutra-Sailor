## When to Use

Use a table pattern when displaying structured data where:
- Users need to compare values across rows and columns
- Data has a defined schema (columns are consistent across all rows)
- Users may need to sort, filter, or act on individual rows

Use a table over a card list when:
- There are 4 or more attributes per item that benefit from columnar alignment
- Sort and filter by column are required

Do not use a table when:
- Items are heterogeneous (different attributes per item) — use a list or cards
- There are fewer than 3 columns — use a definition list or `Card` grid

## Two table options

`@nebutra/ui` ships two complementary table APIs. Pick by capability:

| Use | API |
|---|---|
| Static or simple lists; you control header/body markup | `Table` primitive (`Table`, `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell`) |
| Sortable, filterable, virtualized, with toolbar / column visibility / cell selection | `DataTable` pattern (TanStack Table under the hood) |

Both are tree-shakable; nothing is loaded until you import it.

## Structure

```
Section (title + description + table-level actions)  // from @nebutra/ui/layout
  ├── DataTable                                      // built-in toolbar handles search + filters
  │    └── (rendered table with sticky header,
  │         optional virtualization, column resize)
  ├── EmptyState  (when data is empty)               // from @nebutra/ui/layout
  └── LoadingState / ErrorState (status placeholders)
```

For static content, swap `DataTable` for the bare `Table` primitive.

## Composition

### DataTable (recommended for interactive lists)

`DataTable<TData>` accepts TanStack `ColumnDef[]` and `TData[]`. The toolbar (search, filters, column visibility, extra actions) is on by default.

```tsx
import { DataTable } from "@nebutra/ui/components";
import type { ColumnDef } from "@tanstack/react-table";

type ApiKey = {
  id: string;
  name: string;
  createdAt: string;
  status: "active" | "revoked";
};

const columns: ColumnDef<ApiKey>[] = [
  {
    accessorKey: "name",
    header: "Name",
    cell: ({ row }) => <span className="font-medium">{row.original.name}</span>,
  },
  {
    accessorKey: "createdAt",
    header: "Created",
    cell: ({ row }) => new Date(row.original.createdAt).toLocaleDateString(),
  },
  {
    accessorKey: "status",
    header: "Status",
  },
];

<DataTable
  columns={columns}
  data={rows}
  searchPlaceholder="Search keys…"
/>;
```

### Bare Table primitive (recommended for static content)

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@nebutra/ui/components";

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      <TableHead>Created</TableHead>
      <TableHead>Status</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {rows.map((row) => (
      <TableRow key={row.id}>
        <TableCell className="font-medium">{row.name}</TableCell>
        <TableCell>{new Date(row.createdAt).toLocaleDateString()}</TableCell>
        <TableCell>{row.status}</TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>;
```

### Sorting

`DataTable` enables column sorting through the standard TanStack mechanism — set `enableSorting: true` (default) on the `ColumnDef` and the toolbar header becomes clickable. For server-side sorting, manage sort state externally and pass the sorted slice into `data`.

### Row actions

Row-level actions belong in the last column, right-aligned. There is no `ActionMenu` primitive — compose one with the `DropdownMenu` family from `@nebutra/ui/components`:

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
  Button,
} from "@nebutra/ui/components";
import { MoreHorizontal } from "lucide-react";

function RowActions({ row, onEdit, onRevoke }: { row: ApiKey; onEdit: (r: ApiKey) => void; onRevoke: (r: ApiKey) => void }) {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button type="button" variant="ghost" size="sm" aria-label={`Actions for ${row.name}`}>
          <MoreHorizontal className="h-4 w-4" />
        </Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end">
        <DropdownMenuItem onSelect={() => onEdit(row)}>Edit</DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem className="text-destructive" onSelect={() => onRevoke(row)}>
          Revoke
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

Add it to the column list:

```tsx
{
  id: "actions",
  cell: ({ row }) => <RowActions row={row.original} onEdit={onEdit} onRevoke={onRevoke} />,
}
```

### Filtering and search

`DataTable` has a built-in search input and an optional `filterableColumns` set. Pass column-scoped filter definitions to render filter chips in the toolbar:

```tsx
<DataTable
  columns={columns}
  data={rows}
  searchPlaceholder="Search keys…"
  filterableColumns={[
    {
      id: "status",
      title: "Status",
      accessorKey: "status",
      options: [
        { label: "Active", value: "active" },
        { label: "Revoked", value: "revoked" },
      ],
    },
  ]}
/>;
```

For uses outside `DataTable`, filter the array yourself with `useMemo` before passing to the bare `Table` primitive.

### Dataset Pagination

`DataTable` does not ship a paginator out of the box. For very large datasets enable virtualization (`enableVirtualization`, `virtualizeThreshold`) to render thousands of rows without paging. For server-side pagination, page the data outside the component and pass the current slice to `data`.

Use `PaginationControl` when a table needs explicit first / previous / next / last controls, page size selection, and a visible `Page x of y` status. Do not use the `Pagination` component here; it is reserved for sibling page navigation.

### Empty, loading, and error states

Use the layout-level placeholders from `@nebutra/ui/layout` to keep state UI consistent across the app:

```tsx
import { EmptyState, LoadingState, ErrorState } from "@nebutra/ui/layout";

if (isLoading) return <LoadingState />;
if (error) return <ErrorState error={error} onRetry={refetch} />;
if (!rows.length) {
  return (
    <EmptyState
      title="No API keys"
      description="Create a key to start making requests."
    />
  );
}

return <DataTable columns={columns} data={rows} />;
```

## Examples

### API keys table (full pattern)

```tsx
"use client";

import { useState, useMemo } from "react";
import { DataTable, Button } from "@nebutra/ui/components";
import { Section, EmptyState, LoadingState, ErrorState } from "@nebutra/ui/layout";
import type { ColumnDef } from "@tanstack/react-table";

export function ApiKeysTable() {
  const { data, isLoading, error, refetch } = useApiKeys();
  const [revoking, setRevoking] = useState<string | null>(null);

  const columns = useMemo<ColumnDef<ApiKey>[]>(
    () => [
      {
        accessorKey: "name",
        header: "Name",
        cell: ({ row }) => <span className="font-medium">{row.original.name}</span>,
      },
      {
        accessorKey: "createdAt",
        header: "Created",
        cell: ({ row }) => new Date(row.original.createdAt).toLocaleDateString(),
      },
      {
        accessorKey: "lastUsedAt",
        header: "Last used",
        cell: ({ row }) =>
          row.original.lastUsedAt
            ? new Date(row.original.lastUsedAt).toLocaleDateString()
            : <span className="text-muted-foreground">Never</span>,
      },
      {
        id: "actions",
        cell: ({ row }) => (
          <RowActions row={row.original} onRevoke={(r) => setRevoking(r.id)} />
        ),
      },
    ],
    []
  );

  return (
    <Section
      title="API Keys"
      actions={<Button type="button" onClick={onCreateKey}>New key</Button>}
    >
      {isLoading ? (
        <LoadingState />
      ) : error ? (
        <ErrorState error={error} onRetry={refetch} />
      ) : !data?.length ? (
        <EmptyState
          title="No keys yet"
          description="Create your first API key."
        />
      ) : (
        <DataTable columns={columns} data={data} searchPlaceholder="Search keys…" />
      )}
    </Section>
  );
}
```
