---

> 本页此前记录了 `icons` 数组（三个图标、动画三联）、`theme` 和 `isIconAnimated` 属性。无论是
> `@nebutra/ui/layout` 的 `EmptyState`，还是底层 `@nebutra/ui/primitives` 的 `EmptyState.Root`，都
> 从未有过这些属性——两者都只接受**单个**图标。本页现在记录的是真实组件
> （`packages/design/ui/src/layout/EmptyState.tsx`）。

## 演示

```tsx
import { EmptyState } from "@nebutra/ui/layout";
import { FolderOpen } from "@nebutra/icons";
import { Button } from "@nebutra/ui/components";

<EmptyState
  title="No projects yet"
  description="Create your first project to get started with Nebutra."
  icon={<FolderOpen />}
  action={<Button onClick={() => router.push("/projects/new")}>Create project</Button>}
/>;
```

## 用法

```tsx
import { EmptyState } from "@nebutra/ui/layout";
import { Database } from "@nebutra/icons";

export function PipelinesPage() {
  const { pipelines } = usePipelines();

  if (pipelines.length === 0) {
    return (
      <EmptyState
        title="No pipelines"
        description="Build your first pipeline to start processing events."
        icon={<Database />}
        action={<Button onClick={openCreateDialog}>New pipeline</Button>}
      />
    );
  }

  return <PipelineList pipelines={pipelines} />;
}
```

## 属性
### `EmptyStateProps`

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | `string` | — | **必填。** 主要信息 |
| `description` | `string` | — | 标题下方的补充说明 |
| `mascot` | `React.ReactNode` | — | 视觉锚点。省略且 `tone="branded"` 时渲染默认的 `<BrandMark>` |
| `icon` | `React.ReactNode` | — | 标题上方展示的内联图标。提供 `mascot` 时忽略 |
| `action` | `React.ReactNode` | — | 主操作节点——传入真实的 `Button`/`Link`，而不是配置对象 |
| `secondaryAction` | `React.ReactNode` | — | 次操作节点 |
| `tone` | `"default" \| "branded" \| "subtle"` | `"default"` | `default`：中性带边框状态。`branded`：首触面板的 `BrandMark` 锚点。`subtle`：更克制的内联状态 |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 控制内边距和文字比例 |
| `className` | `string` | — | 附加在根元素上的额外 class |

没有 `icons` 数组，没有 `theme` 属性，也没有 `isIconAnimated` 属性。`icon`（和 `mascot`）各自只接受一个节点。

`action` 和 `secondaryAction` 接受的是渲染节点，而不是 `{ label, onClick, icon }` 配置对象——传入真实的
`<Button>`（或 `<Link>`）元素。

## 示例
### 品牌化 tone

```tsx
<EmptyState
  title="Welcome to Nebutra"
  description="Connect your first data source to get started."
  tone="branded"
/>
```

### 克制样式 — 更安静的内联状态

```tsx
<EmptyState
  title="Nothing here yet"
  description="Items will appear once data is available."
  tone="subtle"
  size="sm"
/>
```

### 带次操作

```tsx
<EmptyState
  title="Failed to load data"
  description="An error occurred while fetching your resources."
  icon={<AlertCircle />}
  action={<Button onClick={refetch}>Retry</Button>}
  secondaryAction={<Link href="/support">Contact support</Link>}
/>
```

## 更高级的组合 — `@nebutra/ui/primitives`

`layout/EmptyState` 是围绕规范复合原语 `@nebutra/ui/primitives` 的 `EmptyState.Root` 的简化封装。
如果新的组合场景需要超出 `default`/`branded`/`subtle` 之外的变体（例如 `no-results`、
`permission`、`error`）或 `align` 控制，应直接使用该原语，而不是扩展这个封装组件的属性面。

## 可访问性
- 根元素渲染为 `<section>`，带 `role="region"` 和指向标题的 `aria-labelledby`。
- 提供 `description` 时，`aria-describedby` 会引用描述段落。
- 图标容器带 `aria-hidden="true"`——仅作装饰。
- `action`/`secondaryAction` 应为真实的可交互元素（`<button type="button">`、`<a>`）——组件本身不会为它们补充语义。
