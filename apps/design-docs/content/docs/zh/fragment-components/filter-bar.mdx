---
title: "FilterBar"
description: "把搜索输入与筛选控件组合在一起，用于收窄列表和表格视图。"
---

## 演示

```tsx
<FilterBar
  searchPlaceholder="搜索流水线..."
  filters={[
    {
      key: "status",
      label: "状态",
      options: [
        { value: "active", label: "运行中" },
        { value: "paused", label: "已暂停" },
        { value: "error", label: "错误" },
      ],
    },
    {
      key: "env",
      label: "环境",
      options: [
        { value: "production", label: "生产" },
        { value: "staging", label: "预发" },
      ],
    },
  ]}
  onSearchChange={(q) => setQuery(q)}
  onFilterChange={(key, value) => setFilters((f) => ({ ...f, [key]: value }))}
/>
```

## 用法

```tsx
import { FilterBar } from "@nebutra/ui";

export function ResourceList() {
  const [query, setQuery] = useState("");
  const [filters, setFilters] = useState<Record<string, string>>({});

  const filtered = resources.filter(
    (r) =>
      r.name.toLowerCase().includes(query.toLowerCase()) &&
      Object.entries(filters).every(([k, v]) => !v || r[k] === v),
  );

  return (
    <>
      <FilterBar
        searchPlaceholder="搜索资源..."
        filters={filterDefs}
        onSearchChange={setQuery}
        onFilterChange={(key, value) =>
          setFilters((prev) => ({ ...prev, [key]: value }))
        }
      />
      <ResourceTable data={filtered} />
    </>
  );
}
```

## 属性
| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `searchPlaceholder` | `string` | `"Search..."` | 搜索框内的占位文案 |
| `searchValue` | `string` | — | 搜索输入的受控值 |
| `onSearchChange` | `(value: string) => void` | — | 每次输入变化时触发 |
| `filters` | `FilterDefinition[]` | `[]` | 筛选分组定义数组 |
| `activeFilters` | `Record<string, string>` | `{}` | 当前激活筛选项的受控状态 |
| `onFilterChange` | `(key: string, value: string) => void` | — | 筛选选项变化时触发 |
| `onReset` | `() => void` | — | 点击“清除筛选”按钮时触发 |
| `showReset` | `boolean` | `true` | 有激活筛选项时是否显示重置按钮 |
| `className` | `string` | — | 根容器上的额外 class |

### `FilterDefinition`

```ts
interface FilterDefinition {
  key: string;
  label: string;
  options: Array<{ value: string; label: string }>;
}
```

## 示例
### 仅搜索（无筛选）

```tsx
<FilterBar
  searchPlaceholder="查找成员..."
  onSearchChange={setQuery}
  filters={[]}
/>
```

### 受控激活筛选状态

```tsx
<FilterBar
  searchValue={query}
  onSearchChange={setQuery}
  filters={filterDefs}
  activeFilters={activeFilters}
  onFilterChange={(key, value) =>
    setActiveFilters((prev) => ({ ...prev, [key]: value }))
  }
  onReset={() => {
    setQuery("");
    setActiveFilters({});
  }}
/>
```

## 可访问性
- 搜索输入使用 `role="searchbox"`，并提供 `aria-label="搜索"`。
- 每个筛选下拉框都有可见 `<label>` 关联。
- 筛选项变化时，激活筛选数量通过 `aria-live="polite"` 宣告。
- 重置按钮提供 `aria-label="清除全部筛选"`。
- 所有交互元素都可键盘访问，并遵循合理的 tab 顺序。
