## 用法

`Modal` 是构建在 Nebutra `Dialog` 之上的 compound API。它保留 Geist modal 的使用模型，同时把 focus management、title wiring、body spacing、inset panel 和 action row 收敛到统一 primitive 中。

```tsx
import { Button, Input, Modal } from "@nebutra/ui/primitives";
import { useRef, useState } from "react";

export function CreateProjectModal() {
  const [active, setActive] = useState(false);
  const cancelRef = useRef<HTMLButtonElement>(null);

  return (
    <>
      <Button onClick={() => setActive(true)}>New Project</Button>

      <Modal.Modal
        active={active}
        onClickOutside={() => setActive(false)}
        initialFocusRef={cancelRef}
      >
        <Modal.Body>
          <Modal.Header>
            <Modal.Title>Create Project</Modal.Title>
            <Modal.Subtitle>
              Create a workspace-scoped project with default observability.
            </Modal.Subtitle>
          </Modal.Header>

          <Modal.Inset>
            <Input aria-label="Project name" placeholder="Nebula Control Plane" />
          </Modal.Inset>
        </Modal.Body>

        <Modal.Actions>
          <Modal.Action ref={cancelRef} type="secondary" onClick={() => setActive(false)}>
            Cancel
          </Modal.Action>
          <Modal.Action onClick={() => setActive(false)}>Create Project</Modal.Action>
        </Modal.Actions>
      </Modal.Modal>
    </>
  );
}
```

## 属性

### `Modal.Modal`

| 属性 | 类型 | 默认值 | 描述 |
|---|---|---|---|
| `active` | `boolean` | — | 受控打开状态。 |
| `onClickOutside` | `() => void` | — | 用户通过外部点击或 Escape 请求关闭时调用。 |
| `sticky` | `boolean` | `false` | body 在面板内滚动，actions 固定在底部。 |
| `initialFocusRef` | `RefObject<HTMLElement \| null>` | — | 打开后聚焦的元素；危险流程应指向 Cancel。 |
| `className` | `string` | — | dialog content panel 的额外类名。 |
| `children` | `ReactNode` | — | compound modal 内容。 |

### 布局部件

| 部件 | 类型 | 描述 |
|---|---|---|
| `Modal.Body` | `HTMLAttributes<HTMLDivElement>` | 主内容区域；`sticky` 为 true 时在内部滚动。 |
| `Modal.Header` | `HTMLAttributes<HTMLDivElement>` | 标题和说明组合。 |
| `Modal.Title` | `HTMLAttributes<HTMLHeadingElement>` | 自动把 `aria-labelledby` 接到 dialog content。 |
| `Modal.Subtitle` | `HTMLAttributes<HTMLParagraphElement>` | 辅助说明文案。 |
| `Modal.Inset` | `HTMLAttributes<HTMLDivElement>` | 用于表单行、元数据或风险上下文的 recessed panel。 |
| `Modal.Actions` | `HTMLAttributes<HTMLDivElement>` | 底部动作行。 |

### `Modal.Action`

| 属性 | 类型 | 默认值 | 描述 |
|---|---|---|---|
| `type` | `"primary" \| "secondary"` | `"primary"` | 视觉动作优先级，映射到 Button variants。 |
| `buttonType` | `"button" \| "submit" \| "reset"` | `"button"` | 用于表单集成的原生 button type。 |
| `fullWidth` | `boolean` | `false` | 让动作按钮横向铺满。 |
| `prefix` | `ReactNode` | — | 可选前置图标。 |

## 可访问性

- Focus trap、Escape 关闭、关闭后回到触发器由底层 `Dialog` 提供。
- `Modal.Title` 会自动通过 `aria-labelledby` 关联 dialog；不要手动重复 title id。
- 危险或高风险决策应通过 `initialFocusRef` 默认聚焦 Cancel。
- 主动作在源码顺序中放最后，让键盘和屏幕阅读器用户先经过 review/cancel 选项。
- 高风险删除动作使用 `DestructiveActionModal`，或在 `Modal.Inset` 内加入 typed confirmation gate。

## 设计契约

- 只有当页面其余区域必须被阻塞，直到用户完成决策或聚焦任务时，才使用 `Modal`。
- 周边页面上下文仍需可读时使用 `Sheet` 或 `Drawer`；字段很多的常规创建/编辑流程应放到独立页面。
- 标题使用简短 Title Case 陈述，不写问句。副标题使用 sentence case，说明后果、作用域或下一步。
- 普通流程保持两个动作按钮。超过两个动作通常说明这个流程应该升级为页面级 surface。
