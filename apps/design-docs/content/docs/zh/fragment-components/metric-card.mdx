## 使用场景

`MetricCard` 用于 dashboard、侧栏和运营摘要中的高密度指标行。它比 `KpiCard` 更轻：默认没有卡片外壳，提供可选 bordered wrapper，并使用更紧凑的字号。

相邻指标需要按二到四列对齐时使用 `MetricGrid`。只有指标需要独立 frame 时才使用 `MetricCardBordered`。

## 用法

```tsx
import { MetricCard, MetricCardBordered, MetricGrid } from "@nebutra/ui/primitives";

<MetricGrid columns={3}>
  <MetricCardBordered
    label="Events ingested"
    value="2.4M"
    trend="up"
    trendValue="+12%"
    description="vs last week"
  />
  <MetricCardBordered
    label="Error rate"
    value="0.18%"
    trend="down"
    trendValue="-0.3%"
    description="lower is better"
  />
</MetricGrid>
```

## 结构

- `MetricCard` 渲染指标 label、value、可选 trend、可选 icon 和可选 description。
- `MetricGrid` 负责二、三、四列对齐。
- `MetricCardBordered` 用 token 化 border 和 card background 包住 `MetricCard`。
- `StatItem` 渲染带状态点、label 和 value 的紧凑 inline stat。

## 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `label` | `string` | — | 值上方的简短指标描述。 |
| `value` | `number \| string` | — | 主指标值。数字会进行 locale-format。 |
| `trend` | `"up" \| "down" \| "neutral"` | — | 可选趋势方向。 |
| `trendValue` | `string` | — | 例如 `+12%` 的紧凑趋势文本。 |
| `description` | `string` | — | value row 下方的弱化说明。 |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | 字号密度。 |
| `icon` | `ReactNode` | — | label 前的装饰性图标。 |
| `className` | `string` | — | 外层样式扩展。 |

### MetricGrid

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `children` | `ReactNode` | — | Metric card 或 stat item。 |
| `columns` | `2 \| 3 \| 4` | `3` | Grid 列数。 |
| `className` | `string` | — | Grid 样式覆盖。 |

## 状态

| 状态 | 契约 |
|------|------|
| Up | 使用上升图标和 success tone。 |
| Down | 使用下降图标和 error tone。 |
| Neutral | 使用中性图标和 muted tone。 |
| Bordered | 增加 frame，但不改变底层 metric API。 |

## 可访问性

- 趋势方向必须同时由图标、文字和颜色表达。
- 图标是装饰性的；label 和 value 保持文本。
- 相关指标应由父级 dashboard section 提供可见 heading。
- 不要把 `MetricCard` 当作无名按钮；需要跳转时用有名称的控制包裹。

## 设计契约

- `MetricCard` 用于高密度运营对比；顶层 executive summary 使用 `KpiCard`。
- Label 保持短，value 使用 tabular 读感。长解释放在外层 copy 或详情页。
- Trend polarity 表示真实方向，不按指标反转颜色；“lower is better” 写进 `description`。
- `MetricCardBordered` 是组合 helper，不是新的语义 variant。
