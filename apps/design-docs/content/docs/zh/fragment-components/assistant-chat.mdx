## 演示

```tsx
<AssistantChat
  assistantName="Nebula"
  assistantAvatar="/avatars/nebula.png"
  messages={[
    {
      id: "1",
      role: "user",
      content: "总结过去 7 天的错误趋势。",
      timestamp: "10:01",
    },
    {
      id: "2",
      role: "assistant",
      content: "过去 7 天，94% 的错误来自支付服务...",
      timestamp: "10:01",
    },
  ]}
  onSend={(message) => console.log(message)}
/>
```

## 用法

```tsx
import { AssistantChat } from "@nebutra/ui";

export function SupportPanel() {
  const [messages, setMessages] = useState<ChatMessage[]>([]);

  async function handleSend(content: string) {
    const userMsg = { id: crypto.randomUUID(), role: "user", content, timestamp: new Date().toLocaleTimeString() };
    setMessages((prev) => [...prev, userMsg]);

    const reply = await fetchAIReply(content);
    setMessages((prev) => [...prev, { id: crypto.randomUUID(), role: "assistant", content: reply, timestamp: new Date().toLocaleTimeString() }]);
  }

  return (
    <AssistantChat
      assistantName="Nebula"
      messages={messages}
      onSend={handleSend}
      isLoading={false}
    />
  );
}
```

## 属性
| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `assistantName` | `string` | `"Assistant"` | 助手消息头中展示的显示名称 |
| `assistantAvatar` | `string` | — | 助手头像图片 URL |
| `messages` | `AssistantChatMessage[]` | `[]` | 按顺序展示的消息数组 |
| `onSend` | `(content: string) => void` | — | 用户提交消息时触发 |
| `isLoading` | `boolean` | `false` | 在最后一条助手消息下方展示输入中状态 |
| `inputPlaceholder` | `string` | `"Ask anything..."` | 消息输入框的占位文案 |
| `className` | `string` | — | 根容器上的额外 class |

### `AssistantChatMessage`

```ts
interface AssistantChatMessage {
  id: string;
  role: "user" | "assistant";
  content: string;
  timestamp: string;
}
```

## 示例
### 空状态

当 `messages` 为空时，组件会渲染带建议提示的欢迎界面。

```tsx
<AssistantChat
  assistantName="Nebula"
  messages={[]}
  onSend={handleSend}
/>
```

### 带加载指示器

```tsx
<AssistantChat
  assistantName="Nebula"
  messages={messages}
  onSend={handleSend}
  isLoading={true}
/>
```

### 全页布局

```tsx
<div className="h-screen flex flex-col">
  <AssistantChat
    assistantName="Nebula"
    messages={messages}
    onSend={handleSend}
    className="flex-1"
  />
</div>
```

## 可访问性
- 消息列表渲染在带 `role="log"` 与 `aria-live="polite"` 的区域中，便于屏幕阅读器宣告新消息。
- 发送按钮提供 `aria-label="发送消息"`。
- `isLoading` 输入中指示器提供 `aria-label="助手正在输入"` 与 `aria-busy="true"`。
- 用户可以用 `Enter` 提交；`Shift+Enter` 插入换行。
- 输入框通过 `aria-label` 关联可访问名称。
