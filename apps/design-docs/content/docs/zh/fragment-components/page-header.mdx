> 本页此前记录了一个通过 `@nebutra/ui` 导入、用 `@primer/react` 的 `Breadcrumbs` 渲染的
> `breadcrumbs` 属性。`@primer/react` 已从仓库中彻底移除，`PageHeader` 从未有过 `breadcrumbs` 或
> `children` 属性，正确的导入路径是 `@nebutra/ui/layout`。本页现在记录的是真实组件
> （`packages/design/ui/src/layout/PageHeader.tsx`）。

## 演示

```tsx
import { PageHeader } from "@nebutra/ui/layout";
import { Button } from "@nebutra/ui/components";

<PageHeader
  title="Pipeline settings"
  description="Configure ingestion rules, filters, and destinations."
  actions={<Button variant="primary">Save changes</Button>}
/>;
```

## 用法

```tsx
import { PageHeader } from "@nebutra/ui/layout";
import { Button } from "@nebutra/ui/components";

export function PipelineSettingsPage({ pipeline }: { pipeline: Pipeline }) {
  return (
    <div className="p-6">
      <PageHeader
        title={pipeline.name}
        description={`Last updated ${formatRelative(pipeline.updatedAt)}`}
        actions={
          <div className="flex gap-2">
            <Button variant="secondary" onClick={handleDisable}>Pause</Button>
            <Button onClick={handleSave}>Save</Button>
          </div>
        }
      />

      <PipelineForm pipeline={pipeline} />
    </div>
  );
}
```

## 属性
### `PageHeaderProps`

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | `string` | — | **必填。** 渲染为 `<h1>` 的页面标题 |
| `description` | `string` | — | 标题下方的次要描述文字 |
| `actions` | `React.ReactNode` | — | 操作控件（按钮、菜单），窄屏下堆叠在标题下方，`sm:` 及以上锚定在右侧 |
| `className` | `string` | — | 附加在根元素上的额外 class |

没有 `breadcrumbs` 属性，也没有 `children` 槽位。面包屑、标签页或其他内容应作为 `PageHeader` 的
兄弟节点渲染，而不是放进它内部。

## 示例
### 仅标题

```tsx
<PageHeader title="Members" />
```

### 无操作

```tsx
<PageHeader
  title="Analytics"
  description="Usage metrics for the last 30 days."
/>
```

### 仅操作

```tsx
<PageHeader
  title="API keys"
  actions={
    <Button onClick={() => setOpen(true)}>
      Generate key
    </Button>
  }
/>
```

### 下方带标签页

由于 `PageHeader` 没有 `children` 槽位，标签页（或任何其他内容）应作为兄弟节点渲染：

```tsx
<PageHeader title="Analytics" description="Usage metrics for the last 30 days." />
<Tabs className="mt-4">
  <Tab>Overview</Tab>
  <Tab>Events</Tab>
  <Tab>Errors</Tab>
</Tabs>
```

## 可访问性
- `title` 渲染为 `<h1>`——每个页面必须恰好有一个 `<h1>`。
- 根元素是普通 `<div>`，不带隐式 landmark role。若上层还没有 `<main>`（或等效 landmark），
  需要在更高层级包裹一层。
- `actions` 槽位没有隐式 landmark role；若其中包含导航内容，请用
  `<nav aria-label="Page actions">` 包裹。
- `description` 是纯 `<p>` 文本——不要把它作为关键指示的唯一来源。
