## 何时使用

当你需要从用户处采集结构化数据，并进行校验或提交时，使用表单模式。它覆盖以下场景：

- 设置面板（账户、账单、通知偏好）
- 创建 / 编辑流程（新建资源、inline edit）
- 认证表单（登录、注册）
- 需要用户输入确认文本的确认对话框

不要把该模式套到单字段快速编辑上。对于保存即变更的单个 toggle 或 select，直接使用 atom 组件（`Switch`、`Select`），不要额外搭建表单脚手架。

## 结构

```
<Form> (react-hook-form + zod)
  └── FormField (one per field)
       └── FormItem
            ├── FormLabel
            ├── FormControl
            │    └── Input | Textarea | Select | Checkbox | RadioGroup
            ├── FormDescription (hint text)
            └── FormMessage (validation error)
  └── Button type="submit"
```

## 组合规则

### 基础字段

每个字段都遵循一致的 `FormField → FormItem → FormControl` 结构。`FormMessage` 会根据 schema 自动渲染校验错误。

```tsx
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";
import {
  Form,
  FormField,
  FormItem,
  FormLabel,
  FormControl,
  FormDescription,
  FormMessage,
  Input,
  Button,
} from "@nebutra/ui";

const schema = z.object({
  name: z.string().min(1, "Name is required"),
});

export function CreateKeyForm({ onSubmit }: { onSubmit: (v: z.infer<typeof schema>) => void }) {
  const form = useForm({ resolver: zodResolver(schema) });

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-6">
        <FormField
          control={form.control}
          name="name"
          render={({ field }) => (
            <FormItem>
              <FormLabel>API key name</FormLabel>
              <FormControl>
                <Input placeholder="e.g. production-server" {...field} />
              </FormControl>
              <FormDescription>
                Used to identify this key in audit logs.
              </FormDescription>
              <FormMessage />
            </FormItem>
          )}
        />
        <Button type="submit">Create key</Button>
      </form>
    </Form>
  );
}
```

### 校验

Schema 是校验规则的唯一真相源。`FormMessage` 会自动呈现错误，不需要手写 error state。

```tsx
const schema = z.object({
  email: z.string().email("Enter a valid email address"),
  age: z.number().min(18, "Must be 18 or older"),
});
```

新表单默认在 `onBlur` 时校验。首次提交后切换到 `onChange`，用于实时纠错反馈。

```tsx
const form = useForm({
  resolver: zodResolver(schema),
  mode: "onBlur",
});
```

### Select 字段

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@nebutra/ui";

<FormField
  control={form.control}
  name="permission"
  render={({ field }) => (
    <FormItem>
      <FormLabel>Permission</FormLabel>
      <Select onValueChange={field.onChange} defaultValue={field.value}>
        <FormControl>
          <SelectTrigger>
            <SelectValue placeholder="Select a permission" />
          </SelectTrigger>
        </FormControl>
        <SelectContent>
          <SelectItem value="read">Read only</SelectItem>
          <SelectItem value="write">Read + write</SelectItem>
        </SelectContent>
      </Select>
      <FormMessage />
    </FormItem>
  )}
/>
```

### Checkbox 字段

```tsx
import { Checkbox } from "@nebutra/ui";

<FormField
  control={form.control}
  name="acceptTerms"
  render={({ field }) => (
    <FormItem className="flex items-start gap-3">
      <FormControl>
        <Checkbox checked={field.value} onCheckedChange={field.onChange} />
      </FormControl>
      <div>
        <FormLabel>Accept terms and conditions</FormLabel>
        <FormMessage />
      </div>
    </FormItem>
  )}
/>
```

### 提交与取消

提交 / 取消操作放在表单末尾。破坏性操作应放在单独区块，并在按钮上方提供明确警告。

```tsx
<div className="flex gap-2 pt-4">
  <Button type="submit" disabled={form.formState.isSubmitting}>
    {form.formState.isSubmitting ? "Saving…" : "Save changes"}
  </Button>
  <Button type="button" variant="ghost" onClick={onCancel}>
    Cancel
  </Button>
</div>
```

### 必填字段

直接在 label 上标注必填。不要在没有解释图例的情况下只依赖星号。

```tsx
<FormItem>
  <FormLabel>
    Organization name <span aria-hidden="true" className="text-destructive">*</span>
  </FormLabel>
  <FormControl>
    <Input required {...field} />
  </FormControl>
  <FormMessage />
</FormItem>
```

### 复杂输入类型

| 使用场景 | 组件 |
|---|---|
| 长文本 | `Textarea` |
| 从列表中单选 | `Select` 或 `RadioGroup` |
| 二元开关 | `Checkbox` 或 `Switch` |
| 固定列表多选 | `MultiSelect` 组件 |
| 可搜索、带标签的多选 | `MultipleSelector` 组件 |
| 日期 | `DatePicker` |
| OTP / PIN | `InputOtp` |

## 示例
### 创建 API Key 表单

```tsx
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";
import {
  Form, FormField, FormItem, FormLabel, FormControl, FormMessage,
  Input, Button,
  Select, SelectTrigger, SelectValue, SelectContent, SelectItem,
} from "@nebutra/ui";

const schema = z.object({
  name: z.string().min(1, "Key name is required"),
  permission: z.enum(["read", "write"]),
});

type FormValues = z.infer<typeof schema>;

export function CreateKeyForm({
  onSubmit,
  onCancel,
}: {
  onSubmit: (v: FormValues) => void;
  onCancel: () => void;
}) {
  const form = useForm<FormValues>({
    resolver: zodResolver(schema),
    defaultValues: { name: "", permission: "read" },
  });

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-4">
        <FormField
          control={form.control}
          name="name"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Name</FormLabel>
              <FormControl>
                <Input placeholder="e.g. production-server" {...field} />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="permission"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Permission</FormLabel>
              <Select onValueChange={field.onChange} defaultValue={field.value}>
                <FormControl>
                  <SelectTrigger>
                    <SelectValue />
                  </SelectTrigger>
                </FormControl>
                <SelectContent>
                  <SelectItem value="read">Read only</SelectItem>
                  <SelectItem value="write">Read + write</SelectItem>
                </SelectContent>
              </Select>
              <FormMessage />
            </FormItem>
          )}
        />

        <div className="flex gap-2 pt-2">
          <Button type="submit">Create key</Button>
          <Button type="button" variant="ghost" onClick={onCancel}>
            Cancel
          </Button>
        </div>
      </form>
    </Form>
  );
}
```
