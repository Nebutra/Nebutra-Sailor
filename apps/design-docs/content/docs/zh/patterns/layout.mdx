## 何时使用

每当组合新页面或主要页面区域时，都应该使用布局模式。布局决策会影响信息层级、响应式行为，以及整个应用的间距一致性。

以下场景使用该模式：
- 完整应用页面（仪表盘、设置、详情页）
- 页面内的内容区块（字段分组、数据区域）
- 营销页和文档页外壳

## 结构

### 仪表盘页面布局

```
<div className="min-h-screen bg-gray-50">       ← page shell
  <Header>                                        ← global nav
  <main>
    <Container size="xl">                         ← width constraint
      <PageHeader title="…" breadcrumbs={…} />   ← page-level heading
      <Section title="Overview">                  ← logical group
        <div className="grid gap-6 md:grid-cols-3">
          <Card>…</Card>
          <Card>…</Card>
          <Card>…</Card>
        </div>
      </Section>
      <Section title="Recent activity">
        {/* table or list */}
      </Section>
    </Container>
  </main>
</div>
```

### 双栏设置布局

```
<Container size="lg">
  <PageHeader title="Settings" />
  <div className="grid gap-8 md:grid-cols-[240px_1fr]">
    <NavList>                         ← settings nav (inner side menu)
      <NavList.Item href="/settings/general">General</NavList.Item>
      <NavList.Item href="/settings/api-keys">API Keys</NavList.Item>
    </NavList>
    <div>
      <Section title="General">…</Section>
    </div>
  </div>
</Container>
```

## 组合规则

### Container 容器

`Container` 约束最大宽度，并应用响应式水平 padding（`px-4 sm:px-6 lg:px-8`）。它应该作为 `<main>` 内最外层包装器使用。

```tsx
import { Container } from "@nebutra/ui";

// wide = max-w-[1400px] — Landing page 区块、Feature Bento
<Container size="wide">…</Container>

// xl = max-w-7xl (1280px) — Dashboard 标准宽度
<Container size="xl">…</Container>

// lg = max-w-5xl (1012px) — 设置、表单
<Container size="lg">…</Container>

// md = max-w-3xl — 文本密集型单列页面
<Container size="md">…</Container>
```

尺寸参考：

| Size | Max-width | CSS Variable | 用途 |
|---|---|---|---|
| `sm` | 544px | — | 窄模态框、确认对话框 |
| `md` | 768px | — | 单列内容 |
| `lg` | 1012px | — | 设置、表单、文档 |
| `xl` | 1280px | — | Dashboard 全页 |
| `wide` | 1400px | `--container-wide` | Landing page 区块、Feature Bento、导航栏 |
| `full` | 100% | — | 全宽表格、出血区块 |

### PageHeader 页头

`PageHeader` 应该紧跟在 `Container` 内，并位于第一个 `Section` 之前。它负责页面级标题、描述、面包屑和主操作。

```tsx
import { PageHeader } from "@nebutra/ui";
import { Button } from "@nebutra/ui";

<PageHeader
  title="API Keys"
  description="Manage programmatic access to the Nebutra API."
  breadcrumbs={[
    { label: "Settings", href: "/settings" },
    { label: "API Keys" },
  ]}
  actions={
    <Button variant="primary" onClick={onCreate}>
      New key
    </Button>
  }
/>
```

### Section 区块

`Section` 将相关内容组织在一个 `h2` 标题下。它会添加底部 `mb-6` 间距，并为标题与可选操作提供 flex 行布局。

```tsx
import { Section } from "@nebutra/ui";

<Section title="Usage this month" description="Resets on the 1st.">
  {/* charts, cards, table */}
</Section>
```

当区块不需要可见标题时（例如紧跟 `PageHeader` 的卡片网格），省略所有 Section props，把它仅作为间距包装器使用。

### 网格布局

响应式卡片网格使用 Tailwind grid utilities。间距 primitive 以 4px 为基础单位：卡片网格使用 `gap-6`（24px），紧凑表单行使用 `gap-4`（16px）。

```tsx
// 3-column stat card grid
<div className="grid gap-6 md:grid-cols-2 lg:grid-cols-3">
  <Card>…</Card>
  <Card>…</Card>
  <Card>…</Card>
</div>

// 2-column form layout
<div className="grid gap-4 sm:grid-cols-2">
  <FormControl>…</FormControl>
  <FormControl>…</FormControl>
</div>
```

网格 preset 参考 `primitives/layout.ts`：`gridLayouts.two`、`gridLayouts.three`、`gridLayouts.four`、`gridLayouts.auto`。

### 间距尺度

设计系统使用 4px 基础单位。常用值如下：

| Token | px | Tailwind | 用途 |
|---|---|---|---|
| `spacing[3]` | 16 | `gap-4` | 紧凑表单行 |
| `spacing[4]` | 24 | `gap-6` | 卡片网格、区块间距 |
| `spacing[5]` | 32 | `gap-8` | 区块之间 |
| `spacing[8]` | 64 | `pt-16` | 页面级垂直留白 |

### Z-index 分层

重叠层级使用 `primitives/layout.ts` 中的 z-index scale。不要使用任意 z-index 值。

| 层级 | 值 | 用途 |
|---|---|---|
| `base` | 0 | 正常文档流 |
| `dropdown` | 1000 | ActionMenu、Select dropdown |
| `sticky` | 1020 | 粘性表头 |
| `fixed` | 1030 | 全局导航栏 |
| `modalBackdrop` | 1040 | Dialog / Drawer 遮罩 |
| `modal` | 1050 | Dialog / Drawer 面板 |
| `tooltip` | 1070 | Tooltip |

## 示例
### 仪表盘首页

`apps/web/src/app/(dashboard)/page.tsx` 中的仪表盘页面遵循以下结构：

```tsx
<div className="min-h-screen bg-gray-50">
  <main className="mx-auto max-w-7xl px-4 py-6 sm:px-6 lg:px-8">
    <PageHeader title="Dashboard" />
    <div className="grid gap-6 md:grid-cols-2 lg:grid-cols-3">
      <Card>Welcome card</Card>
      <Card>API Calls stat</Card>
      <Card>AI Tokens stat</Card>
    </div>
  </main>
</div>
```

新页面中用 `<Container size="xl">` 替代 `mx-auto max-w-7xl`，以便自动继承后续 Container 变更。
