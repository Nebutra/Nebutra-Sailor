## 何时使用

根据目标页面的层级深度与访问频率选择导航模式。

| 模式 | 适用场景 |
|---|---|
| `Header` | 顶层全局导航，始终可见 |
| `NavList` / `Sidebar` | 二级区块导航（设置、管理区） |
| `UnderlineNav` / `Tabs` | 同一资源的同级视图（概览、动态、设置） |
| `Breadcrumbs` | 嵌套资源树中的层级位置 |
| `Pagination` | 在一组同级页面之间前后移动 |
| `TreeView` | 文件系统或嵌套条目的层级导航 |

## 结构

### 全局页头

```
Header
  ├── Header.Item full → brand / logo
  ├── Header.Item → primary nav links (UnderlineNav or links)
  └── Header.Item → auth controls (UserButton, SignIn, SignUp)
```

### 设置页导航

```
<div className="grid gap-8 md:grid-cols-[240px_1fr]">
  NavList                                ← vertical nav
    NavList.Group (optional label)
      NavList.Item (active state)
      NavList.Item
  <div>
    Section content                      ← main panel
  </div>
</div>
```

### 标签页导航（同级视图）

```
UnderlineNav (or Tabs)
  UnderlineNav.Item (current page)
  UnderlineNav.Item
  UnderlineNav.Item
<div>
  {/* content for active tab */}
</div>
```

### 面包屑路径

```
PageHeader
  breadcrumbs={[
    { label: "Settings", href: "/settings" },
    { label: "API Keys", href: "/settings/api-keys" },
    { label: "Production key" },     ← current page, no href
  ]}
```

## 组合规则

### 全局页头

`apps/web/src/app/providers/design-system-shell.tsx` 中的应用 shell 展示了标准 `Header` 模式。`Header.Item full` 占据剩余空间（flex-grow）；后续 `Header.Item` 会排列到右侧。

```tsx
import { Header, Button } from "@nebutra/ui";

<Header>
  <Header.Item full>
    <span className="text-xl font-bold">Nebutra</span>
  </Header.Item>
  <Header.Item>
    {/* auth controls */}
  </Header.Item>
</Header>
```

`Header` 位于 `<main>` 外部。主内容可通过 `min-h-[calc(100vh-64px)]` 使用剩余视口高度。

### NavList（设置侧边栏）

```tsx
import { NavList } from "@nebutra/ui";

<NavList aria-label="Settings navigation">
  <NavList.Group title="Account">
    <NavList.Item href="/settings/general" aria-current={isGeneral ? "page" : undefined}>
      General
    </NavList.Item>
    <NavList.Item href="/settings/api-keys" aria-current={isApiKeys ? "page" : undefined}>
      API Keys
    </NavList.Item>
  </NavList.Group>
  <NavList.Group title="Organisation">
    <NavList.Item href="/settings/members">Members</NavList.Item>
    <NavList.Item href="/settings/billing">Billing</NavList.Item>
  </NavList.Group>
</NavList>
```

给当前项添加 `aria-current="page"`。`NavList` 会渲染为 `<nav>`，必须提供 `aria-label`，以便和页面上其他 `<nav>` 区分。

### UnderlineNav（标签页导航）

同一实体的同级视图切换使用 `UnderlineNav`。该组件渲染为 `<nav>`，并用下划线标识当前项。

```tsx
import { UnderlineNav } from "@nebutra/ui";

<UnderlineNav aria-label="Key details">
  <UnderlineNav.Item href={`/keys/${id}`} aria-current={tab === "overview" ? "page" : undefined}>
    Overview
  </UnderlineNav.Item>
  <UnderlineNav.Item href={`/keys/${id}/logs`} aria-current={tab === "logs" ? "page" : undefined}>
    Logs
  </UnderlineNav.Item>
</UnderlineNav>
```

如果需要不改变 URL 的客户端标签切换（例如模态框内部），使用 `Tabs` atom。

### Breadcrumbs 面包屑

向 `PageHeader` 传入 `breadcrumbs` prop。数组最后一项会渲染为当前页（无链接，并在 `Breadcrumbs.Item` 上设置 `selected={true}`）。

```tsx
<PageHeader
  title="Production key"
  breadcrumbs={[
    { label: "Settings", href: "/settings" },
    { label: "API Keys", href: "/settings/api-keys" },
    { label: "Production key" },
  ]}
/>
```

面包屑适用于嵌套 2 层或更深的资源。不要在顶层页面（Dashboard、Settings root）添加面包屑。

### Pagination 分页

当用户需要在文档文章、博客文章或 onboarding 步骤的相邻页面之间移动时，在底部使用 `Pagination`。

```tsx
import { Pagination } from "@nebutra/ui";

<Pagination
  previous={{ title: "Home", href: "/docs" }}
  next={{ title: "Introduction", href: "/docs/introduction" }}
/>
```

对于大型有序结果集，改用 `PaginationControl` 或表格专用分页模式。

### 目录

长内容页面使用 `TableOfContents` fragment。它会渲染粘性右侧目录，并随滚动高亮当前区块。

## 示例
### 使用 NavList 的设置页布局

```tsx
export default function SettingsLayout({ children }: { children: ReactNode }) {
  const pathname = usePathname();

  return (
    <Container size="lg">
      <PageHeader title="Settings" />
      <div className="grid gap-8 md:grid-cols-[240px_1fr]">
        <NavList aria-label="Settings">
          <NavList.Item
            href="/settings"
            aria-current={pathname === "/settings" ? "page" : undefined}
          >
            General
          </NavList.Item>
          <NavList.Item
            href="/settings/api-keys"
            aria-current={pathname.startsWith("/settings/api-keys") ? "page" : undefined}
          >
            API Keys
          </NavList.Item>
        </NavList>
        <div>{children}</div>
      </div>
    </Container>
  );
}
```
