## 何时使用

任何可能进入以下三种非正常状态的数据表面，都需要有对应状态：

| 条件 | 组件 | 触发时机 |
|---|---|---|
| 零数据 | `EmptyState` | 查询返回空数组 |
| 请求中 | `LoadingState` | 异步请求未完成 |
| 失败 | `ErrorState` | 请求抛错或被拒绝 |

这些状态应该出现在被替换内容的同一层级：`Card` 内、`Section` 内，或整页区域中。不要留下空白区域。

## 结构

### 空状态

```
EmptyState
  ├── icon (optional, 48×48 SVG)
  ├── title (required, h3)
  ├── description (optional, muted text)
  └── actions (optional, Button or ButtonGroup)
```

### 加载状态

```
LoadingState
  ├── Spinner (size: small | medium | large)
  └── message (optional, muted text)
```

### 错误状态

```
ErrorState
  ├── AlertIcon (fixed, red)
  ├── title (defaults to "Something went wrong")
  ├── message (derived from error.message or explicit prop)
  └── onRetry → Button ("Try again")
```

## 组合规则

### EmptyState 组件

列表、表格或数据区域没有记录时使用。只要用户能直接解决空状态，就必须提供动作入口。

```tsx
import { EmptyState } from "@nebutra/ui";
import { PlusIcon } from "@primer/octicons-react";
import { Button } from "@nebutra/ui";

<EmptyState
  icon={<PlusIcon />}
  title="No API keys yet"
  description="Create your first key to start making requests."
  actions={
    <Button variant="primary" onClick={onCreateKey}>
      Create key
    </Button>
  }
/>
```

Props：

| 属性 | 类型 | 默认值 |
|---|---|---|
| `title` | `string` | required |
| `description` | `string` | — |
| `icon` | `ReactNode` | — |
| `actions` | `ReactNode` | — |
| `className` | `string` | — |

### LoadingState 组件

请求进行中时替换数据区域。整页加载使用 `size="large"`；紧凑卡片内使用 `size="small"`。

```tsx
import { LoadingState } from "@nebutra/ui";

// Inside a section
<LoadingState size="medium" message="Fetching usage data…" />

// Full-page
<div className="min-h-screen flex items-center justify-center">
  <LoadingState size="large" />
</div>
```

复杂页面包含多个区域时，优先使用分区域 `LoadingState`，而不是单个全页 spinner。这样用户可以更早看到已加载的局部内容。

### ErrorState 组件

当操作具备幂等性，且无需用户重新输入即可重试时，提供 `onRetry`。

```tsx
import { ErrorState } from "@nebutra/ui";

<ErrorState
  title="Failed to load usage"
  error={error}
  onRetry={refetch}
  retryLabel="Retry"
/>
```

对于不可直接恢复的错误（认证、权限），省略 `onRetry`，改为渲染链接到解决路径的 `Button`。

### Skeleton（替代加载模式）

在内容密集且需要布局稳定的页面中，使用 `Skeleton` atom 替代 `LoadingState`。Skeleton 会匹配真实内容形状，并减少布局位移。

```tsx
import { Skeleton } from "@nebutra/ui";

// 指标卡片骨架占位
<div className="space-y-2">
  <Skeleton className="h-4 w-24" />
  <Skeleton className="h-8 w-16" />
</div>
```

加载时长不可预测时使用 `LoadingState`（spinner）。内容形状和数量已知时使用 `Skeleton`。

## 示例
### 同时覆盖三种状态的表格

```tsx
function UsageTable() {
  const { data, isLoading, error, refetch } = useUsage();

  if (isLoading) return <LoadingState size="medium" />;
  if (error)     return <ErrorState error={error} onRetry={refetch} />;
  if (!data?.length) {
    return (
      <EmptyState
        title="No usage recorded"
        description="Usage will appear here once you make your first API call."
      />
    );
  }

  return <DataTable data={data} columns={columns} />;
}
```
