## 何时使用

需要以表格展示结构化数据时使用此模式：
- 用户需要跨行跨列对比数值
- 数据有明确 schema（每行的列固定一致）
- 用户可能需要排序、筛选或对单行操作

下列情况优先使用表格而非卡片列表：
- 每条记录有 4 个或以上属性需要列对齐
- 需要按列排序与筛选

下列情况**不要**使用表格：
- 各项异构（每条记录属性不同）—— 用列表或卡片
- 列数少于 3 列 —— 用定义列表或 `Card` 网格

## 两种表格 API

`@nebutra/ui` 提供两套互补的表格 API，按能力选择：

| 用途 | API |
|---|---|
| 静态或简单列表，自己控制 thead/tbody 标记 | `Table` 原语（`Table`、`TableHeader`、`TableBody`、`TableRow`、`TableHead`、`TableCell`） |
| 可排序、可筛选、虚拟化、带工具条 / 列显隐 / 单元格选区 | `DataTable` 模式（底层基于 TanStack Table） |

两者都是 tree-shake 的，未导入则不会进 bundle。

## 结构

```
Section（标题 + 描述 + 表级操作）                    // 来自 @nebutra/ui/layout
  ├── DataTable                                     // 内置工具条处理搜索 + 筛选
  │    └── (渲染表格，sticky header、可选虚拟化、列宽可拖拽)
  ├── EmptyState（数据为空时）                       // 来自 @nebutra/ui/layout
  └── LoadingState / ErrorState（状态占位）
```

静态内容把 `DataTable` 换成原生 `Table` 原语即可。

## 组合方式

### DataTable（推荐用于交互列表）

`DataTable<TData>` 接收 TanStack 的 `ColumnDef[]` 与 `TData[]`。工具条（搜索、筛选、列显隐、额外操作）默认开启。

```tsx
import { DataTable } from "@nebutra/ui/components";
import type { ColumnDef } from "@tanstack/react-table";

type ApiKey = {
  id: string;
  name: string;
  createdAt: string;
  status: "active" | "revoked";
};

const columns: ColumnDef<ApiKey>[] = [
  {
    accessorKey: "name",
    header: "名称",
    cell: ({ row }) => <span className="font-medium">{row.original.name}</span>,
  },
  {
    accessorKey: "createdAt",
    header: "创建时间",
    cell: ({ row }) => new Date(row.original.createdAt).toLocaleDateString(),
  },
  {
    accessorKey: "status",
    header: "状态",
  },
];

<DataTable
  columns={columns}
  data={rows}
  searchPlaceholder="搜索 Key…"
/>;
```

### Table 原语（推荐用于静态内容）

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@nebutra/ui/components";

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>名称</TableHead>
      <TableHead>创建时间</TableHead>
      <TableHead>状态</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {rows.map((row) => (
      <TableRow key={row.id}>
        <TableCell className="font-medium">{row.name}</TableCell>
        <TableCell>{new Date(row.createdAt).toLocaleDateString()}</TableCell>
        <TableCell>{row.status}</TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>;
```

### 排序

`DataTable` 通过标准 TanStack 机制启用列排序 —— 在 `ColumnDef` 上设 `enableSorting: true`（默认即开启），表头即可点击排序。需要服务端排序时，将排序状态外置管理，把排序后的切片传入 `data`。

### 行操作

行级操作放最右一列、右对齐。项目中没有 `ActionMenu` 原语 —— 用 `@nebutra/ui/components` 的 `DropdownMenu` 系列组合：

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
  Button,
} from "@nebutra/ui/components";
import { MoreHorizontal } from "@nebutra/icons";

function RowActions({ row, onEdit, onRevoke }: { row: ApiKey; onEdit: (r: ApiKey) => void; onRevoke: (r: ApiKey) => void }) {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button type="button" variant="ghost" size="sm" aria-label={`${row.name} 的操作`}>
          <MoreHorizontal className="h-4 w-4" />
        </Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end">
        <DropdownMenuItem onSelect={() => onEdit(row)}>编辑</DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem className="text-destructive" onSelect={() => onRevoke(row)}>
          吊销
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

加入列定义：

```tsx
{
  id: "actions",
  cell: ({ row }) => <RowActions row={row.original} onEdit={onEdit} onRevoke={onRevoke} />,
}
```

### 筛选与搜索

`DataTable` 自带搜索框与可选的 `filterableColumns` 集合。传入按列范围的筛选定义即可在工具条渲染筛选标签：

```tsx
<DataTable
  columns={columns}
  data={rows}
  searchPlaceholder="搜索 Key…"
  filterableColumns={[
    {
      id: "status",
      title: "状态",
      accessorKey: "status",
      options: [
        { label: "活跃", value: "active" },
        { label: "已吊销", value: "revoked" },
      ],
    },
  ]}
/>;
```

`DataTable` 之外的场景，先用 `useMemo` 自行筛选数组，再传给原生 `Table`。

### 数据集分页

`DataTable` 不附带开箱即用的分页器。超大数据集启用虚拟化（`enableVirtualization`、`virtualizeThreshold`），可以无分页渲染数千行。需要服务端分页时，在组件外做分页，把当前页的切片传给 `data`。

表格需要首页 / 上一页 / 下一页 / 末页、分页大小选择和 `Page x of y` 状态时，使用 `PaginationControl`。不要在这里使用 `Pagination`；它只服务兄弟页面导航。

### 空 / 加载 / 错误状态

使用 `@nebutra/ui/layout` 的布局级占位组件，让全应用的状态 UI 保持一致：

```tsx
import { EmptyState, LoadingState, ErrorState } from "@nebutra/ui/layout";

if (isLoading) return <LoadingState />;
if (error) return <ErrorState error={error} onRetry={refetch} />;
if (!rows.length) {
  return (
    <EmptyState
      title="还没有 API Key"
      description="创建一个 Key 以开始发起请求。"
    />
  );
}

return <DataTable columns={columns} data={rows} />;
```

## 示例

### API Keys 表格（完整模式）

```tsx
"use client";

import { useState, useMemo } from "react";
import { DataTable, Button } from "@nebutra/ui/components";
import { Section, EmptyState, LoadingState, ErrorState } from "@nebutra/ui/layout";
import type { ColumnDef } from "@tanstack/react-table";

export function ApiKeysTable() {
  const { data, isLoading, error, refetch } = useApiKeys();
  const [revoking, setRevoking] = useState<string | null>(null);

  const columns = useMemo<ColumnDef<ApiKey>[]>(
    () => [
      {
        accessorKey: "name",
        header: "名称",
        cell: ({ row }) => <span className="font-medium">{row.original.name}</span>,
      },
      {
        accessorKey: "createdAt",
        header: "创建时间",
        cell: ({ row }) => new Date(row.original.createdAt).toLocaleDateString(),
      },
      {
        accessorKey: "lastUsedAt",
        header: "最近使用",
        cell: ({ row }) =>
          row.original.lastUsedAt
            ? new Date(row.original.lastUsedAt).toLocaleDateString()
            : <span className="text-muted-foreground">从未</span>,
      },
      {
        id: "actions",
        cell: ({ row }) => (
          <RowActions row={row.original} onRevoke={(r) => setRevoking(r.id)} />
        ),
      },
    ],
    []
  );

  return (
    <Section
      title="API Keys"
      actions={<Button type="button" onClick={onCreateKey}>新建 Key</Button>}
    >
      {isLoading ? (
        <LoadingState />
      ) : error ? (
        <ErrorState error={error} onRetry={refetch} />
      ) : !data?.length ? (
        <EmptyState
          title="还没有 Key"
          description="创建你的第一个 API Key。"
        />
      ) : (
        <DataTable columns={columns} data={data} searchPlaceholder="搜索 Key…" />
      )}
    </Section>
  );
}
```
