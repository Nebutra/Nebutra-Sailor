## 何时使用

模态表面会打断主流程，并要求用户集中注意力。只有当用户必须先回应才能继续，或任务需要额外上下文且 inline 渲染会破坏当前视图时，才使用模态界面。

| 表面 | 适用场景 |
|---|---|
| `Dialog` | 紧凑确认、破坏性操作、关键决策，不需要滚动 |
| `Sheet` | 从屏幕边缘滑入的表单或详情面板，可滚动 |
| `Drawer` | 导航或上下文侧栏，在内容旁打开 |
| `Popover` | 锚定到 trigger 的非阻塞上下文详情，停留在触发器附近 |

以下场景不要使用模态界面：
- 页面之间的导航（使用 routing）
- 可以就地完成的 inline editing
- 应该出现在页面内 `Flash` 或 `Alert` 中的错误

## 结构

### Dialog 对话框

```
Dialog (portal, traps focus)
  ├── Dialog.Header
  │    ├── title (h2)
  │    └── close button (IconButton)
  ├── Dialog.Body (scrollable if content overflows)
  └── Dialog.Footer
       └── ButtonGroup (confirm + cancel)
```

### Sheet 抽屉

```
Sheet (slides in from edge: left | right | top | bottom)
  ├── SheetHeader
  │    ├── SheetTitle
  │    └── SheetDescription
  ├── SheetContent (scrollable)
  └── SheetFooter
       └── ButtonGroup
```

### 确认对话框（Text Confirm）

```
Dialog
  ├── Dialog.Header — destructive action name
  ├── Dialog.Body
  │    ├── Flash variant="danger" — consequence description
  │    └── FormControl — "type NAME to confirm"
  │         └── TextInput
  └── Dialog.Footer
       ├── Button variant="danger" disabled={!confirmed}
       └── Button variant="invisible" — cancel
```

## 组合规则

### 打开与关闭

open state 由父级管理。不要把 open state 存在 overlay 组件内部。

```tsx
const [isOpen, setIsOpen] = useState(false);

<Button onClick={() => setIsOpen(true)}>Open dialog</Button>

<Dialog open={isOpen} onOpenChange={setIsOpen}>
  <DialogTrigger asChild>
    <Button variant="outline">Open dialog</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Confirm deletion</DialogTitle>
      <DialogDescription>This action cannot be undone.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <Button variant="outline" onClick={() => setIsOpen(false)}>Cancel</Button>
      <Button variant="destructive" onClick={handleDelete}>Delete</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

### 焦点管理

`Dialog` 和 `Sheet` 会自动 trap focus。确保 overlay 内第一个可聚焦元素是主操作或第一个输入框，而不是关闭按钮。

### 破坏性确认

不可逆操作（删除、吊销、转移）使用 Text Confirm Dialog fragment，要求用户输入资源名后才启用破坏性按钮。

```tsx
import { TextConfirmDialog } from "@nebutra/ui";

<TextConfirmDialog
  isOpen={isOpen}
  onDismiss={() => setIsOpen(false)}
  onConfirm={handleDelete}
  title="Delete workspace"
  confirmText={workspace.name}
  description="All data in this workspace will be permanently removed."
  confirmButtonLabel="Delete workspace"
/>
```

### 确认 Modal Fragment

更简单的确认（不需要输入文本校验）使用 `ConfirmationModal` fragment。它接受 `title`、`description`、`onConfirm`、`onCancel` 和 `variant`（`default` 或 `danger`）。

### 浮层锚定（Menu、Popover）

`Menu` 和 `Popover` 相对 trigger 元素定位，并在外部点击或 Escape 时关闭。短动作列表使用 `Menu`；非阻塞上下文详情使用 `Popover`。

```tsx
import { Menu, MenuButton, MenuContainer, MenuItem } from "@nebutra/ui/primitives";

<MenuContainer position="bottom-end">
  <MenuButton type="secondary" showChevron>Actions</MenuButton>
  <Menu width={180}>
    <MenuItem onClick={handleEdit}>Edit</MenuItem>
    <MenuItem type="error" onClick={handleDelete}>Delete</MenuItem>
  </Menu>
</MenuContainer>
```

## 示例
### 简单确认对话框

```tsx
function DeleteKeyDialog({ keyName, onConfirm, onCancel, isOpen }: Props) {
  return (
    <Dialog open={isOpen} onOpenChange={(open) => !open && onCancel()}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Delete API key</DialogTitle>
          <DialogDescription>
            Deleting <strong>{keyName}</strong> will immediately revoke all
            requests using this key. This cannot be undone.
          </DialogDescription>
        </DialogHeader>
        <DialogFooter>
          <Button variant="outline" onClick={onCancel}>Cancel</Button>
          <Button variant="destructive" onClick={onConfirm}>Delete key</Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

### 编辑面板（Sheet）

当表单较长需要滚动，或保留底层页面可见性有助于上下文理解时，使用 `Sheet`。

```tsx
import { Sheet, SheetContent, SheetHeader, SheetTitle } from "@nebutra/ui";

<Sheet open={isOpen} onOpenChange={setIsOpen}>
  <SheetContent side="right" className="w-[480px]">
    <SheetHeader>
      <SheetTitle>Edit key</SheetTitle>
    </SheetHeader>
    <EditKeyForm key={selectedKey.id} defaultValues={selectedKey} onSave={handleSave} />
  </SheetContent>
</Sheet>
```
