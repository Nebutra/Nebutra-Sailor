## 概览
图标在 `packages/icons` 中维护，并以内部包 `@nebutra/icons` 发布。完整 Geist 图标集（541 个图标）来源于 [vercel.com/geist/icons](https://vercel.com/geist/icons)，通过 SVGR 转换为 TypeScript React 组件。

所有图标都接受 `size` prop，并把 `ref` 转发到根 `<svg>` 元素。颜色继承父级 `currentColor`，因此应通过父元素的 `color` / `fill` CSS 属性设置图标颜色。

## 安装
`@nebutra/icons` 是私有 workspace package，monorepo 内任何 app 或 package 都可以使用：

```json
// package.json
{
  "dependencies": {
    "@nebutra/icons": "workspace:*"
  }
}
```

## 基础用法

```tsx
import { ArrowDown, LogoVercel, Search } from "@nebutra/icons";

// 默认尺寸（16px）
<ArrowDown />

// 自定义尺寸
<Search size={20} />

// Ref 转发
<LogoVercel ref={myRef} size={24} />
```

---

## 尺寸尺度

所有图标都接受 `size` prop（number 或 string）。为保持一致，使用以下标准值：

| Token | 值 | 用途 |
|---|---|---|
| `sm` | `16` | 行内图标、紧凑 UI |
| `md` | `20` | 按钮、输入框、默认尺寸 |
| `lg` | `24` | 导航、独立图标 |
| `xl` | `32` | 功能插图、空状态 |

```tsx
<ArrowDown size={16} />  // sm — inline
<Search size={20} />     // md — button / input
<Star size={24} />       // lg — standalone
<Globe size={32} />      // xl — empty state
```

## 属性

```ts
import type { IconProps } from "@nebutra/icons";

interface IconProps extends React.SVGProps<SVGSVGElement> {
  /** 图标尺寸，单位 px（默认 16）。同时设置 width 和 height。 */
  size?: number | string;
  // 所有标准 SVGProps 都会透传（className、style、aria-* 等）。
}
```

`size` 会同时覆盖 `width` 和 `height`。如果需要非正方形尺寸，直接传入 `width` 和 `height`，它们优先级高于 `size`。

## 图标分类

541 个图标按名称前缀组织成语义分组：

| 前缀 | 说明 | 示例 |
|---|---|---|
| *(无前缀)* | 通用 UI | `ArrowDown`, `Search`, `Check` |
| `Logo*` | 品牌与产品 Logo | `LogoVercel`, `LogoGitHub`, `LogoAmex` |
| `Function*` | Serverless / edge compute | `FunctionNode`, `FunctionBun` |
| `Firewall*` | 安全与网络 | `FirewallGlobe`, `FirewallFlame` |
| `Edge*` | Edge network | `EdgeNetwork`, `EdgeConfig` |
| `Acronym*` | 短标签变体 | `AcronymTs`, `AcronymJs` |

## 可访问性
没有相邻可见文字的图标必须提供可访问名称。

```tsx
// 错误：没有给辅助技术提供名称
<button><Search size={16} /></button>

// 正确：按钮提供 aria-label，图标标记 aria-hidden
<button aria-label="Search">
  <Search size={16} aria-hidden />
</button>

// 与可见文字并列的装饰图标：从屏幕阅读器隐藏
<button className="flex items-center gap-2">
  <ArrowDown size={16} aria-hidden />
  Sort descending
</button>
```

## 颜色继承

图标以 SVG 渲染并继承 `currentColor`。通过父元素的 `color` 属性或 Tailwind class 设置颜色：

```tsx
// Tailwind：继承文字颜色
<span className="text-blue-500">
  <Star size={16} aria-hidden />
</span>

// 直接 style
<Check size={16} style={{ color: "var(--color-success)" }} aria-hidden />
```

## 按钮和输入框中的图标

```tsx
import { Plus, Search } from "@nebutra/icons";

// 图标按钮
<button className="flex items-center gap-2">
  <Plus size={16} aria-hidden />
  添加项目
</button>

// 带前缀图标的搜索输入
import { Input } from "@nebutra/ui";

<Input
  placeholder="搜索…"
  prefix={<Search size={16} aria-hidden />}
/>
```

pnpm --filter @nebutra/storybook dev
# → http://localhost:6006 → Foundation > Icons

## 新增或更新图标

图标由 `packages/design/icons/src/svg/` 中的 SVG 文件生成。更新 SVG 后使用以下命令重新生成：

```bash
pnpm --filter @nebutra/icons generate
pnpm --filter @nebutra/icons build
```

生成器（`scripts/generate.ts`）使用 SVGR 将每个 `.svg` 文件转换为 TypeScript React 组件，并写入 barrel 文件 `src/index.ts`。

## 应做 / 禁止

**应做**只从 `@nebutra/icons` 导入图标。不要在 app package 中直接新增 `lucide-react`、`@heroicons/react` 或其他图标库依赖。

**应做**使用 `size` prop 控制尺寸。不要用 CSS transform、`width`/`height` style 覆盖或 `transform: scale()` 缩放图标。

**应做**装饰性图标传入 `aria-hidden`，并在父级交互元素上提供可访问名称。

**禁止**使用小于 12px 的图标。低于该尺寸会丢失 SVG 路径细节，并影响可访问性。

**禁止**在图标自身通过 `fill` 或 `stroke` 硬编码颜色。应通过父元素继承 `currentColor`。
