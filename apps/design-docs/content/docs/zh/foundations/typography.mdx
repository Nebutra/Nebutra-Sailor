## 字体层级

Nebutra 使用四级字体层级，每一级有固定的使用场景，不得混用。

<TypographyHierarchyDemos />

## 字体系统 — "精密字体栈"（Precision Stack）

Nebutra 设计系统使用三款字体。Geist 通过字重与字号的变化覆盖所有文本角色，无需额外的展示字体。

| 字体 | 职责 | CSS 变量 | 授权 |
|------|------|----------|------|
| **Geist Sans** | UI、正文、标题、展示 | `--font-geist-sans` | SIL OFL（Vercel） |
| **Geist Mono** | 代码、数据、Token、ID | `--font-geist-mono` | SIL OFL（Vercel） |
| **Noto Sans SC** | 中文（CJK）UI 文字 | `--font-cn` | SIL OFL（Google） |

---

## Geist Sans — 主字体

Geist Sans 是 Nebutra 所有 UI 文字的唯一英文字体——从英雄标题到正文均使用同一字体，通过字重和字号营造层级，无需切换字体。

**设计理念：** Geist 由 Vercel 为高密度开发者产品设计。其几何精度与光学尺寸调节，完全契合 Vercel / Linear / Cursor 的美学定位。

### 字重角色

| 字重 | 值 | 使用场景 |
|------|----|----------|
| Thin | 100 | 96px+ 超大装饰展示文字 |
| ExtraLight | 200 | 大型氛围标题 |
| Light | 300 | Hero 副标题 / 标语 |
| Regular | 400 | 正文、描述、段落 |
| Medium | 500 | 标签、导航、说明文字 |
| SemiBold | 600 | 次级标题、按钮文字（H3–H4） |
| Bold | 700 | 英雄标题（H1–H2）、强调 |
| ExtraBold | 800 | 特殊强调展示文字 |
| Black | 900 | 最大视觉冲击的展示文字 |

### 字间距

大字号需收紧字距——Geist 的比例要求如此：

| 级别 | 字间距 |
|------|--------|
| 展示（72px+） | `-0.04em` |
| 标题（40–64px） | `-0.03em` |
| 副标题（24–36px） | `-0.02em` |
| 正文（14–20px） | `0em` |

### 代码示例

```css
/* 展示标题 */
font-family: var(--font-sans);
font-weight: 700;
letter-spacing: -0.03em;

/* 正文 */
font-family: var(--font-sans);
font-weight: 400;
letter-spacing: 0;
```

```tsx
{/* 英雄标题 */}
<h1 className="font-sans font-bold text-heading-72 tracking-tight">
  Enterprise SaaS Platform
</h1>

{/* 正文 */}
<p className="font-sans font-normal text-copy-16">
  Nebutra transforms raw data into intelligent cloud-native outcomes.
</p>

{/* 导航标签 */}
<span className="font-sans font-medium text-ui-14">
  Dashboard
</span>
```

## Geist Mono — 代码字体

Geist Mono 是所有代码、终端输出和技术数据展示的等宽字体，与 Geist Sans 同源，保持一致的几何美感。

### 使用场景

- 代码块与内联代码
- 终端 / CLI 输出
- API 端点展示
- 技术数据值（ID、哈希、Token、API Key）
- 配置示例与环境变量

### 代码示例

```css
font-family: var(--font-mono);
font-weight: 400;
font-feature-settings: "calt" 1, "liga" 1;
```

```tsx
<code className="font-mono text-copy-14">
  const apiKey = process.env.NEBUTRA_API_KEY
</code>

<pre className="font-mono text-copy-14 bg-neutral-950 text-cyan-400 p-4 rounded-lg">
  <code>npm install @nebutra/ui</code>
</pre>
```

## Noto Sans SC — 中文字体

Noto Sans SC 是所有中文 UI 文字的字体，通过 `font-cn` Tailwind 类或 `--font-cn` CSS 变量使用。

### 使用场景

- 所有中文正文与 UI 标签
- 中英混排内容
- 中文营销文案
- CJK 数据标签与描述文字

### 字重

| 字重 | 值 | 使用场景 |
|------|----|----------|
| Regular | 400 | 中文正文 |
| Medium | 500 | 中文标签、导航 |
| Bold | 700 | 中文标题 |

### 代码示例

```css
font-family: var(--font-cn);
font-weight: 400;
```

```tsx
<p className="font-cn font-normal text-copy-16">
  云端聚合 · 引领未来
</p>
```

## 字体栈

### CSS 自定义属性

```css
:root {
  /* 主 UI — Geist Sans（所有拉丁文字） */
  --font-sans: var(--font-geist-sans), "Geist", -apple-system,
               BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif;

  /* 代码 — Geist Mono */
  --font-mono: var(--font-geist-mono), "Geist Mono",
               ui-monospace, SFMono-Regular, "SF Mono", Menlo, monospace;

  /* 中文 — token 提供的本地 / 系统字体栈 */
  --font-cjk: var(--font-cn), "Noto Sans SC", "PingFang SC",
              "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
}
```

### Tailwind 工具类

```tsx
{/* 所有 UI 文字（拉丁） */}
<h1 className="font-sans">Enterprise SaaS Platform</h1>

{/* 中文文字 */}
<p className="font-cn">中文正文内容</p>

{/* 代码 / 等宽 */}
<code className="font-mono">const x = 1</code>
```

### Next.js 字体加载

```tsx
// app/layout.tsx
import { GeistSans } from "geist/font/sans";
import { GeistMono } from "geist/font/mono";
import "@nebutra/tokens/styles.css";

// 应用到 <html>：
// className={`${GeistSans.variable} ${GeistMono.variable}`}
//
// CJK fallback 来自 @nebutra/tokens --font-cn。
// CI 构建的应用不要为 Noto Sans SC 使用 next/font/google。
```

## 中文排版节奏

中英混排内容需要特殊处理以维持视觉节奏。

### `font-cn` 类

对任何含中文的容器应用 `font-cn`，切换字体栈至 Noto Sans SC，并自动调整：

- **行高**从 1.5 增加至 1.75（CJK 字符需要更多垂直空间）
- **字间距**重置为 0（CJK 不使用字间距）
- **词间距**由浏览器自动处理

```tsx
{/* 纯中文内容 */}
<p className="font-cn text-copy-16">
  无锡云毓智能科技有限公司致力于企业级SaaS平台建设
</p>

{/* 中英混排 */}
<div className="font-cn">
  <p>Nebutra（云毓智能）是一个企业级 SaaS 平台</p>
</div>
```

### 尺寸调整

CJK 字形在相同字号下视觉上比拉丁字母大，混排时需轻微缩小：

```css
/* 混排内容调整 */
.font-cn {
  font-family: var(--font-cjk);
  line-height: 1.75;
  font-size-adjust: 0.52;
}
```

### 标点使用

- 中文句子使用中文标点（。，！？；：""''）
- 英文句子使用英文标点
- 混排内容以所在语言的标点规则为准

## 规范与禁忌

**应该** 对所有拉丁文字使用 Geist Sans——展示标题与正文均适用。

**应该** 通过字重（400 正文 → 700 标题）和字号控制层级，而非切换字体。

**应该** 对所有中文文字使用 Noto Sans SC（通过 `font-cn`）。

**应该** 对含 CJK 内容的容器应用 `font-cn`，以激活正确的行高。

**应该** 对所有代码和技术数据使用 Geist Mono。

**应该** 在展示字号下收紧字间距（`-0.03em` 至 `-0.04em`）。

**不应该** 使用非品牌字体（Inter、Poppins、Roboto、Arial、SF Pro）于 Nebutra 产品。

**不应该** 为"展示"使用独立字体家族——Geist Sans 通过字重变化覆盖所有级别。

**不应该** 对正文设置字间距——字间距调整仅适用于标题和展示文字。

**不应该** 在同一元素上混用 `font-sans` 与 `font-cn`——根据内容语言选择其一。
