<Callout>
  动效不是装饰。Nebutra 每一个动画都映射到一个数据隐喻——具象化、流动、或脉动。禁止任意为之的动画。
</Callout>

## 动效哲学：云端聚合

Nebutra 的动效语言取自云计算的数据流。三个核心动效代表数据的完整生命周期：

1. **Emerge（涌现）** — 数据从云端具象化进入视野
2. **Flow（流动）** — 数据在管道与界面之间流转
3. **Pulse（脉动）** — 系统活着、呼吸、主动处理

任何 UI 动画必须映射到这三种隐喻之一。

## 核心动效

<MotionDemos />

### Emerge（涌现）

数据从云端具象化。用于：内容进入视口、弹窗打开、页面切换。

| 属性 | 起始 | 终态 |
|------|------|------|
| `translateY` | `16px` | `0` |
| `filter: blur` | `6px` | `0` |
| `opacity` | `0` | `1` |

| 时序参数 | 值 |
|----------|----|
| Duration | `cinematic` 轨（500ms） |
| Easing | `cubic-bezier(0.16, 1, 0.3, 1)` |

```tsx
import { motion } from "framer-motion"
import { brandMotion } from "@nebutra/brand"

// 使用品牌 preset
<motion.div {...brandMotion.emerge}>
  <h1>Welcome to Nebutra</h1>
</motion.div>

// 手动实现
<motion.div
  initial={{ y: 16, filter: "blur(6px)", opacity: 0 }}
  animate={{ y: 0, filter: "blur(0px)", opacity: 1 }}
  transition={{ duration: 0.5, ease: [0.16, 1, 0.3, 1] }}
>
  <h1>Welcome to Nebutra</h1>
</motion.div>
```

### Flow（流动）

数据在管道间流转。用于：水平方向切换、滑入面板、导航变更、序列化内容。

| 属性 | 起始 | 终态 |
|------|------|------|
| `translateX` | `-20px` | `0` |
| `opacity` | `0` | `1` |

| 时序参数 | 值 |
|----------|----|
| Duration | `reveal` 轨（300ms） |
| Easing | `cubic-bezier(0, 0, 0.2, 1)` |

```tsx
import { motion } from "framer-motion"
import { brandMotion } from "@nebutra/brand"

// 使用品牌 preset
<motion.div {...brandMotion.flow}>
  <SidePanel />
</motion.div>

// 手动实现
<motion.div
  initial={{ x: -20, opacity: 0 }}
  animate={{ x: 0, opacity: 1 }}
  transition={{ duration: 0.3, ease: [0, 0, 0.2, 1] }}
>
  <SidePanel />
</motion.div>
```

### Pulse（脉动）

系统活着、呼吸。用于：状态指示器、loading 态、环境背景元素。**这是唯一允许无限循环的动画。**

| 属性 | 关键帧 |
|------|--------|
| `scale` | `1 → 1.015 → 1` |
| `opacity` | `1 → 0.85 → 1` |

| 时序参数 | 值 |
|----------|----|
| Duration | `3s` |
| Repeat | `Infinity` |

```tsx
import { motion } from "framer-motion"
import { brandMotion } from "@nebutra/brand"

// Using brand preset
<motion.div {...brandMotion.pulse}>
  <StatusIndicator />
</motion.div>

// Manual implementation
<motion.div
  animate={{
    scale: [1, 1.015, 1],
    opacity: [1, 0.85, 1],
  }}
  transition={{
    duration: 3,
    repeat: Infinity,
    ease: "easeInOut",
  }}
>
  <StatusIndicator />
</motion.div>
```

## 品牌缓动曲线（Easing）

| 名称 | 值 | 描述 | 适用 |
|------|----|------|------|
| **Brand** | `[0.16, 1, 0.3, 1]` | 品牌专属减速曲线 — 快速起始、平滑收尾 | emerge / reveal 类首选 |
| **Enter** | `[0, 0, 0.2, 1]` | Material 减速 | 进入视口的元素 |
| **Exit** | `[0.4, 0, 1, 1]` | Material 加速 | 离开视口的元素 |
| **Spring** | 见下方 Spring 物理参数 | 自然回弹 | 交互式微动效 |

### CSS 自定义属性

```css
:root {
  --ease-brand: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-enter: cubic-bezier(0, 0, 0.2, 1);
  --ease-exit: cubic-bezier(0.4, 0, 1, 1);
}
```

### Framer Motion 用法

```tsx
import { brandEasing } from "@nebutra/brand"

// brandEasing.brand  → [0.16, 1, 0.3, 1]
// brandEasing.enter  → [0, 0, 0.2, 1]
// brandEasing.exit   → [0.4, 0, 1, 1]

<motion.div
  transition={{ ease: brandEasing.brand, duration: 0.5 }}
/>
```

<Warning>
  Nebutra 产品中**禁止**使用通用的 `ease-in-out` 或 `linear` 曲线。始终使用品牌缓动曲线以保证可预期、品牌一致的动效。
</Warning>

## Duration Scale — 四轨

动效时长系统采用**四轨**结构。名称表达**意图**，而非相对速度。按动效语义选轨道，而非"想要多快"。

| 轨道 | 时长 | CSS 变量 | Tailwind | 适用场景 |
|------|-------|---------|----------|----------|
| `micro` | `100ms` | `--duration-micro` | `duration-micro` | hover、focus、toggle、按钮按下 |
| `flow` | `200ms` | `--duration-flow` | `duration-flow` | 弹窗、下拉、tab 切换 — **默认状态流转** |
| `reveal` | `300ms` | `--duration-reveal` | `duration-reveal` | 滑入、展开、accordion、抽屉 |
| `cinematic` | `500ms` | `--duration-cinematic` | `duration-cinematic` | 着陆页 hero 入场、大型 delight 时刻 |

<Callout type="info">
  `flow` 是状态流转的默认值。拿不准时先选 `flow`——覆盖约 70% 场景。
</Callout>

### CSS / Tailwind 用法

```tsx
<div className="transition-opacity duration-flow ease-out" />
<div style={{ transitionDuration: "var(--duration-reveal)" }} />
```

### TypeScript / Framer Motion 用法

```tsx
import { motionDurationSec, brandEasing } from "@nebutra/brand"

// motionDurationSec.micro      → 0.1
// motionDurationSec.flow       → 0.2
// motionDurationSec.reveal     → 0.3
// motionDurationSec.cinematic  → 0.5

<motion.div
  transition={{ duration: motionDurationSec.cinematic, ease: brandEasing.brand }}
/>
```

<Callout type="warning">
  禁止硬编码时长（`duration: 0.4`）。必须选一个轨道。如果四轨都不合适，这个动效大概率有问题——先和设计沟通，不要随手加第五轨。
</Callout>

## 品牌 Spring 配置

Spring 物理参数为交互元素提供自然、响应式的动效。四组预设覆盖所有场景。

| 名称 | Stiffness | Damping | Mass | 性格 | 适用 |
|------|-----------|---------|------|------|------|
| **Default** | 200 | 24 | 1.0 | 平衡、专业 | 通用 UI 切换 |
| **Bouncy** | 300 | 15 | 0.8 | 活力、俏皮 | 按钮反馈、通知、成功态 |
| **Heavy** | 120 | 28 | 1.5 | 沉稳、慎重 | 弹窗切换、大面板、抽屉打开 |
| **Gentle** | 80 | 20 | 1.0 | 柔和、环境感 | 背景元素、细微位置调整 |

### Framer Motion 用法

```tsx
import { brandSpring } from "@nebutra/brand"

// Default spring
<motion.div
  animate={{ scale: 1 }}
  transition={{ type: "spring", ...brandSpring.default }}
/>

// Bouncy spring — button press
<motion.button
  whileTap={{ scale: 0.95 }}
  transition={{ type: "spring", ...brandSpring.bouncy }}
>
  Click Me
</motion.button>

// Heavy spring — modal entrance
<motion.div
  initial={{ y: 100, opacity: 0 }}
  animate={{ y: 0, opacity: 1 }}
  transition={{ type: "spring", ...brandSpring.heavy }}
>
  <ModalContent />
</motion.div>

// Gentle spring — background element
<motion.div
  animate={{ x: targetX }}
  transition={{ type: "spring", ...brandSpring.gentle }}
/>
```

### 原始值

```tsx
import { brandSpring } from "@nebutra/brand"

// brandSpring.default → { stiffness: 200, damping: 24, mass: 1 }
// brandSpring.bouncy  → { stiffness: 300, damping: 15, mass: 0.8 }
// brandSpring.heavy   → { stiffness: 120, damping: 28, mass: 1.5 }
// brandSpring.gentle  → { stiffness: 80,  damping: 20, mass: 1 }
```

## Stagger 模式

列表与网格入场使用 stagger——每个子元素在前一个之后稍微延迟进入。

```tsx
import { motion } from "framer-motion"
import { brandMotion, motionDurationSec, brandEasing } from "@nebutra/brand"

const container = {
  hidden: { opacity: 0 },
  show: {
    opacity: 1,
    transition: {
      staggerChildren: 0.08,
      delayChildren: 0.1,
    },
  },
}

const item = {
  hidden: { y: 16, filter: "blur(6px)", opacity: 0 },
  show: {
    y: 0,
    filter: "blur(0px)",
    opacity: 1,
    transition: {
      duration: motionDurationSec.cinematic,
      ease: brandEasing.brand,
    },
  },
}

<motion.ul variants={container} initial="hidden" animate="show">
  {items.map((data) => (
    <motion.li key={data.id} variants={item}>
      <Card {...data} />
    </motion.li>
  ))}
</motion.ul>
```

| 参数 | 值 | 描述 |
|------|----|------|
| `staggerChildren` | `0.08s` | 每个子元素入场之间的延迟 |
| `delayChildren` | `0.1s` | 第一个子元素入场前的整体延迟 |

## 交互微动效

### 悬停

```tsx
import { brandSpring } from "@nebutra/brand"

<motion.div
  whileHover={{ scale: 1.02 }}
  transition={{ type: "spring", ...brandSpring.default }}
>
  <Card />
</motion.div>
```

### 点击

```tsx
<motion.button
  whileTap={{ scale: 0.97 }}
  transition={{ type: "spring", ...brandSpring.bouncy }}
>
  Submit
</motion.button>
```

### 悬停抬升

垂直上浮 + 阴影抬升的组合。用于卡片与交互表面。

```tsx
<motion.div
  whileHover={{
    y: -4,
    boxShadow: "0 20px 40px rgba(0, 51, 254, 0.15)",
  }}
  transition={{ type: "spring", ...brandSpring.default }}
>
  <FeatureCard />
</motion.div>
```

## 视口触发（Viewport Triggers）

### Once（默认）

只在元素首次进入视口时执行动画。用于：内容章节、feature 网格、客户证言。

```tsx
<motion.section
  initial={{ y: 16, filter: "blur(6px)", opacity: 0 }}
  whileInView={{ y: 0, filter: "blur(0px)", opacity: 1 }}
  viewport={{ once: true, margin: "-100px" }}
  transition={{ duration: 0.5, ease: [0.16, 1, 0.3, 1] }}
>
  <FeatureSection />
</motion.section>
```

### 始终适用

每次元素进入视口都重新触发动画。**慎用**——仅用于环境背景元素与装饰性动效。

```tsx
<motion.div
  initial={{ opacity: 0 }}
  whileInView={{ opacity: 1 }}
  viewport={{ once: false, amount: 0.3 }}
  transition={{ duration: 0.3 }}
>
  <DecorativeElement />
</motion.div>
```

<Tip>
  所有内容类动画默认 `once: true`。`once: false` 仅适用于受益于重复入场的环境/装饰元素。
</Tip>

## Do / Don't（推荐与禁止）

**应做**所有内容进入视口都用 `emerge`（垂直方向 + 模糊揭示）。

**应做**水平方向的切换（面板、导航、序列内容）用 `flow`。

**应做**状态指示器与环境呼吸效果用 `pulse`。

**应做**所有 tween 动画使用品牌缓动曲线（`[0.16, 1, 0.3, 1]`）。

**应做**所有交互微动效（hover、tap、drag）使用品牌 spring。

**应做**列表/网格入场用 `0.08s` 的 stagger 子元素延迟。

**应做**尊重 `prefers-reduced-motion`——关闭所有非必要动画。

**禁止**到处加弹性——`brandSpring.bouncy` 仅用于按钮反馈与成功态。

**禁止**使用通用的 `ease-in-out` 或 `linear` 曲线，始终用品牌曲线。

**禁止**UI 切换时长**超过 `cinematic` 轨（500ms）**——这是绝对上限。

**禁止**内容元素使用 `pulse`——它保留给状态指示器与环境效果。

**禁止**同时动画超过 3 个属性——保持动效聚焦、可读。

**禁止**在 `pulse` 之外创建无限循环动画——只有状态指示器可以循环。
