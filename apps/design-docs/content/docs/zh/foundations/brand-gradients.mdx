## 品牌渐变

四种渐变变体覆盖全部核心场景；每一种都有明确方向、色标和上下文。

<BrandGradientsDemo />

### CSS 自定义属性

```css
:root {
  --gradient-brand: linear-gradient(135deg, #0033FE 0%, #0BF1C3 100%);
  --gradient-brand-reverse: linear-gradient(135deg, #0BF1C3 0%, #0033FE 100%);
  --gradient-brand-vertical: linear-gradient(180deg, #0033FE 0%, #0BF1C3 100%);
  --gradient-brand-glow: radial-gradient(circle, #0BF1C3 0%, #0033FE 100%);
}
```

### Tailwind 用法

```tsx
// 主渐变按钮
<button className="bg-[linear-gradient(135deg,#0033FE_0%,#0BF1C3_100%)] text-white border-0 rounded-lg px-6 py-3">
  Get Started
</button>

// Hover：切换为反向渐变
<button className="bg-[var(--gradient-brand)] hover:bg-[var(--gradient-brand-reverse)] text-white">
  Get Started
</button>

// 渐变文字
<h1 className="bg-[var(--gradient-brand)] bg-clip-text text-transparent">
  Enterprise SaaS Platform
</h1>

// 垂直区块分隔线
<div className="h-1 w-full bg-[var(--gradient-brand-vertical)]" />

// 发光背景
<div className="absolute inset-0 bg-[var(--gradient-brand-glow)] opacity-20 blur-3xl" />
```

### React / CSS-in-JS 用法

```tsx
// CSS 自定义属性
<div style={{ background: 'var(--gradient-brand)' }} />

// 直接值
<div style={{ background: 'linear-gradient(135deg, #0033FE 0%, #0BF1C3 100%)' }} />
```

## 动态渐变

### AnimatedGradientText 组件

缓慢移动渐变填充的文字组件。适用于 hero 标语和重点文案。

```tsx
import { AnimatedGradientText } from "@nebutra/ui"

<AnimatedGradientText>
  AI-Native Data. Cloud Nurtured.
</AnimatedGradientText>
```

渐变会在 6 秒循环中在品牌主方向和反向之间移动，形成克制的微光效果。

### GradientAnimatedText 组件

可配置速度和方向的变体。适用于交互标签。

```tsx
import { GradientAnimatedText } from "@nebutra/ui"

<GradientAnimatedText
  speed={4}
  direction="horizontal"
  className="text-heading-36 font-display font-bold"
>
  Cloud Intelligence
</GradientAnimatedText>
```

## 颗粒纹理

### GrainGradientBackground 组件

在品牌渐变上叠加细腻噪声纹理，为数字界面带来模拟介质的温度。这是 Nebutra hero 区块的标志性处理方式。

```tsx
import { GrainGradientBackground } from "@nebutra/ui"

<section className="relative h-[600px]">
  <GrainGradientBackground
    intensity={0.15}
    className="absolute inset-0"
  />
  <div className="relative z-10">
    {/* Hero 内容 */}
  </div>
</section>
```

### SVG feTurbulence 方案

如果不想引入组件依赖，可以使用内联 SVG filter 实现轻量颗粒：

```css
.grain-overlay::after {
  content: "";
  position: absolute;
  inset: 0;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 256 256' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noise'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.65' numOctaves='3' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noise)' opacity='0.08'/%3E%3C/svg%3E");
  pointer-events: none;
  opacity: 0.1;
}
```

<Tip>
  颗粒纹理可以中和纯 CSS 渐变过于完美的数字感。透明度保持在 8-15%；再高就会和内容可读性竞争。
</Tip>

## 网格渐变

### MeshGradientBg 组件

基于 WebGL 的多点渐变，可生成有机流动的色场。适用于沉浸式 hero 和功能落地页。

```tsx
import { MeshGradientBg } from "@nebutra/ui"

<section className="relative min-h-screen">
  <MeshGradientBg
    colors={["#0033FE", "#0BF1C3", "#002ad4", "#1af7c8"]}
    speed={0.003}
    className="absolute inset-0"
  />
  <div className="relative z-10">
    {/* 页面内容 */}
  </div>
</section>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `colors` | `string[]` | 品牌蓝/青 | 用于控制渐变点位的 4 个 HEX 颜色 |
| `speed` | `number` | `0.003` | 动画速度倍率 |
| `className` | `string` | — | 容器 CSS class |

## 神经噪声

### NeuroNoiseBg 组件

生成类脑有机噪声图案的 WebGL shader。适用于 AI/ML 主题区块和深科技功能页。

```tsx
import { NeuroNoiseBg } from "@nebutra/ui"

<section className="relative h-[500px]">
  <NeuroNoiseBg
    scale={1.5}
    speed={0.002}
    colorA="#0033FE"
    colorB="#0BF1C3"
    className="absolute inset-0"
  />
  <div className="relative z-10">
    {/* AI 功能内容 */}
  </div>
</section>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `scale` | `number` | `1.5` | 噪声图案缩放 |
| `speed` | `number` | `0.002` | 动画速度 |
| `colorA` | `string` | `#0033FE` | 主色 |
| `colorB` | `string` | `#0BF1C3` | 辅色 |

## 波浪

### WavesBg 组件

渲染动态波浪图案的 WebGL shader。适用于数据流和流式传输隐喻。

```tsx
import { WavesBg } from "@nebutra/ui"

<section className="relative h-[400px]">
  <WavesBg
    amplitude={30}
    frequency={0.02}
    speed={0.01}
    color="#0033FE"
    className="absolute inset-0 opacity-30"
  />
  <div className="relative z-10">
    {/* 流式数据区块 */}
  </div>
</section>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `amplitude` | `number` | `30` | 波浪高度，单位 px |
| `frequency` | `number` | `0.02` | 波浪密度 |
| `speed` | `number` | `0.01` | 动画速度 |
| `color` | `string` | `#0033FE` | 波浪颜色 |

## 抖动纹理

### DitheringBackground 组件

纯 CSS 抖动效果，用于生成复古数字纹理。适用于怀旧或技术传承主题区块。

```tsx
import { DitheringBackground } from "@nebutra/ui"

<section className="relative">
  <DitheringBackground
    density={2}
    colorA="#0033FE"
    colorB="#0BF1C3"
    className="absolute inset-0 opacity-20"
  />
  <div className="relative z-10">
    {/* 内容 */}
  </div>
</section>
```

## 各纹理使用场景

| 纹理 | 场景 | 性能 | 降级 |
|---------|---------|-------------|----------|
| **Grain** | Hero 区块、关于页 | 低（CSS/SVG） | 纯渐变 |
| **Mesh Gradient** | 沉浸式 hero、功能落地页 | 中（WebGL） | 静态 CSS 渐变 |
| **Neural Noise** | AI/ML 功能、深科技页面 | 高（WebGL） | 颗粒 + 渐变 |
| **Waves** | 数据流、流水线功能 | 中（WebGL） | CSS 渐变 |
| **Dithering** | 技术传承/复古区块、轻纹理 | 低（CSS） | 纯背景 |
| **AnimatedGradientText** | Hero 标语、重点文案 | 低（CSS） | 静态渐变文字 |

## 性能说明

<Warning>
  WebGL 着色器（MeshGradient、NeuroNoise、Waves）需要 GPU 加速，不应在每个页面都使用。
</Warning>

### 指南

- **每页最多 1 个 WebGL 背景**：多个 shader 会争夺 GPU 资源
- **始终提供 CSS 降级**：检测 WebGL 支持并优雅降级
- **低功耗设备禁用**：结合 `prefers-reduced-motion` 和 Battery API
- **延迟加载 shader**：只在区块进入视口时初始化

### CSS 降级模式

```tsx
<section className="relative">
  {/* CSS 降级：始终渲染 */}
  <div className="absolute inset-0 bg-[var(--gradient-brand)]" />

  {/* WebGL 增强：延迟加载 */}
  <Suspense fallback={null}>
    <MeshGradientBg className="absolute inset-0" />
  </Suspense>
</section>
```

### 减少动态效果

```tsx
import { useReducedMotion } from "@/shared/motion"

function HeroBackground() {
  const prefersReducedMotion = useReducedMotion()

  if (prefersReducedMotion) {
    return <div className="bg-[var(--gradient-brand)]" />
  }

  return <MeshGradientBg />
}
```

## 应做 / 禁止

**应做**：所有渐变 surface 默认使用 135deg 品牌渐变。

**应做**：颗粒纹理透明度保持 8-15%，提供模拟介质质感。

**应做**：所有 WebGL shader 都提供 CSS 降级。

**应做**：所有动态纹理都遵守 `prefers-reduced-motion`。

**禁止**：改变主品牌渐变的 135deg 角度。

**禁止**：单页使用超过 1 个 WebGL 背景。

**禁止**：颗粒透明度超过 15%，这会降低内容可读性。

**禁止**：在渐变色标中使用非品牌色，例如紫色、橙色、粉色。

**禁止**：在内容密集页面使用会争夺注意力的动态纹理。
