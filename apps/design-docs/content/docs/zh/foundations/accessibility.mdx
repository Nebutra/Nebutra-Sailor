## 概览
可访问性原语位于 `apps/docs-hub/design-system/src/primitives/accessibility.ts`。该文件导出样式对象、ARIA 属性辅助函数和实现 WCAG 2.1 AA 要求的工具函数。它们是底层构件：设计系统组件会在内部消费它们，应用代码在创建自定义模式时也可以直接导入。

导出成员：

| 导出 | 类型 | 用途 |
|---|---|---|
| `visuallyHidden` | `StyleObject` | 视觉隐藏，同时保留给屏幕阅读器 |
| `focusRing` | `StyleObject` | 键盘焦点指示样式 |
| `skipLinkStyle` | Object | 跳到正文链接，聚焦时显示 |
| `ariaPatterns` | Object | 可复用 ARIA 属性集合 |
| `minTouchTarget` | Object | WCAG 2.5.5 最小触控目标 |
| `prefersReducedMotion()` | Function | 运行时减少动态效果偏好检测 |
| `contrastRequirements` | Object | WCAG 对比度阈值 |

## 设计依据

可访问性不能在组件发布后再补。这里的原语让正确行为成为阻力最小的路径：使用 `visuallyHidden` 应该比手写六个隐藏 CSS 属性更容易，调用 `ariaPatterns.loading` 也应该比分别记住 `aria-busy` 和 `aria-live` 更稳。

<Warning>
这些原语只建立基线，不替代语义化 HTML。优先使用正确的原生元素（`<button>`、`<nav>`、`<main>`、`<label>`），再补充 ARIA 属性。
</Warning>

## `visuallyHidden`

从视觉布局中移除元素，但保留在可访问性树中。

```ts
import { visuallyHidden } from "@nebutra/ui/primitives/accessibility";

// 样式对象，可展开到 inline style 或 CSS-in-JS
const style = visuallyHidden;
// {
//   position: "absolute",
//   width: "1px",
//   height: "1px",
//   padding: 0,
//   margin: "-1px",
//   overflow: "hidden",
//   clip: "rect(0, 0, 0, 0)",
//   whiteSpace: "nowrap",
//   border: 0,
// }
```

适用于：图标按钮标签、仅屏幕阅读器可见的通知、视觉上重复但语义上必要的文本。

需要屏幕阅读器宣告的内容，不要用 `display: none` 或 `visibility: hidden` 隐藏。

## `focusRing`

符合 WCAG 2.4.7（焦点可见）的标准键盘焦点环。

```ts
import { focusRing } from "@nebutra/ui/primitives/accessibility";

// focusRing 解析为：
// {
//   outline: "2px solid",
//   outlineColor: "accent.fg",
//   outlineOffset: "2px",
// }
```

应用于所有会接收键盘焦点的交互元素。设计系统组件会通过 `&:focus-visible` 选择器自动应用。

<Tip>
使用 `:focus-visible` 而不是 `:focus`，让焦点环只为键盘用户显示。大多数交互元素不应在鼠标点击时显示焦点环。
</Tip>

## `skipLinkStyle`

仅在键盘聚焦时可见的跳转导航链接。WCAG 2.4.1（绕过区块）要求提供这种能力。

```tsx
import { skipLinkStyle } from "@nebutra/ui/primitives/accessibility";

// 在根布局中
<a href="#main-content" style={skipLinkStyle}>
  跳到主要内容
</a>
```

链接默认视觉隐藏；当接收键盘焦点时显示，并固定在左上角，同时应用 `focusRing` 样式。

## `ariaPatterns`

常见 UI 状态的预组合 ARIA 属性对象。

### `ariaPatterns.loading`

```tsx
import { ariaPatterns } from "@nebutra/ui/primitives/accessibility";

<div {...ariaPatterns.loading}>
  内容加载中...
</div>
// 应用：aria-busy="true", aria-live="polite"
```

### `ariaPatterns.expandable(expanded)`

```tsx
<button {...ariaPatterns.expandable(isOpen)}>
  切换区块
</button>
// 应用：aria-expanded={isOpen}
```

### `ariaPatterns.currentPage`

```tsx
<a href="/dashboard" {...ariaPatterns.currentPage}>
  Dashboard
</a>
// 应用：aria-current="page"
```

### `ariaPatterns.required`

```tsx
<input {...ariaPatterns.required} />
// 应用：aria-required="true"
```

### `ariaPatterns.invalid(message?)`

```tsx
<input
  {...ariaPatterns.invalid("Email is required")}
  id="email"
/>
// 应用：aria-invalid="true", aria-errormessage="Email is required"
```

## `minTouchTarget`

WCAG 2.5.5（目标尺寸）要求交互区域至少为 44×44px。

```ts
import { minTouchTarget } from "@nebutra/ui/primitives/accessibility";

// minTouchTarget = { minWidth: 44, minHeight: 44 }

<button style={minTouchTarget}>
  <IconClose size={16} />
</button>
```

所有可视面积小于 44×44px 的交互元素都应应用它，例如图标按钮、关闭图标和开关。

## `prefersReducedMotion()`

运行时检测系统级减少动态效果偏好。

```ts
import { prefersReducedMotion } from "@nebutra/ui/primitives/accessibility";

const duration = prefersReducedMotion() ? 0 : 300;

element.animate([{ opacity: 0 }, { opacity: 1 }], {
  duration,
  easing: "ease-out",
});
```

在服务端返回 `false`，因此 SSR 安全。需要完整覆盖时，和 CSS `@media (prefers-reduced-motion: reduce)` 配合使用。

## `contrastRequirements`

用于程序化对比度检查的 WCAG 对比度阈值。

| Token | 值 | 标准 | 场景 |
|---|---|---|---|
| `contrastRequirements.normalText` | 4.5 | AA | 正文文本（小于 18px 或小于 14px 加粗） |
| `contrastRequirements.largeText` | 3 | AA | 大文本（18px+ 或 14px+ 加粗） |
| `contrastRequirements.normalTextAAA` | 7 | AAA | 增强级普通文本 |
| `contrastRequirements.largeTextAAA` | 4.5 | AAA | 增强级大文本 |

```ts
import { contrastRequirements } from "@nebutra/ui/primitives/accessibility";

function isAccessible(contrastRatio: number, isLargeText: boolean): boolean {
  const required = isLargeText
    ? contrastRequirements.largeText
    : contrastRequirements.normalText;
  return contrastRatio ≥ required;
}
```

设计系统的语义颜色 token 需要在浅色和深色模式下都满足 AA 对比度要求。

## 使用准则
### 键盘导航

每个交互元素都必须可以通过键盘到达和操作。没有等价自定义实现时，不要压制默认焦点行为。

```tsx
// 错误：移除了焦点且没有替代方案
<div onClick={handleClick} tabIndex={-1} style={{ outline: "none" }}>

// 正确：使用语义化 button，焦点环自动生效
<button onClick={handleClick}>
```

### 动效

所有动画都应包在减少动态效果检查中：

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

当 `prefersReducedMotion()` 返回 `true` 时，营销侧的 `marketingTransitions` 应替换为即时过渡。

## 应做 / 禁止

**应做**：把语义化 HTML 元素作为主要可访问性机制。ARIA pattern 是补充，不替代原生语义。

**应做**：用 `visuallyHidden` 为纯图标控件提供上下文，例如标签、说明和通知。

**应做**：对所有视觉尺寸小于 44×44px 的交互元素应用 `minTouchTarget`。

**应做**：新增颜色组合时，用 `contrastRequirements` 阈值验证对比度。

**禁止**：在非交互元素上使用 `aria-label`。不能聚焦、也没有交互的元素通常不需要 `aria-label`。

**禁止**：用 `outline: none` 或 `outline: 0` 压制默认焦点环，除非已经通过 `:focus-visible` 应用了 `focusRing`。

**禁止**：当 `prefersReducedMotion()` 返回 `true` 时触发动画。
