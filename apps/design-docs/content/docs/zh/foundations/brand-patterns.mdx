  Nebutra 的视觉 DNA 来自 Logo 的六边形几何结构。
  每一种视觉图案都必须强化“结构化智能”的品牌核心，而不是成为无意义装饰。
</Callout>

## 视觉 DNA 概览

Nebutra 的设计 DNA 由五个视觉元素组成：

| 元素 | 来源 | 作用 |
|---------|--------|------|
| **六边形网格** | Logo 几何 | 主要结构图案 |
| **蓝到青渐变** | 品牌颜色 | 色彩签名（见 [渐变](/zh/docs/foundations/brand-gradients)） |
| **颗粒 / 噪声纹理** | 模拟介质温度 | 深度与触感（见 [渐变](/zh/docs/foundations/brand-gradients)） |
| **玻璃拟态** | 深色优先表面 | 分层透明感 |
| **深色优先设计** | 品牌哲学 | 默认表面处理方式 |

---

## 六边形网格

六边形网格是核心视觉 DNA，直接抽取自 Logo 的几何构成。它适用于 hero 背景、功能区块和环境装饰，但不应压过内容层级。

### HexGrid 组件

<ComponentPreview name="hex-grid-demo" className="min-h-[720px] w-full" />

```tsx
import { HexGrid } from "@nebutra/ui"

// Default — subtle background pattern
<HexGrid
  size={60}
  gap={4}
  strokeColor="rgba(0, 51, 254, 0.08)"
  className="absolute inset-0"
/>

// Accent — gradient-highlighted cells
<HexGrid
  size={48}
  gap={3}
  strokeColor="rgba(0, 51, 254, 0.12)"
  fillColor="rgba(11, 241, 195, 0.03)"
  highlightCells={[5, 12, 19, 26]}
  highlightColor="rgba(0, 51, 254, 0.15)"
  className="absolute inset-0"
/>

// Animated — cells fade in on scroll
<HexGrid
  size={60}
  gap={4}
  strokeColor="rgba(0, 51, 254, 0.1)"
  animated
  staggerDelay={0.02}
  className="absolute inset-0"
/>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `size` | `number` | `60` | 六边形单元像素尺寸 |
| `gap` | `number` | `4` | 单元之间的间距 |
| `strokeColor` | `string` | `rgba(0,51,254,0.08)` | 六边形单元描边色 |
| `fillColor` | `string` | `transparent` | 六边形单元填充色 |
| `highlightCells` | `number[]` | `[]` | 需要高亮的单元索引 |
| `highlightColor` | `string` | `rgba(0,51,254,0.15)` | 高亮单元颜色 |
| `animated` | `boolean` | `false` | 启用入场动画 |
| `staggerDelay` | `number` | `0.02` | 单元动画之间的错峰延迟 |

### 使用准则
- 背景型使用时，描边透明度保持在 5-15%
- 高亮单元不超过 10%，避免视觉噪音
- 描边使用品牌蓝 (`#0033FE`)，高亮使用品牌青 (`#0BF1C3`)
- 始终通过 `absolute inset-0` 和低 `z-index` 放在内容背后

## 点阵图案

点阵是一种更低调的背景纹理。六边形网格太强、会抢占内容注意力时，优先使用点阵。

<div className="my-6">
  <DotPatternDemo />
</div>

```tsx
// CSS implementation
<div
  className="absolute inset-0"
  style={{
    backgroundImage: 'radial-gradient(circle, rgba(0, 51, 254, 0.12) 1px, transparent 1px)',
    backgroundSize: '24px 24px',
  }}
/>
```

```tsx
// Tailwind implementation
<div className="absolute inset-0 bg-[radial-gradient(circle,rgba(0,51,254,0.12)_1px,transparent_1px)] bg-[size:24px_24px]" />
```

### 何时使用

- 仪表盘背景
- 空状态
- 设置页
- 六边形网格显得过重的次级内容区域

## 闪烁网格

闪烁网格会让单元在可见与隐藏之间随机切换。它适合需要技术感、能量感和动态反馈的区块。

<div className="my-6">
  <FlickeringGridDemo />
</div>

```tsx
import { FlickeringGrid } from "@nebutra/ui"

<section className="relative h-[500px]">
  <FlickeringGrid
    cellSize={16}
    color="#0033FE"
    maxOpacity={0.15}
    flickerChance={0.3}
    className="absolute inset-0"
  />
  <div className="relative z-10">
    {/* Content */}
  </div>
</section>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `cellSize` | `number` | `16` | 网格单元像素尺寸 |
| `color` | `string` | `#0033FE` | 单元颜色 |
| `maxOpacity` | `number` | `0.15` | 单元最大透明度 |
| `flickerChance` | `number` | `0.3` | 每帧发生闪烁的概率 |

### 何时使用

- 实时数据处理区块
- API / 基础设施能力页
- 技术能力展示区

## 扭曲背景

扭曲背景是 WebGL 失真效果，用于制造空间扭曲感。它只适合沉浸式、全出血 hero 区块。

<div className="my-6">
  <WarpBackgroundDemo />
</div>

```tsx
import { WarpBackground } from "@nebutra/ui"

<section className="relative min-h-screen">
  <WarpBackground
    speed={0.005}
    intensity={0.3}
    colorA="#0033FE"
    colorB="#0BF1C3"
    className="absolute inset-0"
  />
  <div className="relative z-10">
    {/* Hero content */}
  </div>
</section>
```

<Warning>
  WarpBackground 使用 WebGL。每页最多 1 个，并提供 CSS 渐变 fallback。
  性能边界见 [渐变与纹理](/zh/docs/foundations/brand-gradients)。
</Warning>

## 星点画布

星点画布是基于 canvas 的星空背景，适合空间 / 云计算主题区块，用来强化“云端智能”的品牌叙事。

<div className="my-6">
  <StarsCanvasDemo />
</div>

```tsx
import { StarsCanvas } from "@nebutra/ui"

<section className="relative h-[600px] bg-neutral-950">
  <StarsCanvas
    count={200}
    speed={0.5}
    size={1.5}
    color="#ffffff"
    className="absolute inset-0"
  />
  <div className="relative z-10 text-white">
    {/* Cloud/space themed content */}
  </div>
</section>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `count` | `number` | `200` | 星点数量 |
| `speed` | `number` | `0.5` | 漂移速度 |
| `size` | `number` | `1.5` | 星点最大半径（px） |
| `color` | `string` | `#ffffff` | 星点颜色 |

### 何时使用

- 云基础设施页面
- 定价 / 套餐对比区块
- 关于 / 使命页面
- 使用空间或云隐喻的区块

## 玻璃拟态配方

玻璃拟态是 Nebutra 深色优先表面的核心视觉处理方式。它通过透明度、模糊和细边框建立层次深度。

### 视觉示例

<div className="my-6">
  <GlassmorphismDemo />
</div>

### 配方

```css
/* Standard glass panel */
.glass {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(24px);
  -webkit-backdrop-filter: blur(24px);
  border: 1px solid rgba(255, 255, 255, 0.10);
  border-radius: 16px;
}

/* Elevated glass panel */
.glass-elevated {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(32px);
  -webkit-backdrop-filter: blur(32px);
  border: 1px solid rgba(255, 255, 255, 0.15);
  border-radius: 16px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
}
```

### Tailwind 实现

```tsx
// Standard glass panel
<div className="bg-white/5 backdrop-blur-xl border border-white/10 rounded-2xl">
  <div className="p-6">
    <h3 className="text-white font-semibold">Feature Title</h3>
    <p className="text-neutral-400 mt-2">Feature description text.</p>
  </div>
</div>

// Elevated glass panel (card with shadow)
<div className="bg-white/[0.08] backdrop-blur-[32px] border border-white/[0.15] rounded-2xl shadow-[0_8px_32px_rgba(0,0,0,0.3)]">
  <div className="p-8">
    <h3 className="text-white font-bold text-heading-24">Premium Feature</h3>
  </div>
</div>

// Glass with brand gradient border
<div className="relative bg-white/5 backdrop-blur-xl rounded-2xl overflow-hidden">
  <div className="absolute inset-0 rounded-2xl border border-transparent bg-[linear-gradient(135deg,rgba(0,51,254,0.3),rgba(11,241,195,0.3))] [mask:linear-gradient(#fff_0_0)_padding-box,linear-gradient(#fff_0_0)] [-webkit-mask-composite:xor] [mask-composite:exclude]" />
  <div className="relative p-6">
    {/* Content */}
  </div>
</div>
```

### 规则

- 玻璃拟态**仅用于深色模式**，不要用于浅色背景
- `backdrop-blur` 至少为 `24px`，更低会让透明层显脏
- 边框使用 `10-15%` 白色透明度，过高会太抢眼
- 背景使用 `5-8%` 白色透明度，过高会失去玻璃感
- 始终搭配深色页面背景（`neutral-950` 或更深）

## 深色优先设计

Nebutra 是**深色优先**品牌。深色主题是主要设计表面，浅色模式是次级适配。

### 为什么深色优先

1. **品牌一致性**：蓝到青渐变在深色背景上最有生命力
2. **数据密度**：仪表盘和高密度界面在深色表面上更易扫描
3. **高端定位**：深色界面更容易传达克制、精密和专业感
4. **视觉舒适**：企业用户长时间停留在产品中，深色能降低疲劳

### 实现规则

| 规则 | 说明 |
|------|-------------|
| 深色优先设计 | 所有设计从 `neutral-950` 背景开始 |
| 落地页强制深色 | 落地页不切换到浅色模式 |
| 落地页 Logo 始终为白色 | inline SVG 使用 `text-white` |
| 渐变用于深色背景 | 品牌渐变以深色背景为设计前提 |
| 浅色模式是适配 | 使用品牌色的浅 tint，不换另一套颜色 |
| 先测深色 | 先在深色背景验证组件，再检查浅色 |

### 代码模式

```tsx
// Dark-first component styling
<div className="bg-neutral-950 text-neutral-100">
  {/* Default: dark */}
</div>

// Light mode adaptation
<div className="bg-neutral-950 dark:bg-neutral-950 light:bg-white text-neutral-100 light:text-neutral-900">
  {/* Adapts to light mode */}
</div>

// Forced dark (landing page)
<div className="dark" data-theme="dark">
  {/* Always dark, regardless of system preference */}
</div>
```

## 图案组合

### 推荐组合

| 主图案 | 辅助图案 | 场景 |
|----------------|-------------------|---------|
| 六边形网格 | 颗粒纹理 | Hero 区块 |
| 六边形网格 | 玻璃拟态 | 六边形背景上的功能卡片 |
| 星点画布 | 玻璃拟态 | 云 / 空间主题定价 |
| 点阵 | 无 | 仪表盘背景 |
| 闪烁网格 | 无 | 技术感数据区块 |
| Mesh 渐变 | 颗粒纹理 | 沉浸式 hero 区块 |
| 扭曲背景 | 玻璃拟态 | 全出血落地页 hero |

### 禁止组合

<Warning>
  以下图案组合会产生视觉噪音，必须避免：
</Warning>

| 组合 | 问题 |
|-------------|---------|
| 六边形网格 + 闪烁网格 | 竞争性的网格图案会制造混乱 |
| 星点画布 + 闪烁网格 | 动效过多，会抢占注意力 |
| 扭曲背景 + Neural Noise | 两个 WebGL shader 会增加 GPU 压力 |
| Mesh 渐变 + 扭曲背景 | 动态场与色彩场互相冲突 |
| 任意两个 WebGL 图案叠加 | GPU 资源竞争与性能风险 |

### 分层顺序

组合图案时遵循以下 z-index 分层：

```
z-0: Background color (neutral-950)
z-10: Pattern layer (hex grid, dots, stars)
z-20: Texture layer (grain, noise)
z-30: Glass panels (glassmorphism)
z-40: Content (text, buttons, images)
z-50: Overlays (modals, tooltips)
```

## 应做 / 禁止

**应做**把六边形网格作为主要装饰图案，它就是品牌视觉 DNA。

**应做**只在深色背景上使用玻璃拟态。

**应做**先设计深色模式，再适配浅色模式。

**应做**保持图案透明度克制（5-15%），让内容保持主角。

**应做**每个区块最多 1 个主图案 + 1 个轻量纹理。

**禁止**组合两个竞争性的网格图案（六边形 + 闪烁）。

**禁止**每页使用超过 1 个 WebGL shader。

**禁止**在浅色背景上使用玻璃拟态，它依赖深色表面才能成立。

**禁止**把动态图案放在内容密集区块，它会干扰阅读。

**禁止**在图案中使用非品牌色，例如紫色六边形或橙色点阵。

**禁止**跳过深色优先流程，浅色模式永远是次级适配。
