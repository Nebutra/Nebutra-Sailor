### Tailwind CSS 类

```tsx
// Brand colors
<div className="bg-brand-blue-500 text-white" />
<div className="bg-brand-cyan-500 text-neutral-950" />

// Blue scale
<div className="bg-blue-50 text-blue-900" />
<div className="border-blue-200" />

// Semantic
<div className="bg-success text-white" />
<div className="bg-error text-white" />
<div className="bg-warning text-neutral-900" />

// Dark mode
<div className="bg-white dark:bg-neutral-950" />
<div className="text-neutral-900 dark:text-neutral-100" />
```

### JavaScript / TypeScript 用法

```ts
import { colors } from "@nebutra/brand"

// 程序化访问品牌颜色
colors.blue[500]   // "#0033FE"
colors.cyan[500]   // "#0BF1C3"
colors.neutral[950] // "#020617"
```

## 禁止用法

<Warning>
  以下颜色替代方式严格禁止：
</Warning>

| 禁止项 | 原因 |
|-----------|--------|
| Tailwind `indigo-*` 或 `blue-*` 作为品牌蓝 | 严禁直接套用，请务必使用全局指定的原生命名 CSS 变量。 |
| Tailwind `teal-500` 作为品牌青 | Teal 不是 Nebutra cyan。 |
| Tailwind `gray-*` 作为中性色 | Nebutra 中性色带有蓝色底色。 |
| 橙色或红色作为主操作色 | 主操作只使用品牌蓝。 |
| 在浅色背景上使用 cyan 文本 | 不满足 WCAG 对比度，只能在深色背景上使用。 |
| 用纯品牌蓝填充背景 | Hero / CTA surface 应使用品牌渐变。 |
| `info` 语义使用非品牌色 | Info 必须使用品牌蓝 `#0033FE`，不能用 sky/teal。 |

---

## 不要 （Don't）

不要将 Tailwind 的默认 `bg-secondary` 或变量 `--secondary` 用作组件的弱化背景轨道（例如进度条 Progress、滑块 Sliders 等组件的底轨）。因为在云毓规范中，`--secondary` 被明确映射为了高饱和度的云毓青 `#0BF1C3`。若直接套用，会导致背景轨道呈现出难以直视的赛博亮色，且无法满足无障碍对比度要求。如果需要弱化轨道颜色，请务必使用带透明度的品牌主色（如 `bg-primary/20`）。

## 应做 / 禁止

**应做**：始终使用全局变量（如 `bg-primary`、`text-primary` 或自定义色名 `blue-500` 即 `#0033FE`）应用于所有主交互，例如按钮、链接和输入框高光。

**应做**：使用完整 11 阶色阶承载微妙 tint、hover 状态和深色模式适配。

**应做**：将 `blue-500` 与 `cyan-500` 组合为品牌专属渐变（Brand Signature）。

**应做**：使用 `neutral-950` 作为深色模式页面背景。

**禁止**：在组件代码里直接写 `bg-indigo-500` 或 `bg-blue-500` 这类 Tailwind 默认调色盘色。所有色彩映射都要回源到 `bg-primary` 或全局语义变量，确保未来主题切换时不会漂移。

**禁止**：在白底上使用 cyan，它不满足 WCAG 对比度。

**禁止**：用 Tailwind 默认色近似品牌色，例如 `blue-500`、`emerald-400`。

**禁止**：在已定义的 blue、cyan、neutral 和语义调色盘之外引入新色阶。

**禁止**在需要品牌渐变的场景把品牌蓝当作纯色填充使用，例如 hero 区块和主 CTA。

**禁止**将 Tailwind 的默认 `bg-secondary` 或变量 `--secondary` 用作组件的弱化背景轨道（例如进度条 Progress、滑块 Sliders 等）。在云毓主题中，`--secondary` 被映射为高饱和度的青色 `#0BF1C3`。若直接套用，会导致背景轨道呈现出难以直视的赛博亮色，且大幅破坏无障碍阅读。请务必使用带透明度的品牌主色（如 `bg-primary/20`）作为任何组件的底层轨道。
