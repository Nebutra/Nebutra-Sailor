# 事件采集 API (Event Ingestion API)

事件采集 API 允许您将衡量用户行为、系统操作或其他指标的自定义事件发送到 Nebutra 生态系统中。

## 接口目的

事件采集会持久化产品分析和系统事件。它应支撑 analytics、audit correlation 和下游处理，但不阻塞用户主流程。

## 接口地址

`POST /api/v1/events/ingest`

### 请求体 (Request Body)

```json
{
  "events": [
    {
      "eventName": "user_signed_up",
      "context": {
        "tenantId": "tenant_123",
        "occurredAt": "2024-03-10T12:00:00Z"
      },
      "payload": {
        "plan": "premium"
      },
      "source": "web"
    }
  ]
}
```

### 响应 (Response)

```json
{
  "success": true,
  "ingested": 1
}
```

## API 驱动的界面状态

- 提交成功后可以清空本地 buffer，并展示克制确认。
- 部分采集失败时，应保留未发送事件等待 retry。
- 连续失败时应降级 analytics collection，不阻塞产品导航。

## 错误 / 加载 / 空状态契约

- 加载：批量并 debounce 事件发送；后台 telemetry 不展示前台 spinner。
- 错误：记录 request id，并保留未发送事件用于 retry。
- 空状态：空 events array 应视为客户端 bug，不应发送。
