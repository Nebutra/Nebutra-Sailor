## 使用方法

```tsx
import { TextShimmer } from "@nebutra/ui/primitives"
```

## 示例

### 加载状态

```tsx
<TextShimmer duration={1}>正在生成代码... (Generating code...)</TextShimmer>
```

### AI 输入指示器

```tsx
<TextShimmer duration={1.5} className="text-sm text-muted-foreground">
  Claude 正在思考中... (Claude is thinking...)
</TextShimmer>
```

### 通过 CSS 变量自定义颜色

```tsx
<TextShimmer
  duration={1.2}
  className="text-xl [--base-color:theme(colors.blue.600)] [--base-gradient-color:theme(colors.blue.200)]"
>
  高级功能 (Premium Feature)
</TextShimmer>
```

### 作为标题渲染

```tsx
<TextShimmer as="h1" className="text-4xl font-bold" duration={3}>
  欢迎 (Welcome)
</TextShimmer>
```

### 暂停状态（静态显示）

```tsx
<TextShimmer paused>静态文本 (Static Text)</TextShimmer>
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `children` | `string` | — | 文本内容（必须是字符串） |
| `as` | `React.ElementType` | `"p"` | 渲染为指定的 HTML 元素 |
| `duration` | `number` | `2` | 微光扫过一周的持续时间（秒） |
| `spread` | `number` | `2` | 微光束的扩散范围（与文本长度成比例） |
| `paused` | `boolean` | `false` | 是否暂停动画 |
| `className` | `string` | — | 额外的 CSS 类名 |

## CSS 变量

可以通过覆盖 CSS 变量来自定义微光颜色：

| 变量 | 默认值 (浅色) | 默认值 (深色) | 用途 |
|----------|-----------------|----------------|---------|
| `--base-color` | `#a1a1aa` | `#71717a` | 文本基础颜色 |
| `--base-gradient-color` | `#000` | `#ffffff` | 微光亮点颜色 |

## 可访问性

- shimmer 只用于短暂生成状态或轻量强调。长时间 loading 需要在动画文本之外提供 status message。
- 文本内容本身仍是 accessible name；不要把重要状态变化只放在 shimmer styling 里。
- 父级进入 reduced-motion 模式，或 shimmer 出现在高密度阅读表面时，应使用 `paused`。
- 不要把 shimmer 和低对比 muted text 叠在一起。highlight 未经过时，base color 也必须可读。

## Token 契约

- `--base-color` 和 `--base-gradient-color` 优先使用 semantic CSS variables，不要在产品表面硬编码 brand hex。
- duration 是 motion parameter，应和周围 loading pattern 保持一致。
- `TextShimmer` 是 tool-family text substrate。紧凑非文本进度用 `LoadingDots`，入场动效用 `AnimateIn`。
- 动画属性限制在 background position 和 color interpolation，不要引入会造成 layout shift 的 shimmer 效果。
