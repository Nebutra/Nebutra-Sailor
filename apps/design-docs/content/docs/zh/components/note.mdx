## 安装

```tsx
import { Note } from "@nebutra/ui/primitives";
```

## 用法

把 `Note` 放在它解释的控件、卡片或区块旁边。它不是 toast，应该持续存在，直到底层状态改变。

```tsx
<Note label="Region Change" tone="warning">
  Changing this region restarts all functions.
</Note>
```

`action` 只放一个内联恢复路径或升级路径。

```tsx
<Note action={<Button size="sm">Review Usage</Button>} tone="secondary">
  This workspace is close to its included usage limit.
</Note>
```

## 语义模型

Geist 示例里暴露了很多视觉化 `type`，例如 `alert`、`lite`、`ghost`、`violet`、`rotate-ccw`。Nebutra 不把这些直接带进 API：`rotate-ccw` 是图标名，`alert` 会和 warning/error 语义重叠，`violet` 在当前 token 系统里没有被批准的语义或品牌层定义。

| Tone        | 含义                         | 默认 role |
| ----------- | ---------------------------- | --------- |
| `default`   | 中性上下文提示               | `note`    |
| `secondary` | 更低强调度的中性信息         | `note`    |
| `success`   | 校验通过或状态完成           | `note`    |
| `warning`   | 用户需要理解的后果           | `note`    |
| `error`     | 用户必须修复的问题           | `alert`   |
| `cyan`      | Nebutra 品牌数据/智能上下文信号 | `note` |

`type` 作为 Geist 迁移别名保留，新代码优先使用 `tone`。

## 行为

- Note 不自带 dismiss。能被随手关掉的消息通常不该是 Note。
- 一个概念只放一个 Note。一个卡片里堆三条 Note，问题在页面架构。
- `action` 只能是一个内联 CTA，不要塞两个按钮。
- `disabled` 会设置 `aria-disabled`，并让 action 子树进入 inert 状态。

## 内容

- `label` 是 1-2 个词的 Title Case 前缀，例如 `Region Change`、`Rate Limit`、`Plan Limit`。
- 当 tone 图标和正文已经足够清楚时，使用 `label={false}`。
- `children` 尽量是一句主动语态，直接说明影响。
- 不使用 `Heads up`、`FYI`、`Please note` 这类填充词。

## Props

| Prop       | Type                                                                 | Default | Description |
| ---------- | -------------------------------------------------------------------- | ------- | ----------- |
| `tone`     | `"default" \| "secondary" \| "success" \| "warning" \| "error" \| "cyan"` | `"default"` | 语义 tone |
| `type`     | Same as `tone`                                                       | —       | Geist 迁移别名，不能和 `tone` 同时传 |
| `size`     | `"small" \| "medium" \| "large"`                                     | `"medium"` | 密度尺寸 |
| `fill`     | `boolean`                                                            | `false` | 更强背景样式 |
| `label`    | `string \| false`                                                    | tone default | 前缀标签 |
| `action`   | `ReactNode`                                                          | —       | 单个内联 CTA |
| `icon`     | `ReactNode \| false`                                                 | tone icon | 前置图标覆盖 |
| `disabled` | `boolean`                                                            | `false` | 禁用 action 子树并降低表面强调 |
| `role`     | `"note" \| "alert" \| "status"`                                      | auto    | 覆盖默认 role |

## Accessibility

- `error` 默认 `role="alert"`；其他 tone 默认 `role="note"`。
- 图标是装饰性的，真正的信息由 label 和正文承载。
- 如果 Note 放在可聚焦卡片或行操作里，外层控件需要显式 accessible name。
- 不要只靠颜色表达阈值；warning/error 必须配合能说明后果的文案。
