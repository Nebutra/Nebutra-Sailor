## 使用方法

```tsx
import { Table } from "@nebutra/ui/primitives";

export function UsageTable() {
  return (
    <Table>
      <Table.Header>
        <Table.Row>
          <Table.Head>Product</Table.Head>
          <Table.Head>Usage</Table.Head>
          <Table.Head numeric>Charge</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body interactive striped>
        <Table.Row>
          <Table.Cell>Brake Pads Set</Table.Cell>
          <Table.Cell>100 sets</Table.Cell>
          <Table.Cell numeric>$5,000.00</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  );
}
```

Compound API 是规范入口。为了不破坏旧消费者，named exports 仍然保留：

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@nebutra/ui/primitives";
```

## 属性

所有部件都继承对应的原生 HTML 属性。

| 组件 | 对应元素 | 核心属性 |
| --- | --- | --- |
| `Table` | `<table>` | `className`, `style`, `wrapperClassName`, `wrapperStyle` |
| `Table.Colgroup` | `<colgroup>` | 原生 colgroup 属性 |
| `Table.Col` | `<col>` | 原生 col 属性 |
| `Table.Header` | `<thead>` | 原生 section 属性 |
| `Table.Body` | `<tbody>` | `striped`, `bordered`, `interactive`, `virtualize` |
| `Table.Row` | `<tr>` | 原生 row 属性 |
| `Table.Head` | `<th>` | `numeric`, `scope` |
| `Table.Cell` | `<td>` | `numeric`, `colSpan`, `rowSpan` |
| `Table.Footer` | `<tfoot>` | 原生 footer 属性 |
| `Table.Caption` | `<caption>` | 原生 caption 属性 |

## 示例

### 分隔线与斑马纹

```tsx
<Table>
  <Table.Header>
    <Table.Row>
      <Table.Head>Product</Table.Head>
      <Table.Head>Status</Table.Head>
      <Table.Head numeric>Requests</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body bordered striped>
    {rows.map((row) => (
      <Table.Row key={row.id}>
        <Table.Cell>{row.product}</Table.Cell>
        <Table.Cell>{row.status ?? "—"}</Table.Cell>
        <Table.Cell numeric>{row.requests}</Table.Cell>
      </Table.Row>
    ))}
  </Table.Body>
</Table>
```

### 完整费用表

```tsx
<Table>
  <Table.Colgroup>
    <Table.Col className="w-[44%]" />
    <Table.Col className="w-[22%]" />
    <Table.Col className="w-[22%]" />
    <Table.Col className="w-[12%]" />
  </Table.Colgroup>
  <Table.Header>
    <Table.Row>
      <Table.Head>Product</Table.Head>
      <Table.Head>Usage</Table.Head>
      <Table.Head>Price</Table.Head>
      <Table.Head numeric>Charge</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body interactive striped>
    {items.map((item) => (
      <Table.Row key={item.product}>
        <Table.Cell>{item.product}</Table.Cell>
        <Table.Cell>{item.usage}</Table.Cell>
        <Table.Cell>{item.price}</Table.Cell>
        <Table.Cell numeric>{formatCurrency(item.charge)}</Table.Cell>
      </Table.Row>

  </Table.Body>
  <Table.Footer>
    <Table.Row>
      <Table.Cell className="font-medium text-foreground" colSpan={3}>

      </Table.Cell>
      <Table.Cell className="font-medium text-foreground" numeric>
        {formatCurrency(total)}
      </Table.Cell>
    </Table.Row>
  </Table.Footer>

```

### 渐进展开

```tsx
<div className="relative">
  <Table id={tableId}>
    <Table.Header>{/* columns */}</Table.Header>
    <Table.Body interactive striped virtualize>
      {visibleRows.map((row) => (
        <Table.Row key={row.id}>{/* cells */}</Table.Row>
      ))}
    </Table.Body>
  </Table>
  <ShowMore
    controls={tableId}
    expanded={expanded}
    hiddenCount={hiddenCount}
    onExpandedChange={setExpanded}
  />
</div>
```

## 最佳实践

- 当行结构一致，并且至少一列需要横向比较时使用 `Table`。
- 单行描述加一个操作按钮时用 `Entity`；详情页 key/value 信息块用 `Description`。
- 底层列表为空时，在表格外渲染 `EmptyState`，不要输出空的 `Table.Body`。
- 未知或不适用的单元格值渲染为 `—`。不要用 `N/A`、`null` 或空字符串。
- 可排序表头应在 `Table.Head` 内放 button；排序箭头是装饰性的，button 负责宣布下一次排序状态。
- 数值列给 `Table.Head` 和 `Table.Cell` 加 `numeric`，让数字使用 tabular numbers 对齐。
- 列标题使用 Title Case 名词或名词短语：Last Used、Requests (7d)、Created、Status。

## 可访问性

- 组件保留原生表格语义：`table`、`thead`、`tbody`、`th`、`td`、`tfoot`、`caption`。
- `Table.Head` 默认 `scope="col"`。复杂表格里的行标题请显式设为 `scope="row"`。
- 可排序列需要在当前 `Table.Head` 上设置 `aria-sort="ascending"` 或 `aria-sort="descending"`。
- 渐进展开场景用 `ShowMore`，确保触发器带有 `aria-controls` 和 `aria-expanded`。
