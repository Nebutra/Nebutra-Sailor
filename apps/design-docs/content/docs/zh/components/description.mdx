## 概览

`Description` 是一个紧凑的“标题 + 副标题”组合块。通过可选的 `tooltip` 属性，可以在标题旁边渲染一个信息图标 —— 悬停或聚焦该图标时，会显示一个包含额外背景信息的 `ContextCard`。

## 安装

```tsx
import { Description } from "@nebutra/ui/primitives";
```

## 使用方法

### 默认用法

```tsx
import { Description } from "@nebutra/ui/primitives"

<Description
  title="部分标题"
  content="关于此部分的数据。"
/>
```

### 带有工具提示

```tsx
<Description
  title="部分标题"
  content="关于此部分的数据。"
  tooltip="关于此部分所指内容的额外背景信息。"
/>
```

### 富文本工具提示内容

`tooltip` 属性接受任何 `ReactNode`：

```tsx
<Description
  title="部署区域"
  content="您的工作负载运行在何处。"
  tooltip={
    <div className="flex flex-col gap-1">
      <p className="font-medium">区域选择</p>
      <p className="text-muted-foreground text-xs">
        选择离您的用户最近的区域以降低延迟。
      </p>
    </div>
  }
/>
```

## 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `title` | `string` | — | **必填。** 元数据标签或标题。 |
| `content` | `ReactNode` | — | **必填。** 标题下方的值内容。 |
| `tooltip` | `ReactNode` | — | 提供后会显示信息图标，并在 hover/focus 时展示补充说明。 |
| `className` | `string` | — | 外层样式扩展。 |

## 状态

| 状态 | 契约 |
|------|------|
| 默认 | 渲染语义化 `<dl>`，`dt` 保持弱化，`dd` 承载用户真正关心的值。 |
| 带 tooltip | 增加可聚焦的信息图标，背后使用 `ContextCard`；不打开 tooltip 也能读到主值。 |
| 富文本 tooltip | 可传结构化说明，但触发器仍然是小型解释性 affordance。 |

## 可访问性

- 工具提示基于 `ContextCard` 构建；`ContextCard` 使用 Base UI Popover，并带有 200ms 的悬停延迟。
- 键盘可达：通过聚焦信息图标来显示工具提示。
- 屏幕阅读器通过 `role="tooltip"` 播报工具提示内容。
- 使用 `Escape` 键可关闭工具提示。

## 设计契约

- `Description` 只用于 definition-list 元数据：Region、Plan、Last Deployed、Build Duration。
- 表单帮助文本归 `Field` 管，不要用 `Description` 伪装 helper text。
- `title` 保持纯文本；按钮、菜单、链接放在 `content` 或外层布局中。
- 保留 `<dl><dt><dd>` 语义，不要为了样式把它拍平成普通段落。
