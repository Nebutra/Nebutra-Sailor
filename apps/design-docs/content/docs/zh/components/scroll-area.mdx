`ScrollArea` 仍作为文档兼容 helper 保留。面向同级项目溢出的 rail、feed、snippet 和按钮辅助滚动，请使用 `Scroller`。

## 使用方法

```tsx
import { ScrollArea, ScrollBar } from "@/components/mdx-scroll-area"
```

## 属性

### ScrollArea (根组件)

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `className` | `string` | — | 额外的 CSS 类名 |
| `children` | `ReactNode` | — | 可滚动内容 |

### ScrollBar (滚动条)

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | 滚动条方向 |
| `className` | `string` | — | 额外的 CSS 类名 |

## 可访问性

- 滚动区域的内容对键盘和屏幕阅读器用户均可访问 —— 保留了原生的滚动语义。
- 自定义滚动条带有 `aria-hidden="true"` 属性 —— 仅作为视觉参考。
- 焦点保留在滚动区域内的内容元素上，而不是滚动条本身。
