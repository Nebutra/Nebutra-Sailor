## 用法

```tsx
import { Slider } from "@nebutra/ui/primitives"
```

```tsx
const [value, setValue] = useState([50])

<Slider
  label="Sample Rate"
  max={96}
  min={8}
  onValueChange={setValue}
  step={4}
  unit=" kHz"
  value={value}
/>
```

## 属性
Slider 渲染原生 `<input type="range">`，因此保留浏览器默认键盘行为。公开 API 同时兼容历史 `number` 形态和 Geist 风格的单项 `number[]` 形态。

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|------|
| `value` | `number \| number[]` | — | 受控值；数组只读取第一项，因为这是单手柄 Slider |
| `defaultValue` | `number \| number[]` | `min` | 非受控初始值 |
| `valueMode` | `"number" \| "array"` | inferred | 当没有 value/defaultValue 时强制回调形态 |
| `onValueChange` | `(value) => void` | — | 数值变化时触发 |
| `onValueCommit` | `(value) => void` | — | 指针释放或键盘提交时触发 |
| `min` | `number` | `0` | 产品真实最小值 |
| `max` | `number` | `100` | 产品真实最大值 |
| `step` | `number` | `1` | 吸附步进 |
| `label` | `string` | — | 可见标签和可访问名称 |
| `unit` | `string` | — | 实时数值后缀 |
| `showValue` | `boolean` | `true` | 是否用 tabular numerals 显示实时值 |
| `formatValue` | `(value: number) => ReactNode` | — | 自定义实时值格式化 |

## 最佳实践

当用户需要选择近似范围，而不是精确值时使用 Slider：带宽上限、透明度、音量、颜色通道。

端口号、内存限制这类精确值应和数字 Input 组合使用。键盘用户通常会直接输入精确值。

使用合理 `step`，例如 `1`、`5`、`10`，避免拖动产生噪声数值。`min` 和 `max` 必须来自真实产品限制。

始终在轨道旁显示实时值，并说明数字代表什么，例如 Sample Rate · 44 kHz。轨道本身不是自解释的。

阈值颜色必须复用产品其它位置已经出现的断点。不要只为 Slider 发明 warning/error 阈值。

## 可访问性

为 Slider 提供可见 `label` 或 `aria-label`。不要拦截原生方向键、Page Up/Down、Home、End 行为。

实时值是视觉上下文。屏幕阅读器仍会从原生 range input 获得 `aria-valuemin`、`aria-valuemax` 和 `aria-valuenow`。
