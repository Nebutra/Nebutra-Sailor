## 安装

```tsx
import { FileAttachment } from "@nebutra/ui/primitives";
```

```bash
npx shadcn@latest add https://ui.nebutra.com/r/file-attachment.json
```

## 用法

`FileAttachment` 展示用户上传或粘贴的文件。它不是 AI tool-family 成员；tool 组件渲染 AI 输出，而 FileAttachment 渲染用户输入。

```tsx
<FileAttachment
  filename="quarterly-report.pdf"
  size={245_000}
  onRemove={() => removeFile(id)}
/>
```

## 模式

| 模式 | 渲染 |
| --- | --- |
| `chip` | icon 或 thumbnail + 文件名 + size |
| `image-only` | 仅 thumbnail；没有图片 URL 时回退为 chip |

## 可移除状态

传入 `onRemove` 后会显示可键盘访问的移除按钮。按钮不仅在 hover 时出现，也会在 `focus-visible` / `focus-within` 时出现，避免 hover-only 交互。

## 可访问性

- 移除按钮使用 `aria-label="Remove <filename>"`。
- 图片 thumbnail 使用有意义的 `alt={filename}`。
- 文件类型 icon 由扩展名和 `isImage` 推导，避免调用方重复判断。
