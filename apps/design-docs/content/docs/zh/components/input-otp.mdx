## 属性

### InputOTP (根组件)

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `maxLength` | `number` | — | **必填。** OTP 字符的总长度 |
| `value` | `string` | — | 受控的 OTP 值 |
| `onChange` | `(value: string) => void` | — | 值改变时的回调函数 |
| `disabled` | `boolean` | `false` | 禁用所有插槽 |
| `pattern` | `string` | — | 允许字符的正规表达式 (例如：仅限数字) |
| `className` | `string` | — | 额外的 CSS 类名 |

### InputOTPSlot (输入插槽)

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `index` | `number` | — | **必填。** 从零开始的插槽索引 |
| `className` | `string` | — | 额外的 CSS 类名 |

### 受控 OTP

```tsx
const [otp, setOtp] = useState("")

<InputOTP maxLength={6} value={otp} onChange={setOtp}>
  <InputOTPGroup>
    {Array.from({ length: 6 }).map((_, i) => (
      <InputOTPSlot key={i} index={i} />
    ))}
  </InputOTPGroup>
</InputOTP>

{otp.length === 6 && <p>完整的验证码： {otp}</p>}
```

## 可访问性

- 渲染一个隐藏的原生 `<input>` 元素 —— 屏幕阅读器可以正常交互。
- 每个视觉插槽都会视觉化跟踪光标位置。
- 自动递进：输入后焦点会自动移至下一个插槽。
- 支持粘贴完整的 OTP 字符串。
- 输入框上带有描述性的 `aria-label="One-time password"`。
