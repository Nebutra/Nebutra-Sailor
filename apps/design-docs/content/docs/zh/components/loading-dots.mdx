## 安装

```tsx
import { LoadingDots } from "@nebutra/ui/primitives";
```

Standalone registry 安装：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/loading-dots.json
```

## 用法

`LoadingDots` 用于 inline “工作仍在继续” 文案，例如 saving、building 或等待 AI 工具。独立 loading affordance 使用 `Spinner`。

```tsx
<LoadingDots>Saving</LoadingDots>
```

## 可访问性

- wrapper 使用 `aria-live="polite"`，让 label 可以被读出且不打断用户。
- 三个点为 `aria-hidden`。
- `prefers-reduced-motion: reduce` 会关闭动画，保留静态点。

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 控制文字尺寸和点动画节奏。 |
| `children` | `ReactNode` | `"Loading"` | 渲染在点之前的可见 label。 |
| `className` | `string` | - | 只用于外部布局上下文的补充 class。 |

## 治理规则

- 保持这个 primitive 为 inline 语义，不用于整页 loading state。
- 不在调用处自定义动画 timing；motion 属于 primitive。
- 优先使用具体 label，例如 `Saving`、`Building`、`Thinking`。
