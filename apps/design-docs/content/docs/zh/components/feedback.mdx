## 概览 (Overview)

`Feedback` 是用于页面、文档或完成型流程末尾的轻量反馈 primitive。它不是客服表单、缺陷提交流程，也不是 NPS 采样组件。

提交后组件会关闭面板并把焦点还给触发按钮。关闭本身就是确认反馈已提交，不要再替换成泛泛的感谢 toast。

## 安装 (Installation)

```tsx
import { Feedback } from "@nebutra/ui/primitives"
```

## 使用方法 (Usage)

### 默认模式 (Default)

默认的 popover 模式只用于桌面宽度界面。

```tsx
<Feedback label="Feedback" dryRun />
```

### 行内模式 (Inline)

```tsx
<Feedback dryRun label="Feedback" type="inline" />
```

### 带话题分类 (With Topics)

使用 `showTopics` 启用默认分类列表，也可以通过 `topics` 传入业务自己的分类。

```tsx
<Feedback
  dryRun
  label="Report a Bug"
  showTopics
/>
```

### 带元数据 (With Metadata)

只附加非敏感上下文，帮助团队复现问题。

```tsx
<Feedback
  dryRun
  label="Feedback on Checkout"
  metadata={{
    buildId: "build_12345",
    location: "post-checkout",
    plan: "pro",
    viewport: "desktop",
  }}
/>
```

### 自定义提示语 (Custom Copy)

```tsx
<Feedback
  copy="How did the import go?"
  label="Feedback on Imports"
  type="inline"
/>
```

## 属性 (Props)

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `label` | `string` | — | 可见触发文案/标题，同时写入 payload。使用 Title Case |
| `type` | `"default" \| "inline"` | `"default"` | 展示模式 |
| `copy` | `string` | 随模式变化 | 情绪按钮旁的提示语 |
| `topics` | `Array<string \| { value: string; label: string }>` | — | 业务自定义分类 |
| `showTopics` | `boolean` | `false` | 启用默认 Bug/Pricing/Documentation/Performance/Other 分类 |
| `metadata` | `FeedbackMetadata` | — | 附加到 payload 的非敏感上下文 |
| `onSubmit` | `(payload: FeedbackPayload) => void \| Promise<void>` | — | 将反馈发送到后端 |
| `dryRun` | `boolean` | `false` | 演示时跳过 `onSubmit` |
| `disabled` | `boolean` | `false` | 禁用触发器和表单控件 |
| `className` | `string` | — | 根节点 class 覆盖 |

## FeedbackPayload

```ts
interface FeedbackPayload {
  label: string
  emotion?: "love" | "okay" | "not-great" | "hate"
  message: string
  topic?: string
  metadata?: Record<string, string | number | boolean | null | undefined>
}
```

## 最佳实践 (Best Practices)

- 只在用户已经形成判断后放置 Feedback：页面末尾、文档页脚或完成型流程之后。
- 只有团队确实按分类处理反馈时才使用 topics。普通开放反馈不需要分类。
- `metadata` 只放非敏感上下文：路由、构建 ID、套餐、视口。
- `label` 使用短 Title Case：`Feedback`、`Feedback on Imports`、`Report a Bug`。
- `copy` 使用 sentence case，避免 `please` 和道歉式文案。
- 文本域占位符固定为 `Your feedback...`。

## 可访问性 (Accessibility)

- 情绪控件以 radio group 暴露，每个选项都有可访问名称。
- 表单打开时文本域获得焦点，并由提示文案标注。
- 提交成功后关闭面板，并把焦点还给触发按钮。
- 提交失败时保持面板打开，并通过 `role="alert"` 播报内联错误。
