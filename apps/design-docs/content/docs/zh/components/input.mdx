## 使用

`Input` 用于单行自由文本：名称、域名、令牌、URL、局部搜索。内容可能换行时使用 `Textarea`；值来自固定列表并需要过滤时使用 `Combobox`。

```tsx
<Input
  id="project-name"
  label="Project Name"
  placeholder="my-awesome-project"
  description="Use lowercase letters, numbers, and hyphens."
/>
```

`type="search"` 在字段有内容时可按 Escape 清空。placeholder 必须命名搜索范围，例如 `Search projects`，不要只写 `Search`。

### 文件

当浏览器原生文件选择器就是正确交互时，使用 `type="file"`。文件选择按钮继承 `Input` 的高度、边框和字体尺度；只有在需要拖拽、上传进度或校验预览时，才应升级为专用上传区域。

## Props

`Input` 扩展原生 `React.InputHTMLAttributes<HTMLInputElement>`，但 `prefix` 和 `size` 由组件 API 接管。

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|------|
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 由组件 token 驱动的视觉密度。 |
| `label` | `string` | - | 可见标签。类型层面要求同时传入 `id`。 |
| `id` | `string` | - | 提供 `label` 时必填。 |
| `description` | `string` | - | 通过 `aria-describedby` 关联的辅助文本。 |
| `error` | `string \| boolean` | - | 标记错误态。字符串会同时渲染内联错误文案。 |
| `prefix` | `ReactNode` | - | 左侧非交互前缀。 |
| `suffix` | `ReactNode` | - | 右侧非交互后缀。会被 clear、shortcut、loading 控件替代。 |
| `clearable` | `boolean` | `false` | 字段有值时显示清除按钮。 |
| `onClear` | `() => void` | - | 字段被清空后触发。 |
| `onValueChange` | `(value: string) => void` | - | 面向受控场景的 value-first 回调。 |
| `shortcut` | `string` | - | 可视快捷键提示。字段有内容时显示 `Esc`。 |
| `loading` | `boolean` | `false` | 显示 spinner，但不移除输入焦点能力。 |
| `revealable` | `boolean` | `false` | 在 `type="password"` 时添加密码显示按钮。 |
| `revealLabel` | `string` | `"Show password"` | 密码隐藏状态下的按钮无障碍标签。 |
| `hideLabel` | `string` | `"Hide password"` | 密码可见状态下的按钮无障碍标签。 |
| `clearOnEscape` | `boolean` | `type === "search"` | 字段有内容时按 Escape 清空。 |
| `wrapperClassName` | `string` | - | 应用于带前后缀的 control wrapper。 |
| `fieldClassName` | `string` | - | 应用于 label/helper/error 的 field wrapper。 |

## 设计原则

- Label 使用 Title Case 名词：Project Name、Domain、Environment Variable Name。
- Placeholder 展示示例值，不写操作说明。
- 验证优先在 blur 后触发；错误文案准备好后传入 `error` 字符串。
- 表单提交前由调用方 trim 首尾空格。
- 保存中保持输入框可聚焦；除非真的无法输入，否则用 `loading` 而不是 `disabled`。
- 不要把按钮塞进 `suffix`。优先使用 `clearable`、`revealable` 这类内建控件；右侧需要自定义交互时应抽成专用 field primitive。

## 可访问性

- `label` 没有 `id` 不会通过类型检查，避免 label 与 input 脱钩。
- `description`、文本前后缀、字符串错误会合并进 `aria-describedby`。
- 错误文案使用 `role="alert"`。
- 图标前后缀是装饰性内容，应从辅助技术中隐藏。
- 搜索框只有在有内容时拦截 Escape；为空时 Escape 仍可关闭外层 Dialog。
- 密码显示按钮暴露 `aria-pressed`，切换后会把焦点还给输入框。

## Tokens

`Input` 使用 `inputTokens` 管理尺寸、圆角、内边距、前后缀偏移、控制按钮尺寸、图标尺寸与 focus ring 宽度。运行时颜色只消费 semantic tokens：`background`、`foreground`、`input`、`ring`、`muted-foreground`、`destructive`。
