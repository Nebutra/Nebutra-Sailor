## 使用方法 (Usage)

```tsx
import { Textarea } from "@nebutra/ui/primitives";
```

```tsx
<Textarea
  id="message"
  label="Message"
  description="Keep the first sentence user-facing."
  placeholder="Customers can now..."
  rows={4}
/>
```

## 属性 (Props)

支持原生 `<textarea>` 的所有属性，此外还包括：

| 属性 | 类型 | 默认值 | 描述 |
| ---- | ---- | ------ | ---- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 与表单控件一致的 token 化密度尺寸。 |
| `label` | `string` | — | 可见字段标签。类型层面要求同时传入 `id`。 |
| `description` | `string` | — | 通过 `aria-describedby` 关联的辅助说明。渲染字符串错误时会被错误替代。 |
| `error` | `string \| boolean` | — | 标记字段无效；字符串会渲染内联错误消息。 |
| `onValueChange` | `(value: string) => void` | — | 除原生 `onChange` 外的 value-first 回调。 |
| `fieldClassName` | `string` | — | label、辅助说明、错误消息外层容器的类名。 |

## 设计原则 (Design Principles)

- Textarea 只用于天然会换行的内容：发布说明、描述、评论和事故摘要。
- 视觉保持克制：语义 border、background、text、muted placeholder 和 token 化焦点环，不叠额外阴影。
- 鼠标和键盘聚焦都由组件的 `:focus` 接管，避免浏览器原生方形 outline 从圆角控件外漏。
- 只有界面有足够纵向空间时才使用 `ExpandingTextarea`；密集表单和 footer 里固定 rows 更稳。

## 可访问性 (Accessibility)

`label`、`description` 和字符串 `error` 会自动关联到 `id`、`aria-describedby`、`aria-invalid`。错误文本使用 `role="alert"`。

如果外部组合 label，仍需保持同样契约：`htmlFor` 必须匹配 textarea 的 `id`，辅助说明保持一句话，校验文案要指出字段和约束。

## Tokens

Textarea 的几何尺寸来自 `textareaTokens`，颜色来自运行时语义 CSS 变量：

| Token | 用途 |
| ----- | ---- |
| `textareaTokens.sizes` | 每个密度尺寸的最小高度、padding、字号和圆角。 |
| `textareaTokens.focusRingWidth` | focus 与错误 focus 状态共享的焦点环宽度。 |
| `textareaTokens.fieldGap` | label、控件和字段消息之间的间距。 |
| `--background`, `--foreground`, `--input`, `--ring`, `--destructive` | 语义颜色契约。 |
