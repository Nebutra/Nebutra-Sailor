## 概览

`StatusBadge` 通过细垂直分隔线显示两个标签。左侧为加粗字体（主要标签），右侧为柔和/调淡字体（次要标签）。每个标签前都可以添加可选图标，其颜色会根据 `status` 属性自动调整。

## 安装

```tsx
import { StatusBadge } from "@nebutra/ui/primitives";
```

## 使用方法

### 基础用法

```tsx
import { ShieldCheck, CrossCircle as XCircle } from "@nebutra/icons";

<StatusBadge
  leftIcon={ShieldCheck}
  rightIcon={XCircle}
  leftLabel="安全防护"
  rightLabel="SSO 已禁用"
  status="success"
/>
```

### 多种状态展示

```tsx
import { CheckCircle as CheckCircle2, Warning as AlertCircle, CrossCircle as XCircle } from "@nebutra/icons";

<div className="flex gap-2 flex-wrap">
  <StatusBadge leftIcon={CheckCircle2} leftLabel="在线" rightLabel="v2.1.0" status="success" />
  <StatusBadge leftIcon={AlertCircle} leftLabel="运行降级" rightLabel="3 起事件" status="warning" />
  <StatusBadge leftIcon={XCircle} leftLabel="服务中断" rightLabel="5 个受影响" status="error" />
</div>
```

### 无图标模式

```tsx
<StatusBadge leftLabel="区域" rightLabel="us-east-1" status="info" />
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `leftLabel` | `string` | — | **必需。** 主要标签（加粗，前景显示） |
| `rightLabel` | `string` | — | **必需。** 次要标签（调淡/柔和显示） |
| `leftIcon` | `LucideIcon` | — | 左标签前的图标 |
| `rightIcon` | `LucideIcon` | — | 右标签前的图标 |
| `status` | `"success" \| "error" \| "warning" \| "info" \| "default"` | `"default"` | 决定图标的颜色 |
| `className` | `string` | — | 额外的 CSS 类名 |

## 状态图标颜色对照表

| 状态 | 图标颜色 |
|--------|-----------|
| `success` | `text-emerald-600` (深色模式: `text-emerald-500`) |
| `error` | `text-red-600` (深色模式: `text-red-500`) |
| `warning` | `text-amber-600` (深色模式: `text-amber-500`) |
| `info` | `text-blue-600` (深色模式: `text-blue-500`) |
| `default` | `text-muted-foreground` |

## 注意事项

- `status` 仅影响图标颜色 —— 徽章容器始终使用 `bg-background` 并带有 `border`。
- 标签之间的分隔线是一个 `1px` 宽的 `bg-border` 元素。

## 可访问性

- 两侧标签必须保留文本；图标和颜色只是辅助信号。
- 每个标签都应足够短，保证在紧凑状态行里可预测换行。
- 附近文案已经命名同一状态时，避免重复堆叠只靠图标识别的徽章。

## 设计契约

- `StatusBadge` 用于紧凑的成对状态文案，例如能力名称加当前条件。
- 左侧标签表示实体或能力，右侧标签表示当前状态或限定信息。
- 状态颜色只是辅助，不是契约本身。即使没有颜色，两侧标签也必须能解释状态。

## 真实产品示例

- 安全设置行展示 `安全防护` 加 `SSO 已禁用` 或 `SCIM 已启用`。
- 区域或环境页头把位置和当前发布状态配成一组。
- 集成卡片总结服务商连接健康度和最近一次成功同步标签。

## 反模式

- 不要把 `StatusBadge` 当成严重程度警告、toast 或表单校验错误；这些流程应使用专用反馈组件。
- 不要在任意一侧塞入长句；状态需要解释时改用普通正文。
- 不要在高密度表格中只靠多个 badge 承担筛选状态。应使用带文本的表格列和可访问筛选器。
