## 安装

```tsx
import { RelativeTimeCard } from "@nebutra/ui/primitives";
```

```bash
npx shadcn@latest add https://ui.nebutra.com/r/relative-time-card.json
```

## 用法

用于表格单元格、实体行、deploy 列表和 activity feed 等可扫描时间戳。正文里超过约 7 天的静态日期，直接显示绝对日期。

```tsx
<RelativeTimeCard date={deployment.createdAt} />
```

## 不要预格式化

传入 `number`、`Date` 或 ISO/RFC 字符串。不要把 `"2m ago"` 作为 children 传入；formatter 已经定义短标签。

```tsx
// Good
<RelativeTimeCard date={new Date("2026-03-14T12:34:56Z")} />

// Bad
<RelativeTimeCard date={Date.now()}>{"2m ago"}</RelativeTimeCard>
```

## Hydration 安全

服务端和客户端首屏都先渲染确定性的 UTC 绝对时间。挂载后再升级为相对时间并启动自适应 tick，避免 hydration mismatch。

## 可访问性

- 默认 trigger 是语义化 `<time dateTime={ISO}>`。
- Popover 内容由 `ContextCard` 提供。
- 本地时区行挂载后才出现，避免服务端猜测用户 locale。

## 设计契约

- `RelativeTimeCard` 用于密集产品界面里可检查的时间戳，不用于正文叙述。
- 只传原始日期；格式化、tick 节奏、hydration 策略都由 primitive 拥有。
- 不要再给触发器套第二层 tooltip/popover；绝对时间披露已经是它的交互契约。
