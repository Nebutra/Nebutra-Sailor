## 概述

`Tooltip` 使用 canonical Base UI parts API：`Tooltip`、`TooltipTrigger`、`TooltipContent`，以及可选的 `TooltipProvider`。旧的 `GeistTooltip text="..."` 只作为兼容 wrapper 保留，不应出现在新的文档或产品示例中。

## 使用方法

```tsx
import { Tooltip, TooltipContent, TooltipTrigger } from "@nebutra/ui/primitives";

<Tooltip>
  <TooltipTrigger asChild>
    <button aria-label="Add item">...</button>
  </TooltipTrigger>
  <TooltipContent>Creates a new workspace shortcut</TooltipContent>
</Tooltip>
```

## 属性
### Tooltip / TooltipProvider

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `150` | 打开前延迟，单位毫秒。Provider 层值会应用到内部 tooltip。 |
| `children` | `ReactNode` | - | Root、trigger、content 的组合内容。 |

### TooltipTrigger

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | 使用子元素作为 trigger，而不是额外包裹。 |
| `children` | `ReactNode` | - | 可见触发器。纯图标 trigger 必须自带可访问名称。 |

### TooltipContent

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | 首选出现方向。 |
| `align` | `"start" \| "center" \| "end"` | `"center"` | 相对 trigger 的对齐方式。 |
| `sideOffset` | `number` | `4` | 与 trigger 的距离，单位 px。 |
| `alignOffset` | `number` | `0` | 对齐方向偏移，单位 px。 |
| `className` | `string` | - | 应用到 popup 的额外 class。 |

## 可访问性

- 基于 Base UI Tooltip 构建 —— 遵循 WAI-ARIA [文字提示模式](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)。
- 文字提示内容通过 `aria-describedby` 与触发器关联。
- 在获得焦点和悬停时均会打开 —— 方便键盘用户使用。
- 按下 `Escape` 键会关闭文字提示。
- 不要仅在文字提示中放置核心、非冗余的信息 —— 它们在触摸设备上无法通过悬停访问。

## 设计契约

- Tooltip 内容解释约束、范围或限制，不能重复可见 label。
- Tooltip 内容保持非交互。需要动作时使用 Popover、ContextCard、Dialog 或 inline control。
- 纯图标 trigger 必须自带 `aria-label`；tooltip 文案只是补充上下文，不能替代控件名称。

## 真实产品示例

- 添加、复制、刷新、展开等纯图标工具栏动作。
- 需要一句话补充的状态标签，例如保留期限、权限范围或套餐限制。
- 表格中有意压缩的元数据标签。

## 反模式

- 不要把必读说明、错误信息或触摸用户必须完成的内容只放进 Tooltip。
- 不要在 Tooltip 内容里放按钮、链接、输入框或菜单；需要交互时使用 Popover 或 Dialog。
- 不要在新示例中使用旧的 `GeistTooltip` wrapper。
