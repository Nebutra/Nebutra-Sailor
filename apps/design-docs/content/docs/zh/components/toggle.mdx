## 使用

```tsx
import { Toggle } from "@nebutra/ui/primitives";
import { useState } from "react";

export function FirewallToggle() {
  const [checked, setChecked] = useState(false);

  return (
    <Toggle checked={checked} onChange={setChecked}>
      Firewall
    </Toggle>
  );
}
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
| ---- | ---- | ------ | ---- |
| `checked` | `boolean` | — | 受控选中状态。生产设置流优先使用它。 |
| `defaultChecked` | `boolean` | `false` | 非受控示例和表单演示的初始状态。 |
| `onChange` | `(checked: boolean, event: ChangeEvent<HTMLInputElement>) => void` | — | 原生 checkbox 变化时触发。 |
| `onCheckedChange` | `(checked: boolean, event: ChangeEvent<HTMLInputElement>) => void` | — | 显式 switch 命名的回调别名。 |
| `size` | `"small" \| "normal" \| "large"` | `"small"` | 开关和标签的视觉尺寸。 |
| `color` | `"default" \| "blue" \| "cyan" \| "success" \| "warning" \| "error" \| "neutral"` | `"default"` | ON 状态的语义颜色。兼容别名 `green`、`amber`、`red`、`teal`、`gray` 会映射到对应语义 token。 |
| `icon` | `{ checked?: ReactNode; unchecked?: ReactNode }` | — | 渲染在 thumb 内的可选图标。 |
| `direction` | `"label-first" \| "switch-first" \| "switch-last"` | `"label-first"` | 标签和开关的排列顺序。`switch-last` 作为兼容别名保留。 |
| `labelCasing` | `"title" \| "normal"` | `"title"` | 记录期望的标签大小写，不会强制转换文本，避免破坏产品名。 |
| `disabled` | `boolean` | `false` | 禁用原生 input，并降低整个控件的视觉权重。 |

## 最佳实践

Toggle 适合单个布尔设置，并且 ON 后立即生效，例如 Password Protection 或 Auto-Cancel Builds。多选列表用 Checkbox，2-3 个互斥视图用 Switch。

生产流程里保持受控：持有 `checked`，在 `onChange` 中更新状态，持久化新值，并用成功或错误 toast 反馈结果。只有操作确实不可能时才禁用 Toggle，并用辅助文本或 Tooltip 说明解锁方式。

可见标签使用 `children`，不是 `label` prop。标签应是 1-4 个词的 Title Case 名词短语，说明 ON 时成立的状态：`Password Protection`，不要写 `Enable Password Protection`。需要解释时，把一句描述放在标签下方作为 sibling。

## 可访问性

Toggle 使用原生 checkbox input，因此键盘和表单行为保持平台语义。必须通过 `children`、`aria-label` 或 `aria-labelledby` 提供可访问名称；开发环境在三者都缺失时会发出 warning。

只有当可见标签位于行内其它位置时才设置 `aria-label`。否则让 `children` 承载同一份文案，保持视觉用户和屏幕阅读器用户一致。
