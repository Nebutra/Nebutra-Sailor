## 概览

`Combobox` 用于“已知值”的可搜索单选，例如区域、框架、API scope、环境变量名。短固定列表用 `Select`，多选用 `MultipleSelector`，如果用户输入本身就是提交值则用 `Input`。

组件支持两种模式：

1. **Options 模式** — 传入 `options`，组件负责输入框、列表、分组、空状态和选中图标。
2. **复合模式** — 使用 `Combobox.Input`、`Combobox.List`、`Combobox.Group`、`Combobox.Option` 自定义列表结构。

## Props

### Combobox

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `options` | `ComboboxOption[]` | — | Options 模式渲染的已知值。 |
| `value` | `string \| null` | — | 受控选中值。 |
| `onChange` | `(value: string \| null) => void` | — | 选中变化回调。再次选择当前项会清空为 `null`。 |
| `defaultValue` | `string \| null` | `null` | 非受控初始值。 |
| `disabled` | `boolean` | `false` | 禁用触发器并阻止打开。 |
| `errored` | `boolean` | `false` | 应用错误样式并设置 `aria-invalid`。 |
| `size` | `"small" \| "medium" \| "large"` | `"medium"` | 表单控件尺寸。旧的 `sm`、`default`、`lg` 仍会兼容映射。 |
| `width` | `number \| string` | `100%` | 根节点和触发器宽度。数字按像素处理，字符串按 CSS 长度处理。 |
| `listMaxWidth` | `number \| string` | — | 长文本选项的弹层/列表最大宽度。 |
| `label` | `string` | — | 渲染在触发器上方的可见标签。 |
| `hideLabel` | `boolean` | `false` | 视觉隐藏内置标签，但保留无障碍名称。 |
| `placeholder` | `string` | `"Select..."` | 未选择前的触发器文案。推荐领域化文案，例如 `Search regions...`。 |
| `emptyMessage` | `string` | `"No results found."` | Options 模式无结果文案。 |
| `searchPlaceholder` | `string` | `"Search..."` | Options 模式搜索输入占位符。 |
| `loading` | `boolean` | `false` | 异步结果加载时展示 loading 文案。 |
| `loadingMessage` | `string` | `"Loading options..."` | Options 模式 loading 文案。 |

### ComboboxOption

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `value` | `string` | 用于匹配选中状态的稳定机器值。 |
| `label` | `string` | Options 模式展示的人类可读标签。 |
| `disabled` | `boolean` | 禁用单个选项。 |
| `group` | `string` | 将选项归入对应 `CommandGroup` 标题。 |

### 子组件

| 组件 | 基于 | 描述 |
|-----------|----------|-------------|
| `Combobox.Input` | `CommandInput` | 用于过滤选项的搜索输入框。 |
| `Combobox.List` | `CommandList` | 带 `emptyMessage` 与 `maxWidth` 的列表容器。 |
| `Combobox.Option` | `CommandItem` | 带选中图标的可选项。 |
| `Combobox.Empty` | `CommandEmpty` | 旧复合模式的手动空状态。优先使用 `Combobox.List emptyMessage`。 |
| `Combobox.Group` | `CommandGroup` | 相关选项分组。 |
| `Combobox.Separator` | `CommandSeparator` | 分组之间的视觉分隔线。 |

## 设计原则

- 可见标签使用短名词，例如 `Region`、`Environment Variable`。
- placeholder 描述搜索对象，而不是控件本身：用 `Search regions...`，不要只写 `Search...`。
- 异步加载时保持列表打开，不要在 refetch 时折叠弹层。
- 空状态尽量带对象和查询词，例如 `No regions match "fra"`。
- 选项文案遵循官方品牌大小写，例如 `Next.js`，不要写成 `NextJS`。

## 可访问性

- 触发器使用 `role="combobox"`、`aria-expanded`、`aria-controls`，错误时设置 `aria-invalid`。
- 简单字段可用内置 `label`；复杂布局可用兄弟 `Label htmlFor` 关联根节点 `id`。
- 没有可见标签时必须传 `aria-label`。
- 方向键在 `Combobox.Option` 间移动，`Enter` 选择，`Escape` 关闭。
