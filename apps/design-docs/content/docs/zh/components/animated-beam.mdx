## 用法

```tsx
import { AnimatedBeam } from "@nebutra/ui/primitives";
```

Animated Beam 用一条克制的动态轨道连接真实 DOM 节点。它适合表达信息结构里的连接关系：
Webhook 路由、部署流水线、Agent 交接、集成状态。纯装饰性的发光线条应该放到营销装饰组件里。

## 示例

```tsx
function FlowDemo() {
  const containerRef = useRef<HTMLDivElement>(null);
  const sourceRef = useRef<HTMLDivElement>(null);
  const targetRef = useRef<HTMLDivElement>(null);

  return (
    <div ref={containerRef} className="relative grid grid-cols-2">
      <ServiceNode ref={sourceRef} name="GitHub" />
      <ServiceNode ref={targetRef} name="Nebutra" />
      <AnimatedBeam
        containerRef={containerRef}
        fromRef={sourceRef}
        toRef={targetRef}
        tone="brand"
        intensity="normal"
      />
    </div>
  );
}
```

## 属性
| 属性 | 类型 | 默认值 | 说明 |
| -------------------- | ------------------------------------------------ | --------- | ----------- |
| `containerRef`       | `RefObject<HTMLElement>`                         | —         | 外层定位容器 ref |
| `fromRef`            | `RefObject<HTMLElement>`                         | —         | 起点元素 ref |
| `toRef`              | `RefObject<HTMLElement>`                         | —         | 终点元素 ref |
| `tone`               | `"neutral" \| "brand" \| "success" \| "warning"` | `"brand"` | 语义颜色 |
| `intensity`          | `"subtle" \| "normal" \| "strong"`               | `"normal"` | 光束和底线强度 |
| `curvature`          | `number`                                         | `0`       | 贝塞尔曲线弯曲高度，单位 px |
| `reverse`            | `boolean`                                        | `false`   | 反转光束运动方向 |
| `duration`           | `number`                                         | `4`       | 动画周期，单位秒 |
| `delay`              | `number`                                         | `0`       | 启动延迟，单位秒 |
| `startXOffset`       | `number`                                         | `0`       | 起点元素中心的 X 偏移 |
| `startYOffset`       | `number`                                         | `0`       | 起点元素中心的 Y 偏移 |
| `endXOffset`         | `number`                                         | `0`       | 终点元素中心的 X 偏移 |
| `endYOffset`         | `number`                                         | `0`       | 终点元素中心的 Y 偏移 |
| `className`          | `string`                                         | —         | SVG 上的附加 class |

## 高级绘制参数

底层 SVG 绘制参数仍保留用于迁移和一次性可视化：
`pathColor`、`pathWidth`、`pathOpacity`、`gradientStartColor`、`gradientStopColor`。
产品界面优先使用 `tone` 和 `intensity`，避免颜色脱离 token 系统。

## 设计原则

- 节点必须是真实服务或工作流标签，不要使用抽象的 `A → B` 玩具示例。
- 控制光束数量；超过三条同时出现时通常应该改用图结构视图。
- 光束是装饰性内容，组件 `aria-hidden`；语义由节点标签承载。
- reduced motion 用户只看到静态轨道，不播放移动光束。
