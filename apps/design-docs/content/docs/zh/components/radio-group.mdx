## 概览

`RadioGroup` 渲染原生 `<fieldset>` 和可选 `<legend>`，并用共享 `name` 协调一组原生 radio input。适合用户必须从少量可见选项中选择一个值的场景。

如果选项需要图标、描述、徽标或更大的点击卡片，使用 `Choicebox`。超过六个选项后，使用 `Select` 或 `Combobox`。

## 使用方法

```tsx
import { RadioGroup } from "@nebutra/ui/primitives";

export function Example() {
  return (
    <RadioGroup defaultValue="iad1" label="Deployment Region">
      <RadioGroup.Item value="iad1">Washington, D.C.</RadioGroup.Item>
      <RadioGroup.Item value="sfo1">San Francisco</RadioGroup.Item>
      <RadioGroup.Item value="fra1">Frankfurt</RadioGroup.Item>
    </RadioGroup>
  );
}
```

## 属性

### RadioGroup

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `ReactNode` | — | 可见组标签，渲染为 `<legend>`。 |
| `name` | `string` | 自动生成 | 共享表单字段名。 |
| `value` | `string` | — | 受控选中值。 |
| `defaultValue` | `string` | `""` | 非受控初始值。 |
| `onChange` | `(value: string) => void` | — | Geist 兼容的变更回调。 |
| `onValueChange` | `(value: string) => void` | — | Base UI 兼容的变更回调。 |
| `required` | `boolean` | `false` | 要求该组必须选择一个选项。 |
| `disabled` | `boolean` | `false` | 禁用整个 fieldset。 |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | 选项布局方向。 |
| `className` | `string` | — | 应用于选项容器。 |
| `rootClassName` | `string` | — | 应用于 fieldset 根节点。 |

### RadioGroup.Item

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `value` | `string` | — | 必填选项值。 |
| `children` | `ReactNode` | — | 可见选项标签。 |
| `description` | `ReactNode` | — | 可选辅助说明。 |
| `disabled` | `boolean` | `false` | 禁用此选项。 |
| `disabledReason` | `string` | — | 禁用原因，会作为可访问说明和原生 tooltip。 |
| `id` | `string` | 自动生成 | input id，用于外部 label。 |

`RadioGroupItem` 仍保留为兼容命名导出。

### Radio

`Radio` 是用于自定义 UI 的 standalone 控件。必须提供 `id`、`aria-label` 或 `aria-labelledby`，确保控件有可访问名称。

```tsx
<span id="region-iad1">Washington, D.C.</span>
<Radio
  aria-labelledby="region-iad1"
  checked={value === "iad1"}
  name="region"
  onChange={() => setValue("iad1")}
  value="iad1"
/>
```

## Headless

`useRadio` 用于 `RadioGroup` provider 内部的自定义行。它必须从子组件中调用，不要在渲染 `RadioGroup` 之前调用。

```tsx
function DensityRow({ label, value }: { label: string; value: string }) {
  const radio = useRadio({ value, "aria-label": label });

  return (
    <label>
      <span>{label}</span>
      {radio.component}
    </label>
  );
}
```

## 最佳实践

当用户需要从 2 到 6 个互斥选项中选择一个，并且看到所有选项很重要时使用 Radio，例如部署区域、计划等级、计费周期。

默认预选最安全的值，让字段看起来已经配置好。只有当选择有真实后果、需要用户明确确认时才留空。

`required` 放在 `RadioGroup` 上，不放在单个选项上。

组标签是简短的 Title Case 名词：Deployment Region、Billing Cycle。选项标签保持平行：Monthly / Yearly，而不是 Monthly / Pay yearly。

禁用选项必须提供 `disabledReason`。没有原因的灰色 radio 会让用户以为界面坏了。

`RadioGroup` 使用 `<fieldset>` 和 `<legend>` 表达组名。Standalone `Radio` 必须有 `id`、`aria-label` 或 `aria-labelledby`。

不要替换掉 focus ring。键盘用户需要在方向键切换时看到当前目标。
