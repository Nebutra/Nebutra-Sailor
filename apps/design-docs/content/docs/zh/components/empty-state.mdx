## 概览

`EmptyState` 用于避免用户在空视图里困惑。它可以表达首次使用的 blank slate、筛选无结果、任务已清空、权限或套餐限制，以及加载失败。

组件刻意保持克制：一个标题、一段说明、一个主 CTA，最多再加一个次 CTA。

## 安装

```tsx
import { EmptyState } from "@nebutra/ui/primitives"
```

## 使用方法

### 初始空白

```tsx
import { ChartBarPeak } from "@nebutra/icons"
import { EmptyState } from "@nebutra/ui/primitives"

<EmptyState.Root
  description="传达产品当前状态的消息。"
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="Title"
/>
```

### 信息类

```tsx
<EmptyState.Root
  description="说明当前页面还能做什么，以及这个功能为什么值得继续配置。"
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="配置团队工作区"
  variant="informational"
>
  <Button type="button" variant="secondary">开始配置</Button>
  <Button asChild type="button" variant="ghost">
    <a href="/docs">查看文档</a>
  </Button>
</EmptyState.Root>
```

### 无结果

异步筛选后出现空结果时使用 `live`，让辅助技术播报状态变化。

```tsx
<EmptyState.Root
  description="没有日志匹配 “status:error”。清除筛选后可查看全部日志。"
  icon={<EmptyState.Icon icon={<MagnifyingGlass size={32} />} />}
  live
  title="没有匹配筛选条件的日志"
  variant="no-results"
>
  <Button type="button" variant="secondary">清除筛选</Button>
</EmptyState.Root>
```

### 错误状态

```tsx
<EmptyState.Root
  description="部署记录加载失败。请求 ID：req_7K3QZ。"
  icon={<EmptyState.Icon icon={<Warning size={32} />} />}
  title="部署记录加载失败"
  variant="error"
>
  <Button type="button" variant="destructive">重试</Button>
</EmptyState.Root>
```

## 属性

### EmptyState.Root

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | 表达状态的短标题 |
| `description` | `ReactNode` | — | 补充标题没有说出的状态原因或下一步 |
| `icon` | `ReactNode` | — | 使用 `<EmptyState.Icon icon={...} />` 保持尺寸一致 |
| `children` | `ReactNode` | — | CTA 插槽。使用真实 `Button` 或 `Link` |
| `action` | `ReactNode` | — | 主 CTA 的兼容别名 |
| `link` | `ReactNode` | — | 次 CTA 的兼容别名 |
| `variant` | `EmptyStateVariant` | `"blank-slate"` | 语义化空状态变体 |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 布局密度 |
| `align` | `"center" \| "start"` | `"center"` | 内容对齐方式 |
| `live` | `boolean` | `false` | 为异步状态变化添加 `aria-live="polite"` |

### EmptyState.Icon

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `icon` | `ReactNode` | — | 图标元素，通常 32px |
| `className` | `string` | — | 图标容器额外类名 |

## 变体

| 变体 | 使用场景 |
|---------|----------|
| `blank-slate` | 用户还没有创建第一个资源 |
| `informational` | 用户需要理解功能价值并看到 CTA |
| `educational` | 可以启动上下文 onboarding |
| `guide` | starter content 能帮助用户试用或设置 |
| `no-results` | 筛选或搜索返回零结果 |
| `cleared` | 工作完成后列表为空 |
| `permission` | 角色或套餐限制访问 |
| `error` | 加载失败，并且可以重试 |

## 文案

- `title` 使用短句，例如 `没有匹配筛选条件的日志`。
- `description` 补充标题没有说出的原因、作用域或下一步。
- 单个查询词用弯引号包裹：`没有日志匹配 “status:error”。`
- CTA 文案使用明确动作。避免 `开始`、`继续`、`确定` 这类泛化按钮。
- 最多一个主 CTA；只有确实存在两条合理路径时，才加一个次 CTA。

## 可访问性

- CTA 必须是真实 `Button` 或 `Link`，这样才能进入 tab order。
- 异步筛选后的 no-results 状态使用 `live`。
- 图标只是装饰；语义由标题和描述承载。

## 设计契约

- Empty state 解释当前为什么没有内容，不承担整站营销。
- 一个实例只表达一个语义状态；不要把权限拒绝、无结果和 onboarding 文案混在一起。
- 图标是装饰性的，并通过 `EmptyState.Icon` 统一尺寸；含义必须落在文案和 CTA 标签里。
- Variant 映射产品状态，不是颜色开关。不要为了换强调色而错用 variant。

## 真实产品示例

- 新工作区的项目列表还没有第一个项目时，提供直接创建动作。
- 审计日志表格筛选后没有结果，文案命名当前查询，并提供清除筛选动作。
- 部署数据加载失败但可恢复时，提供重试动作和可用于支持排查的 request ID。

## 反模式

- 页面已经有可用内容时，不要把 empty state 当作营销面板或功能介绍。
- 数据仍在加载时不要提前显示空状态；请求完成前应使用 `LoadingState` 或 skeleton。
- 不要用泛泛的 “No items” 掩盖权限、计费或错误原因。状态必须说明内容为什么不可用。
