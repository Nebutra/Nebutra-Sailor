## 概览 (Overview)

`EmptyState` 用于避免用户在空视图里困惑。它可以表达首次使用的 blank slate、筛选无结果、任务已清空、权限或套餐限制，以及加载失败。

组件刻意保持克制：一个标题、一段说明、一个主 CTA，最多再加一个次 CTA。

## 安装 (Installation)

```tsx
import { EmptyState } from "@nebutra/ui/primitives"
```

## 使用方法 (Usage)

### 初始空白 (Blank Slate)

```tsx
import { ChartBarPeak } from "@nebutra/icons"
import { EmptyState } from "@nebutra/ui/primitives"

<EmptyState.Root
  description="传达产品当前状态的消息。"
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="Title"
/>
```

### 信息类 (Informational)

```tsx
<EmptyState.Root
  description="This should detail the actions you can take on this screen, as well as why it's valuable."
  icon={<EmptyState.Icon icon={<ChartBarPeak size={32} />} />}
  title="Title"
  variant="informational"
>
  <Button type="button" variant="secondary">Primary Action</Button>
  <Button asChild type="button" variant="ghost">
    <a href="/docs">Learn More</a>
  </Button>
</EmptyState.Root>
```

### 无结果 (No Results)

异步筛选后出现空结果时使用 `live`，让辅助技术播报状态变化。

```tsx
<EmptyState.Root
  description="No logs match “status:error”. Clear the filter to see all logs."
  icon={<EmptyState.Icon icon={<MagnifyingGlass size={32} />} />}
  live
  title="No Logs Match Your Filter"
  variant="no-results"
>
  <Button type="button" variant="secondary">Clear Filter</Button>
</EmptyState.Root>
```

### 错误状态 (Error)

```tsx
<EmptyState.Root
  description="Couldn't load deployments. Request ID: req_7K3QZ."
  icon={<EmptyState.Icon icon={<Warning size={32} />} />}
  title="Deployments Failed To Load"
  variant="error"
>
  <Button type="button" variant="destructive">Try Again</Button>
</EmptyState.Root>
```

## 属性 (Props)

### EmptyState.Root

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | 表达状态的 Title Case 标题 |
| `description` | `ReactNode` | — | sentence case 的辅助说明 |
| `icon` | `ReactNode` | — | 使用 `<EmptyState.Icon icon={...} />` 保持尺寸一致 |
| `children` | `ReactNode` | — | CTA 插槽。使用真实 `Button` 或 `Link` |
| `action` | `ReactNode` | — | 主 CTA 的兼容别名 |
| `link` | `ReactNode` | — | 次 CTA 的兼容别名 |
| `variant` | `EmptyStateVariant` | `"blank-slate"` | 语义化空状态变体 |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 布局密度 |
| `align` | `"center" \| "start"` | `"center"` | 内容对齐方式 |
| `live` | `boolean` | `false` | 为异步状态变化添加 `aria-live="polite"` |

### EmptyState.Icon

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `icon` | `ReactNode` | — | 图标元素，通常 32px |
| `className` | `string` | — | 图标容器额外类名 |

## 变体 (Variants)

| 变体 | 使用场景 |
|---------|----------|
| `blank-slate` | 用户还没有创建第一个资源 |
| `informational` | 用户需要理解功能价值并看到 CTA |
| `educational` | 可以启动上下文 onboarding |
| `guide` | starter content 能帮助用户试用或设置 |
| `no-results` | 筛选或搜索返回零结果 |
| `cleared` | 工作完成后列表为空 |
| `permission` | 角色或套餐限制访问 |
| `error` | 加载失败，并且可以重试 |

## 文案 (Content)

- `title` 使用 Title Case，例如 `No Logs Match Your Filter`。
- `description` 使用 sentence case，并补充标题没有说出的信息。
- 单个查询词用弯引号包裹：`No logs match “status:error”.`
- CTA 文案使用 Title Case Verb + Noun。避免 `Get Started`、`Continue`、`OK`。
- 最多一个主 CTA；只有确实存在两条合理路径时，才加一个次 CTA。

## 可访问性 (Accessibility)

- CTA 必须是真实 `Button` 或 `Link`，这样才能进入 tab order。
- 异步筛选后的 no-results 状态使用 `live`。
- 图标只是装饰；语义由标题和描述承载。
