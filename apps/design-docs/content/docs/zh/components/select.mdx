## 安装

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@nebutra/ui/primitives";
```

## 概览

`Select` 适用于短固定列表，输入搜索没有收益的场景：框架、区域、套餐、小型状态过滤。产品界面里需要展开菜单仍保持 Nebutra 视觉系统时，优先使用 compound listbox API。

原生 shorthand 仍保留给真实表单提交、移动端系统 picker 和 `optgroup` 语义。它展开后的 `<option>` popup 由浏览器/系统控制，不作为主视觉 demo。需要过滤时使用 `Combobox`，允许多选时使用 `MultiSelect`。

## 用法

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Select a framework" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="nextjs">Next.js</SelectItem>
    <SelectItem value="react">React</SelectItem>
  </SelectContent>
</Select>;
```

也支持原生 `<option>` 和 `<optgroup>` children：

```tsx
<Select label="Region" placeholder="Select a region">
  <optgroup label="North America">
    <option value="iad1">Washington, D.C.</option>
    <option value="sfo1">San Francisco</option>
  </optgroup>
</Select>
```

## 属性
### 原生 Select

当产品需求明确需要浏览器原生控件时使用 native shorthand：经典表单提交、移动端 OS picker 或 `optgroup` 语义。不要依赖展开后的原生 option popup 承载品牌样式。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `options` | `{ value: string; label: string; disabled?: boolean }[]` | — | 短固定选项列表。 |
| `label` | `string` | — | 简短 Title Case 字段标签。 |
| `placeholder` | `string` | — | 选择前展示的 disabled 第一项。 |
| `size` | `"xsmall" \| "small" \| "medium" \| "large"` | `"medium"` | 控件密度。 |
| `variant` | `"default" \| "ghost"` | `"default"` | 视觉样式。 |
| `prefix` | `ReactNode` | — | 装饰性前置图标。 |
| `suffix` | `ReactNode` | `ChevronDown` | 装饰性后置图标。 |
| `error` | `string` | — | 校验消息；设置 `aria-invalid` 和 `aria-describedby`。 |
| `disabled` | `boolean` | `false` | 禁用原生 select。 |
| `value` | `string` | — | 受控值。 |
| `defaultValue` | `string` | — | 非受控默认值。 |
| `onChange` | `ChangeEventHandler<HTMLSelectElement>` | — | 原生 change 回调。 |

### Compound Listbox

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectLabel,
  SelectSeparator,
} from "@nebutra/ui/primitives";
```

compound API 保留 Base UI listbox 行为，适合更像菜单的分组选择，并且拥有展开 surface、圆角、阴影和焦点样式的控制权。

| Component | 作用 |
|---|---|
| `Select` | 未传 native props 时作为 root state provider。 |
| `SelectTrigger` | 按钮触发器。支持和原生 Select 相同的 `size`。 |
| `SelectValue` | 选中值 / placeholder 渲染器。 |
| `SelectContent` | 定位的 listbox surface。 |
| `SelectItem` | 可选择 listbox option。 |
| `SelectGroup` / `SelectLabel` / `SelectSeparator` | 较长列表的分组 primitive。 |

## 最佳实践

- 需要展开菜单符合 Nebutra surface 样式时，优先使用 compound `Select`。
- 只有浏览器表单语义、移动端 picker 或 `optgroup` 支持比展开 popup 样式更重要时，才使用 native shorthand。
- 需要过滤时改用 `Combobox`；允许多选时使用 `MultiSelect`。
- 超过约十项的原生列表用 `<optgroup>` 分组；compound API 也可以用 `SelectGroup` 处理菜单式分组。
- 标签使用简短 Title Case 名词，例如 `Framework`、`Region`。
- placeholder 使用动作句式：`Select a framework`，不要写 `Choose one...` 或重复 label。
- blur 后校验，并传入以句号结尾的 sentence-case `error` 文案。
- 不要把带 label 的 `Select` 包进 Tooltip；提示应放在相邻 icon button 上，避免 label 宣告被破坏。

## 可访问性

- 原生 Select 保留浏览器表单语义、移动端 picker 和键盘行为。
- `error` 会设置 `aria-invalid`，并把字段关联到内联错误消息。
- compound API 通过 Base UI primitive 遵循 ARIA listbox pattern。
