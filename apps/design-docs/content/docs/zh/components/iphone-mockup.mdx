## 概览

`Phone` 用克制的 iPhone 风格外壳承载移动端截图或录屏。设备外壳是装饰性的；可访问名称应该来自截图本身，例如 `imageAlt`、`videoLabel`，或带 `aria-label` 的静态 children。

适合用于营销页、文档示例、changelog 视觉和发布截图。不要把真实可交互的产品 UI 放进框里，因为设备外壳传达的是“已捕获的屏幕”，不是一个可以操作的界面。

## 使用方法

```tsx
import { Phone } from "@nebutra/ui/primitives";

export function Example() {
  return (
    <div className="w-full max-w-xs">
      <Phone
        imageSrc="/screenshots/mobile-dashboard.png"
        imageAlt="展示用量卡片和最近活动的 Nebutra 移动端仪表盘截图"
      />
    </div>
  );
}
```

### 静态 JSX 截图

只在需要静态截图式构图时使用 children。组件会阻止内部交互，因为设备外壳表达的是截图，而不是真实产品表面。

```tsx
<Phone>
  <div role="img" aria-label="移动端引导完成页面截图">
    {/* static captured layout */}
  </div>
</Phone>
```

### 视频

```tsx
<Phone
  videoSrc="/recordings/mobile-demo.mp4"
  videoPoster="/recordings/mobile-demo-poster.png"
  videoLabel="移动端引导流程录屏"
/>
```

`videoPoster` 是 reduced motion 下的回退画面。产品内使用视频时必须提供。

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `imageSrc` | `string` | — | 截图资源地址。必须同时提供 `imageAlt`。 |
| `imageAlt` | `string` | — | 截图内容的可访问描述。 |
| `videoSrc` | `string` | — | 静音循环播放的演示录屏。必须同时提供 `videoLabel`。 |
| `videoLabel` | `string` | — | 录屏的可访问名称。 |
| `videoPoster` | `string` | — | 视频封面，也是 `prefers-reduced-motion` 回退图。 |
| `children` | `ReactNode` | — | 静态截图式 JSX。与图片、视频 props 互斥。 |
| `address` | `string` | — | 空状态占位中展示的来源地址。 |
| `chrome` | `"graphite" \| "silver" \| "titanium"` | `"graphite"` | 语义化设备外壳颜色。 |
| `fit` | `"cover" \| "contain"` | `"cover"` | 图片或视频的 `object-fit`。 |
| `position` | `CSSProperties["objectPosition"]` | `"top"` | 图片或视频的 `object-position`。 |
| `className` | `string` | — | 根节点 class。通过宽度约束控制尺寸。 |

## 迁移

`IphoneMockup` 仍保留为 deprecated 兼容别名。新代码应该导入 `Phone`。

```tsx
import { Phone } from "@nebutra/ui/primitives";
```

旧的 `src` prop 仍可使用，但必须配合 `imageAlt`；新代码使用 `imageSrc`。

## 最佳实践

用 `Phone` 在营销页和文档中展示移动端截图、录屏和演示海报。

不要在框内渲染真实可交互的移动端产品 UI。设备外壳意味着这是捕获画面，不是交互界面。

同时展示桌面和移动端时，搭配 `Browser` 使用，并让两者保持同一主题。

让 `chrome` 与周围主题匹配，避免设备外壳抢走截图主体。

用稳定宽度约束组件，例如 `max-w-xs`、网格列或媒体栏，避免 19.5:9 的屏幕比例在布局中不可预期地裁切内容。

不要在父容器上再叠阴影。`Phone` 已经拥有自己的 elevation token。

设备外壳按装饰处理。可访问名称属于内部截图或录屏，不属于外壳。

自动播放视频时必须提供 `videoPoster`，以尊重 `prefers-reduced-motion`。
