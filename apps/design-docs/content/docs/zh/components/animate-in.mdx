## 安装

```tsx
import { AnimateIn, AnimateInGroup } from "@nebutra/ui/primitives";
```

Standalone registry 安装：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/animate-in.json
```

## 用法

`AnimateIn` 用于短入场动效，前提是动效能帮助用户理解页面层级。不要把密集 dashboard 上的每个元素都包一层；动效应该澄清状态，而不是制造噪音。

```tsx
<AnimateIn preset="emerge" inView>
  <section>Usage report</section>
</AnimateIn>
```

同级列表需要统一节奏时使用 `AnimateInGroup`：

```tsx
<AnimateInGroup stagger="normal" inView>
  {items.map((item) => (
    <AnimateIn key={item.id} preset="fadeUp">
      <Card>{item.title}</Card>
    </AnimateIn>
  ))}
</AnimateInGroup>
```

## 预设
| Preset | 用途 |
| --- | --- |
| `emerge` | 默认 Nebutra materialize-in 入场。 |
| `flow` | 横向流动动效。 |
| `fade` | 最克制的 opacity-only 入场。 |
| `fadeUp` | 列表/card 带轻微上移动效。 |
| `scale` | 小型表面的 pop-in。 |

## 属性
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `preset` | `"emerge" \| "flow" \| "fade" \| "fadeUp" \| "scale"` | `"emerge"` | 品牌化进入动效配方。 |
| `delay` | `number` | `0` | 元素进入前的延迟秒数。 |
| `duration` | `number` | preset duration | 可选 transition duration override，单位为秒。 |
| `inView` | `boolean` | `false` | 元素进入视口后再启动动效。 |
| `className` | `string` | - | 应用在 motion wrapper 上的类名。 |

`AnimateInGroup` 接收 `stagger`、`inView`、`className` 和 `children`。`stagger` 只能使用 `"fast"`、`"normal"`、`"slow"`。

## 可访问性

- 遵守 `prefers-reduced-motion`。
- reduced-motion 用户只看到 opacity transition。
- 使用 `LazyMotion`，避免一次性加载全部 framer-motion features。

## 设计契约

- `AnimateIn` 只用于进入层级，不用于 hover、active、loading 或吸引注意的效果。
- 消费方必须走这个 primitive，而不是散落 raw `motion.div`，这样 duration、easing、reduced-motion 和 lazy-loading 才能一致。
- 优先使用 `opacity` / `transform`。如果设计需要影响 layout 的动效，先提升新的 motion preset。
