## 安装

```tsx
import { ExpandableGallery, type GalleryPhoto } from "@nebutra/ui/primitives";
```

或通过 registry 安装 standalone copy：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/expandable-gallery.json
```

## 用法

`ExpandableGallery` 把前几张图片渲染为可点击的扇形堆叠，激活后展开为完整网格。折叠态的标题和 CTA 由调用方提供，因此它适合营销或展示区域，不适合密集 dashboard 表格。

```tsx
import { Button, ExpandableGallery, type GalleryPhoto } from "@nebutra/ui/primitives";

const photos: GalleryPhoto[] = [
  { id: "setup", src: "/img/setup.jpg", alt: "Setup", rotation: -12, x: -72 },
  { id: "research", src: "/img/research.jpg", alt: "Research", rotation: 4 },
  { id: "build", src: "/img/build.jpg", alt: "Build", rotation: 10, x: 72 },
];

<ExpandableGallery photos={photos}>
  <h2>People remember how a product feels.</h2>
  <Button>Explore</Button>
</ExpandableGallery>
```

## 状态模型

| 状态 | 图片 | children slot |
| --- | --- | --- |
| `collapsed` | 前 `previewCount` 张图片作为按钮扇形堆叠 | 显示 |
| `expanded` | 全部图片进入响应式网格 | 隐藏 |

点击、Enter 或 Space 会展开；Back 按钮或外部点击会收起。

## 可访问性

- 折叠态图片是 `<button>`，使用 `aria-label={photo.alt}`。
- 键盘 focus 与 hover 共享同等可见反馈。
- 展开态图片不再假装可点击，作为展示内容处理。
- 使用原生 `<img>`，保持 registry 分发的框架中立性。
