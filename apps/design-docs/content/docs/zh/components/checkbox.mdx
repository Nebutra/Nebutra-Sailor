## 决策标准

当用户可以选择零个、一个或多个彼此独立的选项时使用 `Checkbox`。立即生效的开关设置使用 `Switch`；必须且只能选一个选项时使用 `RadioGroup`；选项需要更丰富的卡片内容时使用 `Choicebox`。

## 用法

```tsx
import { Checkbox, CheckboxGroup } from "@nebutra/ui/primitives";

<Checkbox name="notifications" defaultChecked>
  Email notifications
</Checkbox>
```

## 结构

`Checkbox` 在 label 内渲染一个原生 `<input type="checkbox">`。视觉 indicator 是装饰层；表单提交、键盘切换、禁用状态和选中状态都由原生 input 承担。

```tsx
<CheckboxGroup label="Notification channels" orientation="vertical">
  <Checkbox name="email" defaultChecked>
    Email
  </Checkbox>
  <Checkbox name="slack">Slack</Checkbox>
</CheckboxGroup>
```

## 状态

| 状态 | Prop 契约 | 行为 |
| --- | --- | --- |
| 未选中 | `checked={false}` 或非受控默认值 | 按 `Space` 切换为选中。 |
| 已选中 | `checked` / `defaultChecked` | indicator 显示勾选路径。 |
| 中间态 | `indeterminate` | indicator 显示混合状态；父级清除 `indeterminate` 前不主动切换。 |
| 禁用 | `disabled` | 原生 input 禁用，视觉 label 不可交互。 |
| 分组 | `CheckboxGroup label="..."` | 分组获得 `role="group"` 和可访问名称。 |

## 属性

### Checkbox

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `checked` | `boolean` | — | 受控选中状态。 |
| `defaultChecked` | `boolean` | `false` | 非受控用法的初始状态。 |
| `onChange` | `(checked: boolean) => void` | — | 原生 input change 触发后的 value-first 回调。 |
| `disabled` | `boolean` | `false` | 禁用原生 input 和指针交互。 |
| `indeterminate` | `boolean` | `false` | 显示混合视觉状态。 |
| `children` | `ReactNode` | — | 可见标签内容。 |
| `id` | `string` | — | 原生 input id。 |
| `name` | `string` | — | 原生表单字段名。 |
| `className` | `string` | — | 应用于 label wrapper。 |

### CheckboxGroup

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `string` | — | 可访问分组名称。 |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | 子项布局方向。 |
| `children` | `ReactNode` | — | 复选框子项。 |
| `className` | `string` | — | 应用于分组 wrapper。 |

## 可访问性

- 原生 checkbox input 拥有表单状态和键盘行为。
- 未禁用时按 `Space` 切换状态。
- 输入框和 indicator 位于同一个 `<label>` 内，因此文本标签天然关联。
- `CheckboxGroup` 在提供 `label` 时使用 `role="group"` 和 `aria-label`。
- 不要把 `indeterminate` 当作持久第三值。它只表达父级控制的子项混合状态。

## 设计契约

- 复选框行保持紧凑：一个标签，旁边可配短 helper text，不要把嵌套控件塞进 label。
- 未选中状态使用中性 chrome；只有选中或混合状态才使用强调。
- 不可用选项用 disabled。需要解释升级或权限边界时，应配合文本或 tooltip 图标，而不是只置灰。

## 真实产品示例

- Billing 设置里选择多个 invoice recipients。
- 权限表单里授予多个独立 scopes。
- 批量选择表头在部分子行已选中时使用 `indeterminate`。

## 反模式

- 不要记录 HeroUI 风格 props，例如 `isSelected`、`isDisabled`、`color` 或 `radius`；这个 primitive 没有这些 API。
- 不要用 `Checkbox` 表达互斥选项；使用 `RadioGroup`。
- 不要只依靠 placeholder 或颜色解释选项含义。
