## 使用方法

```tsx
import { Spinner } from "@nebutra/ui";

<Spinner />
<Spinner size="sm" />
<Spinner label="正在验证部署" />
```

## 设计契约

`Spinner` 是单一规范加载指示器。它只表达“动作正在进行”，不表达进度。
组件渲染 12 段 `currentColor` 指示器，动画走 component motion token，并遵守
`prefers-reduced-motion`。

旧的 `variant` 值仍被接受，避免历史调用立刻失效，但所有 variant 都渲染为同一个
Spinner。区分不同任务应依赖上下文文案，而不是换一种动画。

## 尺寸

系统界面优先使用尺寸 token；只有需要贴合相邻图标时才传数字尺寸。

```tsx
<Spinner size="xs" />
<Spinner size="sm" />
<Spinner size="md" />
<Spinner size="lg" />
<Spinner size={32} />
```

## 色调

`tone` 映射到语义文本色。

```tsx
<Spinner tone="default" />
<Spinner tone="foreground" />
<Spinner tone="inverse" />
```

## 在 Button 中使用

提交按钮应使用 `Button` 的 `loading` 状态，让尺寸、禁用态和 busy 反馈保持一致。

```tsx
<Button loading>保存更改</Button>
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| number` | `"md"` | Spinner 尺寸 token 或明确像素值 |
| `tone` | `"default" \| "foreground" \| "inverse"` | `"default"` | 语义色调 |
| `label` | `string` | — | 独立使用时的可访问状态名称 |
| `decorative` | `boolean` | 自动推断 | 当父级已经暴露 busy 状态时，强制作为装饰元素 |
| `variant` | legacy union | `"default"` | 已废弃兼容属性；所有 variant 渲染一致 |

## 最佳实践

Spinner 用于约一到三秒的单动作等待：提交按钮、行内刷新、行级重试、分页切换。

已知布局的数据加载使用 Skeleton；行内文字等待使用 LoadingDots；已知总量的工作使用
Progress。

动作真正开始后再挂载 Spinner。预先渲染后只切换可见性，会让静止时残留半截旋转状态。

超过约一秒的等待需要配合说明当前任务的文案：`正在验证...`、`正在部署...`、
`正在重试...`。

在执行中的区域外层设置 `aria-busy="true"`。Spinner 独立出现时传 `label`；如果父级已经有
busy 状态，则保持装饰模式，避免屏幕阅读器重复播报。
