## 概览

`CommandMenu` 是一个基于 `cmdk` 和 Dialog 的命令面板。它适合全局、键盘优先的产品操作，例如部署项目、邀请成员、切换主题或打开某个产品工具。

嵌入式搜索界面请直接使用 `Command`。绑定在可见按钮或单行资源上的操作，请使用 `Menu` 或 `ContextMenu`。

## 安装

```tsx
import { CommandMenu } from "@nebutra/ui/primitives";
```

## 使用方法

### 默认

```tsx
import { useState } from "react"
import { Button, CommandMenu } from "@nebutra/ui/primitives"

export function CommandMenuDemo() {
  const [open, setOpen] = useState(false)

  function handleAction(): void {
    setOpen(false)
  }

  return (
    <>
      <Button onClick={() => setOpen(true)}>打开命令菜单 (Open Command Menu)</Button>
      <CommandMenu.Root
        open={open}
        setOpen={setOpen}
        description="搜索命令并执行全局产品操作。"
      >
        <CommandMenu.Input placeholder="您需要什么？ (What do you need?)" />
        <CommandMenu.Results count={5} />
        <CommandMenu.List>
          <CommandMenu.Group heading="建议 (Suggestions)">
            <CommandMenu.Item onSelect={handleAction} value="figma-import">
              Figma 导入 (Figma Import)
            </CommandMenu.Item>
          </CommandMenu.Group>
          <CommandMenu.Group heading="命令 (Commands)">
            <CommandMenu.Item onSelect={handleAction} value="import-extension">
              导入扩展 (Import Extension)
            </CommandMenu.Item>
            <CommandMenu.Item onSelect={handleAction} value="manage-extensions">
              管理扩展 (Manage Extensions)
            </CommandMenu.Item>
          </CommandMenu.Group>
          <CommandMenu.Group heading="协作 (Collaboration)">
            <CommandMenu.Item onSelect={handleAction} value="flags-explorer">
              特性标志浏览 (Flags Explorer)
            </CommandMenu.Item>
          </CommandMenu.Group>
        </CommandMenu.List>
      </CommandMenu.Root>
    </>
  )
}
```

### 使用键盘快捷键

在应用根目录或布局中挂载一次全局快捷键：macOS 使用 `Cmd+K`，其他系统使用 `Ctrl+K`。不要把同一个快捷键再绑定给页面内的过滤输入框。

```tsx
useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    if (e.key === "k" && (e.metaKey || e.ctrlKey)) {
      e.preventDefault()
      setOpen((prev) => !prev)
    }
  }
  document.addEventListener("keydown", handler)
  return () => document.removeEventListener("keydown", handler)
}, [])
```

### 使用快捷键提示

```tsx
<CommandMenu.Item onSelect={handleAction} value="deploy-project">
  <span className="flex-1">部署项目 (Deploy Project)</span>
  <CommandMenu.Shortcut keys={["⌘", "D"]} label="部署项目快捷键" />
</CommandMenu.Item>
```

### 空、加载与错误状态

```tsx
<CommandMenu.List>
  <CommandMenu.Empty>没有找到命令。</CommandMenu.Empty>
</CommandMenu.List>
```

### 使用禁用项

```tsx
<CommandMenu.Item disabled onSelect={handleAction} value="rotate-secrets">
  不可用操作 (Unavailable Action)
</CommandMenu.Item>
```

## 属性

### CommandMenu.Root

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `open` | `boolean` | 命令菜单是否可见 |
| `setOpen` | `(open: boolean) => void` | 用于控制打开状态的 setter 函数 |
| `label` | `string` | 无障碍标题，默认是 `Command Menu` |
| `description` | `string` | 对辅助技术隐藏显示的描述 |
| `className` | `string` | Dialog 面板额外类名 |
| `commandClassName` | `string` | cmdk 框架额外类名 |
| `children` | `ReactNode` | `CommandMenu.Input` + `CommandMenu.List` |

### CommandMenu.Item

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `onSelect` | `(value: string) => void` | 选中条目时调用 |
| `callback` | `() => void` | 兼容别名。新代码优先使用 `onSelect` |
| `value` | `string` | cmdk 用于过滤和选中的稳定值 |
| `disabled` | `boolean` | 禁用此项 |
| `className` | `string` | 额外的 CSS 类名 |
| `children` | `ReactNode` | 条目标签（+ 可选的 `CommandMenu.Shortcut`） |

### CommandMenu.Shortcut

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `keys` | `ReactNode[]` | 渲染为 `Kbd` 的快捷键片段 |
| `label` | `string` | 无障碍快捷键说明 |
| `children` | `ReactNode` | 单个快捷键片段的兼容写法 |

### 子组件

| 组件 | 描述 |
|-----------|-------------|
| `CommandMenu.Input` | 带有搜索图标的搜索输入框 |
| `CommandMenu.List` | 可滚动的搜索结果容器 |
| `CommandMenu.Results` | 使用 `aria-live="polite"` 播报结果数量 |
| `CommandMenu.Group` | 带有可选 `heading` 标签的分组 |
| `CommandMenu.Item` | 可选操作条目 |
| `CommandMenu.Empty` | 当搜索无结果匹配时显示 |
| `CommandMenu.Shortcut` | 通过 `Kbd` 渲染的键盘快捷键提示 |
| `CommandMenu.Separator` | 组与组之间的视觉分隔线 |

## 设计契约

- 打开后进入根页面；输入为空时也要展示最近或默认操作。
- 按产品范围分组。平铺列表超过约 30 项，或跨越多个资源类型时，应拆成页面。
- 条目文案使用 Title Case 动宾短语，例如 `Deploy Project`、`Invite Team Member`。
- 快捷键放在 `CommandMenu.Shortcut` 中，让视觉用户可发现，也让辅助技术获得 label。
- 不要手写方向键状态机。`CommandMenu` 把过滤、选中和角色语义交给 `cmdk`。

## 可访问性

- 对话框覆盖层会锁定焦点，并在关闭时恢复焦点。
- 按下 `Escape` 键可关闭覆盖层。
- 使用 `ArrowUp` / `ArrowDown` 在各条目间导航。
- 按下 `Enter` 键触发当前选中项的 `onSelect`。
- 搜索通过 cmdk 实现实时过滤。
- `CommandMenu.Results` 通过 `aria-live="polite"` 播报结果数量变化。
- 没有关闭按钮 — 命令面板通常依赖 `Escape`、点击外部区域和选择具体操作条目作为退出路径。

## 真实产品示例

- 通过 `Cmd+K` / `Ctrl+K` 打开的全局产品搜索。
- Workspace switcher，默认状态展示最近工作区。
- AI 工具启动器，每个命令都有稳定 `value` 以支持过滤和 telemetry。

## 反模式

- 不要把 CommandMenu 当作局部表格筛选器；inline 场景使用 Command 或 Combobox。
- 不要把破坏性操作混进全局导航，除非后面还有二次确认。
- 不要让 `Cmd+K` 同时绑定 CommandMenu 和当前聚焦的页面内搜索输入框。
