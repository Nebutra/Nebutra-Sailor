## 使用方法

```tsx
import { Kbd } from "@nebutra/ui/primitives";
```

```tsx
<Kbd meta>K</Kbd>
```

## 示例

### 修饰键

```tsx
<Kbd meta />
<Kbd shift />
<Kbd alt />
<Kbd ctrl />
```

### 组合键

```tsx
<Kbd meta shift />
```

### 小尺寸

```tsx
<Kbd small>/</Kbd>
```

## 设计原则

- `Kbd` 用于正文、菜单项、命令行、按钮 suffix 里的快捷键提示。
- 修饰键通过 boolean prop 传入。`meta` 在 Apple 平台显示 Command，在 Windows/Linux 显示 Ctrl。
- `children` 只能是一个键、数字、标点或命名键：`K`、`7`、`/`、`Enter`、`Esc`。
- 不要把完整快捷键字符串塞进 children。用 `<Kbd meta>K</Kbd>`，不要用 `<Kbd>Cmd+K</Kbd>`。
- 高密度界面使用 `small`，例如菜单行、command bar、表格单元格。
- 标点放在元素外部，让复制文本和屏幕阅读器输出保持干净。

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `meta` | `boolean` | `false` | Apple 平台为 Command；Windows/Linux 为 Ctrl |
| `shift` | `boolean` | `false` | Shift 修饰键 |
| `alt` | `boolean` | `false` | Apple 平台为 Option；Windows/Linux 为 Alt |
| `ctrl` | `boolean` | `false` | Control 修饰键 |
| `small` | `boolean` | `false` | 高密度 UI 小尺寸 |
| `children` | `ReactNode` | — | 单个键、数字、标点或命名键 |

## 可访问性

- `Kbd` 渲染原生 `<kbd>` 元素。
- 修饰键 glyph 带有可访问标签，例如 `⌘K` 会读作 “Command or Control K”。
- 相邻正文仍然要说明动作，例如 “Press ⌘ K to open the command menu.”
