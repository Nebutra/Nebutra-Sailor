## 用法

```tsx
import { MiddleTruncate } from "@nebutra/ui/primitives";
```

```tsx
<div className="max-w-64">
  <MiddleTruncate value="apps/vercel-site/app/(dashboard)/[teamSlug]/[project]/settings/page.tsx" />
</div>
```

## 设计契约

- 用于头尾都携带信息的字符串：文件路径、URL、部署 ID、提交哈希、分支名、模型名。
- 不要用于正文、描述和标题。句子被从中间切开后，语义会变差。
- 用户可能需要原文时，配合 Tooltip 或复制按钮暴露完整字符串。
- hover 扩展卡片、动画行这类场景要锁定容器宽度。组件会监听容器宽度，宽度变化会改变截断点。
- 不要再包一层 `text-overflow: ellipsis`。两种截断策略会互相干扰。

## 属性
| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `value` | `string` | 必填 | 完整原始字符串 |
| `minStartChars` | `number` | `6` | 空间允许时至少保留的开头字符数 |
| `minEndChars` | `number` | `8` | 空间允许时至少保留的结尾字符数 |
| `ellipsis` | `string` | `"…"` | 开头和结尾之间的省略符 |
| `className` | `string` | — | 应用于 wrapper 的排版或布局类 |

## 可访问性

- 截断后完整值仍保留在 DOM 中，辅助技术读取的是原始字符串，而不是可见的省略号形式。
- 从组件中复制文本时，剪贴板会得到完整 `value`。
- 放在可聚焦控件内部时，在控件或 MiddleTruncate 上提供明确的 `aria-label`，不要让屏幕阅读器只依赖视觉截断结果。
