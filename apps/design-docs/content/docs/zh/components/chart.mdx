## 安装

```tsx
import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
  type ChartConfig,
} from "@nebutra/ui/primitives";
```

Standalone registry 安装：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/chart.json
```

## 用法

`ChartContainer` 包裹 Recharts primitives，并通过 `ChartConfig` 注入 series label 与 color。

```tsx
const chartConfig = {
  apiCalls: {
    label: "API Calls",
    color: "hsl(var(--chart-1))",
  },
} satisfies ChartConfig;

<ChartContainer config={chartConfig} className="h-[280px]">
  <BarChart data={data}>
    <XAxis dataKey="month" />
    <ChartTooltip content={<ChartTooltipContent />} />
    <Bar dataKey="apiCalls" fill="var(--color-apiCalls)" />
  </BarChart>
</ChartContainer>
```

## 属性
### ChartContainer

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `config` | `ChartConfig` | required | series 的 label、icon、color/theme 映射。 |
| `children` | `ResponsiveContainer["children"]` | required | 渲染在 responsive container 内的 Recharts 图表 primitive。 |
| `className` | `string` | - | 布局 class。必须提供稳定高度或宽高比。 |
| `id` | `string` | auto | 可选稳定 id，用于生成 CSS 变量 scope。 |

### ChartTooltipContent

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `indicator` | `"line" \| "dot" \| "dashed"` | `"dot"` | series 指示器样式。 |
| `hideLabel` | `boolean` | `false` | 隐藏 tooltip label 行。 |
| `hideIndicator` | `boolean` | `false` | 隐藏 series marker。 |
| `labelKey` | `string` | - | 用于解析 label metadata 的 config key。 |
| `nameKey` | `string` | - | 用于解析 item metadata 的 config key。 |

## 何时使用

- 用于定量比较：趋势、占比或多序列数据。
- 单个 headline value 足够时使用 `KpiCard`。
- 精确值比视觉比较更重要时使用 table。

## 相关模式

查看 [Charts](/zh/docs/patterns/charts) 了解更高层的图表组合规则、loading states 和 dashboard layout 指南。

## 可访问性

- Recharts 支持时传入 `accessibilityLayer`，让键盘和辅助技术可以检查图表数据。
- 精确数值重要时，图表旁必须配 summary 句或表格。
- 不能只依赖颜色。Series label、tooltip 文案和 legend 必须能识别数据。

## 设计契约

- `ChartContainer` 负责 theme-aware CSS 变量注入；消费方用 `var(--color-seriesKey)` 填充 series。
- 使用应用主题里的语义 chart token，不使用临时 Tailwind 色值。
- 容器必须有稳定高度/宽高比。数据流式更新时尺寸跳动会破坏 dashboard 扫描。

## 真实产品示例

- 工作区使用量 dashboard，用同一时间窗口比较 API 调用、活跃用户和错误率。
- 计费与用量页面，先给出套餐用量趋势，再让用户进入表格查看明细。
- 事故复盘面板，把延迟或错误率图表和受影响服务的文字摘要放在一起。

## 反模式

- 不要用图表展示单个 headline value；这种场景用 `KpiCard`，图表空间留给趋势形状或横向比较。
- 用户需要审计精确行、发票或日志时不要用图表替代表格。
- 不要为了填满 dashboard 空位而编造装饰性 series 或渐变。如果没有有意义的比较，应保留空状态或解释数据缺失原因。
