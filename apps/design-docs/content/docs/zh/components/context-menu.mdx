## 概览

`ContextMenu` 是给熟练用户使用的快捷操作入口，服务于右键、长按和键盘菜单键。它基于 Base UI，并使用 Nebutra 的菜单项、弹层和 motion token。它绝不能成为某个操作的唯一入口；每个菜单项都必须在可见的行操作、工具栏菜单或详情面板中有等价入口。

全局动作和搜索用 `CommandMenu`。如果可发现性比右键效率更重要，请使用可见触发器菜单。

## 用法

### 禁用项

当操作存在但暂时不可用时，保留禁用项。

```tsx
<ContextMenu.Item disabled value="promote">
  Promote to Production
</ContextMenu.Item>
```

### 链接项

有导航语义时使用 `href`。链接项会渲染为 Base UI 的 link item，而不是模拟点击。

```tsx
<ContextMenu.Item href="/docs" prefix={<Link className="size-4" />} value="docs">
  View Documentation
</ContextMenu.Item>
```

### 前缀和后缀

<ComponentPreview name="context-menu-with-icons-demo" className="min-h-[250px] flex justify-center items-center" />

```tsx
<ContextMenu.Item prefix={<Copy className="size-4" />} value="copy">
  Copy URL
  <ContextMenu.Shortcut>⌘C</ContextMenu.Shortcut>
</ContextMenu.Item>
```

### Checkbox、Radio 和子菜单

```tsx
<ContextMenu.CheckboxItem defaultChecked value="status">
  Status
</ContextMenu.CheckboxItem>

<ContextMenu.RadioGroup defaultValue="comfortable">
  <ContextMenu.RadioItem value="compact">Compact</ContextMenu.RadioItem>
  <ContextMenu.RadioItem value="comfortable">Comfortable</ContextMenu.RadioItem>
</ContextMenu.RadioGroup>

<ContextMenu.Sub>
  <ContextMenu.SubTrigger>Move to Project</ContextMenu.SubTrigger>
  <ContextMenu.SubContent>
    <ContextMenu.Item value="core">Core Platform</ContextMenu.Item>
  </ContextMenu.SubContent>
</ContextMenu.Sub>
```

## Props

### ContextMenu

`ContextMenu` 本身就是 root 组件，同时保留 `ContextMenu.Root` 兼容既有调用。

### ContextMenu.Content

接受 Base UI popup props，并额外支持 `align`、`side`、`alignOffset`、`sideOffset`。

### ContextMenu.Item

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | 菜单项标签。使用 Title Case Verb + Noun。 |
| `onSelect` | `BaseContextMenu.Item["onClick"]` | — | 非链接项的激活回调。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `href` | `string` | — | 渲染为链接项。 |
| `prefix` | `ReactNode` | — | 前置图标或头像。 |
| `suffix` | `ReactNode` | — | 后置提示。快捷键优先用 `ContextMenu.Shortcut`。 |
| `variant` | `"default" \| "destructive"` | `"default"` | 不可逆操作的危险样式。 |
| `value` | `string` | — | 稳定的埋点/测试值。 |

## 设计原则

- Context menu 用于加速二级操作，不替代可见控件。
- 标签使用 Title Case Verb + Noun：`Copy URL`、`Delete Deployment`、`Open in New Tab`。
- 只有打开后续对话框时才使用省略号，例如 `Rename Deployment...`。
- 危险操作放在底部并用分隔线隔开。不要把危险操作藏进子菜单。
- 子菜单最多一层；层级过深会让键盘导航变脆弱。

## 可访问性

- 右键、长按和键盘菜单键应暴露同一组操作。
- 方向键移动焦点；`Enter`/`Space` 激活；`Escape` 关闭并返回焦点。
- 禁用项保持可读，但不可激活。
- 触发区域应限定在具体行/对象，而不是整个页面。
