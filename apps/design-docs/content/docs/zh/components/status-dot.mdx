## 安装

```tsx
import { StatusDot } from "@nebutra/ui/primitives";
```

Standalone registry 安装：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/status-dot.json
```

## 用法

`StatusDot` 只用于 deployment lifecycle state。不要把它复用到任意 workflow、queue 或 billing 状态。

```tsx
<StatusDot state="BUILDING" titlePrefix="Production deployment" label />
```

## 状态

| 状态 | 动效 |
| --- | --- |
| `QUEUED` | 脉冲 |
| `BUILDING` | 脉冲 |
| `READY` | 静态 |
| `ERROR` | 静态 |
| `CANCELED` | 静态 |
| `DELETED` | 静态 |

## 可访问性

- 默认 `aria-label` 由 `titlePrefix` 和状态文案组合。
- 当旁边已有可见文字命名状态时，传入 `decorative`。
- 颜色不是唯一信号；`label` 会渲染 sentence-cased 状态文本。

## 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `state` | `"QUEUED" \| "BUILDING" \| "READY" \| "ERROR" \| "CANCELED" \| "DELETED"` | required | Deployment lifecycle state。 |
| `label` | `boolean` | `false` | 在点旁边渲染可见状态文字。 |
| `titlePrefix` | `string` | `"Deployment"` | 用于组合 accessible label 的前缀。 |
| `decorative` | `boolean` | `false` | 当旁边文案已经命名状态时，把 dot 从 assistive tech 中隐藏。 |
| `className` | `string` | - | 额外布局 class。 |

## 设计契约

- `StatusDot` 只用于 deployment lifecycle。通用实体状态需要独立 status primitive 和独立枚举。
- 脉冲表示活动中，不表示严重程度。只有 `QUEUED` 与 `BUILDING` 动起来。
- 如果同一行已有状态文案，传 `decorative`；否则渲染 `label` 或保留默认可访问名称。
