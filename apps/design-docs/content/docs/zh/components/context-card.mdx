## 概览

`ContextCard` 用于在悬停或键盘聚焦时展示紧凑实体信息：项目、部署、用户、团队、API Key、Webhook 投递或套餐状态。它不是 `Tooltip` 的替代品。一句话解释用 `Tooltip`，2-4 行元数据用 `ContextCard`，长内容或多操作流转到 `Drawer` 或详情页。

底层基于 Base UI Popover，而不是 Tooltip，因此可以承载一个可键盘访问的主操作。触发器必须保留自己的可访问名称，卡片只是补充上下文。

## 安装

```tsx
import { ContextCard } from "@nebutra/ui/primitives";
```

## 使用方法

### 实体元数据

```tsx
import { Button, ContextCard } from "@nebutra/ui/primitives";

<ContextCard.Trigger
  side="top"
  content={
    <ContextCard.Entity
      title="Nebula Console"
      description="nebutra/production"
      metadata={[
        { label: "Plan", value: "Pro" },
        { label: "Owner", value: "Platform" },
        { label: "Last Active", value: "2m ago" },
      ]}
      action={
        <Button size="tiny" variant="outline" className="w-full">
          Open Project
        </Button>
      }
    />
  }
>
  <button type="button">Nebula Console</button>
</ContextCard.Trigger>
```

### 放置位置

```tsx
<ContextCard.Trigger
  side="right"
  align="start"
  width="sm"
  content={<ContextCard.Entity title="API Gateway" description="api.nebutra.com" />}
>
  <button type="button">API Gateway</button>
</ContextCard.Trigger>
```

### 自定义内容

只有当 `ContextCard.Entity` 无法表达内容结构时才使用自定义内容。内容要保持紧凑，并且最多放一个主操作。

```tsx
<ContextCard.Trigger
  side="top"
  content={
    <div className="grid gap-[var(--context-card-section-gap)]">
      <p className="font-medium">API Gateway</p>
      <p className="text-muted-foreground">Routes authenticated tenant traffic.</p>
    </div>
  }
>
  <button type="button">Gateway</button>
</ContextCard.Trigger>
```

## 属性

### ContextCard.Trigger

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `content` | `ReactNode` | - | **必填。** 在卡片内显示的内容 |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | 卡片出现的侧面 |
| `align` | `"start" \| "center" \| "end"` | `"center"` | 相对触发器的对齐方式 |
| `sideOffset` | `number` | `8` | 距离触发器的像素距离 |
| `alignOffset` | `number` | `0` | 垂直于主轴的偏移 |
| `width` | `"sm" \| "md"` | `"md"` | 组件 token 控制的卡片宽度 |
| `openDelay` | `number` | `150` | 打开延迟，单位毫秒 |
| `closeDelay` | `number` | `120` | 关闭延迟，单位毫秒 |
| `children` | `ReactNode` | - | **必填。** 触发卡片的元素 |
| `className` | `string` | - | 卡片的额外 CSS 类名 |

### ContextCard.Entity

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `ReactNode` | - | **必填。** Title Case 的实体名称 |
| `description` | `ReactNode` | - | 一行识别信息，例如 owner、slug 或 URL |
| `metadata` | `{ id?: string; label: ReactNode; value?: ReactNode }[]` | - | 2-4 行紧凑 `Label: value` 元数据。缺失值显示 `—` |
| `action` | `ReactNode` | - | 可选的单个主操作 |

## 最佳实践

- 用 Context Card 展示实体元数据：用户、部署、项目、Webhook、API Key 或套餐。
- 不要承载破坏性操作。鼠标移动时卡片可能关闭。
- 交互内容最多一个主操作。多个操作应使用 `Menu`、`Drawer` 或详情页。
- 不要把 Context Card 嵌套在 Tooltip 或另一个 Context Card 中。
- 不要重复触发器已经展示的信息。

## 可访问性

- 悬停和键盘聚焦都会打开，默认入口延迟来自组件 motion token：150ms。
- 触发器聚焦时按 `Enter` 或 `ArrowDown`，可把焦点移动到卡片内的可聚焦操作。
- 按 `Escape` 关闭卡片，并把焦点返回触发器。
- 触发器必须有清晰的可访问名称；卡片内容只是补充说明。
