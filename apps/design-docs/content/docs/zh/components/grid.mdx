## 概览

`Grid` 用于营销页、文档首页、功能拆解等“引导线本身就是视觉语言”的二维 cell-and-guide 布局。普通卡片列表、n 列内容流请直接用 Tailwind grid utilities，不要引入这个 primitive。

组件分三层：

- `Grid.System` 管理 guide 宽度、debug 模式，以及可选的 container query 边界。
- `Grid` 管理 columns/rows 数学和装饰性 guide 背景。
- `Grid.Cell` 管理内容放置，并可通过 `solid` 遮住 cell 背后的 guide。

Guide 使用 CSS background 绘制，不生成 DOM 节点，因此不会进入无障碍树。

## 安装

```tsx
import { Grid } from "@nebutra/ui/primitives";
```

## 用法

### 空 guide 网格

```tsx
<Grid.System debug guideWidth={1} unstable_useContainer>
  <Grid columns={5} height="preserve-aspect-ratio" rows={2} />
</Grid.System>
```

### 基础网格

```tsx
<Grid.System guideWidth={1} unstable_useContainer>
  <Grid columns={3} rows={2}>
    <Grid.Cell>1</Grid.Cell>
    <Grid.Cell>2</Grid.Cell>
    <Grid.Cell>3</Grid.Cell>
    <Grid.Cell>4</Grid.Cell>
    <Grid.Cell>5</Grid.Cell>
    <Grid.Cell>6</Grid.Cell>
  </Grid>
</Grid.System>
```

### 响应式网格与 guide clipping

```tsx
<Grid.System unstable_useContainer>
  <Grid columns={{ sm: 1, md: 2, lg: 3 }} rows={{ sm: 6, md: 3, lg: 2 }}>
    <Grid.Cell column={{ sm: "1", md: "1/3" }} row={{ sm: "1/3", md: 1 }} solid>
      1 + 2
    </Grid.Cell>
    <Grid.Cell>3</Grid.Cell>
    <Grid.Cell>4</Grid.Cell>
    <Grid.Cell column={{ sm: 1, md: "1/3", lg: "2/4" }} row={{ sm: "5/7", md: 3, lg: 2 }} solid>
      5 + 6
    </Grid.Cell>
  </Grid>
</Grid.System>
```

### 隐藏某个 guide 轴

```tsx
<Grid.System unstable_useContainer>
  <Grid columns={12} height="preserve-aspect-ratio" hideGuides="row" rows={3} />
</Grid.System>
```

## 属性

### `Grid.System`

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `debug` | `boolean` | `false` | 给透明 cell 加上 debug wash，便于检查 guide |
| `guideWidth` | `number \| string` | `1` | 装饰 guide 的线宽 |
| `unstable_useContainer` | `boolean` | `false` | 使用 container queries 解析响应式 `Grid` props |
| `children` | `ReactNode` | — | 通常是一层 `Grid` |

### `Grid`

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `columns` | `number \| { sm?: number; md?: number; lg?: number }` | — | 等宽列数 |
| `rows` | `number \| { sm?: number; md?: number; lg?: number }` | `1` | 行数，用于 guide 数学和 cell 放置 |
| `height` | `"preserve-aspect-ratio" \| string \| number` | — | 保持列/行比例，或设置固定 CSS 高度 |
| `hideGuides` | `"row" \| "column" \| "both"` | — | 隐藏一个或两个装饰 guide 轴 |

### `Grid.Cell`

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `column` | `number \| string \| responsive value` | — | CSS `grid-column` 放置 |
| `row` | `number \| string \| responsive value` | — | CSS `grid-row` 放置 |
| `solid` | `boolean` | `false` | 使用 token 化不透明背景遮住 guide |
| `children` | `ReactNode` | — | cell 内容 |

## 设计原则

只有在 guide line 真的传达结构时才使用 Grid。所有目标断点都要明确设置 rows/columns，保证移动、平板、桌面之间阅读顺序可预测。不要嵌套超过一层 Grid；重叠 guide 会制造视觉噪音。

当 cell 可交互时，把真正的语义元素放在 cell 内部。cell 负责 `focus-within` 的容器反馈，按钮或链接本身继续持有自己的可访问名称和键盘契约。
