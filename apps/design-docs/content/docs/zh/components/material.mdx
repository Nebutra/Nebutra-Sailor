## 概览

`Material` 是一个表面高度原语。它通过 `class-variance-authority` 将语义化的 `type` 属性映射到
Tailwind 中由 theme 派生的阴影和背景工具类（`shadow-sm`、`bg-card` 等）—— 没有手写的阴影或填充值。
在任何需要表达视觉深度的地方都可以使用它：卡片、下拉菜单、对话框或全屏叠加层。

## 安装

```tsx
import { Material } from "@nebutra/ui/primitives";
```

## 使用方法

### 类型

`Material` 有 8 个规范高度级别，外加 1 个已弃用别名——不是 4 个。定义于
`packages/design/ui/src/primitives/material.tsx`：

```tsx
<Material type="base">
  <div className="p-6">静态卡片内容</div>
</Material>

<Material type="menu">
  <div className="py-1">菜单项 (Menu items)</div>
</Material>

<Material type="modal">
  <div className="p-6">对话框内容 (Dialog content)</div>
</Material>

<Material type="fullscreen">
  <div className="p-6">全屏内容 (Full-screen content)</div>
</Material>
```

### `base`

用于静态卡片的默认表面。应用 `shadow-sm` 和 `bg-card`。

```tsx
<Material type="base" className="w-80">
  <div className="p-6">
    <h2 className="text-sm font-medium">卡片标题 (Card title)</h2>
    <p className="text-xs text-muted-foreground mt-1">辅助文本 (Supporting text)</p>
  </div>
</Material>
```

`type="card"` 仍然可用，作为 `base` 的**已弃用**别名，为已有调用方保留。新代码应使用 `base`。

### `small` / `medium` / `large`

依次递增的抬升内容层级。`small` 与 `base` 相同（`shadow-sm`）；`medium` 和 `large` 都应用
`shadow-md` 和 `bg-card`。

```tsx
<Material type="medium" className="w-80">
  <div className="p-6">抬升内容</div>
</Material>
```

### `tooltip` / `menu`

浮动气泡表面。两者都应用 `shadow-md` 和 `bg-popover`。

```tsx
<Material type="menu" className="w-56">
  <div className="py-1">
    <button type="button" className="w-full text-left px-3 py-2 text-sm hover:bg-muted">
      个人资料 (Profile)
    </button>
    <button type="button" className="w-full text-left px-3 py-2 text-sm hover:bg-muted">
      设置 (Settings)
    </button>
  </div>
</Material>
```

### 模态框

对话框和抽屉表面。应用 `shadow-xl` 和 `bg-popover`。

```tsx
<Material type="modal" className="w-96">
  <div className="p-6 flex flex-col gap-4">
    <h2 className="text-sm font-semibold">确认操作 (Confirm action)</h2>
    <p className="text-xs text-muted-foreground">此操作无法撤销。</p>
    <div className="flex justify-end gap-2">
      <Button variant="outline">取消 (Cancel)</Button>
      <Button>确认 (Confirm)</Button>
    </div>
  </div>
</Material>
```

### 全屏

全屏叠加表面。应用 `shadow-none` 和 `bg-background`。

```tsx
<Material type="fullscreen" className="fixed inset-0">
  <div className="p-8">全屏内容 (Full-screen content)</div>
</Material>
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `type` | `"base" \| "small" \| "medium" \| "large" \| "tooltip" \| "menu" \| "modal" \| "fullscreen" \| "card"`（`"card"` 已弃用，为 `"base"` 的别名） | `"base"` | 表面高度级别 |
| `className` | `string` | — | 额外的 CSS 类名 |
| `children` | `ReactNode` | — | 表面内容 |
| `ref` | `Ref<HTMLDivElement>` | — | 转发的引用 (Forwarded ref) |

还支持所有标准的 `div` HTML 属性。不要在同一元素上叠加两个 `Material`——如果子元素需要更高的
层级，把它提升到一个独立的、`type` 更高的 `Material` 中。

## Token 引用

`--shadow-*` 与 `--color-card`/`--color-popover`/`--color-background` 定义在
`packages/design/tokens/styles.css` 的 `@theme inline` 区块中，这是一个 generated 文件，不要手动编辑。
可编辑的源是 `packages/design/design-tokens/tokens/` 下的 DTCG token JSON。
`packages/design/theme/themes.css` 不含任何高度 token；它只是五行生成代码，用于别名 `keyframes.css`。

| 类型 (type) | 阴影 Token | 背景 Token |
|------|-------------|-----------------|
| `base` / `small` / `card`（已弃用） | `--shadow-sm` | `--color-card` |
| `medium` / `large` | `--shadow-md` | `--color-card` |
| `tooltip` / `menu` | `--shadow-md` | `--color-popover` |
| `modal` | `--shadow-xl` | `--color-popover` |
| `fullscreen` | _(无)_ | `--color-background` |

## 可访问性

- `Material` 渲染为一个普通的 `<div>` —— 请根据具体用途在调用处添加语义化角色（如 `role="dialog"`、`role="menu"` 等）。
- 阴影仅作为视觉引导；不要仅依靠阴影向辅助技术传达状态或层级。

## 设计契约

- `Material` 只负责 surface elevation，不添加 semantic role、focus management、dismissal behavior 或 overlay stacking。
- 消费者根据 surface 目的选择合适的语义元素或 role。
- elevation 必须由 theme layer token 驱动，不要在单个 usage 中添加 inline shadow、background 或 border value。
- 需要行为时使用 `Card`、`Dialog`、`Popover` 或 `Menu` primitive；只需要表面质感时才使用 `Material`。
