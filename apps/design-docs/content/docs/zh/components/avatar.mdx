## 导入

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarGroup,
  AvatarImage,
  AvatarWithIcon,
  BitbucketAvatar,
  DiceBearAvatar,
  GitHubAvatar,
  GitLabAvatar,
} from "@nebutra/ui/primitives";
```

常规头像优先使用便捷 API：图片存在时显示图片，缺失时回退到首字母。

## 组合式用法

当调用方需要完全控制图片和 fallback 时，使用 compound API。

## 头像组

`AvatarGroup` 支持 Geist 风格的 `members`、`limit`、`size={32}`，同时保留现有的 `items`、`max` 和预设尺寸 API。

## 属性
### Avatar

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| number` | `"md"` | 预设尺寸或像素尺寸。 |
| `src` | `string` | — | 便捷图片地址。 |
| `title` | `string` | — | 实体名称，用于 fallback 首字母和可访问标签。 |
| `letter` | `string` | 自动推导 | 1-2 个大写首字母。 |
| `placeholder` | `boolean` | `false` | 仅用于加载态骨架。 |

### AvatarGroup

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `members` | `AvatarGroupItem[]` | — | Geist 兼容成员列表。 |
| `items` | `AvatarGroupItem[]` | — | Nebutra 既有成员列表。 |
| `limit` | `number` | `4` | Geist 兼容的最大显示槽位数。 |
| `max` | `number` | `4` | `limit` 的既有别名。 |
| `size` | `AvatarSize \| number` | `"sm"` | 应用于组内所有头像。 |

## 最佳实践

- 单个用户、团队或组织使用一个 `Avatar`。
- 两个及以上堆叠头像使用 `AvatarGroup`，让重叠、尺寸、溢出和可访问标签统一处理。
- 优先传 `src`，图片缺失时用 `letter` 回退。
- `placeholder` 只用于加载壳，不作为永久 fallback。
- `letter` 保持大写，并从实体名称推导，长度为 1-2 个字符。
- 尺寸跟随相邻文本：紧凑标签旁用 20-24px，常规标签旁用 32px，页面头部或 onboarding 状态用 48-64px。

## 可访问性

- `AvatarGroup` 暴露一个组级标签，并隐藏组内重复图片，避免读屏器反复播报。
- 单个图片头像需要提供有意义的 `title` 或 `alt`。
- 当头像触发菜单或操作时，用带明确 `aria-label` 的按钮包裹。
