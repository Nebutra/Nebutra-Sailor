## 使用方法 (Usage)

```tsx
import { Gauge } from "@nebutra/ui/primitives";
```

```tsx
<div>
  <p id="cache-hit-rate">Build Cache Hit Rate · 92%</p>
  <Gauge aria-labelledby="cache-hit-rate" showValue size="medium" value={92} />
</div>
```

## 设计原则 (Design Principles)

- Gauge 用于固定最大值下的 0–100 比率：配额使用量、缓存命中率、可用率、账期消耗。
- 上传进度、多步流程进度这类确定性任务使用 Progress。
- 二元、枚举、部署状态使用 Status Dot 或 Badge。
- 每个 Gauge 都必须搭配相邻标签或 Tooltip，说明这个数字代表什么。
- 不要只靠颜色表达阈值；warning/error 色调旁边要有冗余文案。
- 默认阈值遵循用量语义：`>=80%` warning，`>=95%` error。健康分这类高分更好的场景应显式传入 `colors`。

## 属性 (Props)

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `value` | `number` | `0` | 当前值，会限制在 0–100 |
| `size` | `"tiny" \| "small" \| "medium" \| "large" \| number` | `"medium"` | 预设尺寸或兼容旧版像素直径 |
| `colors` | `GaugeColorMap \| GaugeColorStop[]` | 用量刻度 | 阈值颜色或显式 `primary` / `secondary` 颜色 |
| `secondaryColor` | `string` | — | 兼容旧版轨道颜色覆盖；优先使用 `colors.secondary` |
| `showValue` | `boolean` | `false` | 仅渲染数字，不渲染 `%` |
| `label` | `boolean \| ReactNode` | — | 兼容旧版 `showValue` 别名；ReactNode 作为中心覆盖层 |
| `children` | `ReactNode` | — | 中心图标覆盖层 |
| `arcPriority` | `"default" \| "equal"` | `"default"` | `equal` 用于真实比例，让两段圆弧等长 |
| `indeterminate` | `boolean` | `false` | 数值未知时显示加载态 |

### `GaugeColorMap`

```ts
type GaugeColorMap = Record<string, string> & {
  primary?: string;
  secondary?: string;
};
```

阈值 key 是数字字符串。小于或等于当前 `value` 的最高阈值会生效。

```tsx
<Gauge
  value={50}
  colors={{
    primary: "hsl(var(--info))",
    secondary: "hsl(var(--info) / 0.18)",
  }}
/>
```

## 可访问性 (Accessibility)

- Gauge 设置 `role="progressbar"`，并带有 `aria-valuemin`、`aria-valuemax`、`aria-valuenow`。
- 使用 `aria-labelledby` 关联相邻标签，例如 “Build Cache Hit Rate, 92 percent”。
- indeterminate 状态会省略 `aria-valuenow` 并设置 `aria-busy`。
- `showValue` 仅用于视觉显示；可访问数值来自 ARIA。
