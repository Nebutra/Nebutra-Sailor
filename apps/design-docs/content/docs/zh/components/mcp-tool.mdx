## 安装

```tsx
import { McpTool } from "@nebutra/ui/primitives";
```

```bash
npx shadcn@latest add https://ui.nebutra.com/r/mcp-tool.json
```

## 用法

`McpTool` 渲染 assistant 调用 MCP 工具后的内联状态。它会把工具名规范化为标题，展示最重要的参数，并在有输出时提供展开面板。

```tsx
<McpTool
  name="list_resources"
  args={{ query: "active customers", limit: 25 }}
  output={JSON.stringify(rows, null, 2)}
/>
```

## 状态模型

| 状态 | 渲染 |
| --- | --- |
| `pending` | shimmer 准备态，不展示参数和输出 |
| `completed` | 过去式标题 + 优先级参数 + 可展开输出 |
| `interrupted` | muted interrupted 状态，不展示 body |

## 可访问性

- 外层为带 `aria-label` 的 `<section>`。
- 展开按钮关联 `aria-expanded` 和 `aria-controls`。
- 输出区域是 `<pre role="region" aria-label="Tool output">`。
- interrupted 状态使用 `role="status"`。

## 设计契约

- `McpTool` 只用于 MCP 调用记录。普通命令输出、日志或本地文件编辑需要独立 primitive。
- `name` 传入 MCP server 的原始工具名；归一化只是展示逻辑，不能引入翻译表。
- 输出截断必须诚实。如果消费方需要完整导出，应增加明确动作，而不是静默放大 inline panel。
