## 使用方法

```tsx
import { BentoGrid, BentoCard } from "@nebutra/ui";
import { Sparkles } from "@nebutra/icons";

<BentoGrid>
  <BentoCard
    name="AI 集成"
    description="将 AI 无缝集成到您的工作流中"
    Icon={Sparkles}
    href="/features/ai"
    cta="了解更多"
  />
</BentoGrid>;
```

## 示例

### 基础网格

```tsx
import { Sparkles, Lightning as Zap, LockClosed as Lock } from "@nebutra/icons";

<BentoGrid>
  <BentoCard
    name="AI 驱动"

    Icon={Sparkles}

    href="/features/ai"

    name="闪电般飞速"
```

### 带有背景插槽

`background` 属性接受任何 ReactNode —— 可以使用渐变、图像或动画组件：

```tsx
<BentoCard
  name="波动可视化"
  description="为您的数据流提供实时音频可视化。"
  Icon={Radio}
  background={
    <div className="absolute inset-0 opacity-60">
      <WaveAnimation position="absolute" />
    </div>
  }
  href="/features/streams"
/>
```

### 自定义行/列跨度

使用 `className` 控制网格布局：

```tsx
<BentoGrid className="lg:grid-cols-3">
  <BentoCard
    name="宽屏"
    description="适合强调一个主能力。"
    Icon={Maximize}
    className="lg:col-span-2 lg:row-span-2"
  />
  <BentoCard
    name="纵向"
    description="适合展示长图或纵向状态。"
    Icon={ArrowUp}
    className="lg:row-span-2"
  />
  <BentoCard name="常规" description="适合单个辅助能力。" Icon={Square} />
  <BentoCard name="补充" description="适合链接到下一步。" Icon={Circle} />
</BentoGrid>
```

## 属性

### BentoGrid 网格容器

| 属性 | 类型 | 默认值 | 描述 |
| ----------- | ----------- | ------- | -------------------------- |
| `children`  | `ReactNode` | — | BentoCard 条目 |
| `className` | `string`    | — | 覆盖网格列/行 |

默认网格：`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`，`auto-rows-[22rem]`，`gap-4`。

### BentoCard 网格条目

| 属性 | 类型 | 默认值 | 描述 |
| ------------- | ------------------- | -------------- | ------------------------------------------------------ |
| `name`        | `string`            | — | 卡片标题 |
| `description` | `string`            | — | 卡片描述文本 |
| `Icon`        | `React.ElementType` | — | 图标组件（显示在标题上方） |
| `background`  | `ReactNode`         | — | 背景插槽 —— 绝对定位在内容后方 |
| `href`        | `string`            | — | CTA 链接 URL |
| `cta`         | `string`            | `"了解更多"` | CTA 按钮文本 |
| `className`   | `string`            | — | 网格跨度类名 (`lg:col-span-2` 等) |

## 注意事项

- 在**桌面端** (lg)，CTA 按钮初始状态下是隐藏的，通过向上滑动悬停显示。
- 在**移动端**，CTA 始终显示在描述下方。
- 背景插槽渲染在卡片顶部的 `div` 容器中 —— 在背景内部使用 `absolute inset-0` 定位以实现全覆盖。
- 悬停时图标会缩小至 75% (`group-hover:scale-75`)，且内容会向上滑动 (`group-hover:-translate-y-10`)。

## 可访问性

- 提供 `href` 时，`BentoCard` 只渲染一个链接目标。不要在 `background` 插槽里嵌套额外链接或按钮。
- `name` 要足够短，让它能成为卡片动作的有效可访问名称。
- 装饰性背景应对辅助技术隐藏。关键信息必须放在 `name` 和 `description`，不要烘焙在图片里。
- 保留卡片链接的可见焦点；hover 才出现的 CTA 不能让键盘用户失去导航线索。

## 设计契约

- `BentoGrid` 用于强调节奏和横向比较的编辑型功能组，不用于高密度数据扫描。
- 每张卡片只保留一个主动作。如果需要多个动作，应升级为普通 surface 并放置显式控件。
- `background` 插槽只承担视觉氛围，不承载产品关键信息。产品截图不能依赖 hover 才可读。

## 真实产品示例

- 产品总览页把 AI 编排、计费、治理和可观测性能力分组成少量重点卡片。
- 文档首页把读者导向少数高价值组件或模式家族。
- 发布记录或发布页中，每张卡解释一个已交付能力，并链接到更深的证据页面。

## 反模式

- 不要把 `BentoGrid` 用在后台 dashboard、设置页或高密度资源列表；这些场景需要表格、筛选和稳定行结构。
- 不要在卡片里塞入独立表单、菜单或多个 CTA。一个 bento card 应只有一个清晰去向。
- 不要把必要产品文案藏进装饰性 `background` 插槽或悬停才出现的内容里。
