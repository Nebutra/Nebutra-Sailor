## 安装

```tsx
import { DynamicIslandTOC } from "@nebutra/ui/primitives";
```

或通过 shadcn 注册表独立安装：

```bash
npx shadcn@latest add https://ui.nebutra.com/r/dynamic-island-toc.json
```

## 基本用法

把组件放在页面任意位置——它会以 fixed 覆盖层定位到视口底部居中，并自动扫描文档 heading。

```tsx
import { DynamicIslandTOC } from "@nebutra/ui/primitives";

export default function BlogPostPage() {
  return (
    <main>
      <DynamicIslandTOC />
      <article className="prose">
        <h1>文章标题</h1>
        <h2>章节一</h2>
        {/* … */}
      </article>
    </main>
  );
}
```

## Heading 属性

选择器匹配到的任何元素都可以使用三种"逃生窗口"：

| 属性                 | 效果                                                  |
| -------------------- | ----------------------------------------------------- |
| `data-toc-title`     | 覆写 TOC 中显示的文本（长 heading 时尤其有用）        |
| `data-toc-depth="2"` | 强制嵌套层级 —— 让非 heading 元素也能作为 TOC 条目    |
| `data-toc-ignore`    | 从 TOC 隐藏一个原本匹配的元素                         |
| `data-toc`           | 把非 heading 元素标记为 TOC 条目（配合 `data-toc-depth`） |

```tsx
<h2 data-toc-title="SPA 革命">
  从客户端渲染到单页应用的范式转移
</h2>

<div data-toc data-toc-depth="2" data-toc-title="边缘计算时代">
  {/* 非 heading 区块作为 level-2 TOC 条目 */}
</div>

<h2 data-toc-ignore>不出现在 TOC</h2>
```

## Props

| Prop          | 类型     | 默认                            | 说明                                              |
| ------------- | -------- | ------------------------------- | ------------------------------------------------- |
| `selector`    | `string` | (article + .prose + [data-toc]) | 用于扫描 heading 的 CSS 选择器                    |
| `ariaLabel`   | `string` | `"Table of contents"`           | `<nav>` 地标的无障碍标签                          |
| `menuHeading` | `string` | `"TABLE OF CONTENTS"`           | 展开菜单顶部的标题文本                            |
| `emptyLabel`  | `string` | `"Contents"`                    | 还没有激活 heading 时 pill 上显示的文本           |
| `className`   | `string` | —                               | 外层 fixed 容器的附加 class                       |

## 无障碍（a11y）

- 外层容器是 `<nav role aria-label>` 地标
- pill 本体是 `<button aria-expanded>`，键盘可达
- 当前激活菜单项带 `aria-current="location"`
- **Esc** 关闭菜单并把焦点送回 pill
- 展开时焦点自动跳到第一个菜单项
- `prefers-reduced-motion: reduce` 时，形态变化 + spring + 模糊全部塌缩为透明度过渡；滚动行为从 `smooth` 切换为 `auto`

## 动效语言

本组件**有意**承载 Apple Dynamic Island 的签名缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，**不**使用品牌缓动——这是组件视觉 IP 的一部分。但 **时长**仍然走四轨：

| 用途         | 轨道        | 值     |
| ------------ | ----------- | ------ |
| Pill 形态变化 | `cinematic` | 500ms  |
| 背景淡入     | `flow`      | 200ms  |
| Heading 切换 | `reveal`    | 300ms  |
| 进度环更新   | `micro`     | 100ms  |

## 适用场景

适合**长文内容**——博客、文档章节、深嵌套的营销长页——传统侧边栏 TOC 在移动端笨重、桌面端又显得过于商务。浮动 pill 在读者主动召唤前完全隐身。

不要用于：

- 章节少于 4 个的短页面（杀鸡用牛刀）
- 仪表板 / 应用 UI（浮动 pill 会与持久导航打架）
- 移动优先页面的底部 30px 已经被 tab bar 占用时
