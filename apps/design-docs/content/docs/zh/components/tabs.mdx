## 使用方法

```tsx
import { Tabs } from "@nebutra/ui/primitives";
```

```tsx
const [selected, setSelected] = useState("apple");

<Tabs
  aria-label="Fruit views"
  selected={selected}
  setSelected={setSelected}
  tabs={[
    { title: "Apple", value: "apple" },
    { title: "Orange", value: "orange" },
    { title: "Mango", value: "mango" },
  ]}
/>;
```

## 属性

### Tabs

Tabs 基于 Base UI 构建。简单同域视图切换优先使用 `tabs` 数组 API；每个 tab 需要独立内容面板时使用复合 API。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `tabs` | `readonly TabsItem[]` | — | 可选数组 API，用于直接渲染 tab 行。 |
| `selected` | `string` | — | 受控激活值，数组 API 中等价于 `value`。 |
| `setSelected` | `(value: string) => void` | — | 数组 API 的受控 setter；存在 `onValueChange` 时也会调用。 |
| `value` | `string` | — | 复合 API 的受控激活值。 |
| `defaultValue` | `string` | 第一个可用 tab | 非受控初始激活值。 |
| `onValueChange` | `(value: string) => void` | — | 激活 tab 改变时触发。 |
| `variant` | `"default" \| "button" \| "line" \| "secondary"` | `"default"` | 数组 API 与内部列表的视觉样式。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` | 由 Tabs component tokens 驱动的尺寸。 |
| `shape` | `"default" \| "pill"` | `"default"` | 触发器圆角形态。 |
| `activationMode` | `"manual" \| "automatic"` | `"manual"` | manual 表示方向键移动焦点，Enter/Space 才激活。 |
| `disabled` | `boolean` | `false` | 禁用整个 tab 组。 |

### TabsItem

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | 可见 tab 标题。保持 Title Case，控制在一到两个词。 |
| `value` | `string` | — | 唯一 tab 值。 |
| `icon` | `ReactNode` | — | 可选前置图标；纯装饰图标应加 `aria-hidden`。 |
| `badge` | `ReactNode` | — | 可选数量或状态标记。为 0 时移除，不要拼到标题里。 |
| `disabled` | `boolean` | `false` | 仅禁用该 tab。用于权限或暂不可用状态。 |
| `tooltip` | `ReactNode` | — | disabled tab 的约束说明。 |
| `content` | `ReactNode` | — | 可选内容面板，通过 `TabsContent` 渲染。 |

### 复合 API

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@nebutra/ui/primitives";
```

| 组件 | 必填属性 | 说明 |
|-----------|----------------|-------|
| `TabsList` | 没有可见标题时传 `aria-label` | 支持 `variant`、`shape`、`loop`、`activateOnFocus`。 |
| `TabsTrigger` | `value` | 支持 `icon`、`badge` 和原生 button 属性。 |
| `TabsContent` | `value` | 支持 `keepMounted`；`forceMount` 作为兼容别名保留。 |

## 最佳实践

Tabs 用于同一页面内同域兄弟视图切换，例如 Overview、Logs、Settings。无关页面之间的导航应使用子菜单或侧边导航。

桌面端一行控制在 5–7 个，移动端控制在 3–4 个。超过后应合并信息架构，或把次要视图放进 Menu。

切换 tab 应该即时完成。刷新或深链恢复重要时，把激活 tab 同步到 URL；不要在切换时弹 toast 或做确认。

仅在权限或空状态约束下禁用单个 tab。禁用 tab 应配 tooltip 说明约束，例如 “Only visible to project owners.”

Tab 标题使用 Title Case 名词，一到两个词。不要把数量拼进标题；使用 `badge` 插槽，数量为 0 时移除。

## 可访问性

Tabs 通过 Base UI 渲染 WAI-ARIA tablist/tab/tabpanel 语义。

默认是 manual activation：Left/Right 移动焦点，Enter/Space 激活。仅当所有面板都已挂载、切换几乎零成本时，才使用 `activationMode="automatic"`。

当上方没有可见标题时，为 `TabsList` 或数组模式 `Tabs` 提供稳定的 `aria-label`。

保留可见焦点环。不要为了视觉干净而压掉 active tab 的焦点样式。
