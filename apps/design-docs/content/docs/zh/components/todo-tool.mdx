## 安装

```tsx
import { TodoTool, type TodoItem } from "@nebutra/ui/primitives";
```

```bash
npx shadcn@latest add https://ui.nebutra.com/r/todo-tool.json
```

## 用法

`TodoTool` 在 assistant 调用 TodoWrite 工具时渲染 chat-inline checklist。状态枚举 `pending` / `in_progress` / `completed` 直接镜像工具 wire format。

```tsx
const todos: TodoItem[] = [
  { content: "Audit components", status: "completed" },
  { content: "Tighten spacing", status: "in_progress" },
  { content: "Ship updates", status: "pending" },
];

<TodoTool todos={todos} />
```

## 与 AgentPlan 的关系

| Primitive | Surface |
| --- | --- |
| `TodoTool` | Chat-inline、扁平、只读、轻量。状态枚举使用 `in_progress`。 |
| `AgentPlan` | Dashboard / planning page，层级化、可交互、带 motion。状态枚举使用 `in-progress`。 |

两个组件不要强行统一。一个镜像工具 wire format，另一个服务 dashboard 规划界面。

## 状态模型

| 状态 | 渲染 |
| --- | --- |
| `loading` | shimmer header，只显示创建/更新中 |
| `ready` | 渲染列表；空数组返回 `null` |

## 可访问性

- 容器是 `<ol aria-label="To-dos">`。
- 当前进行项使用 `aria-current="step"`。
- 完成项使用 `<s>`，同时提供视觉和语义删除线。

## 设计契约

- `TodoTool` 只用于 chat-inline TodoWrite 状态。交互式计划管理属于 `AgentPlan`。
- 保留上游 `in_progress` wire enum，不在这个 primitive 内转换成 dashboard status。
- ready 态空数组渲染为 `null`，避免聊天流出现装饰性空壳。
