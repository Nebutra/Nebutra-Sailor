## Resend 配置

<Steps>
  <Step title="创建 Resend 账户">
    在 [resend.com](https://resend.com) 注册账户。免费套餐每月最多发送 3,000 封、每天最多 100 封 — 足以满足开发和早期生产需求。
  </Step>

  <Step title="添加并验证发件域名">
    前往 **Resend 控制台 → 域名 → 添加域名**。

    输入你的域名（如 `mail.nebutra.com`），Resend 将提供需要添加的 DNS 记录：

    | 类型 | 名称 | 值 |
    |------|-----|---|
    | MX | `mail.nebutra.com` | `feedback-smtp.us-east-1.amazonses.com` |
    | TXT | `mail.nebutra.com` | `v=spf1 include:amazonses.com ~all` |
    | TXT | `resend._domainkey.mail.nebutra.com` | DKIM 公钥 |

    在你的 DNS 提供商（Cloudflare、Route 53 等）中添加这些记录，然后在 Resend 控制台点击**验证**。传播通常只需几分钟。

    <Tip>
      使用子域名（如 `mail.nebutra.com`）而非根域名。这样可以将邮件信誉与主域名隔离，SPF/DKIM 记录管理也更为简便。
    </Tip>
  </Step>

  <Step title="创建 API 密钥">
    前往 **Resend 控制台 → API 密钥 → 创建 API 密钥**。

    - **名称：** `nebutra-production`（或 `nebutra-staging`）
    - **权限：** 发送权限
    - **域名：** 限定到已验证的域名

    复制密钥 — 它只会显示一次。
  </Step>

  <Step title="设置环境变量">
    将以下内容添加到 Vercel 项目环境变量（或本地开发的 `.env.local`）：

    ```env
    RESEND_API_KEY=re_...
    EMAIL_FROM=Nebutra <noreply@mail.nebutra.com>
    ```

    将 `noreply@mail.nebutra.com` 替换为已验证域名下的地址。
  </Step>

  <Step title="测试集成">
    先运行本地预览服务器验证模板渲染正确，再发送真实邮件：

    ```bash
    pnpm --filter @nebutra/email dev
    ```

    然后使用 Resend 测试 API 密钥（以 `re_test_` 开头）发送测试邮件。详情请参阅[测试](/email/testing)。
  </Step>
</Steps>

## Resend 测试 API 密钥

Resend 提供测试 API 密钥（`re_test_...`），可接受 API 调用但不向真实收件箱投递邮件。使用测试密钥发送的邮件会出现在 Resend 控制台**日志**中，并带有 `test` 标识。

```env
# .env.local — 仅限开发环境
RESEND_API_KEY=re_test_...
EMAIL_FROM=Nebutra <noreply@mail.nebutra.com>
```

<Warning>
不要在生产环境使用测试 API 密钥。测试邮件不会投递给收件人。
</Warning>

## 域名验证故障排查

| 现象 | 可能原因 | 解决方法 |
|-----|---------|---------|
| 10 分钟后域名仍显示"未验证" | DNS 记录尚未传播 | 等待最长 48 小时；用 `dig TXT mail.nebutra.com` 检查 |
| 邮件进入垃圾邮件 | 缺少 DMARC 记录 | 添加 `TXT _dmarc.mail.nebutra.com "v=DMARC1; p=none; rua=mailto:dmarc@nebutra.com"` |
| 退信 `550 5.7.26` | SPF 记录缺失或错误 | 确保 SPF 记录中包含 `include:amazonses.com` |
| DKIM 验证失败 | 同一选择器存在多条 DKIM 记录 | 删除重复的 `resend._domainkey` TXT 记录 |

## Resend 事件 Webhook

Resend 可以将投递事件（已投递、退信、投诉）POST 到你的应用。在 Resend 控制台注册 Webhook 端点：

```typescript
// app/api/webhooks/resend/route.ts
import { Webhook } from "svix";

export async function POST(request: Request) {
  const payload = await request.text();
  const headers = Object.fromEntries(request.headers);

  const wh = new Webhook(process.env.RESEND_WEBHOOK_SECRET!);
  const event = wh.verify(payload, headers) as ResendWebhookEvent;

  if (event.type === "email.bounced") {
    // 在数据库中标记该地址为退信
    await db.user.update({
      where: { email: event.data.to },
      data: { emailBounced: true },
    });
  }

  return new Response(null, { status: 200 });
}
```
