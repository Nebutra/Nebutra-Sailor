## 认证提供商

Nebutra 支持两个认证提供商，通过单个环境变量切换：

| 提供商 | 最适合 | 说明 |
|--------|--------|------|
| **Clerk** | 生产环境——托管认证含 UI 组件 | 默认。托管仪表板、MFA、社交登录 |
| **Better Auth** | 自托管或合规敏感部署 | 开源，运行在你的基础设施中 |

```bash
AUTH_PROVIDER=clerk       # 或 "better-auth"
```

## Clerk 配置

### 1. 安装 Clerk

```bash
pnpm add @clerk/nextjs
```

### 2. 添加环境变量

```bash
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_live_xxxxxxxxxxxx
CLERK_SECRET_KEY=sk_live_xxxxxxxxxxxx
CLERK_WEBHOOK_SECRET=whsec_xxxxxxxxxxxx
```

### 3. 包裹应用

```tsx app/layout.tsx
import { ClerkProvider } from "@clerk/nextjs";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <ClerkProvider>
      <html lang="zh">
        <body>{children}</body>
      </html>
    </ClerkProvider>
  );
}
```

### 4. 添加认证代理

```typescript proxy.ts
import { clerkMiddleware, createRouteMatcher } from "@clerk/nextjs/server";

const isPublicRoute = createRouteMatcher(["/", "/sign-in(.*)", "/sign-up(.*)"]);

export default clerkMiddleware(async (auth, req) => {
  if (!isPublicRoute(req)) {
    await auth.protect();
  }
});
```

### 5. 在 Server Components 中读取认证信息

```typescript
import { auth, currentUser } from "@clerk/nextjs/server";

export default async function DashboardPage() {
  const { orgId } = await auth();
  const user = await currentUser();

  if (!orgId) redirect("/create-org");

  return <Dashboard userId={user?.id} orgId={orgId} />;
}
```

## JWT 声明内容

每个经过验证的令牌包含：

```json
{
  "sub": "user_2a8bXXXXXXXXX",
  "org_id": "org_2a8bXXXXXXXXX",
  "org_role": "org:admin",
  "scopes": ["project:read", "project:create"],
  "plan": "pro"
}
```

## 组织创建流程

注册后没有组织的用户会被重定向到组织创建流程：

```typescript app/create-org/page.tsx
import { CreateOrganization } from "@clerk/nextjs";

export default function CreateOrgPage() {
  return <CreateOrganization afterCreateOrganizationUrl="/dashboard" />;
}
```

<Warning>
  没有此页面，注册的用户将在 `auth()` 返回 `{ orgId: null }` 时被无限重定向回登录页。请务必实现组织创建流程。
</Warning>
