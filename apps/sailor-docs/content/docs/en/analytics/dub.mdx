Dub.co is Nebutra's link management and marketing analytics layer. It handles everything that happens **before** a user reaches the product: branded short URLs, UTM tracking, and click-through analytics.

## What Dub.co Provides

- **Branded short links** — `links.nebutra.com/welcome`, `links.nebutra.com/upgrade-pro`
- **UTM management** — source, medium, campaign, term, and content parameters on every link
- **Click analytics** — clicks, unique visitors, referrers, devices, and countries per link
- **Campaign grouping** — group links by campaign for aggregate reporting
- **QR codes** — auto-generated for each short link

## Setup

<Steps>
  <Step title="Create a Dub.co account">
    Sign up at [dub.co](https://dub.co) and create a workspace for your Nebutra project.
  </Step>
  <Step title="Add your custom domain">
    In the Dub.co workspace settings, add your branded link domain (e.g. `links.nebutra.com`). Follow Dub.co's DNS instructions to configure the CNAME record.
  </Step>
  <Step title="Generate an API key">
    Go to **Workspace Settings** → **API Keys** → **Create API Key**. Copy the key — it starts with `dub_`.
  </Step>
  <Step title="Set the environment variable">
    Add the key to your server-side environment (never expose it client-side):

    ```bash
    DUB_API_KEY=dub_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
    ```
  </Step>
  <Step title="Verify the connection">
    Create a test link with the client to confirm authentication — there is no separate
    `workspaces.list()` verification call:

    ```typescript
    import { createAnalyticsClient } from "@nebutra/analytics";

    const analytics = createAnalyticsClient({ apiKey: process.env.DUB_API_KEY! });
    const link = await analytics.links.create({ url: "https://nebutra.com" });
    console.log(link);
    ```
  </Step>
</Steps>

## Creating Tracked Links

There is no standalone `dub` export from `@nebutra/analytics` — the client is `AnalyticsClient`
(`createAnalyticsClient(config)` / the `analytics` singleton), wrapping the `dub` npm SDK
internally under `AnalyticsClient["dub"]` (a private field). UTM parameters go under a nested
`utm` object, not individual `utm_source` / `utm_medium` top-level fields:

```typescript
import { createAnalyticsClient } from "@nebutra/analytics";

const analytics = createAnalyticsClient({ apiKey: process.env.DUB_API_KEY! });

// Welcome email link
const welcomeLink = await analytics.links.create({
  url: "https://app.nebutra.com/dashboard",
  domain: "links.nebutra.com",
  key: "welcome",
  utm: { source: "email", medium: "transactional", campaign: "onboarding" },
});

// Upgrade nudge in-app banner
const upgradeLink = await analytics.links.create({
  url: "https://app.nebutra.com/settings/billing",
  domain: "links.nebutra.com",
  utm: { source: "app", medium: "banner", campaign: "upgrade-pro", content: "quota-warning-banner" },
});

console.log(welcomeLink.shortLink); // → https://links.nebutra.com/welcome
```

## UTM Parameter Conventions

Nebutra uses a consistent UTM taxonomy across all campaigns. Adhere to these conventions so PostHog attribution stays clean:

| Parameter | Values | Examples |
|-----------|--------|---------|
| `utm_source` | Origin of traffic | `email`, `app`, `twitter`, `linkedin`, `google` |
| `utm_medium` | Channel type | `transactional`, `newsletter`, `cpc`, `banner`, `social` |
| `utm_campaign` | Campaign slug (kebab-case) | `onboarding`, `upgrade-pro`, `launch-v2` |
| `utm_content` | Specific element (optional) | `cta-button`, `quota-warning-banner`, `hero-headline` |
| `utm_term` | Paid search keyword (optional) | `saas-analytics-tool` |

<Note>
Always use lowercase kebab-case for all UTM values. Mixed case causes duplicate attribution entries in PostHog.
</Note>

## Common Link Patterns

### Transactional Emails

Every transactional email CTA should use a tracked link:

```typescript
import { analytics } from "@nebutra/analytics";

async function sendWelcomeEmail(user: User) {
  const ctaLink = await analytics.links.create({
    url: `https://app.nebutra.com/onboarding?userId=${user.id}`,
    domain: "links.nebutra.com",
    utm: { source: "email", medium: "transactional", campaign: "onboarding", content: "welcome-email-cta" },
  });

  await sendEmail({
    to: user.email,
    subject: "Welcome to Nebutra",
    cta: { label: "Get started", href: ctaLink.shortLink },
  });
}
```

### In-App Referral Links

Use the dedicated `referrals.createLink` helper rather than `links.create` directly — it fills in
the destination URL and tags for you:

```typescript
import { analytics } from "@nebutra/analytics";

async function generateReferralLink(userId: string, tenantId: string, rewardType: string, rewardValue: number) {
  return analytics.referrals.createLink({
    userId,
    tenantId,
    rewardType,
    rewardValue,
  });
}
```

### Marketing Campaigns

For paid campaigns, create links in bulk via the Dub.co dashboard or `links.createMany`:

```typescript
import { analytics } from "@nebutra/analytics";

const variants = ["headline-a", "headline-b", "headline-c"];

const links = await analytics.links.createMany(
  variants.map((variant) => ({
    url: "https://nebutra.com/landing/paid",
    domain: "links.nebutra.com",
    utm: { source: "google", medium: "cpc", campaign: "q1-acquisition", content: variant },
    tags: ["paid", "q1-acquisition"],
  }))
);
```

## Viewing Analytics

Link analytics are available in the Dub.co dashboard at [app.dub.co](https://app.dub.co):

- **Link analytics** — clicks over time, referrers, countries, devices per link
- **Campaign analytics** — aggregate metrics per tag/campaign
- **Top links** — ranked by click volume

<Note>
  There is no `/admin/analytics` route in the codebase today for surfacing this in-app. Use
  `analytics.getAnalytics()` (below) to embed metrics programmatically into your own admin view if
  you build one.
</Note>

## Retrieving Link Stats via API

`AnalyticsClient`'s method is `getAnalytics`, not `analytics.retrieve` on a raw `dub` client:

```typescript
import { analytics } from "@nebutra/analytics";

const stats = await analytics.getAnalytics({
  linkId: welcomeLink.id,
  interval: "30d",
  groupBy: "referrer",
});

// stats.clicks → total clicks
// stats.groupedData → breakdown by referrer
```
