## There is no Python SDK

No `nebutra-sdk` package is published to PyPI, and none ships in Nebutra-Sailor. Per
[ADR 2026-05-10, TS-by-Default](/architecture/backend-language-policy), new backend work — including
API clients — defaults to TypeScript in `backends/gateway`; Python is reserved for batch, ML, or
specialized-library work with no comparable TS port.

If a justified Python service needs to talk to your project, call the gateway's REST API directly
— it's documented via OpenAPI at `/docs` and `/openapi.json` on your gateway host — and
authenticate with the shared `SERVICE_SECRET` (see [Python Quickstart](/quickstart/python)).
