## Architecture

Customization follows a strictly unidirectional token flow. Changes at a lower layer automatically propagate upward.

```
@nebutra/tokens   ← Edit CSS variables here to rebrand
      ↓
@nebutra/ui       ← Components consume tokens; add new components here
      ↓
apps/web          ← Dashboard pages compose components
apps/landing-page ← Marketing site composes components
```

Because every color and spacing value in `@nebutra/ui` is a CSS variable reference (never a hardcoded hex), updating `packages/tokens/styles.css` — or running the palette script — cascades through the entire product.

## Quick wins (under 5 minutes)

### Change the brand color

```bash
# Swap blue → purple, cyan → amber in one command
node scripts/generate-palette.mjs --primary=#7C3AED --secondary=#F59E0B
```

The script rewrites `packages/tokens/styles.css` and all downstream token aliases. Restart the dev server to see the change.

### Switch the active theme preset

```tsx
// apps/web/src/app/layout.tsx
<html data-theme="neon">   {/* default | neon | gradient | dark-dense | minimal | vibrant */}
```

### Toggle dark mode

```tsx
import { useTheme } from "@nebutra/tokens";

const { theme, setTheme } = useTheme();
setTheme("dark"); // "light" | "dark" | "system"
```

## Advanced customization

| Goal | Where to start |
|------|---------------|
| New multi-theme preset | `packages/theme/themes.css` |
| New UI primitive | `packages/ui/src/components/` + Storybook story |
| New dashboard section | `apps/web/src/app/(dashboard)/[section]/page.tsx` |
| Modify onboarding steps | `apps/web/src/app/(onboarding)/` |
| Rewrite the palette generator | `scripts/generate-palette.mjs` |

## Token architecture at a glance

All runtime CSS variables are defined in a single file: `packages/tokens/styles.css`. This is the **single source of truth** — never hardcode hex values anywhere else in the codebase.

```css
/* packages/tokens/styles.css — excerpt */
:root {
  --brand-primary:   var(--blue-9);     /* #0033FE */
  --brand-accent:    var(--cyan-9);     /* #0BF1C3 */
  --brand-gradient:  135deg, var(--blue-9) 0%, var(--cyan-9) 100%;

  --neutral-1:  #ffffff;
  --neutral-12: #0a0a0a;
}
```
