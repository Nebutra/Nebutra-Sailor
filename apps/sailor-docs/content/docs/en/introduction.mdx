# Welcome to Nebutra

<Info>
  **OPC Free License available.** Join the Sleptons community and get early access to upcoming features.
  [Get your free license →](https://nebutra.com/en/get-license)
</Info>

Nebutra-Sailor is a self-hosted SaaS **monorepo template** for AI-native products, scaffolded with
one command (`npx create-sailor`) and run on your own infrastructure. It ships everything a modern
B2B SaaS needs — multi-tenant auth, role-based access control, billing, transactional email, an AI
gateway, and observability — wired together and ready to `pnpm dev` with an empty `.env`.

There is no hosted Nebutra API, no per-customer API key, and no `@nebutra/sdk` package: the code you
get from `create-sailor` **is** your product's backend. You call it the way you'd call any code in
your own repo — through the `backends/gateway` Hono REST API it ships, or directly from the
`@nebutra/*` packages in your app.

Stop spending your first 6 months building infrastructure. Start on day one with what matters: your
product.

## What Nebutra gives you out of the box

<AccordionGroup>
  <Accordion title="Multi-Tenant Authentication" icon="shield-check">
    **Better Auth** — the only auth provider, with organization membership roles. Production uses a dedicated auth center at `auth.nebutra.com` plus shared cookies on `.nebutra.com`. Includes org creation, member invites, and session management.
  </Accordion>
  <Accordion title="Role-Based Access Control (RBAC)" icon="lock">
    17 typed permission scopes across 4 built-in roles: `OWNER`, `ADMIN`, `MEMBER`, and `VIEWER`. Extend the matrix without touching your product logic. CASL in-process for millisecond checks.
  </Accordion>
  <Accordion title="Billing & Subscriptions" icon="credit-card">
    Creem-powered card payments (worldwide, merchant of record) plus WeChat Pay/Alipay for mainland China, with FREE, PRO, and ENTERPRISE tiers pre-wired. Consumption-based metering via ClickHouse aggregation. Usage quotas enforced at the API gateway layer — no application code required.
  </Accordion>
  <Accordion title="AI Gateway" icon="brain">
    The `backends/gateway` `/api/v1/ai` routes proxy your chosen model provider — authenticated, rate-limited, and tenant-scoped. Governed by `nebutra ai provider` / `nebutra ai gateway`.
  </Accordion>
  <Accordion title="Transactional Email" icon="envelope">
    Resend-powered email with ready-made templates for welcome, API key creation, quota warnings, and team invitations. React Email components you can customize in minutes.
  </Accordion>
  <Accordion title="Observability" icon="chart-bar">
    30-day funnel and revenue charts. Sentry error tracking with tenant context. Structured logging via `@nebutra/logger`.
  </Accordion>
</AccordionGroup>

## Platform

Nebutra-Sailor is a [Turborepo](https://turbo.build) monorepo. `backends/gateway` — the sole
business API; see [Architecture](/concepts/architecture) — runs on
[Hono](https://hono.dev) with OpenAPI, mounted in-process inside `apps/web` at
`app/api/[[...route]]` by default (`GATEWAY_MODE=embedded`) or standalone
(`GATEWAY_MODE=external`). The frontend apps run on Next.js 16 with Tailwind v4.

A default scaffold includes:

| App | Description |
|-----|-------------|
| `web` | The authenticated dashboard (Next.js 16), with the gateway mounted at `/api/[[...route]]` |
| `landing` | The public marketing site |
| `auth` | The Better Auth login center |
| `mail-preview` | Local preview server for transactional email templates |
| `backends/gateway` | The Hono REST API — the only place business endpoints belong |
| `sailor-docs` | This documentation site (Fumadocs) |

Nebutra's own instance additionally runs `studio` (Sanity CMS) and `storybook` (component
playground) — neither ships in the default scaffold.
