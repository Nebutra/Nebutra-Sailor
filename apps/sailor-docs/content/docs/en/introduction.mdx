# Welcome to Nebutra

<Info>

Nebutra is a production-ready SaaS scaffold for AI-native products. It ships everything a modern B2B SaaS needs — multi-tenant auth, role-based access control, billing, transactional email, AI service proxies, feature flags, and observability — wired together in a single monorepo.

Stop spending your first 6 months building infrastructure. Start on day one with what matters: your product.

## What Nebutra gives you out of the box

<AccordionGroup>
  <Accordion title="Multi-Tenant Authentication" icon="shield-check">
    **Better Auth by default** (switchable to Clerk / Auth.js / Supabase Auth) with organization membership roles. Production uses a dedicated auth center at `auth.nebutra.com` plus shared cookies on `.nebutra.com`. Includes org creation, member invites, and session management.
  </Accordion>
  <Accordion title="Role-Based Access Control (RBAC)" icon="lock">
    17 typed permission scopes across 4 built-in roles: `OWNER`, `ADMIN`, `MEMBER`, and `VIEWER`. Extend the matrix without touching your product logic. CASL in-process for millisecond checks, OpenFGA for Zanzibar-scale policy evaluation.
  </Accordion>
  <Accordion title="Billing & Subscriptions" icon="credit-card">
    Stripe-powered billing with FREE, PRO, and ENTERPRISE tiers pre-wired. Consumption-based metering via ClickHouse aggregation. Usage quotas enforced at the API gateway layer — no application code required.
  </Accordion>
  <Accordion title="AI Service Proxy" icon="brain">
    Pre-built routes for `/api/v1/ai/chat`, `/embeddings`, and `/models`. Authenticated, rate-limited, and tenant-scoped. Drop in any model provider without touching your frontend.
  </Accordion>
  <Accordion title="Transactional Email" icon="envelope">
    Resend-powered email with ready-made templates for welcome, API key creation, quota warnings, and team invitations. React Email components you can customize in minutes.
  </Accordion>
  <Accordion title="Feature Flags" icon="flag">
    SSR-safe feature flag hooks with tenant context. Ship features to specific org plans or individual tenants without a deploy.
  </Accordion>
  <Accordion title="Observability" icon="chart-bar">
    30-day funnel and revenue charts. Sentry error tracking with tenant context. Structured logging via `@nebutra/logger`. Zero-config on Vercel.
  </Accordion>
</AccordionGroup>

## Platform

Nebutra is a [Turborepo](https://turbo.build) monorepo with 33 packages and 7 apps. The API gateway runs on [Hono](https://hono.dev) with OpenAPI. The frontend apps run on Next.js 16 with Tailwind v4.

| App | Description |
|-----|-------------|
| `landing` | Public marketing site at `nebutra.com` (Vercel) |
| `web` | Authenticated dashboard at `app.nebutra.com` (ECS Next; Vercel optional) |
| `auth` | Login center at `auth.nebutra.com` (Better Auth; ECS; Vercel optional) |
| `backends/gateway` | Hono REST API at `api.nebutra.com` (package `@nebutra/gateway`, ECS / Workers) |
| `studio` | Sanity CMS at `studio.nebutra.com` |
| `sailor-docs` | Public product documentation at `docs.nebutra.com` (Vercel) |
| `design-docs` | Internal design system docs |
| `storybook` | Component library playground |
