## What's included

Nebutra ships AI features out of the box via `@nebutra/agents`, a thin wrapper around the [Vercel AI SDK](https://sdk.vercel.ai/) that adds tenant context, rate limiting, and usage metering automatically.

The following capabilities are available to every tenant:

| Feature | Description | Plan entitlement |
|---------|-------------|--------------|
| **Chat completions** | Streaming and non-streaming LLM responses | `ai.chat` |
| **Embeddings** | Vector representations for semantic search and RAG | `ai.embeddings` |
| **Image analysis / generation** | Vision-capable model support and image generation | `ai.images` |
| **Reasoning** | Extended-reasoning model calls | `ai.reasoning` |

## Architecture

Requests flow through the API gateway, which applies auth, rate limiting, and metering before proxying to the underlying model provider:

```
Client App
    │
    ▼
POST /api/v1/ai/chat/completions   (API Gateway — Hono)
    │
    ├─ Auth check (API key)
    ├─ Feature flag check (ai.chat)
    ├─ Rate limit (per tenant, @nebutra/rate-limit)
    │
    ▼
@nebutra/agents               (Vercel AI SDK v6 wrapper)
    │
    ├─ OpenAI  (default)
    └─ OpenRouter  (multi-model: Claude, Llama, Mistral…)
    │
    ▼
Response / SSE stream
    │
    ▼
@nebutra/metering             (tokens consumed → billing)
    │
    ▼
pgvector (embeddings only)    (PostgreSQL vector storage)
```

## Plan entitlements

AI features are gated by plan, not by a standalone feature-flag toggle. `ai.chat`, `ai.embeddings`,
`ai.images`, and `ai.reasoning` are entries in `PLAN_FEATURES` (`@nebutra/billing`
`entitlements/service.ts`) — which plans include a given feature is data on that table, not a
per-tenant switch. The API gateway checks entitlement (and, where the feature maps to a metered
resource, remaining quota) before any model call is made — no tokens are consumed if the check
fails:

```typescript backends/gateway/src/middlewares/entitlements.ts
app.post("/api/v1/ai/generate", requireFeature("ai.images", 1), handler);
```

See [Paywall](/payments/paywall) for the full entitlement-checking API
(`checkEntitlement`, `requireEntitlement`, `requireFeature`, `isPlanFeature`).

## Environment variables

Add these to your `.env` (or Vercel environment variables):

```bash
# Required: at least one provider key
OPENAI_API_KEY=""

# Optional: enables multi-model routing via OpenRouter
OPENROUTER_API_KEY=""
```

There is no `AI_DEFAULT_MODEL` / `AI_EMBEDDING_MODEL` env var. The default chat model is set by
calling `configure({ defaultModel: "…" })` once at startup (`@nebutra/agents`'s
`NebutraAIConfigSchema` defaults `defaultModel` to `models.flagship`); the default embedding model
is fixed to the `"embedding"` preset alias unless a call passes its own `model`.

<Warning>
Never expose `OPENAI_API_KEY` or `OPENROUTER_API_KEY` to the client. All model calls must go through the API gateway.
</Warning>

## Usage and quotas

Token consumption is automatically metered via `@nebutra/metering` and counts against the tenant's API quota. You can inspect current usage from code or the dashboard:

```typescript
import { getMetering, COMMON_METERS } from "@nebutra/metering";

const metering = await getMetering();
const quota = await metering.getQuota("org_123", "ai_tokens");
// → { limit: 5000000, used: 1243000, remaining: 3757000, percentage: 0.249 }
```

Quota limits by plan:

| Plan | AI tokens / month |
|------|------------------|
| FREE | 100,000 |
| PRO | 5,000,000 |
| ENTERPRISE | Custom |

## Quick usage example

`generateText`, `streamText`, and `embed` take the messages/value as the first positional
argument, and an options object second — not one combined object:

```typescript
import { streamText, generateText, embed } from "@nebutra/agents";

// Streaming chat (SSE)
const result = await streamText(
  [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: userMessage },
  ],
  { model: "gpt-5.5" },
);

// Non-streaming
const { text } = await generateText(
  [{ role: "user", content: "Summarize: " + content }],
  { model: "gpt-5.4-mini" },
);

// Embeddings — preset alias "embedding" by default
const embedding = await embed("text to embed", { model: "text-embedding-3-small" });
```
