---
title: pnpm Scripts Reference
description: Complete reference for all Turborepo-orchestrated pnpm scripts in Nebutra-Sailor.
---

All scripts are orchestrated by [Turborepo](https://turbo.build/repo) and run from the monorepo root unless otherwise noted.

```bash
# Run any script from the monorepo root
pnpm <script>

# Run a script for a specific package
pnpm --filter @nebutra/ui typecheck
pnpm --filter apps/web dev
```

## Development

| Script | Description |
|--------|-------------|
| `pnpm dev` | Zero-key preview (`scripts/dev/preview.ts`): local PGlite database, demo sign-in `admin@example.com` / `preview-demo`, site on `:3000`, product app on `:3001` (falls back a thousand ports on conflict) |
| `pnpm dev:all` | `turbo run dev` across every app — the "start everything" version |
| `pnpm dev:web` | Just the product app (`@nebutra/web`) |
| `pnpm dev:landing` | Just the marketing site |
| `pnpm dev:api` | Just the gateway, standalone |
| `pnpm dev:auth` | Just the Better Auth login center |
| `pnpm dev:storybook` / `pnpm dev:docs` | Component playground / this docs site |

<Note>
  `dev:dashboard`, `dev:ai-saas`, `dev:marketing`, and similar preset filters exist in this
  monorepo's own `package.json` (they target apps like `@nebutra/admin` and `@nebutra/blog`), but
  those apps are Nebutra's own product and aren't part of the default `create-sailor` scaffold —
  don't expect them in a fresh project.
</Note>

## Database

| Script | Description |
|--------|-------------|
| `pnpm db:deploy` | **The deploy command.** Migrations, then `platform.sql` + generated RLS, then verifies. |
| `pnpm db:check` | Read-only drift check — the other half of `db:deploy` |
| `pnpm db:generate` | Regenerate Prisma client (and `generated/rls.sql`) |
| `pnpm db:migrate` | Create and apply a migration (local development) |
| `pnpm db:push` | Push schema without a migration file (local prototyping only) |
| `pnpm db:studio` | Launch Prisma Studio GUI |

## Useful combos

```bash
# Fresh start (full reset)
pnpm infra:down
pnpm infra:up
pnpm db:migrate

# Before a commit
pnpm typecheck && pnpm lint && pnpm test

# After pulling changes
pnpm install
pnpm db:generate
pnpm db:migrate

# Storybook development
pnpm --filter @nebutra/storybook dev

# Production readiness check
pnpm build && pnpm test && pnpm e2e
```

## Filter syntax

Use `--filter` to target specific apps or packages:

```bash
# By package name
pnpm --filter @nebutra/ui typecheck
pnpm --filter @nebutra/billing test

# By app name (without @)
pnpm --filter landing dev
pnpm --filter web build

# Multiple filters
pnpm --filter @nebutra/ui --filter @nebutra/tokens build

# Run script in all packages
pnpm -r typecheck
```

## Turborepo caching

Turborepo caches task outputs locally and (optionally) remotely. Cache hits are shown with `cache hit, replaying output`.

```bash
# Force re-run, bypass cache
pnpm build --force

# Remote caching (requires Vercel account)
pnpm dlx turbo login
pnpm dlx turbo link
```
