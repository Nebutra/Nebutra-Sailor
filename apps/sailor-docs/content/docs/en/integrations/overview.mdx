<Note>
There is no Supabase integration. Per ADR 2026-09-25 (database convergence), Postgres via Prisma
is the one database source — `packages/platform/db/`, with RLS generated from `schema.prisma`
`@rls` annotations, not a Supabase-specific adapter. Point `DATABASE_URL` at any Postgres instance,
including a Supabase-hosted one, but Nebutra does not use Supabase's own client, auth, or RLS
tooling.
</Note>

## Built-in vs configurable

Some integrations are pre-wired and active by default. Others require API keys to activate.

| Integration | Status | Notes |
|-------------|--------|-------|
| Vercel | Optional deploy target | Not the default — the template produces portable Docker/`standalone` output; deploy it wherever you want, Vercel included |
| Resend | Active when `RESEND_API_KEY` is set | Email templates ready |
| Creem | Active when `CREEM_API_KEY` and `CREEM_PRODUCT_ID` are set | Current card rail, merchant of record; webhooks pre-configured |
| Stripe | Active when `STRIPE_SECRET_KEY` is set | Legacy — subscriptions, billing portal, pre-switch checkouts only |
| Sentry | Active when `SENTRY_DSN` is set | Tenant context auto-tagged |
| Sanity | Active when `SANITY_API_TOKEN` is set | Studio at studio.nebutra.com |
| Slack | Requires OAuth setup | Via Settings → Integrations |
| GitHub | Requires OAuth setup | Via Settings → Integrations |
| Linear | Requires API key | Via Settings → Integrations |
| Database (Postgres) | Active when `DATABASE_URL` is set | Prisma + generated RLS — not Supabase-specific |

## Adding a new integration

There is no `@nebutra/integrations` package and no `defineIntegration` helper — `packages/integrations/`
is a category directory (email, storage, queue, search, webhooks, …), each a normal standalone
package, not entries in a shared integration registry. Nebutra's own outbound-event delivery to a
third party runs through [`@nebutra/webhooks`](/guides/webhooks) (signing, retries, replay
protection) — build a new integration as its own package under `packages/integrations/<name>/`, or
as an outbound webhook subscriber if it only needs to react to Nebutra events.
