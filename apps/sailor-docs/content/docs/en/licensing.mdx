## What is covered

| Surface | Licence |
| --- | --- |
| The Nebutra-Sailor repository | Apache-2.0, with a root `NOTICE` |
| Every npm package — `@nebutra/*`, `nebutra`, `create-sailor` | Apache-2.0 |
| The `Nebutra/Sailor-Template` mirror | Apache-2.0 + `NOTICE` |
| Every project `create-sailor` generates | Apache-2.0 `LICENSE` + `NOTICE` — the code is yours |

## What is free

Everything: commercial and closed-source products, client work, internal use, and hosted or
competing platforms. There is no fee, no licence key, no registration and no copyleft.

## What Apache-2.0 asks

Only when you **redistribute** Sailor's source or a derivative of it:

- include a copy of the licence;
- keep the copyright and attribution notices, and carry the `NOTICE` file;
- mark the files you changed.

Running a hosted product built on Sailor is not redistributing its source. Generated projects
already contain the `LICENSE` and `NOTICE` files.

## Trademarks

Apache-2.0 grants no trademark rights (section 6). Rebranding Sailor under your own, unrelated
name needs no permission; using the Nebutra or Sailor names for your product does. See the
[trademark policy](https://github.com/Nebutra/Nebutra-Sailor/blob/main/TRADEMARK.md).

## Paid plans

Paid plans sell support, never permission: a private channel and response guarantees (Team), and
SLAs, indemnification, a DPA, a compliance pack, an LTS branch and a trademark licence
(Enterprise). See [nebutra.com/licensing](https://nebutra.com/licensing) and the full
[Commercial Support terms](https://github.com/Nebutra/Nebutra-Sailor/blob/main/docs/legal/commercial-support.md).

## Earlier versions

Versions released before 2026-10-16 keep the licence they shipped with (FSL-1.1-ALv2 for the
repository, MIT for npm packages). See the
[License History](https://github.com/Nebutra/Nebutra-Sailor/blob/main/docs/legal/license-history.md).
