## Directory tree

```
nebutra-sailor/
├── apps/
│   ├── landing-page/     Next.js 16 — public marketing site (7 locales, port 3002)
│   ├── web/              Next.js 16 — authenticated SaaS dashboard (port 3000)
│   ├── api-gateway/      Hono + OpenAPI — REST API backend (port 3001)
│   ├── storybook/        Storybook 8.x — component library docs (port 6006)
│   ├── design-docs/      Fumadocs — internal design system docs (port 3004)
│   ├── studio/           Sanity Studio v5 — CMS (port 3333)
│   └── docs/             Mintlify — public product docs (this site)
│
├── packages/
│   ├── ui/               PRIMARY component library (Radix + HeroUI + Lobe UI)
│   ├── tokens/           Runtime CSS design tokens + ThemeProvider
│   ├── icons/            541 Geist icons as tree-shakable TSX components
│   ├── brand/            Brand colors, gradients, and motion language
│   ├── theme/            CSS-only multi-theme engine (6 oklch themes)
│   ├── preset/           Feature-based SaaS starter config system
│   ├── db/               Prisma v7 schema, migrations, and client
│   ├── identity/         Auth adapters (Clerk / Better Auth)
│   ├── billing/          Stripe billing, webhooks, and quota gates
│   ├── email/            Transactional email (Resend + React Email)
│   ├── ai-sdk/           AI service proxy helpers and model routing
│   ├── permissions/      RBAC/ABAC — CASL (in-process) + OpenFGA
│   ├── webhooks/         Outbound webhook delivery — Svix + custom
│   ├── metering/         Usage metering pipeline — ClickHouse
│   ├── queue/            Message queue — QStash (serverless) + BullMQ
│   ├── search/           Full-text search — Meilisearch + Typesense + Algolia
│   ├── notifications/    Multi-channel notifications — Novu + dispatchers
│   ├── uploads/          File uploads — S3/R2 multipart + Tus resumable
│   ├── vault/            Envelope encryption for application secrets
│   ├── tenant/           Multi-tenancy context — AsyncLocalStorage + RLS
│   ├── analytics/        Product analytics pipeline
│   ├── audit/            Immutable audit log
│   ├── logger/           Structured logging (replaces console.log)
│   └── errors/           Typed error hierarchy and HTTP error helpers
│
├── scripts/              Repo-level utility scripts (palette generator, etc.)
├── docker-compose.infra.yml  Local infrastructure (PostgreSQL, Redis, ClickHouse)
├── turbo.json            Turborepo task pipeline configuration
├── pnpm-workspace.yaml   pnpm workspace package globs
└── package.json          Root scripts and devDependencies
```

## File naming conventions

| Pattern | Example | Purpose |
|---------|---------|---------|
| `kebab-case.tsx` | `user-avatar.tsx` | React component files |
| `kebab-case.ts` | `format-date.ts` | Utility and helper files |
| `*.test.ts` | `billing.test.ts` | Vitest unit test files |
| `*.test.tsx` | `button.test.tsx` | Vitest component test files |
| `*.stories.tsx` | `button.stories.tsx` | Storybook story files |
| `*.config.ts` | `tailwind.config.ts` | Configuration files |
| `route.ts` | `app/api/webhooks/route.ts` | Next.js App Router API routes |
| `page.tsx` | `app/dashboard/page.tsx` | Next.js App Router pages |
| `layout.tsx` | `app/dashboard/layout.tsx` | Next.js App Router layouts |

## Where to add new features

| You want to... | Where to put it |
|---------------|----------------|
| Add a new dashboard page | `apps/web/src/app/(dashboard)/` |
| Add a new marketing page | `apps/landing-page/src/app/[lang]/` |
| Add a new API route | `apps/api-gateway/src/routes/` |
| Add a new UI component | `packages/ui/src/components/` + story in `apps/storybook/` |
| Add a new layout wrapper | `packages/ui/src/layout/` |
| Add a new design token | `packages/tokens/styles.css` |
| Add a new email template | `packages/email/src/templates/` |
| Add a new Prisma model | `packages/db/prisma/schema.prisma` |
| Add a new background job type | `packages/queue/src/handlers/` |

## Turborepo task pipeline

The `turbo.json` at the repo root defines how tasks depend on each other:

```json
{
  "tasks": {
    "build":     { "dependsOn": ["^build"], "outputs": [".next/**", "dist/**"] },
    "typecheck": { "dependsOn": ["^typecheck"] },
    "lint":      { "dependsOn": [] },
    "test":      { "dependsOn": ["^build"] },
    "dev":       { "cache": false, "persistent": true }
  }
}
```

Use `--filter` to run tasks for a single package:

```bash
pnpm turbo run build --filter=@nebutra/ui
pnpm turbo run typecheck --filter=apps/web
```
