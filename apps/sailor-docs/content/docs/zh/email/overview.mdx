---
title: 邮件概览
description: Nebutra 的事务性邮件 — 六个内置模板、React Email 组件和通过 @nebutra/email 的 Resend 投递。
---

Nebutra 通过 `@nebutra/email` 包发送事务性邮件。模板使用 [React Email](https://react.email) 构建，通过 [Resend](https://resend.com) 投递。六个系统邮件模板开箱即用。

## 架构

```
┌──────────────────────────────────────┐
│    Server Action / API Route /       │
│    后台任务 / Webhook                 │
└──────────────┬───────────────────────┘
               │ email.send({ to, template, data })
┌──────────────▼───────────────────────┐
│         @nebutra/email               │
│  getEmailProvider() → Resend 客户端  │
│  渲染 React Email 模板 →             │
│  HTML + 纯文本                        │
└──────────────┬───────────────────────┘
               │ Resend API（HTTPS）
┌──────────────▼───────────────────────┐
│              Resend                  │
│  事务性投递、日志、域名验证、Webhook  │
└──────────────┬───────────────────────┘
               │ SMTP 投递
┌──────────────▼───────────────────────┐
│         收件人邮箱                    │
└──────────────────────────────────────┘
```

模板渲染在你的应用进程中完成，然后再发送给 Resend。React Email 组件会自动编译为 HTML 和纯文本备用格式。

## 内置模板

| 模板键 | 主题 | 发送时机 |
|-------|-----|---------|
| `welcome` | 欢迎使用 Nebutra | 新用户注册并准备好账户后 |
| `api-key-created` | 您的新 API 密钥 | 为组织生成 API 密钥后 |
| `quota-warning` | 您已使用 [指标] 配额的 80% | 计量使用量达到计划限额的 80% 时 |
| `quota-exceeded` | 您已超出 [指标] 配额 | 计量使用量超过计划限额的 100% 时 |
| `team-invite` | [邀请人] 邀请您加入 [组织] | 用户被邀请加入组织时 |
| `password-reset` | 重置您的密码 | 用户请求密码重置链接时 |

## 快速开始

```typescript
import { getEmailProvider } from "@nebutra/email";

const email = await getEmailProvider();

// 欢迎邮件
await email.send({
  to: user.email,
  template: "welcome",
  data: {
    userName: user.name,
    orgName: org.name,
    dashboardUrl: "https://app.nebutra.com/dashboard",
  },
});

// 配额警告邮件
await email.send({
  to: adminEmails,
  template: "quota-warning",
  data: {
    orgName: org.name,
    metric: "api_calls",
    used: 8100,
    limit: 10000,
    percentage: 81,
    upgradeUrl: "https://app.nebutra.com/billing",
  },
});

// 团队邀请邮件
await email.send({
  to: invitee.email,
  template: "team-invite",
  data: {
    inviteeName: invitee.name ?? invitee.email,
    inviterName: inviter.name,
    orgName: org.name,
    inviteUrl: `https://app.nebutra.com/invites/${invite.token}`,
    expiresAt: invite.expiresAt.toISOString(),
  },
});
```

## 环境变量

| 变量 | 是否必填 | 说明 |
|------|---------|------|
| `RESEND_API_KEY` | 是 | Resend API 密钥，以 `re_` 开头 |
| `EMAIL_FROM` | 是 | 发件人地址，如 `Nebutra <noreply@mail.nebutra.com>` |

<Warning>
`RESEND_API_KEY` 是敏感信息。不要提交到代码仓库。请将其添加到 Vercel 环境变量或密钥管理器中。
</Warning>

## Resend 控制台

[Resend 控制台](https://resend.com) 提供：

- **日志** — 每封邮件的投递状态、退信和打开记录
- **域名验证** — 验证发件域名所需的 DNS 记录
- **API 密钥** — 创建和轮换密钥
- **Webhook** — 在应用中接收投递事件

<Note>
在向 Resend 账户外的收件人投递邮件之前，Resend 要求验证发件域名。域名验证步骤请参阅[提供商](/email/providers)。
</Note>
