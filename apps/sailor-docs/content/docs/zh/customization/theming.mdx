Nebutra-Sailor 的主题系统由三个独立的层级组合而成：

| 层级 | 包 | 职责 |
|------|----|------|
| **运行时 Token** | `@nebutra/tokens` | CSS 变量——颜色、间距、字体排版 |
| **明暗模式** | `@nebutra/tokens`（next-themes） | `ThemeProvider` + `useTheme` |
| **Brand Package** | `@nebutra/theme` | 7 种内置设计语言，通过 `data-brand` 属性应用 |

## 编辑 CSS 变量

不要手动编辑 `packages/design/tokens/styles.css`——它是一个**生成的构建产物**。在这里做的修改会一直保留到该包的下一次 token 构建，然后悄无声息地消失（文件依旧能解析，只是 token 不见了，且不会有任何报错）。

唯一的事实来源是 DTCG token 源：

```
packages/design/design-tokens/tokens/
├── core.json           # 基础色阶
├── themes/light.json   # ┐ 语义 + 层级——始终成对编辑
└── themes/dark.json    # ┘
```

在这里编辑，然后重新构建以让改动生效：

```bash
pnpm --filter @nebutra/design-tokens build && pnpm --filter @nebutra/tokens build
```

### 关键 Token 参考

<Tabs>
  <Tab title="品牌色">
    ```css
    :root {
      --brand-primary:   var(--blue-9);    /* VI 品牌锁定色——logo、favicon、印刷品，不作为 CTA 填充色使用 */
      --brand-accent:    var(--cyan-9);    /* 强调色、成功高亮 */
      --brand-tertiary:  #8b5cf6;          /* 基础设施、第三层数据可视化 */
      --brand-gradient:  135deg, var(--blue-9) 0%, var(--cyan-9) 100%;

      --primary:            225 7.7% 10.2%; /* 墨色——真正的动作填充色：按钮、链接、焦点态 */
      --primary-foreground: 0 0% 100%;

    ```

## 使用调色板生成器重新品牌化

更改整个品牌调色板最快的方式是使用生成器脚本。它从两个颜色推导出两条色阶，并通过 `brand:apply` 写入 token 源，所有生成文件随之更新：

<Steps>
  <Step title="运行调色板生成器">
    ```bash
    node scripts/generate-palette.mjs --primary=#7C3AED --secondary=#F59E0B
    ```
    为 `--primary`（主品牌色）和 `--secondary`（强调色）传入任意有效的十六进制颜色值。
  </Step>
  <Step title="写入 token 源">
    把打印出的 `colors` 块粘贴进 `brand.config.ts`，然后运行：
    ```bash
    pnpm brand:apply
    ```
  </Step>
  <Step title="重启开发服务器">
    ```bash
    pnpm --filter @nebutra/landing dev
    # 或
    pnpm --filter @nebutra/web dev
    ```
    热重载并不总能处理 `styles.css` 的变更；完整重启更为稳妥。
  </Step>
  <Step title="在 Storybook 中验证">
    ```bash
    pnpm --filter @nebutra/storybook dev
    ```
    导航至 **Design Tokens** → **Brand Colors**，确认新调色板在所有色阶中均正确渲染。
  </Step>
</Steps>

### 手动重新品牌化示例

如果您更倾向于手动编辑 token：

```json
// packages/design/design-tokens/tokens/core.json（节选）
{
  "blue": { "9": { "$value": "#7C3AED", "$type": "color" } },
  "cyan": { "9": { "$value": "#F59E0B", "$type": "color" } }
}
```

然后重新构建 token 流水线（`pnpm --filter @nebutra/design-tokens build && pnpm --filter @nebutra/tokens build`），`styles.css` 就会用新调色板重新生成。

<Warning>
  编辑中性色阶时，务必同时更新明色模式（`:root`）和暗色模式（`.dark` / `[data-theme]`）两个代码块。跳过暗色模式代码块会导致深色模式下的对比度问题。
</Warning>

## 明暗模式

明暗模式由 `@nebutra/tokens` 重新导出的 `next-themes` 管理。

### 配置

`ThemeProvider` 已在 `apps/web/src/app/layout.tsx` 和 `apps/landing/src/app/layout.tsx` 中配置完毕，无需额外设置。

```tsx
// apps/web/src/app/layout.tsx
import { ThemeProvider } from "@nebutra/tokens";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  );
}
```

### 以编程方式切换主题

```tsx
"use client";
import { useTheme } from "@nebutra/tokens";

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();

  return (
    <button
      type="button"
      onClick={() => setTheme(theme === "dark" ? "light" : "dark")}
      aria-label="切换深色模式"
      className="rounded-md p-2"
    >
      {theme === "dark" ? "浅色" : "深色"}
    </button>
  );
}
```

### 已解析的主题

当用户未明确选择主题时，`useTheme` 返回 `"system"`。使用 `resolvedTheme` 获取实际计算值：

```tsx
const { resolvedTheme } = useTheme();
// → "light" | "dark"
```

## Brand Package

`@nebutra/theme` 内置 7 个 **Brand Package**——它们是完整的设计语言（角色、chrome 组件配方、层级、区域、字体，作为一个整体应用，而非单纯换色）：`gsap`、`linear`、`notion`、`raycast`、`stripe`、`vanta`、`vercel`。每个 Brand Package 通过 `<html>` 上的 `data-brand` 属性应用，作用域由 `skins.css` 限定（由 `emit-skins.mjs` 根据各 Package 的 `emit-css.ts` 生成）。

### 切换 Brand Package

```tsx
// 静态方式——在 layout 中设置
<html data-brand="linear">

// 动态方式
"use client";
import { applyLanguage, LANGUAGE_REGISTRY } from "@nebutra/theme";

export function BrandPackageSelector() {
  return (
    <div className="flex gap-2">
      {Object.keys(LANGUAGE_REGISTRY).map((id) => (
        <button key={id} type="button" onClick={() => applyLanguage(id)} className="rounded px-3 py-1 text-sm bg-neutral-2">
          {id}
        </button>
      ))}
    </div>
  );
}
```

在 Sailor 项目中，更简单的路径是 [Sailor Studio](https://nebutra.com/sailor/studio)：选一个 Brand Package 作为基础设计语言，调整各项参数，再用 `nebutra apply --preset <code>` 应用生成的预设——参见[定制概览](/zh/customization/overview)。

## 新增一个 Brand Package

<Steps>
  <Step title="添加品牌定义">
    ```
    packages/design/tokens/brands/<id>/brand.json
    ```
  </Step>
  <Step title="注册它">
    在 `packages/design/theme/src/languages.meta.json` 中添加一条记录，然后运行：

    ```bash
    node packages/design/theme/scripts/sync-languages.mjs
    ```

    这会写入生成的 `languages.json`——切勿手动编辑该文件。
  </Step>
  <Step title="应用并验证">
    ```tsx
    <html data-brand="your-id">
    ```

    打开 Storybook 并检查 **Design Tokens** 版块，验证对比度比率符合 WCAG AA 标准。
  </Step>
</Steps>

## 字体排版

字体通过 `next/font` 加载并注入为 CSS 变量，无外部字体请求。字号系统本身存放在 `core.json:type` 中——每一档 `text-*` 都自带对应的行高与字距。

```css
/* packages/design/tokens/styles.css —— 生成文件 */
:root {
  --font-sans: var(--font-geist-sans), "Geist", system-ui, sans-serif;       /* UI 文本 */
  --font-mono: var(--font-geist-mono), "Geist Mono", ui-monospace, monospace; /* 代码、指标 */
}
```

如需更换字体族，请更新应用 layout 中的 `next/font` 配置，然后更新 `packages/design/design-tokens/tokens/core.json` 中的源回退栈并重新构建——切勿直接编辑 `styles.css`。

- 品牌渐变
- 状态颜色
- 字体排版比例
- 动效预设
- 阴影/层级系统
