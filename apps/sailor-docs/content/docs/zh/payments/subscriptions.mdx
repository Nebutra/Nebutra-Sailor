<Note>
订阅是独立于一次性卡支付结账的另一个表面。本页介绍的是循环计划订阅，目前仍运行在 **Stripe** 上（历史遗留，根据 [ADR 2026-09-26](https://github.com/Nebutra/Nebutra-Sailor/blob/main/docs/architecture/2026-09-26-creem-global-payments.md)）。一次性卡支付购买（例如积分）改用 **Creem**——参见 [Creem 集成](/zh/integrations/creem)。
</Note>

## 结账流程

<Steps>
  <Step title="将用户重定向至 Stripe 结账">
    调用 `@nebutra/billing` 中的 `createCheckoutSession` 生成 Stripe 托管的结账 URL，然后将用户重定向至该 URL。该辅助函数接收的是 Stripe `customerId`（来自 `getOrCreateCustomer`），而不是原始租户 id；试用期字段名是 `trialPeriodDays`。

    ```typescript apps/web/src/app/billing/upgrade/route.ts
    import { createCheckoutSession, getOrCreateCustomer } from "@nebutra/billing";
    import { redirect } from "next/navigation";
    import { getCurrentTenant } from "@nebutra/tenant";

    export async function GET() {
      const tenant = getCurrentTenant();
      const customer = await getOrCreateCustomer(tenant.tenantId, tenant.ownerEmail);

      const session = await createCheckoutSession({
        customerId: customer.id,
        priceId: process.env.STRIPE_PRICE_ID_PRO_MONTHLY!,
        successUrl: `${process.env.NEXT_PUBLIC_APP_URL}/billing/success`,
        cancelUrl: `${process.env.NEXT_PUBLIC_APP_URL}/billing`,
        trialPeriodDays: 14,
      });

      redirect(session.url);
    }
    ```
  </Step>
  <Step title="用户在 Stripe 完成支付">
    Stripe 处理支付表单、SCA/3DS 以及错误状态。您无需自行构建支付表单。
  </Step>
  <Step title="处理成功重定向">
    支付成功后，Stripe 将用户重定向至您的 `successUrl`。此时展示确认界面即可——**不要**在这里更新计划。计划激活由 Webhook 确认。

    ```typescript apps/web/src/app/billing/success/page.tsx
    export default function BillingSuccessPage() {
      return (
        <div>
          <h1>您已升级至 PRO！</h1>
          <p>
            您的计划正在激活，通常需要几秒钟。
            如果新的限额未立即生效，请刷新页面。
          </p>
        </div>
      );
    }
    ```
  </Step>
  <Step title="Webhook 确认计划激活">
    Stripe 触发 `checkout.session.completed` 事件。`@nebutra/billing` 中的 Webhook 处理程序更新数据库中的租户计划，配额限额自动更新。
  </Step>
</Steps>

<Warning>
不要仅凭成功重定向 URL 来更新计划。重定向 URL 可以被伪造。请始终等待 `checkout.session.completed` Webhook 来确认支付。
</Warning>

## 查询订阅状态

`@nebutra/billing` 没有 `getSubscription` 这个函数。使用 `getStripeSubscription`（按 Stripe 订阅 id）或 `getCustomerSubscriptions`（按 Stripe 客户 id）获取当前订阅状态：

```typescript
import { getCustomerSubscriptions, mapStripeStatusToLocal } from "@nebutra/billing";

const [subscription] = await getCustomerSubscriptions(customer.id);
// Stripe.Subscription —— 通过 mapStripeStatusToLocal() 映射为
// @nebutra/billing 其余部分使用的本地 SubscriptionStatus 枚举。
```

### 订阅生命周期状态

| 状态 | 含义 | 用户影响 |
|------|------|---------|
| `trialing` | 处于 14 天试用期内 | 享有完整 PRO 权限，尚未收费 |
| `active` | 订阅当前有效且已付款 | 完整计划访问权限 |
| `past_due` | 最新发票付款失败 | 计划保持有效；提示用户更新支付方式 |
| `canceled` | 订阅已取消 | 在当前计费周期结束后降级至 FREE |
| `unpaid` | 多次尝试失败；Stripe 已暂停订阅 | 访问权限被撤销；用户必须更新支付方式 |

### 在 UI 中展示状态

```typescript apps/web/src/app/settings/billing/page.tsx
import { getCustomerSubscriptions, mapStripeStatusToLocal } from "@nebutra/billing";

export default async function BillingSettingsPage({ stripeCustomerId }: { stripeCustomerId: string }) {
  const [subscription] = await getCustomerSubscriptions(stripeCustomerId);
  const status = subscription ? mapStripeStatusToLocal(subscription.status) : "CANCELED";

  return (
    <div>
      <p>状态：{status}</p>
      {status === "PAST_DUE" && (
        <a href="/billing/portal">更新支付方式</a>
      )}
    </div>
  );
}
```

## 试用期

PRO 订阅包含 **14 天免费试用期**，试用期结束前不会向信用卡收费。

- 试用状态通过 `mapStripeStatusToLocal(subscription.status)` 映射为 `TRIALING`。
- 试用到期后，Stripe 向绑定的信用卡收费，状态变为 `active`。
- 若试用期结束前未提供支付方式，订阅变为 `canceled`。

```typescript
// 创建结账会话时传入 trialPeriodDays 以开启试用期
const session = await createCheckoutSession({
  customerId: customer.id,
  priceId: process.env.STRIPE_PRICE_ID_PRO_MONTHLY!,
  successUrl: "https://app.nebutra.com/billing/success",
  cancelUrl: "https://app.nebutra.com/billing",
  trialPeriodDays: 14,
});
```

<Tip>
省略 `trialPeriodDays`（或传 `0`）即可为特定用户（例如从旧计划迁移的用户或使用促销码的用户）跳过试用期。
</Tip>

## 取消与自助管理

客户可通过 **Stripe 客户门户**自助取消、升级或更新支付方式，使用 `@nebutra/billing` 的 `createBillingPortalSession`：

```typescript apps/web/src/app/billing/portal/route.ts
import { createBillingPortalSession } from "@nebutra/billing";
import { redirect } from "next/navigation";

export async function GET({ stripeCustomerId }: { stripeCustomerId: string }) {
  const session = await createBillingPortalSession(
    stripeCustomerId,
    `${process.env.NEXT_PUBLIC_APP_URL}/settings/billing`,
  );

  redirect(session.url);
}
```

若需要在托管门户之外提供完整的取消/暂停/恢复能力，`@nebutra/billing` 还导出了 `cancelStripeSubscription`、`pauseStripeSubscription`、`resumeStripeSubscription`、`unpauseStripeSubscription`、`updateStripeSubscription` 与 `previewSubscriptionChange`。
