Nebutra-Sailor 已不再提供单一的 `@nebutra/sdk` 聚合包。当前的
JavaScript / TypeScript 集成模型是 **按职责拆分包面**：
按你要解决的问题选择具体 surface。

## 当前应该用什么

| 需求 | 当前 surface | 说明 |
| --- | --- | --- |
| 应用认证 | `@nebutra/auth` | `apps/web` 使用的 provider-agnostic auth runtime |
| 类型化网关调用 | `apps/web/src/lib/api/client.ts` | 基于 OpenAPI 生成的 `openapi-fetch` 客户端 |
| AI 生成 | `@nebutra/agents` | `generateText`、`streamText`、embedding、provider helpers |
| 权限检查 | `@nebutra/permissions` | IAM 规则、中间件、可选 React 子路径 |
| 多租户上下文 | `@nebutra/tenant` | Tenant 解析与 RLS 辅助 |
| UI 原语 / 布局 | `@nebutra/ui` | 组件、layout、utils |

## 类型化 API 客户端

在 web 应用里，调用 API 网关的标准方式是生成的 OpenAPI 客户端：

```typescript
import { browserApiClient, getTypedApi } from "@/lib/api/client";

// Server Component / Server Action
const api = await getTypedApi();
const { data } = await api.GET("/api/v1/ai/models");

// Client Component
const response = await browserApiClient.GET("/api/v1/integrations");
```

相关类型来自提交/生成的 `types.generated.ts`，源头是
`backends/gateway/openapi.json`。

## 认证

`apps/web` 通过 `@nebutra/auth` 暴露的运行时完成认证，而页面保护由
`apps/web/src/lib/auth.ts` 提供：

```typescript
import { requireAuth, getTenantContext } from "@/lib/auth";

export default async function Page() {
  await requireAuth();
  const { tenantId, plan } = await getTenantContext();
  return <div>{tenantId} · {plan}</div>;
}
```

如果要直接使用底层 provider runtime，请从 `@nebutra/auth` /
`@nebutra/auth/server` 导入，而不是依赖一个并不存在的 SDK 包装层。

## AI runtime

AI 能力由 `@nebutra/agents` 提供：

```typescript
import { generateText, streamText } from "@nebutra/agents";

const completion = await generateText({
  model: "openai/gpt-4.1-mini",
  prompt: "总结最近一周的漏斗表现。",
});

const stream = await streamText({
  model: "openai/gpt-4.1-mini",
  prompt: "为最新账单改动起草发布说明。",
});
```

## 权限

授权逻辑应通过 `@nebutra/permissions` 以及应用层 helper 使用：

```typescript
import { hasPermission } from "@/lib/permissions";

const allowed = hasPermission("admin", "billing:manage");
```

如果你在独立 React 界面里需要通用权限门控，请使用包的 React 子路径，
而不是旧的 `@nebutra/react`：

```typescript
import { PermissionGate } from "@nebutra/permissions/react";
```

## UI 与布局包

```tsx
import { Button } from "@nebutra/ui/components";
import { PageHeader, EmptyState, LoadingState } from "@nebutra/ui/layout";
import { cn } from "@nebutra/ui/utils";
```

`@nebutra/design-system` 已经并入 `@nebutra/ui`。

## 不要再使用这些旧 surface

- 不要文档化或导入 `@nebutra/sdk`
- 不要文档化或导入 `@nebutra/react`
- 不要文档化或导入 `@nebutra/integrations`
- 不要把 `@nebutra/db` 当成浏览器可用的数据客户端
