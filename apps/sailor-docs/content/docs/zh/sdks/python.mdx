## 没有 Python SDK

PyPI 上没有 `nebutra-sdk` 这个包，Nebutra-Sailor 里也不带这个。根据
[ADR 2026-05-10，TS-by-Default](/zh/architecture/backend-language-policy)，新的后端工作——包括
API 客户端——默认用 TypeScript 写进 `backends/gateway`；Python 只留给没有对应 TS 版本的批处理、
ML 或特殊依赖库场景。

如果一个站得住脚的 Python 服务需要跟你的项目通信，直接调用网关的 REST API——在网关主机的
`/docs` 和 `/openapi.json` 上有 OpenAPI 文档——用共享的 `SERVICE_SECRET` 认证（见
[Python 快速开始](/zh/quickstart/python)）。
