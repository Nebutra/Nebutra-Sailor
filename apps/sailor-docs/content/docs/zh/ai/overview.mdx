## 包含的功能

Nebutra 通过 `@nebutra/agents` 开箱即用地提供 AI 功能。该包是 [Vercel AI SDK](https://sdk.vercel.ai/) 的轻量封装，自动集成了租户上下文、限流和用量计量。

每个租户可使用以下功能：

| 功能 | 描述 | 计划权益 |
|------|------|----------|
| **聊天补全** | 流式和非流式 LLM 响应 | `ai.chat` |
| **嵌入向量** | 用于语义搜索和 RAG 的向量表示 | `ai.embeddings` |
| **图像分析 / 生成** | 支持视觉能力的模型与图像生成 | `ai.images` |
| **推理** | 扩展推理模型调用 | `ai.reasoning` |

## 架构

请求经过 API 网关，在代理到底层模型供应商之前自动完成鉴权、限流和计量：

```
客户端应用
    │
    ▼
POST /api/v1/ai/chat/completions   (API 网关 — Hono)
    │
    ├─ 鉴权检查（API Key）
    ├─ 计划权益检查（ai.chat）
    ├─ 限流（按租户，@nebutra/rate-limit）
    │
    ▼
@nebutra/agents               (Vercel AI SDK v6 封装)
    │
    ├─ OpenAI  （默认）
    └─ OpenRouter  （多模型：Claude、Llama、Mistral……）
    │
    ▼
响应 / SSE 流
    │
    ▼
@nebutra/metering             （消耗的 Token → 计费）
    │
    ▼
pgvector（仅嵌入向量）         （PostgreSQL 向量存储）
```

## 计划权益

AI 功能由计划门控，而不是一个独立的功能开关。`ai.chat`、`ai.embeddings`、`ai.images`、`ai.reasoning` 是 `PLAN_FEATURES`（`@nebutra/billing` 的 `entitlements/service.ts`）中的条目——哪些计划包含某项功能是这张表里的数据，不是一个按租户切换的开关。API 网关会在发起任何模型调用之前检查权益（以及该功能若挂有用量额度时剩余的额度）——检查失败则不消耗任何 Token：

```typescript backends/gateway/src/middlewares/entitlements.ts
app.post("/api/v1/ai/generate", requireFeature("ai.images", 1), handler);
```

完整的权益检查 API（`checkEntitlement`、`requireEntitlement`、`requireFeature`、`isPlanFeature`）参见[付费墙](/zh/payments/paywall)。

## 环境变量

将以下变量添加到 `.env`（或 Vercel 环境变量）：

```bash
# 必填：至少提供一个供应商密钥
OPENAI_API_KEY=""

# 可选：通过 OpenRouter 启用多模型路由
OPENROUTER_API_KEY=""
```

没有 `AI_DEFAULT_MODEL` / `AI_EMBEDDING_MODEL` 环境变量。默认聊天模型是在启动时调用一次 `configure({ defaultModel: "…" })` 设置的（`@nebutra/agents` 的 `NebutraAIConfigSchema` 把 `defaultModel` 默认设为 `models.flagship`）；默认嵌入模型固定为 `"embedding"` 这个预设别名，除非调用时自己传入 `model`。

<Warning>
切勿将 `OPENAI_API_KEY` 或 `OPENROUTER_API_KEY` 暴露给客户端。所有模型调用必须通过 API 网关进行。
</Warning>

## 用量与配额

Token 消耗通过 `@nebutra/metering` 自动计量，并计入租户的 API 配额。可以通过代码或控制台查看当前用量：

```typescript
import { getMetering, COMMON_METERS } from "@nebutra/metering";

const metering = await getMetering();
const quota = await metering.getQuota("org_123", "ai_tokens");
// → { limit: 5000000, used: 1243000, remaining: 3757000, percentage: 0.249 }
```

各套餐配额限制：

| 套餐 | 每月 AI Token 数 |
|------|----------------|
| FREE | 100,000 |
| PRO | 5,000,000 |
| ENTERPRISE | 自定义 |

## 快速使用示例

`generateText`、`streamText`、`embed` 的第一个参数是消息/文本值，第二个参数是选项对象——不是一个合并的对象：

```typescript
import { streamText, generateText, embed } from "@nebutra/agents";

// 流式聊天（SSE）
const result = await streamText(
  [
    { role: "system", content: "你是一个有帮助的助手。" },
    { role: "user", content: userMessage },
  ],
  { model: "gpt-5.5" },
);

// 非流式
const { text } = await generateText(
  [{ role: "user", content: "总结以下内容：" + content }],
  { model: "gpt-5.4-mini" },
);

// 嵌入向量——默认使用 "embedding" 预设别名
const embedding = await embed("需要嵌入的文本", { model: "text-embedding-3-small" });
```
