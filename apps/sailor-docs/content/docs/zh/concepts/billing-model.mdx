## 计量工作原理

使用量通过 `@nebutra/metering` 实时追踪，并通过 ClickHouse 聚合事件。每次 API 调用和 AI Token 使用都记录有：

- `tenant_id`——哪个组织消耗了资源
- `metric_id`——消耗了什么（`api_calls`、`ai_tokens`）
- `quantity`——消耗了多少
- `timestamp`——何时发生

## 配额强制执行

配额在 API 网关层强制执行，在任何业务逻辑运行之前。当租户超出配额时，API 返回：

```json
HTTP 429 Too Many Requests

{
  "success": false,
  "error": {
    "code": "QUOTA_EXCEEDED",
    "message": "月度 API 调用配额已超出。升级到 PRO 可获得 100 倍更多调用次数。",
    "details": {
      "metric": "api_calls",
      "limit": 1000,
      "used": 1001,
      "reset_at": "2026-04-01T00:00:00Z"
    }
  }
}
```

用户在达到配额 80% 和 100% 时会收到事务性邮件警告。

## 查询配额

```typescript
const quota = await metering.getQuota("org_123", "api_calls");
// → {

//   }
```
