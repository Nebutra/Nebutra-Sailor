开源。

## 覆盖范围

| 范围 | 许可 |
| --- | --- |
| Nebutra-Sailor 仓库 | Apache-2.0，根目录附 `NOTICE` |
| 所有 npm 包——`@nebutra/*`、`nebutra`、`create-sailor` | Apache-2.0 |
| `Nebutra/Sailor-Template` 镜像 | Apache-2.0 + `NOTICE` |
| `create-sailor` 生成的每个项目 | Apache-2.0 `LICENSE` + `NOTICE`——代码归你 |

## 哪些免费

全部免费：商业与闭源产品、外包交付、公司内部使用，以及托管或竞品平台。不收费、不需要许可证密钥、
不需要注册，也没有传染性（copyleft）条款。

## Apache-2.0 的要求

只在你**再分发** Sailor 的源码或其衍生作品时适用：

- 附上许可证副本；
- 保留版权和署名声明，并随附 `NOTICE` 文件；
- 标明你修改过的文件。

运行一个基于 Sailor 的托管产品，不属于再分发它的源码。生成的项目已经自带 `LICENSE` 和 `NOTICE`。

## 商标

Apache-2.0 不授予商标权（第 6 条）。用你自己的、无关的名字重新命名 Sailor 不需要许可；用 Nebutra
或 Sailor 的名字来命名你的产品则需要。见
[商标政策](https://github.com/Nebutra/Nebutra-Sailor/blob/main/TRADEMARK.md)。

## 付费方案

付费方案卖的是支持，不是使用许可：专属沟通渠道与响应保证（Team），以及 SLA、知识产权赔偿、DPA、
合规材料包、LTS 分支和商标授权（Enterprise）。见
[nebutra.com/licensing](https://nebutra.com/licensing) 和完整的
[商业支持条款](https://github.com/Nebutra/Nebutra-Sailor/blob/main/docs/legal/commercial-support.md)。
