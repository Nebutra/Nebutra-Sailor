## 安装

```bash
pip install nebutra-sdk
```

## 初始化客户端

```python
import os
from nebutra import Client

nebutra = Client(
    api_key=os.environ["NEBUTRA_API_KEY"],
    org_id=os.environ["NEBUTRA_ORG_ID"],
)
```

## 验证 JWT 令牌（FastAPI）

```python
from fastapi import HTTPException, Header
from nebutra import verify_token
import os

async def require_auth(authorization: str = Header(...)):
    token = authorization.removeprefix("Bearer ")
    try:
        return await verify_token(token, api_key=os.environ["NEBUTRA_API_KEY"])
    except Exception:
        raise HTTPException(status_code=401, detail="无效令牌")
```

## 检查权限

```python
allowed = await nebutra.permissions.check(
    user_id=user_id,
    action="delete",
    resource="Project",
)
if not allowed:
    raise HTTPException(status_code=403, detail="权限不足")
```
