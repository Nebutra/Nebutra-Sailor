<Warning>
  **Python 只保留给批处理 / ML / 特殊依赖库场景**（见 [ADR 2026-05-10，TS-by-Default 后端语言策略](/zh/architecture/backend-language-policy)）。

  CRUD、Webhooks、计费、内容管理、第三方 API 代理——都应该放进 **`backends/gateway/`**（TypeScript + Hono）。只有满足以下至少一条，新建 Python 服务才成立：

  1. 边缘运行时跑不动的批处理 / 队列任务（通常 >5 秒）
  2. 依赖 Python 生态的 ML / 科学计算（transformers、vLLM 等）
  3. 没有对应 TS 版本的特殊依赖库

  目前没有发布过 `nebutra-sdk` 这个 Python 包。这页讲的是从一个已经站得住脚的 Python 服务
  （FastAPI / Django）调用网关的 REST API——不是鼓励你随便起一个 Python 服务做通用业务。
</Warning>

## 调用网关

每一个网关端点都是普通的 REST，在网关主机的 `/docs` 和 `/openapi.json` 上有 OpenAPI 文档——用
`httpx` 或 `requests` 像调用任何 HTTP API 一样调用它：

```python
import httpx

resp = httpx.get(
    "https://your-gateway-host/api/v1/ai/models",
    headers={"x-service-token": service_token},
)
```

## 服务间认证

内部调用用一个由共享 `SERVICE_SECRET` 签名的短期 HS256 JWT（`x-service-token`），TypeScript
那一侧用 `@nebutra/auth` 的 `verifyServiceToken` 校验。用任意标准 JWT 库（比如 `pyjwt`）签同样
结构的 claim——这里没有 Python SDK，只有一个共享密钥和一份 JWT 约定。

```python
import jwt
import time

token = jwt.encode(
    {"service": "my-python-worker", "iat": int(time.time())},
    SERVICE_SECRET,
    algorithm="HS256",
)
```
