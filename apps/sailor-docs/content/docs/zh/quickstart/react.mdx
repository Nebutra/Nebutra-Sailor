没有单独的 `@nebutra/react` 客户端包——`apps/web`（脚手架出来的 Next.js 16 App Router 项目）
**就是**你的 React 应用。这页讲的是它自带的那些部分。

## 用权限检查控制 UI

`@nebutra/permissions/react` 把 CASL 包成了 React 绑定：

```tsx src/components/DeleteButton.tsx
import { Can } from "@nebutra/permissions/react";

export function DeleteButton({ projectId }: { projectId: string }) {
  return (
    <Can action="delete" resource="Project">
      <button type="button" onClick={() => handleDelete(projectId)}>
        Delete Project
      </button>
    </Can>
  );
}
```

没有对应权限时 `<Can>` 什么都不渲染。如果要在组件里做命令式检查，用 `usePermission`：

```tsx
import { usePermission } from "@nebutra/permissions/react";

const canDelete = usePermission("delete", "Project", project);
```

两者都从包裹应用的 `<PermissionProvider>` 读取上下文——脚手架的根 layout 里已经接好了。

## 认证状态

会话状态来自 Better Auth 自己的 React 客户端（项目里 `lib/auth-client.ts` 导出的
`authClient`，由 `better-auth/react` 的 `createAuthClient` 生成），不是什么 Nebutra SDK：

```tsx src/components/UserMenu.tsx
import { authClient } from "@/lib/auth-client";

export function UserMenu() {
  const { data: session, isPending } = authClient.useSession();

  if (isPending) return <Skeleton />;
  if (!session) return <SignInButton />;

  return <p>{session.user.name}</p>;
}
```
