## 目录树

```
nebutra-sailor/
├── apps/
│   ├── landing-page/     Next.js 16 — 公开营销网站（7 种语言，端口 3002）
│   ├── web/              Next.js 16 — 已认证的 SaaS 控制台（端口 3000）
│   ├── api-gateway/      Hono + OpenAPI — REST API 后端（端口 3001）
│   ├── storybook/        Storybook 8.x — 组件库文档（端口 6006）
│   ├── design-docs/      Fumadocs — 内部设计系统文档（端口 3003）
│   ├── studio/           Sanity Studio v5 — 内容管理系统（端口 3333）
│   └── sailor-docs/      Fumadocs — 公开产品文档（端口 3004，本站）
│
├── packages/
│   ├── ui/               主要组件库（Radix + HeroUI + Lobe UI）
│   ├── tokens/           运行时 CSS 设计 Token + ThemeProvider
│   ├── icons/            541 个 Geist 图标，以可按需加载的 TSX 组件提供
│   ├── brand/            品牌色彩、渐变和动效语言
│   ├── theme/            纯 CSS 多主题引擎（6 个 oklch 主题）
│   ├── preset/           基于功能的 SaaS 入门配置系统
│   ├── db/               Prisma v7 Schema、迁移和客户端
│   ├── identity/         认证适配器（Clerk / Better Auth）
│   ├── billing/          Stripe 计费、Webhook 和配额门控
│   ├── email/            事务邮件（Resend + React Email）
│   ├── ai-sdk/           AI 服务代理辅助工具和模型路由
│   ├── permissions/      RBAC/ABAC — CASL（进程内）+ OpenFGA
│   ├── webhooks/         出站 Webhook 分发 — Svix + 自定义
│   ├── metering/         使用量计量管道 — ClickHouse
│   ├── queue/            消息队列 — QStash（无服务器）+ BullMQ
│   ├── search/           全文检索 — Meilisearch + Typesense + Algolia
│   ├── notifications/    多渠道通知 — Novu + 直接分发器
│   ├── uploads/          文件上传 — S3/R2 分片 + Tus 断点续传
│   ├── vault/            应用层密钥信封加密
│   ├── tenant/           多租户上下文 — AsyncLocalStorage + RLS
│   ├── analytics/        产品分析管道
│   ├── audit/            不可变审计日志
│   ├── logger/           结构化日志（替代 console.log）
│   └── errors/           类型化错误层次结构和 HTTP 错误辅助工具
│
├── scripts/              仓库级别工具脚本（调色板生成器等）
├── docker-compose.infra.yml  本地基础设施（PostgreSQL、Redis、ClickHouse）
├── turbo.json            Turborepo 任务管道配置
├── pnpm-workspace.yaml   pnpm workspace 包路径配置
└── package.json          根脚本和开发依赖
```

## Turborepo 任务管道

仓库根目录的 `turbo.json` 定义了任务之间的依赖关系：

```json
{
  "tasks": {
    "build":     { "dependsOn": ["^build"], "outputs": [".next/**", "dist/**"] },
    "typecheck": { "dependsOn": ["^typecheck"] },
    "lint":      { "dependsOn": [] },
    "test":      { "dependsOn": ["^build"] },
    "dev":       { "cache": false, "persistent": true }
  }
}
```

使用 `--filter` 为单个包运行任务：

```bash
pnpm turbo run build --filter=@nebutra/ui
pnpm turbo run typecheck --filter=apps/web
```
