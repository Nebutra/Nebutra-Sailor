## 概述

Slack 集成在你的 Nebutra 组织中发生重要事件时，向你选择的 Slack 频道发送实时通知。

## 第一步：创建 Slack 应用

1. 前往 [api.slack.com/apps](https://api.slack.com/apps) 点击**创建新应用**
2. 选择**从头开始**
3. 命名为 "Nebutra" 并选择你的工作区
4. 在 **OAuth 和权限**下，添加机器人权限：`chat:write`、`chat:write.public`
5. 将应用安装到工作区，复制 **Bot User OAuth Token**

## 第二步：配置集成

```bash
SLACK_BOT_TOKEN=xoxb-xxxxxxxxxxxx
SLACK_CHANNEL_ID=C0XXXXXXXXXX
```

## 第三步：配置通知

```typescript
await nebutra.integrations.slack.configure({
  orgId: "org_123",
  channelId: "C0XXXXXXXXXX",
  events: ["member.joined", "quota.warning", "invoice.paid"],
});
```

## 通知示例

**新成员加入：**
```
✅ Alice (alice@acme.com) 以成员身份加入了 Acme 公司。
```

**配额预警（80%）：**
```
⚠️ Acme 公司已使用 80% 的月度 API 配额（800/1,000 次调用）。
考虑升级到 PRO 获取 100 倍更多调用次数。
```
