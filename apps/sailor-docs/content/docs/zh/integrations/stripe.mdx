<Warning>
本页介绍的是**历史遗留**的 Stripe 集成。根据 [ADR 2026-09-26](https://github.com/Nebutra/Nebutra-Sailor/blob/main/docs/architecture/2026-09-26-creem-global-payments.md)，全球范围的卡支付已迁移至 [Creem](/zh/integrations/creem)——一个自行代收代缴销售税/增值税的记录商户。Stripe 已不再承接新工作，其代码仅保留给订阅、计费门户、许可证 Webhook 以及切换前已发起的结账使用。请勿在其上构建任何新功能。当前的卡支付通道请参见 [Creem](/zh/integrations/creem)。
</Warning>

## 前提条件

- 一个 [Stripe 账户](https://stripe.com)
- 已安装 Stripe CLI：`npm install -g stripe`

## 第一步：设置环境变量

```bash
STRIPE_SECRET_KEY=sk_live_xxxxxxxxxxxxxxxxxxxx
STRIPE_WEBHOOK_SECRET=whsec_xxxxxxxxxxxxxxxxxxxx
```

开发时使用 `sk_test_` 密钥。

## 第二步：在 Stripe 中创建产品

```bash
# 创建产品
stripe products create --name="Nebutra PRO"

# 创建价格
stripe prices create \
  --product=prod_xxx \
  --unit-amount=2900 \
  --currency=usd \
  --recurring[interval]=month
```

## 第三步：配置 Webhook 端点

在 Stripe 仪表板：**开发者 → Webhooks → 添加端点**

- URL：`https://api.nebutra.com/api/webhooks/stripe`
- 监听的事件：
  - `checkout.session.completed`
  - `customer.subscription.created`
  - `customer.subscription.updated`
  - `customer.subscription.deleted`
  - `invoice.paid`
  - `invoice.payment_failed`

### 本地测试 Webhook

```bash
stripe listen --forward-to localhost:3000/api/webhooks/stripe
```

## Stripe 测试卡

| 卡号 | 场景 |
|------|------|
| `4242 4242 4242 4242` | 支付成功 |
| `4000 0000 0000 9995` | 余额不足 |
| `4000 0025 0000 3155` | 3D Secure 认证 |

使用任意未来到期日和任意 3 位 CVC。
