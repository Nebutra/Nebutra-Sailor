## 内置 vs 可配置

部分集成已预先接好线，默认处于激活状态。其他需要 API 密钥才能激活。

| 集成 | 状态 | 说明 |
|------|------|------|
| Vercel | 内置 | 零配置部署 |
| Resend | 设置 `RESEND_API_KEY` 后激活 | 邮件模板已就绪 |
| Stripe | 设置 `STRIPE_SECRET_KEY` 后激活 | Webhook 已预配置 |
| Sentry | 设置 `SENTRY_DSN` 后激活 | 租户上下文自动标记 |
| Sanity | 设置 `SANITY_API_TOKEN` 后激活 | Studio 在 studio.nebutra.com |
| Slack | 需要 OAuth 配置 | 通过设置 → 集成 |
| GitHub | 需要 OAuth 配置 | 通过设置 → 集成 |
| Linear | 需要 API 密钥 | 通过设置 → 集成 |
