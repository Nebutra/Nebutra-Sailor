`create-sailor` 是一次性脚手架工具，它会克隆 Nebutra-Sailor 模板，通过配置问题引导你完成设置，并写入 `.env.local`——让你在不到一分钟内就能开始编码。

## 用法

```bash
npx create-sailor [目录]
```

若省略 `[目录]` 参数，向导会提示你输入目录名称。

## 执行流程

<Steps>
  <Step title="询问项目创建位置">
    提示输入目标目录（默认：`./my-saas-app`）。
  </Step>
  <Step title="选择应用配置">
    通过交互菜单选择：应用类型、ORM、数据库、支付服务商、AI 服务商、i18n。
  </Step>
  <Step title="设置环境变量">
    提示输入 `DATABASE_URL`、Clerk 密钥等关键密钥——直接写入 `.env.local`。
  </Step>
  <Step title="克隆、配置并剪枝">
    克隆 Nebutra-Sailor 仓库，在 `package.json` 中设置项目名称，写入 `nebutra.config.json`，裁剪未使用的模板功能，并注入环境变量。
  </Step>
  <Step title="输出后续步骤">
    显示接下来要运行的命令：`cd my-saas-app && pnpm install && pnpm dev`。
  </Step>
</Steps>

## 配置选项

### 应用类型

| 选项 | 说明 |
|------|------|
| `saas`（默认） | 标准 B2B/B2C SaaS——优化的 UI + 数据库架构 |
| `full` | 完整 monorepo——含 Python AI 工作流和 Web3 |
| `ecommerce` | 电商套件 |
| `web3` | Web3 DApp |

### ORM

| 选项 | 说明 |
|------|------|
| `prisma`（默认） | Prisma v7——推荐 |
| `drizzle` | Drizzle ORM |
| `none` | 跳过——自行配置 |

### 数据库

| 选项 | 说明 |
|------|------|
| `postgresql`（默认） | PostgreSQL——Supabase、Vercel、Neon 等 |
| `mysql` | MySQL / PlanetScale |
| `sqlite` | SQLite / Turso |
| `none` | 跳过 |

### 支付服务商

| 选项 | 说明 |
|------|------|
| `stripe`（默认） | Stripe 订阅 |
| `lemonsqueezy` | Lemon Squeezy |
| `none` | 跳过 |

### AI 服务商

| 选项 | 说明 |
|------|------|
| `openai`（默认） | OpenAI |
| `anthropic` | Anthropic Claude |
| `none` | 跳过 |

### i18n

使用 `next-intl` 启用国际化（支持 7 种语言）。默认**启用**。

## 脚手架后的操作

```bash
cd my-saas
pnpm install          # 安装所有依赖
pnpm infra:lite       # 启动 PostgreSQL（Docker）
pnpm db:generate      # 生成 Prisma 客户端
pnpm db:migrate       # 运行初始迁移
pnpm dev:dashboard    # 启动 Web 应用 + API 网关
```

<Note>
  `create-sailor` 是一次性工具。项目创建后，日常任务（添加组件、管理基础设施、运行迁移）请使用 `nebutra` CLI。
</Note>
