如果你想直接看盘，而不是开发应用，请打开托管工作台 [kcq.nebutra.com/app](https://kcq.nebutra.com/app)。它是 KLineChartQuant 图表加上一层轻量的 Nebutra 外壳：你的账号、你的工作区、托管行情和托管 AI Agent。

图表本身就是这份文档介绍的开源库。工具栏、画线工具、指标和 Agent 面板的行为，与你自己嵌入时完全一致。

## 登录

工作台使用 Nebutra 账号。未登录时，账户菜单里会提供登录入口；工作区、自带的数据源 Key 和托管 Agent 都需要登录后才能使用。身份与工作区成员关系来自 Nebutra 认证中心，工作台不会另建用户库。账户设置位于同一域名下的 `/settings/profile`。

窗口重新获得焦点时，以及每隔一分钟，工作台都会重新校验登录状态。如果你在别处退出登录，或失去了当前工作区的访问权限，页面会自动重新加载。

## 工作区

账户菜单位于图表工具栏的最前端。在这里可以看到当前登录的身份，并在个人工作区和团队工作区之间切换。

布局、自选、图表偏好和 Agent 会话都按账号和工作区分别保存，切换工作区就会看到那个工作区的图表。切换时页面会重新加载，以丢弃上一个工作区的缓存状态。

这些偏好保存在你的浏览器中，不会同步到云端，也不会跟随你到另一台设备。

## 行情数据

工作台随应用一起托管了两个连接器：

- **GOTDX：**A 股、指数及扩展市场。
- **TradingView：**全球品种的历史 K 线。

两者无需任何配置，直接出现在图表的数据源列表中。BaoStock、FinShare 和 MT5 在开源库中可用，但托管工作台不提供。

### 使用自己的数据源 Key

你可以接入自己的 Twelve Data Key，用自己的订阅查看美股、ETF 和加密货币。在工具栏或图表设置中打开数据源面板，即可连接、测试、替换或断开 Key。

- **个人连接**只有你自己可见。
- **团队连接**可供工作区成员使用；只有所有者和管理员可以添加或更换 Key。

Key 保存之后就不会再回到浏览器。它在 Nebutra 网关上加密存储，浏览器只能看到名称和打码后的尾号；图表的数据请求经由网关转发，由网关代你调用 Twelve Data。使用你的 Key 发出的请求计入你自己的 Twelve Data 套餐；你的连接出错时，也不会回退到 Nebutra 自己的数据。具体实现见[行情数据指南](/zh/docs/guides/data-feeds)。

## Agent

Agent 面板在图表右侧打开。工作台已预先配置好 Nebutra 托管模型，登录后即可使用。浏览器中不保存任何 API Key，你的登录会话就是唯一凭据。

托管 Agent 的用量从当前工作区的 KCQ 钱包扣费。账户导航中的钱包标签会显示余额、最近的调用记录和充值入口。余额不足时，图表上方会出现提示并提供充值操作。

你也可以像在开源图表中一样，在 Agent 设置里添加自己的模型服务。

## 工作台还是开源库

| 你想要 | 选择 |
| --- | --- |
| 看盘、试用 Agent，或与团队共享一个工作区 | 工作台 |
| 把图表放进自己的产品，使用自己的登录体系 | 开源库：见[安装](/zh/docs/installation) |
| 自己决定数据来源，或运行自己的连接器 | 开源库加上你自己的 [Provider](/zh/docs/guides/data-feeds) |
| 修改图表行为或新增指标 | 开源库，并向上游贡献 |

工作区、连接管理和钱包属于 Nebutra 产品；图表上发生的一切都属于开源库。所以你在工作台上熟悉的操作，嵌入时同样适用。
