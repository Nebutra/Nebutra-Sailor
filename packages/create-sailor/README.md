## Quick Start

```bash
# npm
npm create sailor@latest

# pnpm
pnpm create sailor@latest

# bun
bun create sailor
```

Or specify a directory:

```bash
npx create-sailor@latest ./my-saas-app
```

## What You Get

- **8 apps** — landing + dashboard + docs + storybook + api-gateway + community + IDP + studio
- **54 packages** — auth · billing · i18n · notifications · permissions · queue · search · tenant · vault · metering · uploads · webhooks · agents · and more
- **9 microservices** — AI/ML workloads, Python-native
- **Full-stack TypeScript** — Next.js 16 + Hono + Prisma + Tailwind v4 + shadcn/ui + Radix + Framer Motion
- **AI-native** — Multi-Agent orchestration, LLM-ready, MCP server, agent-friendly CLI
- **White-label ready** — `brand.config.ts` one-command rebrand (colors, domains, logos, SEO)
- **Dual-license** — AGPL-3.0 + free Commercial Exception for OPC / solo founders

## Interactive Setup

The CLI asks about:
1. Application type (Standard SaaS · Full Monorepo · E-Commerce · Web3)
2. ORM (Prisma · Drizzle · none)
3. Database (PostgreSQL · MySQL · SQLite)
4. Payment provider (Stripe · Lemon Squeezy)
5. AI provider (OpenAI · Anthropic)
6. i18n enablement
7. Environment variables (DATABASE_URL, auth keys)

Then clones and configures the full Nebutra-Sailor template.

## After Scaffolding

```bash
cd my-saas-app
pnpm install
pnpm dev
```

## Why Sailor?

Unlike generic SaaS starters, **Sailor is both a template and a community** — you build your product with it, and you join the OPC creator network in the process.
