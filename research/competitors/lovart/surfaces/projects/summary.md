# lovart.projects — 项目

Flat grid of project cards (cover mosaic + name + 更新于 date), a 新建项目 card, and a select-mode toggle that adds checkboxes (O). No folders, search, sort, tags, or hover actions (O). Cards open `/canvas?projectId=…` in a new tab (O). Project = one canvas document (I2). Bulk actions and rename/delete not observed (U).
Evidence: `evidence/projects.list.webp`, `evidence/projects.select-mode.webp`.
