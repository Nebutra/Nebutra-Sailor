# lovart.brand-kit — 我的品牌套件 (Beta)

Account-level library with its own route and a kit list column (O). A kit has six sections — Logo / 字体 / 颜色 / 设计指南 / 图像 / 品牌指南 (O). Empty state: upload a brand book (PNG/JPG/PDF ≤ 50 MB) to auto-fill, or 从零开始 on the canvas (O). Kits attach to a project from the canvas top-left project-name menu (O, from onboarding copy). Filled-kit UI and whether kit images feed generation as references: U.
Evidence: `evidence/brandkit.list.webp`.
