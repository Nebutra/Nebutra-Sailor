# Production loop — Flowith

**Core loop (O):** `/blank` composer → Send → flow `/conv/<uuid>` with prompt node + answer node → click any node (it becomes context) → type / Follow Up / Vary → new child nodes → repeat. The flow is a growing tree; nothing is overwritten — Rerun and Vary produce new nodes (I2 for Rerun: not run; Vary form says "1 Generation", cost line, and the tutorial shows sibling images per prompt).

**Entry points into generation (O):** home composer (6 modes); in-flow composer (same modes, plus node tokens); image toolbar tools (Crop, Upscale, Background Removal, Vary); Rerun on answer/step nodes; Follow Up; Apps rail templates on home; template gallery "Use".

**Export / share (O):** flow share link with view permission; image Download on node; Search Node → Export (not pressed); Copy Content on every node. No publish-to-community button in the flow (community lists Knowledge Gardens, not flows — I2).

**Review / compare (O/I2):** comparison is spatial — sibling nodes side by side under one prompt (8 image siblings in the tutorial; Knowledge Market even advertises "compare the results instantly"). No dedicated compare/diff view seen (U). Versioning appears only as version strings inside agent-produced documents (O) — no node history UI (U).
