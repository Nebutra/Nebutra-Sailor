# fal — production loop
fal is model infrastructure; its "loop" is **pick model → configure → run → inspect result → chain to next model / export**.
- **O** Explore (task-first gallery) → model page Playground (required-first form, cost line) → Run (guard) → Result (Preview/JSON, Download) → chain via Edit / Upscale / Make Video (`?fromOutput=`) or Sandbox fan-out for comparison.
- **O** Developer branch of the same loop: API tab (public) → client `subscribe`/`queue.*` → Requests/Analytics tabs for observability → Webhooks dashboard for delivery.
- **O** Workflows (/workflows, templates) and fal Agent (Early Access add-on) exist as higher-level orchestration but were enumerated only.
- No project/canvas/timeline concept: the Assets library + Collections + Entities is the only cross-run organisation (O).
