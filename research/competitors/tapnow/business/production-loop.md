# TapNow production loop (tier per line)

**Observed core loop (O):**
Project (or cloned Skill/Template) → Canvas → add Node (Text / Image / Video / Audio / 3D) → prompt + model + params (+ Reference inputs) → Generate (cost shown) → output lands *in the node* → refine in-node (Change Angle / Relight / Redraw / Crop) or fork to another node via Reference/edge → Save to Library / Download / Publish to TapTV / Share by link.

**Agent-driven variant (O):** describe in composer (with selected nodes as context) → agent reads skills/docs, discovers models, inspects nodes → proposes fully-specified action with `~cost` → user Confirm (Ask mode) or auto (Act mode) → agent creates node + edge, submits task → result in node → agent reports with node mention chips.

**Unit of work:** the Node (manifesto: "Node is the Vocabulary"); the Canvas is the composition space; the Project groups canvases; Group = reusable "Phrase" (O in manifesto, kind visible in node search, not exercised — I1 on behaviour).

**Reuse loop (O/I2):** Library (Private/Team) with Character/Scene/Item/Style/Sound Effect; Elements → Subject packs for Seedance video; AI Character presets; Skills (clonable graphs; "Reusable personal Skills" sold in plans); Templates (Share by link = copyable template; Publish to TapTV).

**Review loop:** Good/Bad response on agent messages; Fork conversation; comment mode on canvas (O exists, not exercised). No approve/reject on generated outputs beyond keep/regenerate (U).

**Export:** Download per node / History bulk Download; Image Editor Download/Save; Timeline Editor (Beta) for arranging clips (U — could not open in-tab).

**Not observed on this track (U):** video/audio generation end-to-end, Timeline Editor, 3D Studio, comment threads, team collaboration presence, retries/failures.
