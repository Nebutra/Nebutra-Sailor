# Type Lens — 产品措辞（Product Voice）

**Brand:** Type Lens · **Domain:** typelens.nebutra.com · **Slogan:** The Typography Lens

## 原则

对外、UI、落地页、Agent 文档统一用**产品语言**。少用内务 / 仓储 / 公文味。

## 禁区 → 产品说法

| 少用 | 产品化 |
|------|--------|
| 档案 / 归档 / 档案站 | **案例库 · 作品 · 范例 · Type Lens** |
| 收录 / 条目 | **精选作品 · Works** |
| 给人翻阅 | **浏览 · 发现 · 搭配灵感** |
| 给机器调用 | **检索 · Extract · 注入生成** |
| 字库清单 / 字体仓库 | **字体 · 可商用字体 · Typefaces** |
| 人工标注台 | **策展 · 精选 · 校对** |
| 结构化档案 | **结构化范例 · Specimen** |

## One-liners

- **ZH:** Type Lens 把真实设计作品拆成可验证的字体搭配：设计师能逛，Design Agent 能调。
- **EN:** Type Lens turns real-world design into verified type pairings — browseable by designers, callable by agents.
- **Vs FiU:** Fonts In Use 是灵感参考站；Type Lens 是 **AI 原生搭配范例库**。
