# Router × 302.AI 用户旅程与路由对照

> 依据 2026-07-23 Playwright 全路由截图（`/tmp/302-study`）+ 帮助中心文案。

## 302 路由地图

| 路径 | 角色 | 布局要点 |
|------|------|----------|
| `/` | AI 推荐首页 | 工具条 · Logo+**唯一大搜索** · 频道(应用/API…) · **三栏**(分类行\|主视觉\|Hi) · 最新卡片 |
| `/?product_type=api` | API 超市首页态 | **同一壳**，频道高亮 API，左栏为 API 类目 |
| `/?product_type=tool` | 应用超市首页态 | **同一壳**，左栏换应用类目（机器人/效率…） |
| `/product/list?cate=api&tag=&brand=` | 商品列表 | **无左栏双树**；**顶部分类展开条** + 品牌 chips + 纯网格 |
| 管理后台 | 登录后 | 与超市**壳分离**（数据汇总/Keys/钱包…） |
| 快捷使用 | 使用界面 | 与管理/超市分离 |

## 用户旅程

```
逛货架(首页/列表) → 点模型卡片 → 体验/文档
                 ↘ 管理后台 → 充值/Key → 复制 baseURL → 自己的 App 调用
                 ↘ 快捷使用 → 当场试聊
```

关键原则：**管理归后台，使用走前台，货架是公共门面**。不要把三件事叠在一个侧栏里。

## Nebutra Router 落地

| 路径 | 对应 |
|------|------|
| `/` | 302 首页（AI 推荐） |
| `/models` | 302 `/product/list`（API 列表） |
| `/dashboard` `/keys` `/wallet` `/docs` | 管理后台 |
| `/use` | 快捷使用 |
