# docs/ and research/ conventions

Two kinds of document, told apart by the filename.

## Dated records — `YYYY-MM-DD-slug.md`

A point-in-time decision, plan, proposal, report or spec. Never renamed; superseded by a newer
dated file that links back. The date is when the decision was made, not when the file was last edited.

| Directory | Holds | Header must carry |
| --- | --- | --- |
| `docs/architecture/` | ADRs | Date · Status (Proposed / Accepted / Superseded by …) · Owner · Related |
| `docs/rfcs/` | Governance and contract proposals awaiting decision | Date · Status |
| `docs/proposals/` | Product / business proposals | Date · Status |
| `docs/plans/` | Execution plans and roadmaps | Date · Owner |
| `docs/reports/` | Audits and one-off findings | Date |
| `docs/superpowers/{plans,specs}/` | **Legacy** location for plans and specs produced by the superpowers workflow. Frozen: no new files; new plans go to `docs/plans/`, new specs to `docs/rfcs/`. |

ADRs are not numbered. The date-slug is the identifier; cite as “ADR 2026-09-08 competitive product cartography”.

## Living references — `slug.md`

Guides, governance rules, indexes and registries that are edited in place and describe the current
state. They carry a `Last reviewed:` line instead of a date in the name.

| Directory | Holds |
| --- | --- |
| `docs/INDEX.md`, `docs/DOMAINS.md`, `docs/package-status.md`, `docs/RELEASING.md` | Top-level registries |
| `docs/design-system/`, `docs/microcopy/`, `docs/security/`, `docs/ops/`, `docs/i18n/`, `docs/seo/`, `docs/legal/` | Governance and how-to |
| `docs/capabilities/<name>/` | Per-capability living docs |
| `docs/plans/tools/` | Forge tool briefs (one per tool slug, living) |
| `docs/product-intelligence/` | PARA decision pack, living, cites `research/` |
| `docs/tech-debt/`, `docs/design/` | Baselines and studies |

A governance rule is a living reference, so it does not belong in `docs/architecture/` even when an
ADR created it: the ADR records the decision, the living doc carries the current rule.

## Filenames

- ASCII kebab-case only. Chinese-titled documents keep the Chinese title inside the file (`# 阿里云 ECS 部署指南`)
  and take an English slug.
- No spaces, no version suffixes (`-v2`, `-final`). Supersede instead.
- Sidecar files share the stem: `2026-06-06-x.md` + `2026-06-06-x.reviews.json`.

## research/

Evidence-graded competitor knowledge; rules in `research/README.md`. Directories are per competitor slug;
files inside are living (regenerated by re-exploration) except `synthesis/*.md`, which carry a
`Last synthesized:` date line. Captures: `evidence/<state-id>.webp` committed, `raw/` local only.
